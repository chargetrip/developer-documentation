# Crea percorso

Migra entro: Q1 2027

Esegui la migrazione dal servizio Route legacy all'ultima versione. Il nuovo servizio offre uno schema riorganizzato, preferenze degli operatori per paese, un calcolo del percorso più veloce e una maggiore manutenibilità.

## Operazioni

| Precedente        | Nuovo                                                           |
| ----------------- | ----------------------------------------------------------------|
| `newRoute`        | [`createRoute`](/api-reference/route/mutation-create-route)     |

## Modifiche generali allo schema

- **Tipizzazione esplicita**: i campi JSON in precedenza flessibili ora sono tipizzati esplicitamente nello schema per migliorare struttura e validazione.
- **Convenzioni di denominazione**: i campi ora usano `snake_case` invece di `camelCase`.
- **Supporto delle unità**: gli input numerici ora supportano diversi tipi di unità, espressi come oggetto con `value`, `type` e un `source` facoltativo (`manual`, `telemetry` o `default`).

## Modifiche alla mutation

L'argomento `input` di `createRoute` è stato riorganizzato e semplificato.

### routeRequest

A livello radice, i seguenti campi sono stati rimossi. I campi relativi agli operatori sono ora coperti dalle [preferenze degli operatori](#preferenze-degli-operatori), mentre quelli relativi ai servizi sono stati spostati nella loro [query dedicata per i servizi](/api-reference/route/query-get-route-stations-with-amenities).

| Campo                  | Spostato in                           |
| ---------------------- | -------------------------------------- |
| `operatorIds`          | Rimosso                                |
| `amenities`            | Rimosso                                |
| `amenity_preferences`  | Rimosso                                |
| `operatorRequired`     | Rimosso                                |
| `operatorPrefer`       | Rimosso                                |

### EV

A livello di EV, la maggior parte dei campi di primo livello è stata spostata in un oggetto dedicato `vehicle`.

| Campo             | Spostato in                           |
| ----------------- | -------------------------------------- |
| `ev.id`           | `vehicle.id`                     |
| `battery`         | `vehicle`                        |
| `climate`         | `vehicle`                        |
| `heat_pump`       | `vehicle`                        |
| `plugs`           | `vehicle.charging.connectors`    |
| `safeRiskMargin`       | `vehicle.charging.risk_margin`   |
| `chargeMode`           | `vehicle.charging.mode`          |
| `bmsConsumption`  | Rimosso                                |

### Carico del veicolo

Le proprietà del carico del veicolo non vengono più impostate in un unico punto. Ora sono specificate per ciascun punto `origin` e `via`, offrendo un controllo più granulare sul peso di occupanti e carico per ogni tratta. Si trovano sotto `properties.vehicle` di ciascuna posizione, e i nomi dei loro campi cambiano come segue:

| Campo       | Spostato in           |
| ----------- | --------------------- |
| `occupants` | Invariato              |
| `cargo`     | `total_cargo_weight`  |

### Telemetria

I seguenti dati di telemetria sono stati spostati dal livello radice all'oggetto `vehicle`.

| Campo                 | Spostato in      |
| --------------------- | ---------------- |
| `heading`             | `vehicle`  |
| `motor_rpm`           | `vehicle`  |
| `odometer`            | `vehicle`  |
| `outside_temperature` | `vehicle`  |
| `tire_pressure`       | `vehicle`  |
| `vehicle_speed`       | `vehicle`  |

## Modifiche in evidenza

Alcuni campi dell'argomento `input` hanno ora strutture nuove e più organizzate. Sono descritti più in dettaglio di seguito.

### Preferenze degli operatori

Le preferenze degli operatori sono semplificate in tre livelli: `high`, `medium` e `low`. Ogni voce, che sia in classifica, esclusa o da evitare, può essere limitata a paesi specifici tramite il campo `countries`. Se omesso, vengono considerati tutti i paesi.

```graphql Preferenze degli operatori {{ mark: [6,9,12] }}
input: {
  operators: {
    ranking: {
      type: preferred
      levels: {
        high: [
          {
            id: "op1"
            countries: [NL]
          }
        ]
        low: [
          {
            id: "op3"
          }
        ]
      }
    }
  }
}
```

### Peso totale degli occupanti

Un nuovo campo `total_occupant_weight` ti consente di sostituire il peso predefinito degli occupanti, espresso con il nuovo oggetto unità.

```graphql Peso totale degli occupanti {{ mark: [6,7,8,9,10] }}
input: {
  origin: {
    properties: {
      vehicle: {
        occupants: 3
        total_occupant_weight: {
          value: 160
          type: kilogram
          source: manual
        }
      }
    }
  }
}
```
