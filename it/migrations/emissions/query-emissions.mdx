# Emissioni del percorso
Esegui la migrazione dal servizio Emissions legacy all'ultima versione. Il nuovo servizio è costruito come query dedicata, più adatta alla scalabilità e agli aggiornamenti futuri.

## Modifiche alle query

I dati sulle emissioni sono stati spostati dalla risposta del percorso a una query dedicata `getRouteEmissions`, così possono essere richiesti indipendentemente dal calcolo di un percorso.
