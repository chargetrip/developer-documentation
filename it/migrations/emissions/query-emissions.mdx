# Emissioni del percorso

Esegui la migrazione entro: Q1 2027

Passa dal servizio Emissions legacy alla versione più recente. Il nuovo servizio è realizzato come query dedicata, più adatta alla scalabilità e agli aggiornamenti futuri.

## Modifiche alla query

I dati sulle emissioni sono stati spostati dalla risposta del percorso a una query dedicata `getRouteEmissions`, così possono essere richiesti indipendentemente dal calcolo di un percorso.
