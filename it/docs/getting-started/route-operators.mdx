---
title: "Instradamento con operatori preferiti"
description: "Controlla quali reti di ricarica preferisce il servizio di instradamento impostando le preferenze degli operatori nella dashboard o per singola richiesta."
---
Le preferenze degli operatori ti permettono di controllare quali reti di ricarica preferisce il servizio di instradamento quando calcola un percorso per veicoli elettrici.

Puoi configurare le preferenze in due punti:
- [Dashboard di Chargetrip](https://account.chargetrip.io/projects): imposta la configurazione globale delle preferenze degli operatori per il tuo progetto in progetto / avanzate / preferenze degli operatori delle stazioni.
- [Richiesta Create Route](/api-reference/core/route/mutation-create-route#arg-input-operators): definisci le preferenze dinamicamente o sostituisci la configurazione delle preferenze degli operatori della dashboard per singola richiesta usando il campo `input.operators` nella mutation `createRoute`.

---

### 1. Tipi di preferenza e comportamento del percorso


Le preferenze degli operatori sono di quattro tipi e ciascuna può essere limitata a specifici paesi:

| Preferenza | Comportamento di instradamento |
|:---|:---|
| Esclusi | Le stazioni di questi operatori sono rigorosamente escluse in ogni circostanza. |
| Evitati  |  Le stazioni di questi operatori vengono evitate a meno che non esista un'alternativa migliore. |
| Preferiti | Le stazioni di questi operatori hanno la priorità in base alla loro classificazione (high, medium, low). Più alto è il livello, più è probabile che la stazione venga selezionata. Il percorso userà comunque stazioni senza classificazione o evitate se non esiste un'alternativa migliore.|
| Obbligatori  | Vengono usate solo le stazioni di questi operatori. All'interno di questo insieme consentito, i livelli di classificazione continuano ad applicarsi, quindi gli operatori di livello high sono preferiti a quelli di livello medium e low. Se il veicolo non può raggiungere la destinazione usando solo stazioni classificate, il calcolo del percorso non riesce.|


---

### 2. Come vengono applicate le preferenze a livello di dashboard

Capire come gli input a livello di richiesta interagiscono con le impostazioni della dashboard garantisce un comportamento di instradamento prevedibile:

- **Gli operatori Esclusi ed Evitati nella dashboard si applicano automaticamente**:
Gli operatori configurati come Esclusi o Evitati nella dashboard si applicano a ogni calcolo di percorso senza richiedere alcun parametro nella tua richiesta `createRoute`.
- **I livelli di classificazione della dashboard restano inattivi senza un tipo di classificazione**:
Gli operatori configurati nei livelli di classificazione devono essere attivati impostando `input.operators.ranking.type` nella tua richiesta `createRoute`, altrimenti non influiscono sulla selezione delle stazioni.
- **Gli operatori a livello di richiesta sostituiscono le rispettive preferenze della dashboard**:
Specificare gli ID degli operatori nella richiesta `createRoute` sostituisce solo la configurazione corrispondente della dashboard. Ad esempio, fornire `input.operators.exclude[]` sostituisce l'intera configurazione degli operatori esclusi della dashboard, mentre gli operatori da evitare a livello di dashboard continuano ad applicarsi.
---
### 3. Esempi di implementazione

<details>
  <summary>Usa solo le esclusioni e le evitazioni della dashboard</summary>
  Applica le configurazioni degli operatori esclusi ed evitati impostate nella dashboard. Le impostazioni di classificazione della dashboard sono inattive perché non è specificato alcun `input.operators.ranking.type`.

```graphql Example request
createRoute(
  input: {
    vehicle: { id: "607823b2c246f9001b97b1a2" }
    origin: {
      type: Feature
      geometry: { type: Point, coordinates: [4.895168, 52.370216] }
    }
    destination: {
      type: Feature
      geometry: { type: Point, coordinates: [2.352222, 48.856614] }
    }
  }
)
```
</details>

<details>
  <summary>Usa gli operatori classificati della dashboard come "Preferiti"</summary>
  Applica le configurazioni degli operatori esclusi ed evitati della dashboard e preferisce le stazioni che appartengono ai livelli di classificazione della dashboard.

```graphql Example request {{ mark: [14] }}
createRoute(
  input: {
    vehicle: { id: "607823b2c246f9001b97b1a2" }
    origin: {
      type: Feature
      geometry: { type: Point, coordinates: [4.895168, 52.370216] }
    }
    destination: {
      type: Feature
      geometry: { type: Point, coordinates: [2.352222, 48.856614] }
    }
    operators: {
      ranking: {
        type: preferred
      }
    }
  }
)
```
</details>

<details>
  <summary>Usa gli operatori classificati della dashboard come "Obbligatori"</summary>
  Limita il percorso in modo da ricaricare esclusivamente presso stazioni che appartengono agli operatori configurati nei livelli di classificazione della dashboard.

```graphql Example request {{ mark: [14] }}
createRoute(
  input: {
    vehicle: { id: "607823b2c246f9001b97b1a2" }
    origin: {
      type: Feature
      geometry: { type: Point, coordinates: [4.895168, 52.370216] }
    }
    destination: {
      type: Feature
      geometry: { type: Point, coordinates: [2.352222, 48.856614] }
    }
    operators: {
      ranking: {
        type: required
      }
    }
  }
)
```
</details>

<details>
  <summary>Definisci preferenze personalizzate e sostituisci le impostazioni della dashboard</summary>
  Fornisci le configurazioni complete degli operatori direttamente nella chiamata API. Qualsiasi campo specificato (ranking, avoid o exclude) sostituisce la corrispondente configurazione della dashboard per quella richiesta.

```graphql Example request  {{ mark: [13,14,15,16,17,18,19,20,21] }}
createRoute(
  input: {
    vehicle: { id: "607823b2c246f9001b97b1a2" }
    origin: {
      type: Feature
      geometry: { type: Point, coordinates: [4.895168, 52.370216] }
    }
    destination: {
      type: Feature
      geometry: { type: Point, coordinates: [2.352222, 48.856614] }
    }
    operators: {
      ranking: {
        type: preferred
        level: {
          high: [{ id: "5e8c22366f9c5f23ab0eff01" }]
          medium: [{ id: "5e8c22366f9c5f23ab0eff02" }]
        }
      }
      avoid: [{ id: "5e8c22366f9c5f23ab0eff03" }]
      exclude: [{ id: "5e8c22366f9c5f23ab0eff04" }]
    }
  }
)
```
</details>

<details>
  <summary>Definisci preferenze personalizzate per paesi specifici</summary>
  Fornisci le configurazioni complete degli operatori direttamente nella chiamata API. Qualsiasi campo specificato (ranking, avoid o exclude) sostituisce la corrispondente configurazione della dashboard per quella richiesta.

```graphql Example request  {{ mark: [13,14,15,16,17,18,19,20,21] }}
createRoute(
  input: {
    vehicle: { id: "607823b2c246f9001b97b1a2" }

    destination: {
      type: Feature
      geometry: { type: Point, coordinates: [2.352222, 48.856614] }
    }
    operators: {

          high: [{ id: "5e8c22366f9c5f23ab0eff01", countries: ["NL", "DE"] }]

        }
      }
      avoid: [{ id: "5e8c22366f9c5f23ab0eff03", countries: ["AT"] }]

  }
```

</details>
