---
title: Dai priorità alle singole stazioni di ricarica
---

I Boosting Group ti permettono di orientare la selezione delle stazioni verso specifiche località di ricarica in base alle tue regole aziendali.

Mentre le [preferenze degli operatori](/docs/getting-started/route-operators) permettono di dare priorità a intere reti di ricarica, i Boosting Group offrono un controllo granulare a livello di singola stazione. Qualunque sia il motivo per cui favorisci queste stazioni, come prezzi più bassi, scarso utilizzo o un accordo commerciale più vantaggioso, puoi portarle in cima alla gerarchia delle stazioni.

## Come potenziare le stazioni

Per iniziare, contatta il [supporto](https://www.chargetrip.com/contact/support) con l'elenco delle stazioni a cui vuoi dare priorità.

Una volta configurato e abilitato il gruppo sul tuo progetto, tutti i percorsi calcolati con [createRoute](/api-reference/core/route/mutation-create-route) lo useranno automaticamente in background, quindi non servono modifiche né parametri aggiuntivi nelle tue richieste API.

## Come funziona

I Boosting Group supportano solo la prioritizzazione positiva. Puoi usarli per promuovere le stazioni, ma non per evitarle o escluderle. Quando sono usati da soli, le stazioni potenziate hanno la priorità su tutte le altre stazioni lungo il percorso.

Se combinato con le preferenze degli operatori, il pianificatore di percorso dà priorità alle stazioni nel seguente ordine di priorità (dalla più alta alla più bassa):

- I Boosting Group attivi sono singole stazioni potenziate. Prevalgono su tutte le preferenze degli operatori, anche se l'operatore della stazione è impostato su `avoid` o `excluded`.
- Gli operatori preferiti (`high`, `medium`, `low`) sono stazioni che appartengono a reti di ricarica preferite.
- Le stazioni senza classificazione sono stazioni standard a cui non è applicato alcun boosting group né alcuna preferenza di operatore.
- Gli operatori con priorità ridotta (`avoid`) sono stazioni che appartengono a operatori contrassegnati da evitare. Vengono usate solo quando non esistono opzioni migliori.

Come le preferenze degli operatori, il potenziamento delle stazioni opera secondo il principio del best effort. Il pianificatore di percorso bilancia la priorità delle stazioni con la densità delle stazioni e l'impatto della deviazione, in modo che la scelta di una stazione potenziata non produca mai un percorso inefficiente.

## Esempi

<details>
  <summary>Calcola un percorso con boosting group attivi</summary>

  Poiché i Boosting Group vengono applicati automaticamente a livello di progetto, devi solo inviare una mutation `createRoute` standard. Tutti i Boosting Group attivi vengono prioritizzati automaticamente.

```graphql Example request
mutation CreateRoute {
  createRoute(
    input: {
      vehicle: { id: "607823b2c246f9001b97b1a2" }
      origin: {
        type: Feature
        geometry: { type: Point, coordinates: [4.895168, 52.370216] }
      }
      destination: {
        type: Feature
        geometry: { type: Point, coordinates: [6.773456, 51.227741] }
      }
    }
  ) {
    id
    status
  }
}
```
</details>

<details>
  <summary>Verifica se le stazioni consigliate appartengono a un boosting group</summary>

  Quando recuperi il percorso calcolato con `getRoute` o con la subscription `route`, richiedi `boosting_group_ids` sulla stazione della tratta per vedere quali Boosting Group attivi corrispondono a quella fermata.

```graphql Example request {{ mark: [11] }}
query GetRoute {
  getRoute(id: "6527e1f1a8b4c2d3e4f5a6b7") {
    status
    route {
      id
      legs {
        origin {
          properties {
            station_id
            station {
              boosting_group_ids
            }
          }
        }
      }
    }
  }
}
```
</details>
