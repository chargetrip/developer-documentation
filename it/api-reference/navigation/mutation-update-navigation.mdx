Aggiorna una sessione di navigazione attiva usando la mutation updateNavigation. È utile quando vuoi comunicare la posizione di un conducente mentre procede lungo un percorso.

## Mutation

Per aggiornare una sessione di navigazione sono necessari il suo `id` e `location_data`. L'`id` si ottiene tramite la [mutation startNavigation](/api-reference/navigation/mutation-start-navigation).
