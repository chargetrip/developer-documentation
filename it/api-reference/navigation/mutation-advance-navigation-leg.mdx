Fai avanzare una sessione di navigazione attiva alla tratta successiva del percorso usando la mutation advanceNavigationLeg. È utile quando un conducente completa una tratta, ad esempio terminando una tappa di ricarica, e prosegue verso la successiva.

## Mutation

Per passare alla tratta successiva sono necessari l'`id` della sessione di navigazione e `current_location`. Facoltativamente includi `state_of_charge` per indicare il livello di carica del veicolo nella posizione attuale. L'`id` si ottiene tramite la [mutation startNavigation](/api-reference/navigation/mutation-start-navigation).
