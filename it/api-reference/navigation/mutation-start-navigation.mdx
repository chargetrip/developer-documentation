Avvia una nuova sessione di navigazione su un percorso esistente usando la mutation startNavigation. È utile quando un conducente inizia a seguire un percorso calcolato.

> [!WARNING] Durata della sessione
> Una sessione di navigazione viene terminata automaticamente dopo 48 ore di inattività.

## Mutation

Per avviare una sessione di navigazione sono necessari `route_id`, `route_details_id` e `current_location`. Entrambi gli id del percorso si ottengono tramite la [query getRoute](/api-reference/route/query-get-route). La mutation restituisce un `id` della sessione di navigazione, che può essere usato per recuperare, aggiornare o terminare la sessione.
