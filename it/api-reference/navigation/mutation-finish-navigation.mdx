Termina una sessione di navigazione attiva usando la mutation finishNavigation. È utile quando un conducente raggiunge la destinazione o il viaggio viene annullato.

## Mutation

Per terminare una sessione di navigazione sono necessari il suo `id` e `current_location`. L'`id` si ottiene tramite la [mutation startNavigation](/api-reference/navigation/mutation-start-navigation).
