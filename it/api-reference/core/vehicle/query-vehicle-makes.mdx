Ottieni un elenco di marche di veicoli utilizzando la query vehicleMakes.

## Query
Per eseguire la query vehicleMakes non è richiesto alcun input. Usa l'argomento `filter` per restringere i risultati per regione e/o tipo, e gli argomenti `first` e `after` per [paginare](/api-reference/core/api/pagination) i risultati. Usa l'argomento `country` per applicare la localizzazione ai dati.
