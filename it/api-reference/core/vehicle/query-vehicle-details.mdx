Ottieni le specifiche di un veicolo utilizzando la query vehicle.

## Query

Per ottenere i dettagli di un veicolo è necessario un `id` del veicolo. L'`id` può essere ottenuto tramite la [query vehicleList](/api-reference/core/vehicle/query-vehicles). Usa l'argomento country per applicare la localizzazione ai dati.
