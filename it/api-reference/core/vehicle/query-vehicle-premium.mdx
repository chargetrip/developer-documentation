Accedi a dati ancora più dettagliati tramite la query vehiclePremium. Contiene dati estesi su batteria, carrozzeria del veicolo, disponibilità, prezzi, efficienza, sicurezza e altro. [Contatta il reparto vendite](https://www.chargetrip.com/contact/sales) per passare ai dati premium dei veicoli.

## Query

Per ottenere i dettagli premium di un veicolo è necessario un `id` del veicolo. L'`id` può essere ottenuto tramite la [query vehicleList](/api-reference/core/vehicle/query-vehicles). Usa l'argomento country per applicare la localizzazione ai dati.
