Sottoscriviti a una rotta utilizzando la subscription route. È utile quando vuoi ricevere aggiornamenti in tempo reale mentre una rotta viene calcolata.

## Subscription

Per sottoscriversi agli aggiornamenti di una rotta è obbligatorio il suo `id`. L'`id` può essere ottenuto tramite la [mutation createRoute](/api-reference/core/route/mutation-create-route).
