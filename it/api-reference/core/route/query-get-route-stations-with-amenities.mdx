Cerca stazioni di ricarica con servizi in un determinato punto di una rotta utilizzando la query getRouteStationsWithAmenities. È utile quando vuoi pianificare una sosta di ricarica vicino a ristoranti, negozi o altri servizi.

## Query

Per cercare stazioni lungo una rotta sono obbligatori `route_id`, `route_details_id`, `time_window` e `amenity_types`. Entrambi gli ID possono essere ottenuti tramite la [query getRoute](/api-reference/core/route/query-get-route). Usa l'argomento `filter` per restringere i risultati in base a criteri specifici e gli argomenti `first` e `after` per [paginarli](/api-reference/core/api/pagination).

> [!WARNING] Limiti
> `first` non può superare 10 per questa query.
