Ottieni i dettagli di una rotta calcolata in precedenza utilizzando la query getRoute. È utile quando vuoi mostrare le soste di ricarica, la distanza e la durata di una rotta.

## Query

Per ottenere i dettagli di una rotta è obbligatorio il suo `id`. L'`id` può essere ottenuto tramite la [mutation createRoute](/api-reference/core/route/mutation-create-route).
