Sottoscriviti a un'isolina utilizzando la subscription isoline. È utile quando vuoi ricevere aggiornamenti in tempo reale mentre un'isolina viene calcolata.

## Subscription

Per sottoscriversi agli aggiornamenti di un'isolina è obbligatorio il suo `id`. L'`id` può essere ottenuto tramite la [mutation createIsoline](/api-reference/core/isoline/mutation-create-isoline).
