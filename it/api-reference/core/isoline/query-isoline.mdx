Ottieni i dettagli di un'isolina calcolata in precedenza utilizzando la query isoline. È utile quando vuoi mostrare l'area raggiungibile da un veicolo.

## Query

Per ottenere i dettagli di un'isolina è obbligatorio il suo `id`. L'`id` può essere ottenuto tramite la [mutation createIsoline](/api-reference/core/isoline/mutation-create-isoline).
