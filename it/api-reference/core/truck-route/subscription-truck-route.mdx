Sottoscrivi un percorso camion utilizzando la subscription truckRoute. È utile quando vuoi ricevere aggiornamenti in tempo reale durante il calcolo del percorso di un camion elettrico.

## Subscription

Per sottoscrivere gli aggiornamenti di un percorso camion è necessario il suo `id`. L'`id` può essere ottenuto tramite la [mutation createTruckRoute](/api-reference/core/truck-route/mutation-create-truck-route).
