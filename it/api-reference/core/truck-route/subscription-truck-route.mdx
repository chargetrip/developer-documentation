Iscriviti a un percorso camion usando la subscription truckRoute. È utile quando vuoi ricevere aggiornamenti in tempo reale mentre viene calcolato il percorso di un camion elettrico.

## Subscription

Per iscriversi agli aggiornamenti di un percorso camion è necessario il suo `id`. L'`id` si ottiene tramite la [mutation createTruckRoute](/api-reference/core/truck-route/mutation-create-truck-route).
