Ottieni i dettagli di un percorso camion calcolato in precedenza utilizzando la query getTruckRoute. È utile quando vuoi mostrare le soste di ricarica, la distanza e la durata di un percorso camion.

## Query

Per ottenere i dettagli del percorso è necessario un `id` del percorso camion. L'`id` può essere ottenuto tramite la [mutation createTruckRoute](/api-reference/core/truck-route/mutation-create-truck-route).
