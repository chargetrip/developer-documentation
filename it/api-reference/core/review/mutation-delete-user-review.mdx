Rimuovi una recensione aggiunta dall'utente autenticato utilizzando la mutation deleteUserReview. Questa è una funzionalità premium. Contattaci per maggiori informazioni.

## Mutation

Per rimuovere una recensione è obbligatorio il suo `id`. Per autorizzare l'utente è obbligatorio un header `x-token`. La recensione deve appartenergli, altrimenti si verifica un errore.
