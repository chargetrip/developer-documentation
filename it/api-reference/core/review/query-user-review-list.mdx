Recupera tutte le recensioni aggiunte dall'utente autenticato per le varie stazioni utilizzando la query userReviewList. È utile quando vuoi mostrare la cronologia delle recensioni di un utente. Questa è una funzionalità premium. Contattaci per maggiori informazioni.

## Query

Per autorizzare l'utente di cui vuoi recuperare le recensioni è richiesto un header `x-token`. Usa gli argomenti `size` e `page` per [paginarle](/api-reference/core/api/pagination).
