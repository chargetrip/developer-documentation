Per ottimizzare tempi e dimensioni di risposta, per impostazione predefinita le API MVT e JSON restituiscono una risposta minimizzata. Questo approccio garantisce prestazioni ottimali e riduce le dimensioni dei payload dei tile, un aspetto fondamentale per interazioni fluide con la mappa. Usando i selettori, puoi includere i dati aggiuntivi di cui la tua applicazione ha specificamente bisogno.

## Selettori disponibili

Qualsiasi campo elencato nelle proprietà della stazione per i tile MVT e JSON può essere usato come selettore nel rispettivo servizio, ad eccezione dei campi GeoJSON obbligatori restituiti dall'endpoint JSON.

`count` · `integer` · <span class="text-accent">default</span>
: Il numero di stazioni all'interno di un cluster. Un conteggio pari a 1 indica una feature Station, mentre un conteggio maggiore di 1 indica una feature Cluster.

`expansion_zoom` · `integer` · <span class="text-accent">default</span>
: Il livello di zoom al quale un cluster si divide in più cluster o stazioni più piccoli.

`id` · `string`
: L'identificativo della stazione.

`lng` · `float`
: La longitudine della stazione.

`lat` · `float`
: La latitudine della stazione.

`operator_id` · `string`
: L'identificativo Chargetrip univoco dell'operatore della stazione. Non restituito se l'operatore è sconosciuto.

`station_maximum_power` · `integer`
: La potenza di ricarica massima (in kW) disponibile presso la stazione. Questo valore è statico e riflette sempre la capacità massima della stazione, indipendentemente dai filtri sui connettori.

`connector_maximum_power` · `integer`
: La potenza di ricarica massima (in kW) disponibile dai connettori che corrispondono al filtro `connectors[]`. Se non viene fornito alcun filtro, vengono considerati tutti i connettori e corrisponde a `station_maximum_power`.

`preferred_operator` · `boolean`
: Indica se l'operatore di una stazione è un operatore preferito. Gli operatori preferiti possono essere gestiti a livello di progetto nel Dashboard.

`connector_minimum_energy_price` · `float` · [beta](tip:Beta;;Questo campo è in beta e potrebbe cambiare prima di diventare stabile.)
: Il prezzo dell'energia più basso tra i connettori della stazione. Non viene restituito se non disponibile. Applicabile solo se viene utilizzato il database di stazioni Eco-Movement; in caso contrario viene ignorato.

`connector_maximum_energy_price` · `float` · [beta](tip:Beta;;Questo campo è in beta e potrebbe cambiare prima di diventare stabile.)
: Il prezzo dell'energia più alto tra i connettori della stazione. Non viene restituito se non disponibile. Applicabile solo se viene utilizzato il database di stazioni Eco-Movement; in caso contrario viene ignorato.

`price_vat` · `float` · [beta](tip:Beta;;Questo campo è in beta e potrebbe cambiare prima di diventare stabile.)
: L'IVA applicata al prezzo. Non viene restituito se non disponibile. Applicabile solo se viene utilizzato il database di stazioni Eco-Movement; in caso contrario viene ignorato.

`price_valid_until` · `string` · [beta](tip:Beta;;Questo campo è in beta e potrebbe cambiare prima di diventare stabile.)
: La data e l'ora fino alle quali il prezzo è valido. Non viene restituito se non disponibile. Applicabile solo se viene utilizzato il database di stazioni Eco-Movement; in caso contrario viene ignorato.

`price_original_currency` · `string` · [beta](tip:Beta;;Questo campo è in beta e potrebbe cambiare prima di diventare stabile.)
: La valuta in cui il prezzo era originariamente definito, prima della conversione in `currency`. Non viene restituito se non disponibile. Applicabile solo se viene utilizzato il database di stazioni Eco-Movement; in caso contrario viene ignorato.

`price_conversion_rate` · `float` · [beta](tip:Beta;;Questo campo è in beta e potrebbe cambiare prima di diventare stabile.)
: Il tasso utilizzato per convertire il prezzo dalla valuta originale a `currency`. Non viene restituito se non disponibile. Applicabile solo se viene utilizzato il database di stazioni Eco-Movement; in caso contrario viene ignorato.

`evses_blocked` · `integer`
: Il numero di EVSE con stato bloccato. Se viene fornito un filtro `connectors[]`, conta solo gli EVSE bloccati che corrispondono ai tipi di connettore selezionati.

`evses_planned` · `integer`
: Numero di EVSE con stato pianificato. Se viene fornito un filtro `connectors[]`, conta solo gli EVSE pianificati che hanno almeno uno dei tipi di connettore selezionati.

`evses_available` · `integer`
: Numero di EVSE con stato disponibile. Se viene fornito un filtro `connectors[]`, conta solo gli EVSE disponibili che hanno almeno uno dei tipi di connettore selezionati.

`evses_charging` · `integer`
: Numero di EVSE con stato in ricarica. Se viene fornito un filtro `connectors[]`, conta solo gli EVSE in ricarica che hanno almeno uno dei tipi di connettore selezionati.

`evses_unknown` · `integer`
: Numero di EVSE con stato sconosciuto. Se viene fornito un filtro `connectors[]`, conta solo gli EVSE sconosciuti che hanno almeno uno dei tipi di connettore selezionati.

`evses_reserved` · `integer`
: Numero di EVSE con stato riservato. Se viene fornito un filtro `connectors[]`, conta solo gli EVSE riservati che hanno almeno uno dei tipi di connettore selezionati.

`evses_out_of_order` · `integer`
: Numero di EVSE con stato out_of_order. Se viene fornito un filtro `connectors[]`, conta solo gli EVSE fuori servizio che hanno almeno uno dei tipi di connettore selezionati.

`evses_inoperative` · `integer`
: Numero di EVSE con stato inoperative. Se viene fornito un filtro `connectors[]`, conta solo gli EVSE inoperativi che hanno almeno uno dei tipi di connettore selezionati.

## Implementazione

Per richiedere proprietà specifiche, aggiungi il parametro di query `station_properties[]` all'URL della richiesta del tile.

```bash Tile / Selectors / Example
https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?station_properties[]={selector1}&station_properties[]={selector2}&station_properties[]={selector3}
```

## Esempi di comportamento

Quando vengono forniti i selettori, la richiesta restituisce solo i campi specificati.

### GeoJSON

Nell'endpoint GeoJSON, i campi GeoJSON obbligatori (`type`, `geometry` e `id`) vengono sempre restituiti indipendentemente dai selettori scelti.

```json JSON Selectors example
{
  "type": "FeatureCollection",
  "features": [
    // Station feature
    {
      "id": "132313",
      "type": "Feature",
      "geometry": {
        "type": "Point",
        "coordinates": [6.789, 52.234]
      },
      // 'count' is missing because it wasn't provided as selector
      "properties": {
        "station_maximum_power": 350,
        "preferred_operator": true
      }
    },
    // Cluster feature
    // Cluster feature is not modified, as it's not affected by the selectors.
    {
      "type": "Feature",
      "geometry": {
        "type": "Point",
        "coordinates": [6.723, 50.0]
      },
      "properties": {
        "count": 3,
        "expansion_zoom": 18
      }
    }
  ]
}
```

### MVT

Nell'endpoint MVT vengono restituiti solo i parametri selezionati esplicitamente, poiché non esistono campi obbligatori.

```json MVT Selectors example
// Station feature
// 'count' is missing because it wasn't provided as a selector.
{
  "id": "132313",
  "preferred_operator": false,
  "station_maximum_power": 350
}

// Cluster feature
// Cluster feature is not modified, as it's not affected by the selectors.
{
  "count": 3,
  "expansion_zoom": 32
}
```
