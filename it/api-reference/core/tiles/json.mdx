Il servizio di tile JSON fornisce accesso ai dati geografici relativi alle stazioni in formato JSON.

## Configurazione

Per accedere ai dati delle stazioni in formato JSON, invia una richiesta al seguente endpoint:

```bash Tile / JSON / Base URL
https://api.chargetrip.io/v2/station/{z}/{x}/{y}/tile.json
```

L'URL JSON utilizza i seguenti parametri di percorso:

- `z`: Il livello di zoom del tile.
- `x`: La coordinata x del tile.
- `y`: La coordinata y del tile.

La maggior parte dei provider di mappe dispone di metodi integrati per convertire latitudine e longitudine in coordinate in pixel. Per convertire manualmente le coordinate di latitudine e longitudine in x e y, usa la [proiezione Web Mercator](https://en.wikipedia.org/wiki/Web_Mercator_projection).

### Filtri
Usa il parametro di query `filter` per filtrare le stazioni restituite in base a criteri specifici. Consulta la [documentazione sui filtri](/api-reference/core/tiles/filters) per maggiori informazioni.

### Selettori
Usa il parametro di query `station_properties[]` per specificare i campi restituiti per ogni feature di stazione. Consulta la [documentazione sui selettori](/api-reference/core/tiles/selectors) per maggiori informazioni.

## Risposta
L'API restituisce una `FeatureCollection` GeoJSON contenente i campi GeoJSON obbligatori (id, type, geometry e properties). Ogni elemento di `features` rappresenta una singola stazione (`count: 1`) oppure un cluster di stazioni (`count > 1`).



`id` · `string` · <span class="text-accent">mandatory</span>
: L'identificativo univoco della stazione. Restituito solo per le feature di singole stazioni.

`type` · `string` · <span class="text-accent">mandatory</span>
: Sempre impostato su `"Feature"`.

`geometry` · `object` · <span class="text-accent">mandatory</span>
: Geometria GeoJSON `Point` standard contenente le coordinate `[longitude, latitude]`.

`properties` · `object` · <span class="text-accent">mandatory</span>
: Attributi della feature. Per impostazione predefinita, le feature di stazione restituiscono `{ "count": 1 }` e le feature di cluster restituiscono `{ "count": N, "expansion_zoom": Z }`. Ulteriori campi della stazione possono essere richiesti tramite i [selettori](/api-reference/core/tiles/selectors).

I campi restituiti all'interno di `properties` dipendono dal tipo di feature e dai selettori forniti:

- Feature di cluster: restituiscono sempre `{ "count": N, "expansion_zoom": Z }`.

- Feature di stazione: restituiscono `{ "count": 1 }` se non vengono forniti selettori, oppure solo i campi richiesti se vengono forniti i [selettori](/api-reference/core/tiles/selectors).

### Valuta
Usa il parametro di query `currency` per impostare la valuta dei prezzi dell'energia restituiti e usati per il filtraggio. Consulta la [documentazione sulla conversione di valuta](/api-reference/core/tiles/filters) per maggiori informazioni.
