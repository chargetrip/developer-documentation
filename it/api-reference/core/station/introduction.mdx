Il routing di un veicolo elettrico dipende dal sapere dove può ricaricare, quindi il database delle stazioni deve essere popolato con i dati delle stazioni prima che sia possibile pianificare qualsiasi rotta. Per impostazione predefinita, lo schema delle stazioni è conforme allo standard [OCPI](https://evroaming.org/ocpi/) più recente. È possibile aggiungere proprietà personalizzate, ma di solito vengono spostate in query aggiuntive anziché nella query delle stazioni stessa.
