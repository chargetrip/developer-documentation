Ottieni un elenco dei servizi disponibili nelle vicinanze di una stazione specifica utilizzando la query amenityList. È utile quando vuoi mostrare ristoranti, negozi o altre strutture vicine mentre un veicolo è in ricarica.

## Query

Per ottenere i servizi di una stazione è necessario un `id` della stazione. L'`id` può essere ottenuto tramite un [percorso](/api-reference/core/route/query-get-route), il [servizio di tile](/api-reference/core/tiles/mvt) oppure la [query stazioni nelle vicinanze](/api-reference/core/station/query-station-around). Usa l'argomento `filter` per restringere i risultati in base a criteri specifici e gli argomenti `size` e `page` per [paginare](/api-reference/core/api/pagination) i risultati.
