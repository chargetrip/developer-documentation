Ottieni i dettagli di un operatore di punti di ricarica utilizzando la query operator. È utile quando vuoi mostrare le informazioni sull'operatore insieme a una stazione o a una sessione.

## Query

Per ottenere i dettagli di un operatore è obbligatorio il suo `id`. L'`id` può essere ottenuto tramite la [query operatorList](/api-reference/core/operator/query-operator-list).
