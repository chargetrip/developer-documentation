Accedi all'elenco completo degli operatori dei punti di ricarica utilizzando la query operatorList. È utile quando vuoi sfogliare o cercare gli operatori.

## Query

Per eseguire questa query non è richiesto alcun input. Usa `filter` e `search` per restringere i risultati e gli argomenti `size` e `page` per [paginarli](/api-reference/core/api/pagination).
