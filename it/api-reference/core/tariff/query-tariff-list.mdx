Accedi all'elenco completo delle tariffe usando la query tariffList. È utile quando vuoi mostrare o confrontare i costi di ricarica tra le stazioni. Per scoprire come mostrare i prezzi, consulta la [guida alle tariffe delle stazioni](/docs/getting-started/station-pricing).

## Query

Per eseguire questa query non è richiesto alcun input. Usa gli argomenti `size` e `page` per [paginarle](/api-reference/core/api/pagination).
