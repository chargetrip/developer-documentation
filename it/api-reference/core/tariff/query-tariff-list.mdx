Accedi all'elenco completo delle tariffe utilizzando la query tariffList. È utile quando vuoi mostrare o confrontare i costi di ricarica tra le stazioni. Per scoprire come visualizzare i prezzi, consulta la [guida ai prezzi delle stazioni](/docs/getting-started/station-pricing).

## Query

Per eseguire questa query non è richiesto alcun input. Usa gli argomenti `size` e `page` per [paginare](/api-reference/core/api/pagination) i risultati.
