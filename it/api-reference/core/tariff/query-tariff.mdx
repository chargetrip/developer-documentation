Ottieni i dettagli di una tariffa utilizzando la query tariff. È utile quando utilizzi un database di stazioni diverso da Ecomovement e vuoi mostrare il costo della ricarica presso una stazione. Per scoprire come visualizzare i prezzi, consulta la [guida ai prezzi delle stazioni](/docs/getting-started/station-pricing).

## Query

Per ottenere i dettagli di una tariffa è necessario un `id` della tariffa. L'`id` può essere ottenuto tramite la [query tariffList](/api-reference/core/tariff/query-tariff-list).
