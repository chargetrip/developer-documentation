Aggiorna una sessione di navigazione attiva utilizzando la mutation updateNavigation. È utile quando vuoi comunicare la posizione di un conducente mentre procede lungo una rotta.

## Mutation

Per aggiornare una sessione di navigazione sono obbligatori il suo `id` e `location_data`. L'`id` può essere ottenuto tramite la [mutation startNavigation](/api-reference/core/navigation/mutation-start-navigation).
