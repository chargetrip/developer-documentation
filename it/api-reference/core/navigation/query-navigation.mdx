Ottieni una sessione di navigazione attiva utilizzando la query navigation. È utile quando vuoi mostrare l'avanzamento attuale di un conducente lungo una rotta.

## Query

Per ottenere i dettagli di una sessione di navigazione è obbligatorio il suo `id`. L'`id` può essere ottenuto tramite la [mutation startNavigation](/api-reference/core/navigation/mutation-start-navigation).
