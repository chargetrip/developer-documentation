Avvia una nuova sessione di navigazione su una rotta esistente utilizzando la mutation startNavigation. È utile quando un conducente inizia a seguire una rotta calcolata.

> [!WARNING] Durata della sessione
> Una sessione di navigazione viene terminata automaticamente dopo 48 ore di inattività.

## Mutation

Per avviare una sessione di navigazione sono obbligatori `route_id`, `route_details_id` e `current_location`. Entrambi gli ID della rotta possono essere ottenuti tramite la [query getRoute](/api-reference/core/route/query-get-route). La mutation restituisce l'`id` di una sessione di navigazione, che può essere usato per recuperare, aggiornare o terminare la sessione.
