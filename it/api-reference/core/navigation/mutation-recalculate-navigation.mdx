Ricalcola il percorso di una sessione di navigazione attiva usando la mutation recalculateNavigation. È utile quando un conducente si discosta dal percorso originale o le condizioni cambiano lungo la strada.

## Mutation

Per ricalcolare il percorso di una sessione di navigazione sono necessari il suo `id` e `current_location`. Facoltativamente includi `state_of_charge`, `via` o `telemetry` per affinare il nuovo percorso. L'`id` si ottiene tramite la [mutation startNavigation](/api-reference/core/navigation/mutation-start-navigation).
