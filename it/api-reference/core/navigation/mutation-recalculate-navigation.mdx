Ricalcola la rotta di una sessione di navigazione attiva utilizzando la mutation recalculateNavigation. È utile quando un conducente devia dalla rotta originale o le condizioni cambiano lungo il percorso.

## Mutation

Per ricalcolare la rotta di una sessione di navigazione sono obbligatori il suo `id` e `current_location`. Facoltativamente includi `state_of_charge`, `via` o `telemetry` per affinare la nuova rotta. L'`id` può essere ottenuto tramite la [mutation startNavigation](/api-reference/core/navigation/mutation-start-navigation).
