---
title: Operazioni asincrone
description: "Scopri come funzionano le operazioni asincrone nell'API: crea con una mutation, poi monitora e recupera il risultato con una subscription o una query."
---

Alcune operazioni, come la creazione di una rotta o di una rotta abbinata, vengono eseguite in modo asincrono per mantenere l'API reattiva. Invece di attendere che una mutation restituisca il risultato completo, ottieni subito un `id` e lo usi in seguito per monitorarlo e recuperarlo.

## Come funziona

1. **Crea**
   Chiama la mutation. Restituisce subito un `id`, che userai nel passaggio successivo per monitorare e recuperare il risultato.
2. **Apri una subscription**
   Sottoscriviti usando l'`id` del passaggio precedente. Mentre il risultato viene calcolato, la subscription invia aggiornamenti di stato che puoi usare per gestire uno stato di caricamento asincrono nella tua interfaccia.
3. **Mostra il risultato**
   Quando `status` assume un valore finale, mostra l'interfaccia corrispondente a quell'esito.
4. **Recupera di nuovo un risultato completato**
   Quando un risultato raggiunge uno stato finale, è già precalcolato. Se ti serve di nuovo in seguito, ad esempio dopo esserci tornato, usa la query corrispondente invece di aprire una nuova subscription.
