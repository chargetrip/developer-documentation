---
title: Sicurezza
description: "Previeni l'uso non autorizzato delle tue applicazioni limitando quale piattaforma o origine può inviare richieste con il tuo ID app."
---

Gli header inviati con una richiesta, incluso `x-app-id`, sono visibili a chiunque ispezioni il traffico di rete. Per prevenire l'uso non autorizzato delle tue applicazioni, applica una restrizione che limiti quale piattaforma o origine può usarle.

> [!WARNING] Una restrizione per applicazione
> Per ogni applicazione può essere applicata una sola restrizione. Per combinare più restrizioni, ad esempio un client web e uno mobile, crea un'applicazione separata per ciascuno.

## Tipi di restrizione

Sono disponibili quattro tipi di restrizione, ciascuno adatto a una diversa piattaforma o a un diverso schema di comunicazione.

### Web

Limita un'applicazione web tramite il referrer HTTP, applicato all'header `x-app-id`. È possibile aggiungere più URL a una singola applicazione.

### Machine-to-machine (M2M)

Limita la comunicazione server-to-server tramite indirizzo IP (sono supportati IPv4 e IPv6), configurato nella dashboard dell'app. È l'opzione più sicura, poiché le credenziali non raggiungono mai un browser o un dispositivo.

### Android

Limita un'applicazione Android usando gli header `x-app-identifier` e `x-app-fingerprint`, inviati con ogni richiesta.

### iOS

Limita un'applicazione iOS usando l'header `x-app-identifier`, che contiene il bundle identifier dell'app.
