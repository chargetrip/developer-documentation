Sottoscriviti a un veicolo connesso utilizzando la subscription connectedVehicle. È utile quando vuoi ricevere aggiornamenti in tempo reale sul suo stato di autorizzazione.

## Subscription

Per sottoscriversi agli aggiornamenti di un veicolo connesso è obbligatorio il suo `id`. L'`id` può essere ottenuto tramite la [mutation createConnectedVehicle](/api-reference/core/connected-vehicle/mutation-create-connected-vehicle).
