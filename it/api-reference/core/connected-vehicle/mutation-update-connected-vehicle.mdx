Aggiorna un veicolo connesso utilizzando la mutation updateConnectedVehicle. È utile quando vuoi modificare l'etichetta di un veicolo connesso.

## Mutation

Per aggiornare un veicolo connesso è obbligatorio un `id`. Usa `label` per impostare una nuova etichetta. L'`id` può essere ottenuto tramite la [mutation createConnectedVehicle](/api-reference/core/connected-vehicle/mutation-create-connected-vehicle).
