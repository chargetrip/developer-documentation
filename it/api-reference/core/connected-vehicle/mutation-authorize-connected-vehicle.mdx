Completa l'autorizzazione di un veicolo connesso utilizzando la mutation authorizeConnectedVehicle. È utile dopo che l'utente finale ha concesso l'accesso tramite il provider di connettività.

## Mutation

Per autorizzare un veicolo connesso sono obbligatori un `id` e le `options` specifiche del provider. L'`id` può essere ottenuto tramite la [mutation createConnectedVehicle](/api-reference/core/connected-vehicle/mutation-create-connected-vehicle).
