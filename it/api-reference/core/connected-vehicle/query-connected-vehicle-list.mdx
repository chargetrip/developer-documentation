Ottieni l'elenco dei veicoli connessi dell'utente corrente utilizzando la query connectedVehicleList. È utile quando vuoi mostrare tutti i veicoli che un utente ha collegato a un provider.

## Query

Per eseguire questa query non è richiesto alcun input. Usa `filter` per restringere i risultati per stato e gli argomenti `size` e `page` per [paginarli](/api-reference/core/api/pagination).
