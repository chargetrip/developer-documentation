Un'applicazione di navigazione per veicoli elettrici ha bisogno di dati in tempo reale del veicolo, come lo stato di carica, con cui pianificare le rotte. Quasi tutti i veicoli elettrici in circolazione oggi dispongono di un modem in grado di inviare questi dati ad applicazioni esterne, ma gli standard e i modi per renderli disponibili differiscono da un costruttore all'altro.

La connettività dei veicoli porta questi dati nella tua applicazione attraverso un'unica fonte. Un livello di astrazione acquisisce, ripulisce e prepara i dati di molti fornitori per il motore di routing e una pagina di destinazione personalizzabile con il tuo marchio consente ai tuoi utenti di autenticarsi e dare il consenso. Funziona con il tuo attuale fornitore di dati dei veicoli connessi, la tua API di telemetria o il tuo dongle OBD-II ed è preintegrato con [Enode](https://enode.io).

Per ottenere l'accesso, o per usare un diverso fornitore di dati o la tua API, contatta [sales@chargetrip.com](mailto:sales@chargetrip.com).

## Fonti di dati supportate

Piattaforma di dati dei veicoli connessi
: Soluzioni cloud che si collegano alle API dei costruttori di veicoli ed espongono tali dati a terze parti. Gestiscono il consenso del proprietario del veicolo e standardizzano il formato dei dati. I marchi supportati e i prezzi variano notevolmente da una piattaforma all'altra. È adatta agli sviluppatori di app, ad esempio per un CPO o un eMSP. Le piattaforme supportate sono [Enode](https://enode.io), [High Mobility](https://high-mobility.com), [Smartcar](https://smartcar.com) e [WirelessCar](https://wirelesscar.com).

Dongle hardware
: Dongle Bluetooth che vengono installati manualmente nel veicolo. Hanno un costo iniziale relativamente alto ma costi ricorrenti bassi, il che li rende popolari tra gli operatori di flotte logistiche. Il [Geotab Go9](https://support.geotab.com/go-devices/go9/doc/go9-document) è supportato a livello globale.

La tua API o un'API specifica di un marchio
: Un costruttore di veicoli può trasmettere i dati del veicolo tramite il modem del veicolo ed esporli attraverso un'API. Questo vale anche se vuoi supportare solo uno specifico marchio di veicoli. [Disponibile su richiesta](mailto:sales@chargetrip.com).

Un altro fornitore di dati di telemetria
: Aggiunto tramite un flusso di integrazione dati personalizzato. [Disponibile su richiesta](mailto:sales@chargetrip.com).
