Ottieni i dettagli di un veicolo connesso usando la query connectedVehicle. È utile quando vuoi verificare lo stato di autorizzazione di un veicolo connesso.

## Query

Per ottenere i dettagli di un veicolo connesso è necessario il suo `id`. L'`id` si ottiene tramite la [mutation createConnectedVehicle](/api-reference/core/connected-vehicle/mutation-create-connected-vehicle) o la [query connectedVehicleList](/api-reference/core/connected-vehicle/query-connected-vehicle-list).
