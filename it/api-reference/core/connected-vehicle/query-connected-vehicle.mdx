Ottieni i dettagli di un veicolo connesso utilizzando la query connectedVehicle. È utile quando vuoi controllare lo stato di autorizzazione di un veicolo connesso.

## Query

Per ottenere i dettagli di un veicolo connesso è obbligatorio il suo `id`. L'`id` può essere ottenuto tramite la [mutation createConnectedVehicle](/api-reference/core/connected-vehicle/mutation-create-connected-vehicle) o la [query connectedVehicleList](/api-reference/core/connected-vehicle/query-connected-vehicle-list).
