Ottieni i dati del veicolo in tempo reale utilizzando la query connectedVehicleData. È utile quando vuoi recuperare dati in tempo reale direttamente da un veicolo connesso, come il suo stato di carica o la sua posizione.

## Query

Per ottenere i dati in tempo reale di un veicolo connesso è obbligatorio il suo `id`. L'`id` può essere ottenuto tramite la [mutation createConnectedVehicle](/api-reference/core/connected-vehicle/mutation-create-connected-vehicle).
