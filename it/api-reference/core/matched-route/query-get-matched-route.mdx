Ottieni i dettagli di un percorso associato calcolato in precedenza usando la query getMatchedRoute. È utile quando vuoi recuperare di nuovo un percorso associato senza aprire una nuova subscription.

## Query

Per ottenere i dettagli del percorso è necessario l'`id` del percorso associato. L'`id` si ottiene tramite la [mutation createMatchedRoute](/api-reference/core/matched-route/mutation-create-matched-route).
