Ottieni i dettagli di una rotta abbinata calcolata in precedenza utilizzando la query getMatchedRoute. È utile quando vuoi recuperare di nuovo una rotta abbinata senza aprire una nuova subscription.

## Query

Per ottenere i dettagli della rotta è obbligatorio l'`id` di una rotta abbinata. L'`id` può essere ottenuto tramite la [mutation createMatchedRoute](/api-reference/core/matched-route/mutation-create-matched-route).
