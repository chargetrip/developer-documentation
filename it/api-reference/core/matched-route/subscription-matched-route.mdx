Sottoscriviti a una rotta abbinata utilizzando la subscription matchedRoute. È utile quando vuoi ricevere aggiornamenti in tempo reale mentre una rotta abbinata viene calcolata.

## Subscription

Per sottoscriversi agli aggiornamenti di una rotta abbinata è obbligatorio il suo `id`. L'`id` può essere ottenuto tramite la [mutation createMatchedRoute](/api-reference/core/matched-route/mutation-create-matched-route).
