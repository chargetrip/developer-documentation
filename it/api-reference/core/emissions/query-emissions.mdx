Ottieni il profilo delle emissioni di una rotta utilizzando la query getRouteEmissions. È utile quando vuoi mostrare l'impatto ambientale di un viaggio.

## Query

Per ottenere le emissioni di una rotta sono obbligatori un `route_id` e un `route_details_id`. Entrambi possono essere ottenuti tramite la [query getRoute](/api-reference/core/route/query-get-route).
