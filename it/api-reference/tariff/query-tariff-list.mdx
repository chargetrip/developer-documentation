title: Elenco tariffe
schemaName: tariffList
schemaType: Query

Accedi all'elenco completo delle tariffe usando la query tariffList. È utile quando vuoi mostrare o confrontare i costi di ricarica tra le stazioni.

## Query

Per eseguire questa query non è richiesto alcun input. Usa gli argomenti `size` e `page` per [paginarle](/api-reference/api/pagination).
