Calcolare un percorso per un EV dipende dal sapere dove può ricaricarsi, quindi il database delle stazioni deve essere popolato con i dati delle stazioni prima di poter pianificare qualsiasi percorso. Per impostazione predefinita, lo schema delle stazioni è conforme all'ultimo standard [OCPI](https://evroaming.org/ocpi/). È possibile aggiungere proprietà personalizzate, ma di solito vengono spostate in query aggiuntive anziché nella query delle stazioni stessa.

Dati Eco-Movement

Copre oltre 100.000 stazioni di ricarica in tutta Europa, inclusi disponibilità in tempo reale, prezzi e disponibilità prevista, dove disponibili. Questo elimina la necessità di collegare più fornitori di database di stazioni per ottenere la copertura europea. Consulta [eco-movement.com](https://eco-movement.com) per le limitazioni regionali. [Contatta le vendite](mailto:sales@chargetrip.com) per i prezzi.
