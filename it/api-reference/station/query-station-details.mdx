Ottieni i dettagli specifici di una stazione usando la query station. È utile quando vuoi mostrare il tipo e il numero di caricatori, la posizione o qualsiasi altro dettaglio attualmente disponibile per una stazione.

## Query

Per ottenere i dettagli di una stazione è necessario un `id` o un `evse_id` della stazione. L'`id` si ottiene tramite un [percorso](/api-reference/route/query-get-route), il [servizio di tile](/api-reference/tiles/mvt) o la [query station around](/api-reference/station/query-station-around).
