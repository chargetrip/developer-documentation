Ottieni un elenco dei servizi disponibili intorno a una stazione specifica usando la query amenityList. È utile quando vuoi mostrare ristoranti, negozi o altre strutture nelle vicinanze mentre un veicolo è in carica.

## Query

Per ottenere i servizi di una stazione è necessario il suo `id`. L'`id` si ottiene tramite un [percorso](/api-reference/route/query-get-route), il [servizio di tile](/api-reference/tiles/mvt) o la [query station around](/api-reference/station/query-station-around). Usa l'argomento `filter` per restringere i risultati in base a criteri specifici e gli argomenti `size` e `page` per [paginarli](/api-reference/api/pagination).
