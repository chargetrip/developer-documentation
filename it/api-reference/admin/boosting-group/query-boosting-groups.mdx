Elenca i gruppi di boosting del tuo workspace utilizzando la query boostingGroups. È utile quando vuoi creare una panoramica dei tuoi gruppi o trovare quelli attualmente attivi.

## Query

Per eseguire questa query non è richiesto alcun input. Usa gli argomenti `first` e `after` per [paginare](/api-reference/core/api/pagination) i risultati e l'argomento `filter` per restringerli per `client_id` o `status`.
