Ottieni un Boosting Group usando la query boostingGroup. È utile quando vuoi verificare se un gruppo è attivo o quali stazioni promuove al momento. Per capire come i Boosting Groups influenzano un percorso, consulta la [guida ai Boosting Groups](/docs/getting-started/route-boosting-groups).

## Query

È necessario l'`id` di un Boosting Group. L'`id` si ottiene tramite la [mutation createBoostingGroup](/api-reference/admin/boosting-group/mutation-create-boosting-group) o la [query boostingGroups](/api-reference/admin/boosting-group/query-boosting-groups).

> Questa operazione è in alpha e non è disponibile nei piani gratuiti. Contatta il supporto per l'accesso.
