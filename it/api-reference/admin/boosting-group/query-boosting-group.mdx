Ottieni un gruppo di boosting utilizzando la query boostingGroup. È utile quando vuoi verificare se un gruppo è attivo o quali stazioni favorisce in questo momento. Per scoprire come i gruppi di boosting influiscono su una rotta, consulta la [guida ai gruppi di boosting](/docs/getting-started/route-boosting-groups).

## Query

È obbligatorio l'`id` di un gruppo di boosting. L'`id` può essere ottenuto tramite la [mutation createBoostingGroup](/api-reference/admin/boosting-group/mutation-create-boosting-group) o la [query boostingGroups](/api-reference/admin/boosting-group/query-boosting-groups).
