Crea un gruppo di boosting utilizzando la mutation createBoostingGroup. È utile quando vuoi orientare le rotte verso specifiche stazioni di ricarica, ad esempio per un accordo commerciale più vantaggioso. I gruppi attivi vengono applicati automaticamente a ogni rotta che calcoli con [createRoute](/api-reference/core/route/mutation-create-route). Per scoprire come funziona, consulta la [guida ai gruppi di boosting](/docs/getting-started/route-boosting-groups).

## Mutation

Sono obbligatori un `name`, un `client_id` e un elenco di `stations`. Identifica ogni stazione tramite il suo `id` oppure tramite l'`external_id` usato dal tuo provider di stazioni. Imposta `status` su `inactive` per creare il gruppo senza utilizzarlo ancora per il calcolo delle rotte.

<details>
  <summary>Crea un gruppo di boosting inattivo con due stazioni.</summary>
  Una stazione è identificata dal suo `id` interno, l'altra dall'`external_id` del tuo provider.

```graphql Example request
mutation CreateBoostingGroup {
  createBoostingGroup(
    input: {
      name: "Preferred stations"
      client_id: "60b8d5a2f1c8e9001b9e2831"
      status: inactive
      stations: [{ id: "5f6a1b2c3d4e5f6a7b8c9d0e" }, { external_id: "NL-AMS-0001" }]
    }
  ) {
    id
    status
  }
}
```
</details>
