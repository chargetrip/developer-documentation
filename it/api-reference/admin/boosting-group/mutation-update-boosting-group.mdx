Aggiorna un Boosting Group usando la mutation updateBoostingGroup. È utile quando vuoi attivare o disattivare un gruppo senza eliminarlo.

## Mutation

È necessario l'`id` di un Boosting Group. L'`id` si ottiene tramite la [mutation createBoostingGroup](/api-reference/admin/boosting-group/mutation-create-boosting-group). Invia solo i campi che vuoi modificare. Questa mutation non modifica le stazioni di un gruppo.

> [!WARNING] Alpha
> Questa operazione è in alpha e non è disponibile nei piani gratuiti. Contatta il supporto per l'accesso.

<details>
  <summary>Disattivare un Boosting Group.</summary>
  Un gruppo inattivo non viene più usato nei calcoli dei percorsi.

```graphql Example request
mutation UpdateBoostingGroup {
  updateBoostingGroup(
    input: { id: "6527e1f1a8b4c2d3e4f5a6b7", status: inactive }
  ) {
    id
    status
  }
}
```
</details>
