Aggiorna un gruppo di boosting utilizzando la mutation updateBoostingGroup. È utile quando vuoi attivare o disattivare un gruppo senza eliminarlo.

## Mutation

È obbligatorio l'`id` di un gruppo di boosting. L'`id` può essere ottenuto tramite la [mutation createBoostingGroup](/api-reference/admin/boosting-group/mutation-create-boosting-group). Invia solo i campi che vuoi modificare. Questa mutation non modifica le stazioni di un gruppo.

<details>
  <summary>Disattiva un gruppo di boosting.</summary>
  Un gruppo inattivo non viene più utilizzato nel calcolo delle rotte.

```graphql Example request
mutation UpdateBoostingGroup {
  updateBoostingGroup(
    input: { id: "6527e1f1a8b4c2d3e4f5a6b7", status: inactive }
  ) {
    id
    status
  }
}
```
</details>
