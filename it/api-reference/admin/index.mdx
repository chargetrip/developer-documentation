title: Riferimento Admin API
description: "Consulta le query e le mutation della Admin API, che usi per gestire risorse come i gruppi di boosting per il tuo workspace."
---

La Admin API è un'API GraphQL separata con un proprio schema. Usala per gestire le risorse che determinano il comportamento del tuo progetto, anziché richiederle al supporto Chargetrip. Oggi copre i gruppi di boosting, che ti permettono di dare priorità a singole stazioni di ricarica durante il calcolo della rotta. Per scoprire come i gruppi di boosting influiscono su una rotta, consulta [dare priorità a singole stazioni di ricarica](/docs/getting-started/route-boosting-groups).

> [!WARNING] Alpha
> La Admin API è in alpha e non è disponibile nei piani gratuiti. Contatta il supporto per ottenere l'accesso e aspettati che lo schema cambi.
