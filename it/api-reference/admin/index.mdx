description: "Esplora le query e le mutation della Admin API, che usi per gestire risorse come i Boosting Groups del tuo workspace."
---

La Admin API è un'API GraphQL separata, con un proprio schema. Usala per gestire le risorse che determinano il comportamento del tuo progetto, invece di richiederle al supporto Chargetrip. Oggi copre i Boosting Groups, che ti permettono di dare priorità a singole stazioni di ricarica durante il calcolo del percorso.

Le richieste vanno a un endpoint diverso rispetto al resto dell'API reference, e ogni risorsa che crei o leggi appartiene al workspace identificato dall'header `x-token`.

> [!WARNING] Alpha
> La Admin API è in alpha e non è disponibile nei piani gratuiti. Contatta il supporto per ottenere l'accesso e aspettati modifiche allo schema.
