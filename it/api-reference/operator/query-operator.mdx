Ottieni i dettagli di un operatore di punti di ricarica usando la query operator. È utile quando vuoi mostrare le informazioni sull'operatore insieme a una stazione o a una sessione.

## Query

Per ottenere i dettagli di un operatore è necessario il suo `id`. L'`id` si ottiene tramite la [query operatorList](/api-reference/operator/query-operator-list).
