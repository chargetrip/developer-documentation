title: Operazioni deprecate
description: "Sfoglia le query, le mutation e le subscription deprecate e trova l'operazione che sostituisce ciascuna di esse."
toc: false
---

Queste operazioni sono deprecate. Un'operazione deprecata continua a funzionare normalmente per almeno 12 mesi. Trascorso tale periodo viene rimossa e le richieste che la utilizzano restituiscono errori GraphQL. Consulta le [deprecazioni](/deprecations) per il calendario e per l'operazione che sostituisce ciascuna di esse.
