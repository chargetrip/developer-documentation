## Politica di deprecazione

Queste operazioni sono deprecate. Un'operazione deprecata continua a funzionare normalmente per almeno 12 mesi. Dopo questo periodo viene rimossa e le richieste che la utilizzano restituiscono errori GraphQL. Consulta le [deprecazioni](/deprecations) per le scadenze.
