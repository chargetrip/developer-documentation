Accedi all'elenco completo delle tariffe utilizzando la query legacy tariffList. Le nuove integrazioni dovrebbero invece usare la [query stationPrices](/api-reference/core/station-pricing/query-station-prices).

## Query

Per eseguire questa query non è richiesto alcun input. Usa gli argomenti `size` e `page` per [paginare](/api-reference/core/api/pagination) i risultati.
