Sottoscrivi un percorso utilizzando la subscription legacy routeUpdatedById per ricevere aggiornamenti in tempo reale durante il suo calcolo. Le nuove integrazioni dovrebbero invece usare la [subscription route](/api-reference/core/route/subscription-route).
