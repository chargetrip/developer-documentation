Iscriviti a un percorso usando la subscription legacy routeUpdatedById per ricevere aggiornamenti in tempo reale mentre viene calcolato. Le nuove integrazioni dovrebbero usare invece la [subscription route](/api-reference/core/route/subscription-route).
