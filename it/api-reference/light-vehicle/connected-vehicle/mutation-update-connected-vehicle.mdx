Aggiorna un veicolo connesso usando la mutation updateConnectedVehicle. È utile quando vuoi cambiare l'etichetta di un veicolo connesso.

## Mutation

Per aggiornare un veicolo connesso è necessario un `id`. Usa `label` per impostare una nuova etichetta. L'`id` si ottiene tramite la [mutation createConnectedVehicle](/api-reference/light-vehicle/connected-vehicle/mutation-create-connected-vehicle).
