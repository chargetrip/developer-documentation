Ottieni i dettagli di una tariffa usando la query tariff. È utile quando usi un database di stazioni diverso da Ecomovement e vuoi mostrare il costo di ricarica in una stazione. Per scoprire come mostrare i prezzi, consulta la [guida alle tariffe delle stazioni](/docs/getting-started/station-pricing).

## Query

Per ottenere i dettagli di una tariffa è necessario il suo `id`. L'`id` si ottiene tramite la [query tariffList](/api-reference/light-vehicle/tariff/query-tariff-list).
