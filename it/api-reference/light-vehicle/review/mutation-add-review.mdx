Aggiungi una recensione per una stazione usando la mutation addReview. Includi una valutazione e un messaggio, insieme all'EV e al tipo di connettore utilizzati, per dare agli altri utenti più contesto. Se viene inviato un header `x-token` per un utente valido, la recensione apparterrà a quell'utente, altrimenti viene aggiunta in forma anonima.

## Mutation

È richiesto un oggetto `review`, che contiene l'`id` della stazione, `rating` e `message`. Facoltativamente includi `ev`, `plugType`, `locale`, `properties` e `tags` utilizzati durante la visita.
