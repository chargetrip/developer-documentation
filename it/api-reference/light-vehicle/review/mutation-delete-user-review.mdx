Rimuovi una recensione aggiunta dall'utente autenticato usando la mutation deleteUserReview. Questa è una funzionalità premium. Contattaci per maggiori informazioni.

## Mutation

Per rimuovere una recensione è necessario il suo `id`. È obbligatorio un header `x-token` per autorizzare l'utente: la recensione deve appartenergli, altrimenti si verifica un errore.
