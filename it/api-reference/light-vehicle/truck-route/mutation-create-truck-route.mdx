Crea un nuovo percorso per camion usando la mutation createTruckRoute. È utile quando vuoi calcolare le tappe di ricarica, il consumo energetico e il tempo di guida di un camion elettrico tra un punto di partenza e una destinazione.

## Mutation

Per creare un percorso per camion sono necessari `vehicle`, `origin` e `destination`. Facoltativamente aggiungi punti `via`, `operators`, `weather` o altre preferenze per affinare il calcolo. La mutation restituisce un `id` del percorso camion, che può essere usato per recuperare i dettagli del percorso o per iscriversi agli aggiornamenti.
