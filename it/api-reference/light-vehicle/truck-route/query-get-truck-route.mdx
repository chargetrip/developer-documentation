Ottieni i dettagli di un percorso camion calcolato in precedenza usando la query getTruckRoute. È utile quando vuoi mostrare le tappe di ricarica, la distanza e la durata di un percorso camion.

## Query

Per ottenere i dettagli del percorso è necessario l'`id` del percorso camion. L'`id` si ottiene tramite la [mutation createTruckRoute](/api-reference/light-vehicle/truck-route/mutation-create-truck-route).
