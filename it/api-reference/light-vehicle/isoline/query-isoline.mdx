Ottieni i dettagli di una isoline calcolata in precedenza usando la query isoline. È utile quando vuoi mostrare l'area raggiungibile da un veicolo.

## Query

Per ottenere i dettagli di una isoline è necessario il suo `id`. L'`id` si ottiene tramite la [mutation createIsoline](/api-reference/light-vehicle/isoline/mutation-create-isoline).
