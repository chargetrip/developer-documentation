Iscriviti a una isoline usando la subscription isoline. È utile quando vuoi ricevere aggiornamenti in tempo reale mentre una isoline viene calcolata.

## Subscription

Per iscriversi agli aggiornamenti di una isoline è necessario il suo `id`. L'`id` si ottiene tramite la [mutation createIsoline](/api-reference/light-vehicle/isoline/mutation-create-isoline).
