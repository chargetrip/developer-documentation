Crea una isoline basata sul consumo usando la mutation createIsoline. È utile quando vuoi visualizzare l'area che un veicolo può raggiungere da un determinato punto.

## Mutation

Per creare una isoline sono necessari un `vehicle_id` e un `origin`. Facoltativamente aggiungi `state_of_charge`, `polygon_count` o altre preferenze per affinare il calcolo. La mutation restituisce un `id` della isoline, che può essere usato per recuperarne i dettagli o per iscriversi agli aggiornamenti.
