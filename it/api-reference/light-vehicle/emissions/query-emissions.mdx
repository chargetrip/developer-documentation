Ottieni il profilo delle emissioni di un percorso usando la query getRouteEmissions. È utile quando vuoi mostrare l'impatto ambientale di un viaggio.

## Query

Per ottenere le emissioni di un percorso sono necessari un `route_id` e un `route_details_id`. Entrambi si ottengono tramite la [query getRoute](/api-reference/light-vehicle/route/query-get-route).
