Per mantenere l'API veloce e reattiva, le query di elenco limitano la quantità di dati restituiti in una singola richiesta. Nell'API vengono utilizzati due tipi di paginazione:

- Basata su cursore (attuale): utilizzata dalle query di elenco di nuova realizzazione.
- Basata su offset (legacy): utilizzata dalla maggior parte delle query di elenco esistenti. Verranno prima o poi sostituite da versioni basate su cursore.

> [!WARNING] Limiti di paginazione
> Indipendentemente dal tipo di paginazione, le query di elenco restituiscono al massimo 100 elementi per pagina, ad eccezione della query `getRouteStationsWithAmenities`, che è limitata a 10.

## Paginazione basata su cursore

La paginazione basata su cursore è lo standard attuale. Ti permette di definire il punto di partenza di una richiesta tramite un cursore, un identificatore univoco per una posizione nel set di risultati.

### Argomenti

`first` · <span class="text-muted">Integer</span>
: Il numero di elementi da restituire.

`after` · <span class="text-muted">String</span>
: Il cursore da cui iniziare. Ometti questo argomento, o impostalo su `null`, per recuperare la prima pagina. Per le pagine successive, usa il valore `page_info.end_cursor` della risposta precedente.

### Risposta

La risposta restituisce i risultati direttamente tramite un array `nodes`, insieme ai metadati di paginazione.

`nodes` · <span class="text-muted">Array</span>
: L'elenco degli oggetti dati per la pagina corrente.

`total_count` · <span class="text-muted">Integer</span>
: Il numero totale di elementi che corrispondono alla query, su tutte le pagine.

`page_info.has_next_page` · <span class="text-muted">Boolean</span>
: Indica se sono disponibili altri risultati dopo la pagina corrente.

`page_info.has_previous_page` · <span class="text-muted">Boolean</span>
: Indica se sono disponibili altri risultati prima della pagina corrente.

`page_info.start_cursor` · <span class="text-muted">String</span>
: Il cursore del primo nodo in `nodes`.

`page_info.end_cursor` · <span class="text-muted">String</span>
: Il cursore dell'ultimo nodo in `nodes`. Usa questo valore come argomento `after` nella tua query successiva.

## Paginazione basata su offset (legacy)

La paginazione basata su offset è lo standard legacy, ancora utilizzato dalla maggior parte delle query di elenco. Usa `page` per saltare un determinato numero di record e `size` per restituire una finestra fissa di risultati.

### Argomenti

`size` · <span class="text-muted">Integer</span>
: Il numero di elementi da restituire per pagina.

`page` · <span class="text-muted">Integer</span>
: Il numero della pagina da recuperare. Ometti questo argomento, o impostalo su `0`, per recuperare la prima pagina.

### Risposta

La risposta restituisce direttamente un elenco di oggetti dati, limitato dal valore di `size`.
