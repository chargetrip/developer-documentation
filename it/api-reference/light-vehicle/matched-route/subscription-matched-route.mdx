Iscriviti a un percorso associato usando la subscription matchedRoute. È utile quando vuoi ricevere aggiornamenti in tempo reale mentre un percorso associato viene calcolato.

## Subscription

Per iscriversi agli aggiornamenti di un percorso associato è necessario il suo `id`. L'`id` si ottiene tramite la [mutation createMatchedRoute](/api-reference/light-vehicle/matched-route/mutation-create-matched-route).
