Ottieni una sessione di navigazione attiva usando la query navigation. È utile quando vuoi mostrare l'avanzamento attuale di un conducente lungo un percorso.

## Query

Per ottenere i dettagli di una sessione di navigazione è necessario il suo `id`. L'`id` si ottiene tramite la [mutation startNavigation](/api-reference/light-vehicle/navigation/mutation-start-navigation).
