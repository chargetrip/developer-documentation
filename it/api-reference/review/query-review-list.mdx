Ogni stazione può essere accompagnata da recensioni degli utenti. Interroga proprietà come valutazione e messaggio, oppure ricevi i dati sull'EV usato per la ricarica. Le recensioni sono limitate a un singolo database di stazioni e non possono essere usate tra progetti diversi.

## Query

Per ottenere le recensioni di una stazione è necessario il suo `id`. L'`id` si ottiene tramite un [percorso](/api-reference/route/query-get-route), il [servizio di tile](/api-reference/tiles/mvt) o la [query station around](/api-reference/station/query-station-around). Usa gli argomenti `size` e `page` per [paginarle](/api-reference/api/pagination).
