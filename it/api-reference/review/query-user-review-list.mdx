---
title: Elenco recensioni utente
schemaName: userReviewList
schemaType: Query
---

Recupera tutte le recensioni aggiunte dall'utente autenticato per le varie stazioni usando la query userReviewList. È utile quando vuoi mostrare la cronologia delle recensioni di un utente. Questa è una funzionalità premium. Contattaci per maggiori informazioni.

## Query

È richiesto un header `x-token` per autorizzare l'utente di cui vuoi recuperare le recensioni. Usa gli argomenti `size` e `page` per [paginarle](/api-reference/api/pagination).
