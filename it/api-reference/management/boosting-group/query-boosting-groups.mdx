Elenca i Boosting Groups del tuo workspace usando la query boostingGroups. È utile quando vuoi creare una panoramica dei tuoi gruppi o trovare quelli attualmente attivi.

## Query

Per eseguire questa query non è richiesto alcun input. Usa gli argomenti `first` e `after` per [paginare](/api-reference/light-vehicle/api/pagination) i risultati e l'argomento `filter` per restringerli per `client_id` o `status`.

> [!WARNING] Alpha
> Questa operazione è in alpha e non è disponibile nei piani gratuiti. Contatta il supporto per l'accesso.
