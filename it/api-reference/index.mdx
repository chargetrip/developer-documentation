GraphQL è un linguaggio di query per le API. Ti permette di richiedere esattamente i dati di cui hai bisogno in una singola chiamata, invece di passare attraverso numerosi endpoint REST fissi.

L'API è basata su GraphQL. Ogni risorsa, come veicoli, stazioni, percorsi e sessioni di navigazione, è disponibile tramite un'unica API GraphQL. Puoi accedere a ciascuna come query, mutation o subscription.

Se non conosci GraphQL, la [documentazione ufficiale di GraphQL](https://graphql.org/learn/) è un buon punto di partenza.

## Endpoint GraphQL

Query, mutation e subscription sono disponibili agli endpoint indicati di seguito. Consulta [invia la tua prima richiesta](/docs/getting-started/api-request) per un esempio.

Per query e mutation, usa:

```bash Mutation and Query URL
https://api.chargetrip.io/graphql
```

Per le subscription, usa:

```bash Subscriptions URL
wss://api.chargetrip.io/subscription
```

### Autenticazione

Ogni richiesta viene autenticata con gli header `x-client-id` e `x-app-id`. Consulta [autorizzazione](/docs/getting-started/api-request#header-di-autorizzazione) per scoprire come ottenerli e inviarli.

### Paginazione

Le query di elenco usano gli argomenti `size` e `page` oppure, per la paginazione basata su cursore, gli argomenti `first` e `after`. Consulta [paginazione](/api-reference/api/pagination) per i dettagli.

### Limitazione della frequenza

Le richieste sono soggette a [limitazione della frequenza](/api-reference/api/rate-limiting).

### Ciclo di vita

Chargetrip utilizza un'unica API GraphQL in continua evoluzione anziché rilasci con versioni. Consulta [ciclo di vita](/api-reference/api/lifecycle) per scoprire come gestiamo le modifiche incompatibili e compatibili.
