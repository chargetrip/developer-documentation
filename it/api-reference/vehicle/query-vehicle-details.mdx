Ottieni le specifiche del veicolo usando la query vehicle.

## Query

Per ottenere i dettagli di un veicolo è necessario il suo `id`. L'`id` si ottiene tramite la [query vehicleList](/api-reference/vehicle/query-vehicles). Usa l'argomento country per applicare la localizzazione ai dati.
