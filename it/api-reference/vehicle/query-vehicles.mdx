Accedi al database completo dei veicoli con la query `vehicleList`. Per impostazione predefinita il database dei veicoli usa la denominazione UE per veicoli e tipi di connettore.

## Query

Per eseguire la query `vehicleList` non è richiesto alcun input. Usa `filter` e `search` per restringere e personalizzare i risultati. Usa il parametro country in combinazione con il filtro region per restituire i veicoli disponibili nella tua regione con nomi e tipi di connettore noti localmente. Usa gli argomenti `size` e `page` per [paginarli](/api-reference/api/pagination).
