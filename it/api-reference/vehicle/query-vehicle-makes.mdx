Ottieni un elenco dei marchi dei veicoli usando la query vehicleMakes.

## Query
Per eseguire la query vehicleMakes non è richiesto alcun input. Usa l'argomento `filter` per restringere i risultati per regione e/o tipo e gli argomenti `first` e `after` per [paginarli](/api-reference/api/pagination). Usa l'argomento `country` per applicare la localizzazione ai dati.
