I filtri permettono alle applicazioni di restringere le stazioni di ricarica restituite dall'API del servizio Tile. Oltre a nascondere i risultati non corrispondenti, alcuni filtri trasformano anche i dati delle stazioni per garantire che la risposta sia pertinente al contesto.

## Come i filtri influenzano i dati

Quando una richiesta include dei filtri, il servizio Tile esegue due operazioni distinte:

1. **Esclusione delle stazioni non corrispondenti**
   Qualsiasi stazione che non soddisfa i criteri di filtro specificati viene rimossa del tutto dalla risposta. Questa operazione avviene quando vengono usati filtri a livello di stazione o a livello di EVSE.
2. **Trasformazione dei dati**
   Quando vengono forniti determinati parametri di filtro, il servizio Tile ricalcola alcune proprietà dinamiche della stazione. Questa operazione avviene quando vengono usati filtri a livello di EVSE.

## Implementazione

I parametri di filtro possono essere aggiunti all'URL della richiesta come stringhe di query a qualsiasi endpoint del servizio Tile (MVT, JSON o Conteggio). Se non viene applicato alcun filtro, vengono restituite tutte le stazioni di ricarica disponibili e non viene eseguita alcuna trasformazione dei dati.

```bash Tile / Filter / Example
https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?{filter_1}&{filter_2}&{filter_n}
```

## Livelli

I filtri possono esistere su due livelli: a livello di EVSE o a livello di stazione, ciascuno con il proprio impatto e i propri risultati come descritto di seguito.

### Livello stazione

Filtri che valutano gli attributi globali della stazione. Questi filtri sono solo di esclusione: escludono le stazioni non corrispondenti ma non modificano mai i campi di dati restituiti.

`amenities` · `enum` · [Mostra URL di esempio](tip:https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?amenities[]=HOTEL)
: Filtra per includere solo le stazioni che offrono i servizi specificati.
: `HOTEL`, `SHOPPING`, `BATHROOM`, `SUPERMARKET`, `PLAYGROUND`, `PHARMACY`, `MUSEUM`, `COFFEE`, `PARK`, `RESTAURANT`

`preferred_operators` · `boolean` · [Mostra URL di esempio](tip:https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?preferred_operators=true)
: Filtra per includere solo le stazioni gestite da operatori configurati come preferiti. Gli operatori preferiti possono essere impostati nelle impostazioni del progetto nel dashboard.
: `true`, `false`

`hide_excluded_operators` · `boolean` · [Mostra URL di esempio](tip:https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?hide_excluded_operators=true)
: Filtra per escludere le stazioni gestite da operatori configurati come esclusi. Gli operatori esclusi possono essere impostati nelle impostazioni del progetto nel dashboard.
: `true`, `false`

`operator_ids` · `string` · [Mostra URL di esempio](tip:https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?operator_ids[]=631834841e604d2273ffb2b5&operator_ids[]=64e6979d49ed0ae2316ec052)
: Filtra per includere solo le stazioni gestite da specifici ID operatore. Accetta un array di ID operatore.

`truck_dedicated` · `boolean` · [Mostra URL di esempio](tip:https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?truck_dedicated=true)
: Filtra per includere solo le stazioni dedicate o destinate principalmente alla ricarica di camion. **Applicabile solo se viene utilizzato il database di stazioni Eco-Movement; in caso contrario viene ignorato.**
: `true`, `false`

`vehicle_types` · `enum` · [Mostra URL di esempio](tip:https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?vehicle_types[]=VAN&vehicle_types[]=RIGID)
: Filtra per includere solo le stazioni che supportano i tipi di veicolo OCPI specificati. Per impostazione predefinita sono inclusi tutti i tipi di veicolo. **Applicabile solo se viene utilizzato il database di stazioni Eco-Movement; in caso contrario viene ignorato.**
: `VAN`, `RIGID`, `TRUCK_WITH_TRAILER`

### Livello EVSE

Filtri che valutano le specifiche capacità di ricarica della stazione. Questi filtri eseguono esclusione e [trasformazione](/api-reference/tiles/filters#esempi-di-trasformazione-dei-dati): le stazioni non corrispondenti vengono escluse e per quelle corrispondenti i campi dinamici vengono ricalcolati.

`minimum_power` · `integer` · [Mostra URL di esempio](tip:https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?minimum_power=50)
: Filtra per includere solo le stazioni in cui almeno un connettore raggiunge o supera il valore di potenza specificato (in kW). Accetta un numero intero maggiore di 0.

`maximum_power` · `integer` · [Mostra URL di esempio](tip:https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?maximum_power=150)
: Filtra per includere solo le stazioni in cui la potenza di ricarica massima di nessun connettore supera il valore di potenza specificato (in kW). Accetta un numero intero maggiore di 0.

`minimum_energy_price` · `number` · [beta](tip:Beta;;Questo filtro è in beta e potrebbe cambiare prima di diventare stabile.) · [Mostra URL di esempio](tip:https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?minimum_energy_price=0.2&currency=EUR)
: Filtra per includere solo le stazioni i cui connettori compatibili hanno almeno un prezzo attivo maggiore o uguale al valore specificato, valutato nella valuta impostata da `currency`. Vedi [tariffe delle stazioni](/docs/getting-started/station-pricing).

`maximum_energy_price` · `number` · [beta](tip:Beta;;Questo filtro è in beta e potrebbe cambiare prima di diventare stabile.) · [Mostra URL di esempio](tip:https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?maximum_energy_price=0.5&currency=EUR)
: Filtra per includere solo le stazioni i cui connettori compatibili hanno almeno un prezzo attivo minore o uguale al valore specificato, valutato nella valuta impostata da `currency`. Vedi [tariffe delle stazioni](/docs/getting-started/station-pricing).

`connectors` · `enum` · [Mostra URL di esempio](tip:https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?connectors[]=CHADEMO)
: Filtra per includere solo le stazioni che hanno EVSE con i tipi di connettore specificati. Accetta un array di stringhe con qualsiasi valore di connettore OCPI 2.2.1.
: `CHADEMO`, `DOMESTIC_A`, `DOMESTIC_B`, `DOMESTIC_C`, `DOMESTIC_D`, `DOMESTIC_E`, `DOMESTIC_F`, `DOMESTIC_G`, `DOMESTIC_H`, `DOMESTIC_I`, `DOMESTIC_J`, `DOMESTIC_K`,
`DOMESTIC_L`, `DOMESTIC_M`, `DOMESTIC_N`, `DOMESTIC_O`, `IEC_60309_2_single_16`, `IEC_60309_2_three_16`, `IEC_60309_2_three_32`, `IEC_60309_2_three_64`, `IEC_62196_T1`,
`IEC_62196_T1_COMBO`, `IEC_62196_T2`, `IEC_62196_T2_COMBO`, `IEC_62196_T3A`, `IEC_62196_T3C`, `PANTOGRAPH_BOTTOM_UP`, `PANTOGRAPH_TOP_DOWN`, `TESLA_R`, `TESLA_S`, `GB_T`,
`CHAOJI`, `NEMA_5_20`, `NEMA_6_30`, `NEMA_6_50`, `NEMA_10_30`, `NEMA_10_50`, `NEMA_14_30`, `NEMA_14_50`

`evse_statuses` · `enum` · [Mostra URL di esempio](tip:https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?evse_statuses[]=AVAILABLE&evse_statuses[]=CHARGING)
: Filtra per includere solo le stazioni con EVSE che hanno gli stati specificati.
: `BLOCKED`, `PLANNED`, `AVAILABLE`, `CHARGING`, `UNKNOWN`, `RESERVED`, `OUT_OF_ORDER`, `INOPERATIVE`

## Conversione di valuta

Il parametro di query `currency` è supportato dall'endpoint del servizio Tile (`tile.json`, `tile.mvt` e `count`). Imposta la valuta dei prezzi dell'energia restituiti e usati per il filtraggio.

- Quando `currency` è omesso, `connector_minimum_energy_price` e `connector_maximum_energy_price` vengono restituiti in EUR.
- Quando `currency` è un codice valuta ISO 4217 valido, come `USD`, `GBP`, `DKK` o `EUR`:
  - I valori restituiti in `connector_minimum_energy_price` e `connector_maximum_energy_price` vengono convertiti dalla valuta di origine alla valuta richiesta lato server, utilizzando il tasso di conversione attivo.
  - I filtri `minimum_energy_price` e `maximum_energy_price` vengono valutati sui prezzi convertiti nella valuta richiesta, o in EUR se `currency` è omesso.
- Quando la valuta originale coincide con la valuta richiesta, `price_conversion_rate` viene restituito come `1.0`.
- Quando `currency` non è un codice valuta ISO 4217 valido, il servizio Tile restituisce un errore con questi dettagli:
  - Stato: `400 Bad Request`
  - Codice: `TILE_INVALID_PARAMETER_VALUE`
  - Messaggio: `Invalid parameter 'currency': found string {invalid currency} but expected one of {supported currencies}.`

```bash Example URL
https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?maximum_energy_price=0.5&currency=USD
```

### Esempi di trasformazione dei dati

Alcuni output vengono ricalcolati quando si applicano filtri a livello di EVSE. Questi campi vengono "trasformati" per ignorare i connettori che non corrispondono ai criteri di ricerca dell'utente.
Questi campi di output "dinamici" sono `connector_maximum_power`, `connector_minimum_energy_price`, `connector_maximum_energy_price` e `evse_status_*`.

<details>
  <summary>Stesso tipo di filtro, valori diversi</summary>
  La richiesta include un filtro per il connettore CHADEMO. La stazione è inclusa perché ha un connettore CHADEMO, ma i campi dinamici vengono trasformati per ignorare i caricatori Combo Type 1.

```bash Example URL
https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?connectors[]=IEC_62196_T1_COMBO&connectors[]=CHADEMO
```

```json Response
{
  "id": "station_a",
  // Static: Remains 150 kW (This represents the station maximum power across all connectors)
  "station_maximum_power": 150,
  // Dynamic: Adjusted to 100 kW (Max power of the CHADEMO connector)
  "connector_maximum_power": 100,
  // Dynamic: Counts the 1 CHADEMO chargers
  "evse_status_out_of_order": 0,
  // Dynamic: 0, because the charging Type 1 plugs are filtered out
  "evse_status_available": 1
}
```
</details>

<details>
  <summary>Filtri di prezzo</summary>
  La richiesta include un filtro `maximum_energy_price`, eventualmente combinato con altri filtri a livello EVSE. Un connettore corrisponde solo se soddisfa tutti i filtri contemporaneamente e i campi di prezzo dinamici vengono ricalcolati solo per i connettori corrispondenti.


**Stazione A di base**

- **EVSE 1:** CCS • 150 kW • Disponibile • 0,65 €
- **EVSE 2:** CCS • 50 kW • Disponibile • 0,35 €
- **EVSE 3:** Tipo 2 • 22 kW • Disponibile • 0,25 €

**Scenario 1: solo filtro di prezzo**

```bash Example URL
https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?maximum_energy_price=0.40
```

Corrispondenza: Gli EVSE 2 e 3 sono idonei. L'EVSE 1 è escluso.

```json Response
{
  "connector_maximum_power": 50,
  "evse_status_available": 2,
  // Dynamic: lowest price of the matching connectors, not of the entire station
  "connector_minimum_energy_price": 0.25,
  // Dynamic: highest price of the matching connectors, not of the entire station
  "connector_maximum_energy_price": 0.35
}
```

**Scenario 2: solo filtro di connettore**

```bash Example URL
https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?connectors[]=CCS
```

Corrispondenza: Gli EVSE 1 e 2 sono idonei.

```json Response
{
  "connector_maximum_power": 150,
  "evse_status_available": 2,
  // Dynamic: lowest price of the CCS connectors
  "connector_minimum_energy_price": 0.35,
  // Dynamic: highest price of the CCS connectors
  "connector_maximum_energy_price": 0.65
}
```

**Scenario 3: filtro di prezzo e di connettore**

```bash Example URL
https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?connectors[]=CCS&maximum_energy_price=0.30
```

Corrispondenza:

- Valuta `connector == CCS AND price <= 0.30`.
- I connettori CCS (EVSE 1 e 2) costano 0,65 € e 0,35 €, quindi non rispettano il filtro di prezzo.
- Il connettore Tipo 2 (EVSE 3) rispetta il prezzo, ma non il filtro di connettore.

Risultato: Stazione esclusa (0 EVSE corrispondenti).

**Scenario 4: filtro di prezzo e di potenza**

```bash Example URL
https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?minimum_power=100&maximum_energy_price=0.40
```

Corrispondenza:

- Valuta `power >= 100 kW AND price <= 0.40 €` sullo **stesso EVSE**.
- Il connettore da 150 kW è troppo costoso (0,65 €).
- I connettori più economici (da 0,25 € a 0,35 €) sono troppo lenti (50 kW o meno).

Risultato: Stazione esclusa (0 EVSE corrispondenti).
</details>
