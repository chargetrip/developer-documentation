L'endpoint di conteggio delle stazioni restituisce il numero totale di stazioni di ricarica.

## Configurazione
Per recuperare il conteggio delle stazioni, effettua una richiesta `GET` al seguente URL:

```bash Count / Base URL
https://api.chargetrip.io/v2/station/count
```

### Filtri
Usa il parametro di query `filter` per restringere il conteggio in base a criteri specifici. Consulta la [documentazione sui filtri](/api-reference/tiles/filters) per maggiori informazioni.
