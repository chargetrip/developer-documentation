Ottieni i dettagli di un percorso calcolato in precedenza usando la query getRoute. È utile quando vuoi mostrare le tappe di ricarica, la distanza e la durata di un percorso.

## Query

Per ottenere i dettagli di un percorso è necessario il suo `id`. L'`id` si ottiene tramite la [mutation createRoute](/api-reference/route/mutation-create-route).
