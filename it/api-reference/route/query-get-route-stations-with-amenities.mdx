Cerca stazioni di ricarica con servizi in un determinato punto lungo un percorso usando la query getRouteStationsWithAmenities. È utile quando vuoi pianificare una tappa di ricarica vicino a ristoranti, negozi o altri servizi.

## Query

Per cercare stazioni lungo un percorso sono necessari `route_id`, `route_details_id`, `time_window` e `amenity_types`. Entrambi gli id si ottengono tramite la [query getRoute](/api-reference/route/query-get-route). Usa l'argomento `filter` per restringere i risultati in base a criteri specifici e gli argomenti `first` e `after` per [paginarli](/api-reference/api/pagination).

> [!WARNING] Limiti
> `first` non può superare 10 per questa query.
