Crea un nuovo percorso usando la mutation createRoute. È utile quando vuoi calcolare le tappe di ricarica, il consumo energetico e il tempo di guida tra un punto di partenza e una destinazione.

## Mutation

Per creare un percorso sono necessari `vehicle`, `origin` e `destination`. Facoltativamente aggiungi punti `via`, `operators`, `weather` o altre preferenze per affinare il calcolo. La mutation restituisce un `id` del percorso, che può essere usato per recuperare i dettagli del percorso, le emissioni o i servizi lungo il tragitto.
