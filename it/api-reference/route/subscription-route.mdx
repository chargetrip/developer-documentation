Iscriviti a un percorso usando la subscription route. È utile quando vuoi ricevere aggiornamenti in tempo reale mentre un percorso viene calcolato.

## Subscription

Per iscriversi agli aggiornamenti di un percorso è necessario il suo `id`. L'`id` si ottiene tramite la [mutation createRoute](/api-reference/route/mutation-create-route).
