Ottieni i dati live del veicolo usando la query connectedVehicleData. È utile quando vuoi recuperare dati in tempo reale direttamente da un veicolo connesso, come il suo stato di carica o la sua posizione.

## Query

Per ottenere i dati live di un veicolo connesso è necessario il suo `id`. L'`id` si ottiene tramite la [mutation createConnectedVehicle](/api-reference/connected-vehicle/mutation-create-connected-vehicle).
