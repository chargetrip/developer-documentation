Iscriviti a un veicolo connesso usando la subscription connectedVehicle. È utile quando vuoi ricevere aggiornamenti in tempo reale sul suo stato di autorizzazione.

## Subscription

Per iscriversi agli aggiornamenti di un veicolo connesso è necessario il suo `id`. L'`id` si ottiene tramite la [mutation createConnectedVehicle](/api-reference/connected-vehicle/mutation-create-connected-vehicle).
