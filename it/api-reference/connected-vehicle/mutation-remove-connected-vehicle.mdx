Rimuovi un veicolo connesso e revoca il suo accesso usando la mutation removeConnectedVehicle. È utile quando un utente finale scollega il proprio veicolo dal provider di connettività.

## Mutation

Per rimuovere un veicolo connesso è necessario un `id`. L'`id` si ottiene tramite la [mutation createConnectedVehicle](/api-reference/connected-vehicle/mutation-create-connected-vehicle).
