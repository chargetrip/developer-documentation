Collega un veicolo a un provider di connettività usando la mutation createConnectedVehicle. È utile quando vuoi recuperare i dati live del veicolo direttamente dal veicolo invece che da un calcolo del percorso.

## Mutation

Per creare un veicolo connesso sono necessari un `vehicle_id` e un `provider`, insieme alle `options` specifiche del provider. La mutation restituisce un `id` del veicolo connesso e un `authorization_url`, che può essere usato per completare l'autorizzazione tramite la [mutation authorizeConnectedVehicle](/api-reference/connected-vehicle/mutation-authorize-connected-vehicle).
