## Deprecation policy

These operations are deprecated. A deprecated operation continues to work normally for at least 12 months. After that period it is removed, and requests that use it return GraphQL errors. See [deprecations](/deprecations) for the schedule.

## Replacements

New integrations should use the replacement operations below.

| Legacy operation | Replacement |
| --- | --- |
| [`newRoute` mutation](/api-reference/legacy/route/mutation-new-route) | [`createRoute` mutation](/api-reference/light-vehicle/route/mutation-create-route) |
| [`route` query](/api-reference/legacy/route/query-route) | [`getRoute` query](/api-reference/light-vehicle/route/query-get-route) |
| [`routePath` query](/api-reference/legacy/route/query-route-path) | `RouteDetails.path_plot` field |
| [`routeEmissions` query](/api-reference/legacy/route/query-route-emissions) | [`getRouteEmissions` query](/api-reference/light-vehicle/emissions/query-emissions) |
| [`routeUpdatedById` subscription](/api-reference/legacy/route/subscription-route-updated-by-id) | [`route` subscription](/api-reference/light-vehicle/route/subscription-route) |
