Create a new route by using the legacy newRoute mutation. It remains available while you migrate to the [createRoute mutation](/api-reference/light-vehicle/route/mutation-create-route), which calculates charging stops, energy consumption, and drive time with a reorganized schema and per-country operator preferences.
