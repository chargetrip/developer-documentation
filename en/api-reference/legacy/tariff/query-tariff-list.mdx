Access the full list of tariffs by using the legacy tariffList query. New integrations should use the [stationPrices query](/api-reference/core/station-pricing/query-station-prices) instead.

## Query

No input is required to execute this query. Use the `size` and `page` arguments to [paginate](/api-reference/core/api/pagination) through them.
