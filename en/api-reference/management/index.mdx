The Management API is a separate GraphQL API with its own schema. Use it to manage the resources that shape how your project behaves, instead of requesting them from Chargetrip support. Today it covers boosting groups, which let you prioritize individual charging stations during routing.

Requests go to a different endpoint than the rest of the API reference, and every resource you create or read belongs to the workspace that your `x-token` header identifies.

> [!WARNING] Alpha
> The Management API is in alpha and is not available on free plans. Contact support to get access, and expect the schema to change.
