Delete a boosting group by using the deleteBoostingGroup mutation. This is useful when you no longer want to boost the stations in a group. To stop using a group temporarily, [set its status to inactive](/api-reference/management/boosting-group/mutation-update-boosting-group) instead.

## Mutation

A boosting group `id` is required. The mutation returns a boolean.
