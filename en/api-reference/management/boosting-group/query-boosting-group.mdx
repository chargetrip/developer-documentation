Get a boosting group by using the boostingGroup query. This is useful when you want to check whether a group is active, or which stations it currently boosts. To learn how boosting groups affect a route, see the [boosting groups guide](/docs/getting-started/route-boosting-groups).

## Query

A boosting group `id` is required. The `id` can be obtained through the [createBoostingGroup mutation](/api-reference/management/boosting-group/mutation-create-boosting-group) or the [boostingGroups query](/api-reference/management/boosting-group/query-boosting-groups).
