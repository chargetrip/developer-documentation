List the boosting groups of your workspace by using the boostingGroups query. This is useful when you want to build an overview of your groups, or find the groups that are currently active.

## Query

No input is required to execute this query. Use the `first` and `after` arguments to [paginate](/api-reference/light-vehicle/api/pagination) through the results, and the `filter` argument to narrow them down by `client_id` or `status`.

> This operation is in alpha and is not available on free plans. Contact support for access.
