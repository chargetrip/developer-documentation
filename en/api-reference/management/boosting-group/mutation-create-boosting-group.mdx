Create a boosting group by using the createBoostingGroup mutation. This is useful when you want to steer routes toward specific charging stations, for example because of a better commercial deal. Active groups are applied automatically to every route you calculate with [createRoute](/api-reference/light-vehicle/route/mutation-create-route). To learn how, see the [boosting groups guide](/docs/getting-started/route-boosting-groups).

## Mutation

A `name`, a `client_id` and a list of `stations` are required. Identify each station either by its `id`, or by the `external_id` that your station provider uses. Set `status` to `inactive` to create the group without using it for routing yet.

> [!WARNING] Alpha
> This operation is in alpha and is not available on free plans. Contact support for access.

<details>
  <summary>Create an inactive boosting group with two stations.</summary>
  One station is identified by its internal `id`, the other by the `external_id` of your provider.

```graphql Example request
mutation CreateBoostingGroup {
  createBoostingGroup(
    input: {
      name: "Preferred stations"
      client_id: "60b8d5a2f1c8e9001b9e2831"
      status: inactive
      stations: [{ id: "5f6a1b2c3d4e5f6a7b8c9d0e" }, { external_id: "NL-AMS-0001" }]
    }
  ) {
    id
    status
  }
}
```
</details>
