Routing an EV depends on knowing where it can charge, so the station database must be populated with station data before any routes can be planned. By default, the station schema is compliant with the latest [OCPI](https://evroaming.org/ocpi/) standard. Custom properties can be added, but are usally moved to additional queries instead of the station query itself.

## Supported data sources

Eco-Movement data
: Without a commercial agreement in place, Chargetrip can pre-load your account with premium station data from [Eco-Movement](https://eco-movement.com). It covers over 100,000 charging stations across Europe, including real-time availability, pricing and predicted availability, where available. This removes the need to connect several station database providers to get European coverage. See [eco-movement.com](https://eco-movement.com) for regional limitations. [Contact sales](mailto:sales@chargetrip.com) for pricing.

Custom station data
: Both static and dynamic station data can be imported into Chargetrip. This requires a commercial agreement with the provider. [Contact sales](mailto:sales@chargetrip.com) to discuss the possibilities.
