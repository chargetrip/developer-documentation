Get specific station details by using the station query. This is useful when you want to display the type and number of chargers, the location, what charging costs, or any other detail currently available for a station. The [station pricing guide](/docs/getting-started/station-pricing) covers the pricing side in detail.

## Query

A station `id` or `evse_id` is required to get station details. The `id` can be obtained through either a [route](/api-reference/route/query-get-route), the [tile service](/api-reference/tiles/mvt), or the [station around query](/api-reference/station/query-station-around).
