With the stationAround query you can fetch the stations within a specific radius of a GeoJSON point. This can be useful when a station is busy, or when you want to provide several charging options.

## Query

A `location` (GeoJSON point) and `distance` in meters are required to search for stations around a point. Use the `filter` and `search` arguments to narrow down the results, and the `size` and `page` arguments to [paginate](/api-reference/api/pagination) through them.
