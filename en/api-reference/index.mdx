GraphQL is a query language for APIs. It lets you request exactly the data you need in a single call, instead of working through many fixed REST endpoints.

The API is built on GraphQL. Every resource, such as vehicles, stations, routes, and navigation sessions, is available through one GraphQL API. You can access each one as a query, mutation, or subscription.

If you're new to GraphQL, the [official GraphQL documentation](https://graphql.org/learn/) is a good place to start.

## GraphQL Endpoints

Queries, mutations, and subscriptions are available at the endpoints below. See [send your first request](/docs/getting-started/api-request) for an example.

For queries and mutations, use:

```bash Mutation and Query URL
https://api.chargetrip.io/graphql
```

For subscriptions, use:

```bash Subscriptions URL
wss://api.chargetrip.io/subscription
```

## Resources

Browse the API by resource. Each section below links to its queries, mutations, and subscriptions.

| Resource | Description |
| --- | --- |
| [Vehicle](/api-reference/vehicle/query-vehicles) | Look up EV specs, consumption models, and premium pricing data. |
| [Connected vehicle](/api-reference/connected-vehicle/query-connected-vehicle-list) | Connect a vehicle to a connectivity provider and retrieve its live data. |
| [Station](/api-reference/station/query-station-details) | Look up individual charge stations, nearby stations, and amenities. |
| [Station review](/api-reference/review/query-user-review-list) | Read, add, and remove user reviews for a charge station. |
| [Station tariff](/api-reference/tariff/query-tariff-list) | Look up the cost of charging at a station. |
| [Station operator](/api-reference/operator/query-operator-list) | Look up details about a station's charge point operator. |
| [Tiles](/api-reference/tiles/mvt) | Access station data as vector or JSON map tiles for rendering on a map. |
| [Route](/api-reference/route/mutation-create-route) | Calculate an EV route with charging stops, energy consumption, and drive time. |
| [Truck route](/api-reference/truck-route/mutation-create-truck-route) | Calculate an e-truck route accounting for vehicle weight and dimensions. |
| [Navigation](/api-reference/navigation/mutation-start-navigation) | Track a vehicle's progress along a route and receive real-time updates. |
| [Emissions](/api-reference/emissions/query-emissions) | Calculate the emissions saved by taking a route. |
| [Isoline](/api-reference/isoline/mutation-create-isoline) | Visualize the area a vehicle can reach from a point given its state of charge. |

### Authentication

Every request is authenticated with the `x-client-id` and `x-app-id` headers. See [authorization](/docs/getting-started/api-request#authorization-headers) for how to obtain and send them.

### Pagination

List queries use either `size` and `page` arguments or, for cursor-based pagination, `first` and `after` arguments. See [pagination](/api-reference/api/pagination) for details.

### Rate limiting

Requests are subject to [rate limiting](/api-reference/api/rate-limiting).

### Lifecycle

Chargetrip uses a single, evolving GraphQL API rather than versioned releases. See [lifecycle](/api-reference/api/lifecycle) for how we handle breaking and non-breaking changes.
