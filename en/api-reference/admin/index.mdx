The Admin API is a separate GraphQL API with its own schema. Use it to manage the resources that shape how your project behaves, instead of requesting them from Chargetrip support. Today it covers boosting groups, which let you prioritize individual charging stations during routing. To learn how boosting groups affect a route, see [prioritize individual charging stations](/docs/getting-started/route-boosting-groups).

> [!WARNING] Alpha
> The Admin API is in alpha and is not available on free plans. Contact support to get access, and expect the schema to change.
