Get the tariff details by using the tariff query. This is useful when you're using a station database other than Ecomovement and want to display the cost of charging at a station.

## Query

A tariff `id` is required to get tariff details. The `id` can be obtained through the [tariffList query](/api-reference/tariff/query-tariff-list).
