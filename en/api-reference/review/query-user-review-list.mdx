---
title: User review list
schemaName: userReviewList
schemaType: Query
---

Retrieve all reviews added by the authenticated user across stations by using the userReviewList query. This is useful when you want to display a user's own review history. This is a premium feature, contact us for more information.

## Query

An `x-token` header is required to authorize the user whose reviews you want to retrieve. Use the `size` and `page` arguments to [paginate](/docs/pagination) through them.
