Get the details of a previously calculated truck route by using the getTruckRoute query. This is useful when you want to display a truck route's charging stops, distance, and duration.

## Query

A truck route `id` is required to get route details. The `id` can be obtained through the [createTruckRoute mutation](/api-reference/truck-route/mutation-create-truck-route).
