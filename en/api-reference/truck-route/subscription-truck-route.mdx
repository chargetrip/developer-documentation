Subscribe to a truck route by using the truckRoute subscription. This is useful when you want to receive real-time updates as an e-truck route is calculated.

## Subscription

A truck route `id` is required to subscribe to its updates. The `id` can be obtained through the [createTruckRoute mutation](/api-reference/truck-route/mutation-create-truck-route).
