Get the list of connected vehicles for the current user by using the connectedVehicleList query. This is useful when you want to display all vehicles a user has connected to a provider.

## Query

No input is required to execute this query. Use `filter` to narrow the results down by status, and the `size` and `page` arguments to [paginate](/api-reference/api/pagination) through them.
