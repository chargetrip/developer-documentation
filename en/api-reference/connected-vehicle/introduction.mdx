A navigation application for electric vehicles needs real-time vehicle data, such as the state of charge, to plan routes with. Almost all EVs on the road today have a modem that can send this data to external applications, but the standards and the ways of exposing it differ between vendors.

Vehicle connectivity brings that data into your application through a single source. An abstraction layer ingests, sanitizes and prepares the data from many vendors for the routing engine, and a brandable landing page lets your users authenticate and give consent. It works with your current connected vehicle data vendor, telemetry API or OBD-II dongle, and is pre-integrated with [Enode](https://enode.io).

To get access, or to use a different data provider or your own API, contact [sales@chargetrip.com](mailto:sales@chargetrip.com).

## Supported data sources

Connected vehicle data platform
: Cloud solutions that connect to the APIs of vehicle manufacturers and expose that data to third parties. They handle vehicle owner consent and standardize the data format. Supported brands and pricing differ significantly between platforms. This suits app developers, for example for a CPO or eMSP. Supported platforms are [Enode](https://enode.io), [High Mobility](https://high-mobility.com), [Smartcar](https://smartcar.com), and [WirelessCar](https://wirelesscar.com).

Hardware dongle
: Bluetooth dongles that are installed manually in the vehicle. They have a relatively high upfront cost but low recurring costs, which makes them popular with logistics fleet operators. The [Geotab Go9](https://support.geotab.com/go-devices/go9/doc/go9-document) is supported globally.

Your own API or a brand-specific API
: A vehicle manufacturer may broadcast vehicle data over the vehicle modem and expose it through an API. This also applies if you only want to support a specific vehicle brand. [Available on request](mailto:sales@chargetrip.com).

Another telemetry data provider
: Added through a custom data integration flow. [Available on request](mailto:sales@chargetrip.com).
