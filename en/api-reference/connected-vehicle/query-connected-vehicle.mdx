Get the details of a connected vehicle by using the connectedVehicle query. This is useful when you want to check the authorization status of a connected vehicle.

## Query

A connected vehicle `id` is required to get its details. The `id` can be obtained through the [createConnectedVehicle mutation](/api-reference/connected-vehicle/mutation-create-connected-vehicle) or the [connectedVehicleList query](/api-reference/connected-vehicle/query-connected-vehicle-list).
