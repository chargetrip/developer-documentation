Access the full list of charge point operators by using the operatorList query. This is useful when you want to browse or search operators.

## Query

No input is required to execute this query. Use `filter` and `search` to narrow down the results, and the `size` and `page` arguments to [paginate](/api-reference/light-vehicle/api/pagination) through them.
