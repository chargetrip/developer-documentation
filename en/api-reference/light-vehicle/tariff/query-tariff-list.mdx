Access the full list of tariffs by using the tariffList query. This is useful when you want to display or compare charging costs across stations. To learn how to render pricing, see the [station pricing guide](/docs/getting-started/station-pricing).

## Query

No input is required to execute this query. Use the `size` and `page` arguments to [paginate](/api-reference/light-vehicle/api/pagination) through them.
