Subscribe to a route by using the route subscription. This is useful when you want to receive real-time updates as a route is calculated.

## Subscription

A route `id` is required to subscribe to its updates. The `id` can be obtained through the [createRoute mutation](/api-reference/light-vehicle/route/mutation-create-route).
