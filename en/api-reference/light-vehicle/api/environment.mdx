The API uses two distinct endpoints depending on the operation type: an HTTPS URL for queries and mutations, and a WebSocket (WSS) URL for subscriptions.

## Endpoints

### Queries and mutations

Queries and mutations are executed via HTTP POST requests to the main GraphQL endpoint.

```bash GraphQL queries and mutations endpoint URL
https://api.chargetrip.io/graphql
```

### Subscriptions

Subscriptions require a persistent connection over WebSockets and can be implemented by using the `graphql-transport-ws` protocol.

```bash GraphQL subscription URL
wss://api.chargetrip.io/subscription
```

> [!WARNING] graphql-ws protocol is deprecated
> The legacy graphql-ws subscription protocol is deprecated and soon will be removed. Please migrate to the graphql-transport-ws protocol to prevent subscription errors and service disruptions.

### Server-Sent Events

Server-Sent Events (SSE) is an alternative to WebSockets for receiving real-time updates. It is not a subscription type but a different message transport: it streams subscription results over a regular HTTP connection instead of a persistent WebSocket.

```bash Server-Sent Events URL
https://subscription.chargetrip.io/sse
```

## Authorization headers

Add the following headers to each request. Headers marked required must always be sent.

`x-client-id` · <span class="text-accent">required</span>
: A project id that contains the project configuration.

`x-app-id` · <span class="text-accent">required</span>
: An app id for security and splitting up analytics.

`x-app-identifier`
: An iOS or Android bundle identifier.

`x-app-fingerprint`
: An Android SHA fingerprint.

> [!TIP] Secure your keys
> For maximum security, restrict your application to machine-to-machine (M2M) access and keep credentials on your own server behind your own authentication, rather than exposing them to a browser or device. See [Security](/api-reference/light-vehicle/api/security) for all available restriction types.

## Sending an authorized request

By default, a unique `x-app-id` is generated for each project.

```bash Example request
curl -X POST \
  -H "Content-Type: application/json" \
  -H "x-client-id: YOUR_KEY_HERE" \
  -H "x-app-id: YOUR_KEY_HERE" \
  -d '{ "query": "{ } " }' \
  https://api.chargetrip.io/graphql
```
