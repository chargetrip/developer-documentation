---
title: Async operations
description: "Learn how asynchronous operations work in the API: create with a mutation, then track and retrieve the result with a subscription or query."
---

Some operations, like creating a route or a matched route, run asynchronously to keep the API responsive. Rather than waiting for a mutation to return the full result, you get an `id` right away and follow up to track and retrieve it.

## How it works

1. **Create**
   Call the mutation. It returns an `id` right away, which you use in the next step to track and retrieve the result.
2. **Open a subscription**
   Subscribe using the `id` from the previous step. While the result is being calculated, the subscription pushes status updates you can use to drive an async loading state in your UI.
3. **Render the result**
   Once `status` resolves to a final value, render the corresponding UI for that outcome.
4. **Re-fetch a finished result**
   Once a result reaches a final status, it's already precomputed. If you need it again later, for example after navigating back to it, use the matching query instead of opening a new subscription.
