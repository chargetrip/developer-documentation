Get the emissions profile of a route by using the getRouteEmissions query. This is useful when you want to display the environmental impact of a journey.

## Query

A `route_id` and `route_details_id` are required to get a route's emissions. Both can be obtained through the [getRoute query](/api-reference/light-vehicle/route/query-get-route).
