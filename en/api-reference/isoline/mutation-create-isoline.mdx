Create a consumption-based isoline by using the createIsoline mutation. This is useful when you want to visualize the area a vehicle can reach from a given point, for example as a range map. The [vehicle range guide](/docs/getting-started/vehicle-range) shows how to turn the result into shapes you can place on a map.

## Mutation

A `vehicle_id` and `origin` are required to create an isoline. Optionally add `state_of_charge`, `polygon_count`, or other preferences to refine the calculation. The mutation returns an isoline `id`, which can be used to retrieve isoline details or subscribe to updates.
