---
title: Create matched route
schemaName: createMatchedRoute
schemaType: Mutation
---

Create a route from a sequence of GPS points by using the createMatchedRoute mutation. This is most useful when you already have a route based on your own business rules and want to add charging stops and calculate energy consumption on top of it.

## Mutation

A `vehicle` and at least two chronological `points` are required to create a matched route. Optionally add `via` points, `departure_time`, `weather`, `driving_preferences`, `operators`, or `alternative_station_radius` to refine the calculation. Set `plan_charging_stops` to find and plan charging stops if the vehicle's state of charge reaches the threshold at any point along the route. The mutation returns a matched route `id`, which can be used to retrieve route details or subscribe to updates.
