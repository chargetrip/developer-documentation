Create a new route by using the createRoute mutation. This is useful when you want to calculate charging stops, energy consumption, and drive time between an origin and a destination. If you're new to routing, the [route guide](/docs/getting-started/route) takes you from a first request to a customized route. From there, you can [steer which charging networks a route prefers](/docs/getting-started/route-operators) with operator preferences, or [shape the trip around your own waypoints](/docs/getting-started/route-stop) with via stops.

## Mutation

A `vehicle`, `origin`, and `destination` are required to create a route. Optionally add `via` points, `operators`, `weather`, or other preferences to refine the calculation. The mutation returns a route `id`, which can be used to retrieve route details, emissions, or amenities along the way.
