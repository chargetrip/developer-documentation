Get the details of a previously calculated matched route by using the getMatchedRoute query. This is useful when you want to re-fetch a matched route without opening a new subscription.

## Query

A matched route `id` is required to get route details. The `id` can be obtained through the [createMatchedRoute mutation](/api-reference/core/matched-route/mutation-create-matched-route).
