Subscribe to a matched route by using the matchedRoute subscription. This is useful when you want to receive real-time updates as a matched route is calculated.

## Subscription

A matched route `id` is required to subscribe to its updates. The `id` can be obtained through the [createMatchedRoute mutation](/api-reference/core/matched-route/mutation-create-matched-route).
