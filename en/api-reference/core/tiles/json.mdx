The JSON tile service provides access to station-related geographic data in JSON format.

## Setup

To access the station data in JSON format, send a request to the following endpoint:

```bash Tile / JSON / Base URL
https://api.chargetrip.io/v2/station/{z}/{x}/{y}/tile.json
```

The JSON URL uses the following path parameters:

- `z`: The zoom level of the tile.
- `x`: The x-coordinate of the tile.
- `y`: The y-coordinate of the tile.

Most map providers have built-in methods to convert latitude and longitude to pixel coordinates. To manually convert latitude and longitude coordinates to x and y, use the [Web Mercator Projection](https://en.wikipedia.org/wiki/Web_Mercator_projection).

### Filtering
Use the `filter` query parameter to filter the stations returned based on specific criteria. See the [filters documentation](/api-reference/core/tiles/filters) for more information.

### Selectors
Use the `station_properties[]` query parameter to specify the fields returned for each station feature. See the [selectors documentation](/api-reference/core/tiles/selectors) for more information.

## Response
The API returns a GeoJSON `FeatureCollection` containing the mandatory GeoJSON fields (id, type, geometry, and properties). Each item in `features` represents either an individual station (`count: 1`) or a station cluster (`count > 1`).



`id` · `string` · <span class="text-accent">mandatory</span>
: The unique identifier of the station. Only returned on individual station features.

`type` · `string` · <span class="text-accent">mandatory</span>
: Always set to `"Feature"`.

`geometry` · `object` · <span class="text-accent">mandatory</span>
: Standard GeoJSON `Point` geometry containing `[longitude, latitude]` coordinates.

`properties` · `object` · <span class="text-accent">mandatory</span>
: Feature attributes. By default, station features return `{ "count": 1 }` and cluster features return `{ "count": N, "expansion_zoom": Z }`. Additional station fields can be requested using [selectors](/api-reference/core/tiles/selectors).

The fields returned inside `properties` depend on the feature type and the selectors provided:

- Cluster features: always return `{ "count": N, "expansion_zoom": Z }`.

- Station features: return `{ "count": 1 }` if no selectors are provided, or only the requested fields if [selectors](/api-reference/core/tiles/selectors) are provided.

### Currency
Use the `currency` query parameter to set the currency of the energy prices returned and filtered on. See the [currency conversion documentation](/api-reference/core/tiles/filters) for more information.
