Update a connected vehicle by using the updateConnectedVehicle mutation. This is useful when you want to change the label of a connected vehicle.

## Mutation

An `id` is required to update a connected vehicle. Use `label` to set a new label. The `id` can be obtained through the [createConnectedVehicle mutation](/api-reference/core/connected-vehicle/mutation-create-connected-vehicle).
