Access the complete vehicle database with the `vehicleList` query. By default the vehicle database uses EU naming for vehicles and plug types.

## Query

No input is required to execute the `vehicleList` query. Use `filter` and `search` to narrow down and customize the results. Use the country parameter in combination with the region filter to return vehicles available in your region with locally known names and plug types here. Use the `size` and `page` arguments to [paginate](/api-reference/core/api/pagination) through them.
