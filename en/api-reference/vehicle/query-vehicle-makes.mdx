Get a list of vehicle makes by using the vehicleMakes query.

## Query
No input is required to execute the vehicleMakes query. Use the `filter` argument to narrow the results down by region and/or type, and the `first` and `after` arguments to [paginate](/api-reference/api/pagination) through them. Use the `country` argument to apply localization to the data.
