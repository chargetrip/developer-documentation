## Route matching

![Route matching](../../../assets/changelog/2026/september.jpg)

We have introduced Route Matching operations, allowing you to map-match external GPS traces and run them through our Routing Engine to calculate energy consumption and insert optimal charging stops.

- Calculate matched routes from coordinate sequences using the new `createMatchedRoute` mutation;
- Designate intermediate stopovers using `vias` defined by coordinate array index (`via.index`), with support for updating vehicle passenger counts and cargo weight dynamically along the journey;
- Enable `plan_charging_stops: true` to evaluate vehicle energy consumption along the pre-determined path and automatically insert compatible charging stops when needed;
- Query full CO₂ emissions profiles for completed matched routes using `getRouteEmissions`.
