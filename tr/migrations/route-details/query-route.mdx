# Rota ayrıntıları

Eski Rota hizmetinden en son sürüme geçin. Yeni hizmet; yeniden düzenlenmiş bir şema, ülke bazlı operatör tercihleri, daha hızlı rota hesaplama ve daha kolay sürdürülebilirlik sunar.

## İşlemler

| Eski               | Yeni                                                  |
| ------------------ | ------------------------------------------------------|
| `route`            | [`getRoute`](/api-reference/route/query-get-route)     |
| `routeUpdatedById`  | [`route`](/api-reference/route/subscription-route)     |

## Genel şema değişiklikleri

- **Açık tür tanımlama**: daha önce esnek olan JSON alanları, yapıyı ve doğrulamayı iyileştirmek için artık şemada açıkça türlendirilmiştir.
- **Adlandırma kuralları**: alanlar artık `camelCase` yerine `snake_case` kullanır.
- **Birim desteği**: sayısal girdiler artık farklı birim türlerini destekler; bunlar `value`, `type` ve isteğe bağlı bir `source` (`manual`, `telemetry` veya `default`) içeren bir nesne olarak ifade edilir.

## Sorgu ve abonelik değişiklikleri

Alan adlandırması ve gruplandırması gözden geçirilmiş, gereksiz alanlar kaldırılmıştır. Yanıt artık varsayılanlarla zenginleştirilmiş özgün girdiyi içerir; böylece gelecekteki rota yeniden hesaplamalarında yeniden kullanılabilir.

### Üst düzey

Üst düzeyde alanların çoğu `recommended` altına taşınır; `ev`, `telemetry` ve `routeRequest` girdileri ise tek bir `request_input` nesnesinde birleştirilir.

| Alan           | Taşındığı yer          |
| -------------- | ---------------------- |
| `route`        | `recommended`          |
| `alternatives` | Kaldırıldı             |
| `ev`           | `request_input`        |
| `telemetry`    | `request_input`        |
| `routeRequest` | `request_input`        |
| `app`          | `meta.app_id`          |
| `status`       | Değişmedi              |

### Rota

Rota düzeyinde alanların çoğu kendi adlarını koruyarak `recommended` altına taşınır; birkaç alan ise açıkça yeniden adlandırılır.

| Alan                  | Taşındığı yer                        |
| --------------------- | ------------------------------------ |
| `rangeStart*`         | `range_at_origin`                    |
| `rangeEnd*`           | `range_at_destination`               |
| `charges`             | `recommended.charges`                |
| `distance`            | `recommended.distance`               |
| `consumption`         | `recommended.consumption`            |
| `chargeTime`          | `recommended.durations.charging`     |
| `polyline`            | `recommended.polyline`               |
| `pathPlot`            | `recommended.path_plot`              |
| `legs`                | `recommended.legs`                   |
| `tags`                | `recommended.tags`                   |
| `instructions`        | Kaldırıldı                           |
| `amenityRanking`      | Kaldırıldı                           |
| `stationsAlongRoute`  | `recommended.alternative_stations`   |

### Bölümler (legs)

Bölüm düzeyinde menzil alanları rotayla aynı yeniden adlandırmayı izler; yolcu ve kargo ayrıntıları ise her bölümün `origin` ve `via` konum özelliklerine taşınır.

| Alan          | Taşındığı yer                           |
| ------------- | --------------------------------------- |
| `rangeStart*` | `range_at_origin`                       |
| `rangeEnd*`   | `range_at_destination`                  |
| `steps`       | `sections`                              |
| `stationId`   | `recommended.legs.station.station_id`   |

Bölümlere ayrıca yeni bir `range_after_charge` alanı da eklenmiştir.

## Öne çıkan değişiklikler

Yanıt ayrıca rota kesitleri için yeni ve daha yapılandırılmış bir şekil sunar. Bu aşağıda daha ayrıntılı olarak ele alınmıştır.

### Kesitler

Adımlar (steps), her kesit için başlangıç ve varış ayrıntıları dahil daha ayrıntılı bilgi sağlayan kesitlerle (sections) değiştirilmiştir.

```graphql Kesitler {{ mark: [1,13,14,26,27] }}
sections {
  type
  tags
  polyline(decimals: five)
  distance(unit: meter)
  duration
  consumption
  origin {
    id
    type
    properties {
      occupants
      total_occupant_weight
      total_cargo_weight
    }
    geometry {
      type
      coordinates
    }
  }
  destination {
    id
    type
    properties {
      occupants
      total_occupant_weight
      total_cargo_weight
    }
    geometry {
      coordinates
      type
    }
  }
}
```
