# Rota ayrıntıları

Şu tarihten önce geçiş yapın: 2027 1. Çeyrek

Eski Rota hizmetinden en son sürüme geçin. Yeni hizmet yeniden düzenlenmiş bir şema, ülke bazında operatör tercihleri, daha hızlı rota hesaplama ve daha iyi sürdürülebilirlik sunar.

## İşlemler

| Eski                | Yeni                                                   |
| ------------------ | ------------------------------------------------------|
| `route`            | [`getRoute`](/api-reference/core/route/query-get-route)     |
| `routeUpdatedById`  | [`route`](/api-reference/core/route/subscription-route)     |

## Genel şema değişiklikleri

- **Açık tür tanımları**: daha önce esnek olan JSON alanları, yapıyı ve doğrulamayı iyileştirmek için artık şemada açıkça türlendirilmiştir.
- **Adlandırma kuralları**: alanlar artık `camelCase` yerine `snake_case` kullanır.
- **Birim desteği**: sayısal girdiler artık farklı birim türlerini destekler ve `value`, `type` ile isteğe bağlı bir `source` (`manual`, `telemetry` veya `default`) içeren bir nesne olarak ifade edilir.

## Sorgu ve abonelik değişiklikleri

Alan adlandırması ve gruplandırması gözden geçirilmiş, gereksiz alanlar kaldırılmıştır. Yanıt artık varsayılanlarla zenginleştirilmiş özgün girdiyi içerir; böylece gelecekteki rota yeniden hesaplamalarında yeniden kullanılabilir.

### Üst düzey

Üst düzeyde alanların çoğu `recommended` altına taşınır ve `ev`, `telemetry` ile `routeRequest` girdileri tek bir `request_input` nesnesinde birleştirilir.

| Alan          | Taşındığı yer               |
| -------------- | ---------------------- |
| `route`        | `recommended`          |
| `alternatives` | Kaldırıldı                |
| `ev`           | `request_input`        |
| `telemetry`    | `request_input`        |
| `routeRequest` | `request_input`        |
| `app`          | `meta.app_id`          |
| `status`       | Değişmedi              |

### Rota

Rota düzeyinde alanların çoğu, birkaç açık yeniden adlandırmayla birlikte kendi adlarını koruyarak `recommended` altına taşınır.

| Alan                 | Taşındığı yer                             |
| --------------------- | ------------------------------------ |
| `rangeStart*`         | `range_at_origin`                    |
| `rangeEnd*`           | `range_at_destination`               |
| `charges`             | `recommended.charges`                |
| `distance`            | `recommended.distance`               |
| `consumption`         | `recommended.consumption`            |
| `chargeTime`          | `recommended.durations.charging`     |
| `polyline`            | `recommended.polyline`               |
| `pathPlot`            | `recommended.path_plot`              |
| `legs`                | `recommended.legs`                   |
| `tags`                | `recommended.tags`                   |
| `instructions`        | Kaldırıldı                              |
| `amenityRanking`      | Kaldırıldı                              |
| `stationsAlongRoute`  | `recommended.alternative_stations`   |

### Bölümler

Bölüm düzeyinde menzil alanları rotayla aynı yeniden adlandırmayı izler; yolcu ve yük ayrıntıları ise her bölümün `origin` ve `via` konum özelliklerine taşınır.

| Alan         | Taşındığı yer                               |
| ------------- | --------------------------------------- |
| `rangeStart*` | `range_at_origin`                       |
| `rangeEnd*`   | `range_at_destination`                  |
| `steps`       | `sections`                              |
| `stationId`   | `recommended.legs.station.station_id`   |

Bölümlere ayrıca yeni bir `range_after_charge` alanı eklenir.

## Öne çıkan değişiklikler

Yanıt ayrıca rota kesimleri için yeni, daha yapılandırılmış bir biçim sunar. Aşağıda daha ayrıntılı olarak ele alınmıştır.

### Kesimler

Adımların yerini, her kesim için başlangıç ve varış ayrıntıları dahil daha ayrıntılı bilgi sağlayan kesimler (sections) almıştır.

```graphql Sections {{ mark: [1,13,14,26,27] }}
sections {
  type
  tags
  polyline(decimals: five)
  distance(unit: meter)
  duration
  consumption
  origin {
    id
    type
    properties {
      occupants
      total_occupant_weight
      total_cargo_weight
    }
    geometry {
      type
      coordinates
    }
  }
  destination {
    id
    type
    properties {
      occupants
      total_occupant_weight
      total_cargo_weight
    }
    geometry {
      coordinates
      type
    }
  }
}
```
