# Rota oluşturma

Şu tarihten önce geçiş yapın: 2027 Q1

Eski Rota hizmetinden en son sürüme geçin. Yeni hizmet; yeniden düzenlenmiş bir şema, ülke bazlı operatör tercihleri, daha hızlı rota hesaplama ve daha kolay sürdürülebilirlik sunar.

## İşlemler

| Eski              | Yeni                                                            |
| ----------------- | ----------------------------------------------------------------|
| `newRoute`        | [`createRoute`](/api-reference/core/route/mutation-create-route)     |

## Genel şema değişiklikleri

- **Açık tür tanımlama**: daha önce esnek olan JSON alanları, yapıyı ve doğrulamayı iyileştirmek için artık şemada açıkça türlendirilmiştir.
- **Adlandırma kuralları**: alanlar artık `camelCase` yerine `snake_case` kullanır.
- **Birim desteği**: sayısal girdiler artık farklı birim türlerini destekler; bunlar `value`, `type` ve isteğe bağlı bir `source` (`manual`, `telemetry` veya `default`) içeren bir nesne olarak ifade edilir.

## Mutasyon değişiklikleri

`createRoute` üzerindeki `input` argümanı yeniden düzenlenmiş ve basitleştirilmiştir.

### routeRequest

Kök düzeyinde aşağıdaki alanlar kaldırılmıştır. Operatörle ilgili alanlar artık [operatör tercihleri](#operatör-tercihleri) kapsamındadır, olanakla ilgili alanlar ise kendi özel [olanak sorgusuna](/api-reference/core/route/query-get-route-stations-with-amenities) taşınmıştır.

| Alan                   | Taşındığı yer                          |
| ---------------------- | -------------------------------------- |
| `operatorIds`          | Kaldırıldı                             |
| `amenities`            | Kaldırıldı                             |
| `amenity_preferences`  | Kaldırıldı                             |
| `operatorRequired`     | Kaldırıldı                             |
| `operatorPrefer`       | Kaldırıldı                             |

### EV

EV düzeyinde, üst düzey alanların çoğu özel bir `vehicle` nesnesine taşınmıştır.

| Alan              | Taşındığı yer                          |
| ----------------- | -------------------------------------- |
| `ev.id`           | `vehicle.id`                     |
| `battery`         | `vehicle`                        |
| `climate`         | `vehicle`                        |
| `heat_pump`       | `vehicle`                        |
| `plugs`           | `vehicle.charging.connectors`    |
| `safeRiskMargin`       | `vehicle.charging.risk_margin`   |
| `chargeMode`           | `vehicle.charging.mode`          |
| `bmsConsumption`  | Kaldırıldı                             |

### Araç yükü

Araç yükü özellikleri artık tek bir yerde ayarlanmaz. Bunlar artık her `origin` ve `via` noktası için ayrı ayrı belirtilir ve bölüm başına yolcu ve kargo ağırlığı üzerinde daha ayrıntılı kontrol sağlar. Her konumda `properties.vehicle` altında yer alırlar ve alan adları şu şekilde değişir:

| Alan        | Taşındığı yer         |
| ----------- | --------------------- |
| `occupants` | Değişmedi              |
| `cargo`     | `total_cargo_weight`  |

### Telemetri

Aşağıdaki telemetri verileri kök düzeyinden `vehicle` nesnesine taşınmıştır.

| Alan                  | Taşındığı yer    |
| --------------------- | ---------------- |
| `heading`             | `vehicle`  |
| `motor_rpm`           | `vehicle`  |
| `odometer`            | `vehicle`  |
| `outside_temperature` | `vehicle`  |
| `tire_pressure`       | `vehicle`  |
| `vehicle_speed`       | `vehicle`  |

## Öne çıkan değişiklikler

`input` argümanındaki birkaç alan artık yeni ve daha yapılandırılmış şekillere sahiptir. Bunlar aşağıda daha ayrıntılı olarak ele alınmıştır.

### Operatör tercihleri

Operatör tercihleri üç seviyeye indirilmiştir: `high`, `medium` ve `low`. Her giriş; sıralanmış, hariç tutulmuş veya kaçınılmış olsun, `countries` alanı aracılığıyla belirli ülkelere göre kapsamlandırılabilir. Belirtilmezse tüm ülkeler dikkate alınır.

```graphql Operatör tercihleri {{ mark: [6,9,12] }}
input: {
  operators: {
    ranking: {
      type: preferred
      levels: {
        high: [
          {
            id: "op1"
            countries: [NL]
          }
        ]
        low: [
          {
            id: "op3"
          }
        ]
      }
    }
  }
}
```

### Toplam yolcu ağırlığı

Yeni bir `total_occupant_weight` alanı, varsayılan yolcu ağırlığını yeni birim nesnesiyle ifade ederek geçersiz kılmanıza olanak tanır.

```graphql Toplam yolcu ağırlığı {{ mark: [6,7,8,9,10] }}
input: {
  origin: {
    properties: {
      vehicle: {
        occupants: 3
        total_occupant_weight: {
          value: 160
          type: kilogram
          source: manual
        }
      }
    }
  }
}
```
