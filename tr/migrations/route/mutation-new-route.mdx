# Rota oluştur

Şu tarihten önce geçiş yapın: 2027 1. Çeyrek

Eski Rota hizmetinden en son sürüme geçin. Yeni hizmet yeniden düzenlenmiş bir şema, ülke bazında operatör tercihleri, daha hızlı rota hesaplama ve daha iyi sürdürülebilirlik sunar.

## İşlemler

| Eski               | Yeni                                                             |
| ----------------- | ----------------------------------------------------------------|
| `newRoute`        | [`createRoute`](/api-reference/core/route/mutation-create-route)     |

## Genel şema değişiklikleri

- **Açık tür tanımları**: daha önce esnek olan JSON alanları, yapıyı ve doğrulamayı iyileştirmek için artık şemada açıkça türlendirilmiştir.
- **Adlandırma kuralları**: alanlar artık `camelCase` yerine `snake_case` kullanır.
- **Birim desteği**: sayısal girdiler artık farklı birim türlerini destekler ve `value`, `type` ile isteğe bağlı bir `source` (`manual`, `telemetry` veya `default`) içeren bir nesne olarak ifade edilir.

## Mutasyon değişiklikleri

`createRoute` üzerindeki `input` argümanı yeniden düzenlenmiş ve basitleştirilmiştir.

### routeRequest

Kök düzeyde aşağıdaki alanlar kaldırılmıştır. Operatörle ilgili alanlar artık [operatör tercihleri](#operatör-tercihleri) kapsamındadır ve olanakla ilgili alanlar kendi özel [olanak sorgusuna](/api-reference/core/route/query-get-route-stations-with-amenities) taşınmıştır.

| Alan                  | Taşındığı yer                              |
| ---------------------- | -------------------------------------- |
| `operatorIds`          | Kaldırıldı                                |
| `amenities`            | Kaldırıldı                                |
| `amenity_preferences`  | Kaldırıldı                                |
| `operatorRequired`     | Kaldırıldı                                |
| `operatorPrefer`       | Kaldırıldı                                |

### EV

EV düzeyinde üst düzey alanların çoğu özel bir `vehicle` nesnesine taşınmıştır.

| Alan             | Taşındığı yer                              |
| ----------------- | -------------------------------------- |
| `ev.id`           | `vehicle.id`                     |
| `battery`         | `vehicle`                        |
| `climate`         | `vehicle`                        |
| `heat_pump`       | `vehicle`                        |
| `plugs`           | `vehicle.charging.connectors`    |
| `safeRiskMargin`       | `vehicle.charging.risk_margin`   |
| `chargeMode`           | `vehicle.charging.mode`          |
| `bmsConsumption`  | Kaldırıldı                                |

### Araç yükü

Araç yükü özellikleri artık tek bir yerde ayarlanmaz. Artık her `origin` ve `via` noktası için ayrı ayrı belirtilir ve bölüm başına yolcu ve yük ağırlığı üzerinde daha ayrıntılı kontrol sağlar. Her konumda `properties.vehicle` altında bulunurlar ve alan adları şu şekilde değişir:

| Alan       | Taşındığı yer             |
| ----------- | --------------------- |
| `occupants` | Değişmedi              |
| `cargo`     | `total_cargo_weight`  |

### Telemetri

Aşağıdaki telemetri verileri kök düzeyden `vehicle` nesnesine taşınmıştır.

| Alan                 | Taşındığı yer        |
| --------------------- | ---------------- |
| `heading`             | `vehicle`  |
| `motor_rpm`           | `vehicle`  |
| `odometer`            | `vehicle`  |
| `outside_temperature` | `vehicle`  |
| `tire_pressure`       | `vehicle`  |
| `vehicle_speed`       | `vehicle`  |

## Öne çıkan değişiklikler

`input` argümanındaki birkaç alan artık yeni, daha yapılandırılmış biçimlere sahiptir. Bunlar aşağıda daha ayrıntılı olarak ele alınmıştır.

### Operatör tercihleri

Operatör tercihleri üç düzeye indirgenmiştir: `high`, `medium` ve `low`. Sıralanmış, hariç tutulmuş veya kaçınılmış her giriş, `countries` alanı aracılığıyla belirli ülkelerle sınırlandırılabilir. Belirtilmezse tüm ülkeler dikkate alınır.

```graphql Operator preferences {{ mark: [6,9,12] }}
input: {
  operators: {
    ranking: {
      type: preferred
      levels: {
        high: [
          {
            id: "op1"
            countries: [NL]
          }
        ]
        low: [
          {
            id: "op3"
          }
        ]
      }
    }
  }
}
```

### Toplam yolcu ağırlığı

Yeni bir `total_occupant_weight` alanı, yeni birim nesnesiyle ifade edilen varsayılan yolcu ağırlığını geçersiz kılmanıza olanak tanır.

```graphql Total occupant weight {{ mark: [6,7,8,9,10] }}
input: {
  origin: {
    properties: {
      vehicle: {
        occupants: 3
        total_occupant_weight: {
          value: 160
          type: kilogram
          source: manual
        }
      }
    }
  }
}
```
