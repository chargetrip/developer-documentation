connectedVehicleList sorgusunu kullanarak mevcut kullanıcının bağlı araçlarının listesini alın. Bir kullanıcının bir sağlayıcıya bağladığı tüm araçları görüntülemek istediğinizde kullanışlıdır.

## Sorgu

Bu sorguyu çalıştırmak için girdi gerekmez. Sonuçları duruma göre daraltmak için `filter`, sonuçlar arasında [sayfalandırmak](/api-reference/core/api/pagination) için `size` ve `page` argümanlarını kullanın.
