connectedVehicleData sorgusunu kullanarak canlı araç verilerini alın. Şarj durumu veya konum gibi gerçek zamanlı verileri doğrudan bir bağlı araçtan almak istediğinizde kullanışlıdır.

## Sorgu

Canlı verilerini almak için bir bağlı araç `id` değeri gerekir. `id` değerini [createConnectedVehicle mutation'ı](/api-reference/core/connected-vehicle/mutation-create-connected-vehicle) ile alabilirsiniz.
