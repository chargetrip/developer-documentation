connectedVehicleData sorgusunu kullanarak canlı araç verilerini alın. Bu, şarj durumu (SoC) veya konum gibi gerçek zamanlı verileri doğrudan bağlı bir araçtan almak istediğinizde kullanışlıdır.

## Sorgu

Canlı verilerini almak için bir bağlı araç `id` gereklidir. `id`, [createConnectedVehicle mutasyonu](/api-reference/core/connected-vehicle/mutation-create-connected-vehicle) üzerinden alınabilir.
