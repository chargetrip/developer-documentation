navigation sorgusunu kullanarak etkin bir navigasyon oturumunu alın. Bir sürücünün rota üzerindeki mevcut ilerlemesini göstermek istediğinizde kullanışlıdır.

## Sorgu

Ayrıntılarını almak için bir navigasyon oturumu `id` değeri gerekir. `id` değerini [startNavigation mutation'ı](/api-reference/core/navigation/mutation-start-navigation) ile alabilirsiniz.
