schemaName: operatorList
schemaType: Query
---

operatorList sorgusunu kullanarak şarj noktası operatörlerinin tam listesine erişin. Operatörlere göz atmak veya operatörler arasında arama yapmak istediğinizde kullanışlıdır.

## Sorgu

Bu sorguyu çalıştırmak için girdi gerekmez. Sonuçları daraltmak için `filter` ve `search`, sonuçlar arasında [sayfalandırmak](/api-reference/core/api/pagination) için `size` ve `page` argümanlarını kullanın.
