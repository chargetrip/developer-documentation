operator sorgusunu kullanarak bir şarj noktası operatörünün ayrıntılarını alın. Bir istasyonun veya oturumun yanında operatör bilgilerini görüntülemek istediğinizde kullanışlıdır.

## Sorgu

Operatör ayrıntılarını almak için bir operatör `id` değeri gerekir. `id` değerini [operatorList sorgusu](/api-reference/core/operator/query-operator-list) ile alabilirsiniz.
