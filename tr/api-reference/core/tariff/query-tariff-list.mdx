schemaName: tariffList
schemaType: Query
---

tariffList sorgusunu kullanarak tarifelerin tam listesine erişin. Bu, istasyonlar arasındaki şarj maliyetlerini göstermek veya karşılaştırmak istediğinizde kullanışlıdır. Fiyatların nasıl gösterileceğini öğrenmek için [istasyon fiyatlandırma kılavuzuna](/docs/getting-started/station-pricing) bakın.

## Sorgu

Bu sorguyu çalıştırmak için herhangi bir girdi gerekmez. Sonuçlar arasında [sayfalandırma](/api-reference/core/api/pagination) yapmak için `size` ve `page` argümanlarını kullanın.
