vehicle sorgusunu kullanarak araç özelliklerini alın.

## Sorgu

Araç ayrıntılarını almak için bir araç `id` gereklidir. `id`, [vehicleList sorgusu](/api-reference/core/vehicle/query-vehicles) üzerinden alınabilir. Verilere yerelleştirme uygulamak için country argümanını kullanın.
