Filtreler, uygulamaların Tile Service API tarafından döndürülen şarj istasyonlarını daraltmasına olanak tanır. Eşleşmeyen sonuçları gizlemenin ötesinde, bazı filtreler yanıtın bağlama uygun olması için istasyon verilerini de dönüştürür.

## Filtreler verileri nasıl etkiler

Bir istek filtreler içerdiğinde Tile servisi iki ayrı işlem gerçekleştirir:

1. **Eşleşmeyen istasyonların hariç tutulması**
   Belirtilen filtreleme ölçütlerini karşılamayan tüm istasyonlar yanıttan tamamen çıkarılır. Bu işlem, istasyon düzeyi filtreler veya EVSE düzeyi filtreler kullanıldığında gerçekleşir.
2. **Veri dönüştürme**
   Belirli filtreleme parametreleri verildiğinde Tile Service, istasyonun bazı dinamik özelliklerini yeniden hesaplar. Bu işlem, EVSE düzeyi filtreler kullanıldığında gerçekleşir.

## Uygulama

Filtre parametreleri, Tile Service uç noktalarının herhangi birine (MVT, JSON veya Count) sorgu dizeleri olarak istek URL'sine eklenebilir. Hiçbir filtre uygulanmazsa mevcut tüm şarj istasyonları döndürülür ve hiçbir veri dönüştürmesi yapılmaz.

```bash Tile / Filter / Example
https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?{filter_1}&{filter_2}&{filter_n}
```

## Düzeyler

Filtreler iki düzeyde bulunabilir: EVSE düzeyi veya istasyon düzeyi. Her birinin etkisi ve sonuçları aşağıda açıklanmıştır.

### İstasyon düzeyi

İstasyonun genel özelliklerini değerlendiren filtrelerdir. Bu filtreler yalnızca hariç tutma yapar: eşleşmeyen istasyonları dışarıda bırakır ancak döndürülen veri alanlarını asla değiştirmez.

`amenities` · `enum` · [Örnek URL'yi göster](tip:https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?amenities[]=HOTEL)
: Yalnızca belirtilen olanakları sunan istasyonları dahil eden filtre.
: `HOTEL`, `SHOPPING`, `BATHROOM`, `SUPERMARKET`, `PLAYGROUND`, `PHARMACY`, `MUSEUM`, `COFFEE`, `PARK`, `RESTAURANT`

`preferred_operators` · `boolean` · [Örnek URL'yi göster](tip:https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?preferred_operators=true)
: Yalnızca tercih edilen olarak yapılandırılmış operatörler tarafından işletilen istasyonları dahil eden filtre. Tercih edilen operatörler dashboard'daki proje ayarlarından belirlenebilir.
: `true`, `false`

`hide_excluded_operators` · `boolean` · [Örnek URL'yi göster](tip:https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?hide_excluded_operators=true)
: Yalnızca hariç tutulan olarak yapılandırılmış operatörler tarafından işletilen istasyonları dışarıda bırakan filtre. Hariç tutulan operatörler dashboard'daki proje ayarlarından belirlenebilir.
: `true`, `false`

`operator_ids` · `string` · [Örnek URL'yi göster](tip:https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?operator_ids[]=631834841e604d2273ffb2b5&operator_ids[]=64e6979d49ed0ae2316ec052)
: Yalnızca belirli operatör kimlikleri tarafından işletilen istasyonları dahil eden filtre. Operatör kimliklerinden oluşan bir dizi kabul eder.

`truck_dedicated` · `boolean` · [Örnek URL'yi göster](tip:https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?truck_dedicated=true)
: Yalnızca kamyon şarjına ayrılmış veya öncelikli olarak kamyon şarjı için tasarlanmış istasyonları dahil eden filtre. Yalnızca Eco-Movement istasyon veritabanı kullanılıyorsa geçerlidir; aksi halde yok sayılır.
: `true`, `false`

`vehicle_types` · `enum` · [Örnek URL'yi göster](tip:https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?vehicle_types[]=VAN&vehicle_types[]=RIGID)
: Yalnızca belirtilen OCPI araç tiplerini destekleyen istasyonları dahil eden filtre. Varsayılan olarak tüm araç tipleri dahildir. Yalnızca Eco-Movement istasyon veritabanı kullanılıyorsa geçerlidir; aksi halde yok sayılır.
: `VAN`, `RIGID`, `TRUCK_WITH_TRAILER`

### EVSE düzeyi

İstasyonun belirli şarj yeteneklerini değerlendiren filtrelerdir. Bu filtreler hariç tutma ve [dönüştürme](/api-reference/core/tiles/filters#veri-dönüştürme-örnekleri) yapar: eşleşmeyen istasyonlar hariç tutulur ve eşleşen istasyonların dinamik alanları yeniden hesaplanır.

`minimum_power` · `integer` · [Örnek URL'yi göster](tip:https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?minimum_power=50)
: Yalnızca en az bir konektörü belirtilen güç değerine (kW cinsinden) ulaşan veya bu değeri aşan istasyonları dahil eden filtre. 0'dan büyük bir tam sayı kabul eder.

`maximum_power` · `integer` · [Örnek URL'yi göster](tip:https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?maximum_power=150)
: Yalnızca hiçbir konektörünün maksimum şarj gücü belirtilen güç değerini (kW cinsinden) aşmayan istasyonları dahil eden filtre. 0'dan büyük bir tam sayı kabul eder.

`minimum_energy_price` · `number` · [beta](tip:Beta;;Bu filtre beta aşamasındadır ve kararlı hale gelmeden önce değişebilir.) · [Örnek URL'yi göster](tip:https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?minimum_energy_price=0.2&currency=EUR)
: Yalnızca uyumlu konektörlerinden en az birinin etkin fiyatı belirtilen değerden büyük veya ona eşit olan istasyonları dahil eden filtre; değerlendirme `currency` ile belirlenen para biriminde yapılır. Bkz. [istasyon fiyatlandırması](/docs/getting-started/station-pricing). Yalnızca Eco-Movement istasyon veritabanı kullanılıyorsa geçerlidir; aksi halde yok sayılır.

`maximum_energy_price` · `number` · [beta](tip:Beta;;Bu filtre beta aşamasındadır ve kararlı hale gelmeden önce değişebilir.) · [Örnek URL'yi göster](tip:https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?maximum_energy_price=0.5&currency=EUR)
: Yalnızca uyumlu konektörlerinden en az birinin etkin fiyatı belirtilen değerden küçük veya ona eşit olan istasyonları dahil eden filtre; değerlendirme `currency` ile belirlenen para biriminde yapılır. Bkz. [istasyon fiyatlandırması](/docs/getting-started/station-pricing). Yalnızca Eco-Movement istasyon veritabanı kullanılıyorsa geçerlidir; aksi halde yok sayılır.

`connectors` · `enum` · [Örnek URL'yi göster](tip:https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?connectors[]=CHADEMO)
: Yalnızca belirtilen konnektör türlerine sahip EVSE'leri bulunan istasyonları dahil eden filtre. Herhangi bir OCPI 2.2.1 konnektör değerini içeren bir dize dizisi kabul eder.
: `CHADEMO`, `DOMESTIC_A`, `DOMESTIC_B`, `DOMESTIC_C`, `DOMESTIC_D`, `DOMESTIC_E`, `DOMESTIC_F`, `DOMESTIC_G`, `DOMESTIC_H`, `DOMESTIC_I`, `DOMESTIC_J`, `DOMESTIC_K`,
`DOMESTIC_L`, `DOMESTIC_M`, `DOMESTIC_N`, `DOMESTIC_O`, `IEC_60309_2_single_16`, `IEC_60309_2_three_16`, `IEC_60309_2_three_32`, `IEC_60309_2_three_64`, `IEC_62196_T1`,
`IEC_62196_T1_COMBO`, `IEC_62196_T2`, `IEC_62196_T2_COMBO`, `IEC_62196_T3A`, `IEC_62196_T3C`, `PANTOGRAPH_BOTTOM_UP`, `PANTOGRAPH_TOP_DOWN`, `TESLA_R`, `TESLA_S`, `GB_T`,
`CHAOJI`, `NEMA_5_20`, `NEMA_6_30`, `NEMA_6_50`, `NEMA_10_30`, `NEMA_10_50`, `NEMA_14_30`, `NEMA_14_50`

`evse_statuses` · `enum` · [Örnek URL'yi göster](tip:https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?evse_statuses[]=AVAILABLE&evse_statuses[]=CHARGING)
: Yalnızca belirtilen durumlara sahip EVSE'leri bulunan istasyonları dahil eden filtre.
: `BLOCKED`, `PLANNED`, `AVAILABLE`, `CHARGING`, `UNKNOWN`, `RESERVED`, `OUT_OF_ORDER`, `INOPERATIVE`

## Para birimi dönüşümü

`currency` sorgu parametresi, Tile Service endpoint'inde (`tile.json`, `tile.mvt` ve `count`) desteklenir. Döndürülen ve filtrelemede kullanılan enerji fiyatlarının para birimini belirler.

- `currency` belirtilmezse `connector_minimum_energy_price` ve `connector_maximum_energy_price` EUR cinsinden döndürülür.
- `currency`, `USD`, `GBP`, `DKK` veya `EUR` gibi geçerli bir ISO 4217 para birimi kodu olduğunda:
  - `connector_minimum_energy_price` ve `connector_maximum_energy_price` içinde döndürülen değerler, sunucu tarafında geçerli dönüşüm oranı kullanılarak kaynak para biriminden istenen para birimine dönüştürülür.
  - `minimum_energy_price` ve `maximum_energy_price` filtreleri, istenen para birimindeki (`currency` belirtilmemişse EUR) dönüştürülmüş fiyatlara göre değerlendirilir.
- Özgün para birimi istenen para birimiyle aynıysa `price_conversion_rate` `1.0` olarak döndürülür.
- `currency` geçerli bir ISO 4217 para birimi kodu değilse tile hizmeti aşağıdaki ayrıntılarla bir hata döndürür:
  - Durum: `400 Bad Request`
  - Kod: `TILE_INVALID_PARAMETER_VALUE`
  - Mesaj: `Invalid parameter 'currency': found string {invalid currency} but expected one of {supported currencies}.`

```bash Example URL
https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?maximum_energy_price=0.5&currency=USD
```

### Veri dönüştürme örnekleri

EVSE düzeyi filtreler uygulandığında bazı çıktılar yeniden hesaplanır. Bu alanlar, kullanıcının arama ölçütleriyle eşleşmeyen konnektörleri yok saymak üzere "dönüştürülür".
Bu "dinamik" çıktı alanları `connector_maximum_power`, `connector_minimum_energy_price`, `connector_maximum_energy_price` ve `evses_*` alanlarıdır.

<details>
  <summary>Aynı filtre türü, farklı değerler</summary>
  İstek bir CHADEMO konnektör filtresi içerir. İstasyon bir CHADEMO konnektörüne sahip olduğu için dahil edilir, ancak dinamik alanlar Combo Type 1 şarj cihazlarını yok sayacak şekilde dönüştürülür.

```bash Example URL
https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?connectors[]=IEC_62196_T1_COMBO&connectors[]=CHADEMO
```

```json Response
{
  "id": "station_a",
  // Static: Remains 150 kW (This represents the station maximum power across all connectors)
  "station_maximum_power": 150,
  // Dynamic: Adjusted to 100 kW (Max power of the CHADEMO connector)
  "connector_maximum_power": 100,
  // Dynamic: Counts the 1 CHADEMO chargers
  "evses_out_of_order": 0,
  // Dynamic: 0, because the charging Type 1 plugs are filtered out
  "evses_available": 1
}
```
</details>

<details>
  <summary>Fiyat filtreleri</summary>
  İstek, isteğe bağlı olarak diğer EVSE düzeyi filtrelerle birleştirilmiş bir `maximum_energy_price` filtresi içerir. Bir konektör yalnızca tüm filtreleri aynı anda karşılıyorsa eşleşir ve dinamik fiyat alanları yalnızca eşleşen konektörler için yeniden hesaplanır.


**Temel istasyon A**

- **EVSE 1:** CCS • 150 kW • Müsait • 0,65 €
- **EVSE 2:** CCS • 50 kW • Müsait • 0,35 €
- **EVSE 3:** Tip 2 • 22 kW • Müsait • 0,25 €

**Senaryo 1: yalnızca fiyat filtresi**

```bash Example URL
https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?maximum_energy_price=0.40
```

Eşleşme: EVSE 2 ve 3 uygundur. EVSE 1 hariç tutulur.

```json Response
{
  "connector_maximum_power": 50,
  "evses_available": 2,
  // Dynamic: lowest price of the matching connectors, not of the entire station
  "connector_minimum_energy_price": 0.25,
  // Dynamic: highest price of the matching connectors, not of the entire station
  "connector_maximum_energy_price": 0.35
}
```

**Senaryo 2: yalnızca konektör filtresi**

```bash Example URL
https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?connectors[]=CCS
```

Eşleşme: EVSE 1 ve 2 uygundur.

```json Response
{
  "connector_maximum_power": 150,
  "evses_available": 2,
  // Dynamic: lowest price of the CCS connectors
  "connector_minimum_energy_price": 0.35,
  // Dynamic: highest price of the CCS connectors
  "connector_maximum_energy_price": 0.65
}
```

**Senaryo 3: fiyat ve konektör filtresi**

```bash Example URL
https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?connectors[]=CCS&maximum_energy_price=0.30
```

Eşleşme:

- `connector == CCS AND price <= 0.30` olarak değerlendirilir.
- CCS konektörleri (EVSE 1 ve 2) 0,65 € ve 0,35 € olduğundan fiyat filtresini karşılamaz.
- Tip 2 konektörü (EVSE 3) fiyatı karşılar ancak konektör filtresini karşılamaz.

Sonuç: İstasyon hariç tutuldu (eşleşen 0 EVSE).

**Senaryo 4: fiyat ve güç filtresi**

```bash Example URL
https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?minimum_power=100&maximum_energy_price=0.40
```

Eşleşme:

- Aynı **EVSE** üzerinde `power >= 100 kW AND price <= 0.40 €` olarak değerlendirilir.
- 150 kW'lık konektör çok pahalıdır (0,65 €).
- Daha ucuz konektörler (0,25 € ile 0,35 € arası) çok yavaştır (50 kW veya daha az).

Sonuç: İstasyon hariç tutuldu (eşleşen 0 EVSE).
</details>
