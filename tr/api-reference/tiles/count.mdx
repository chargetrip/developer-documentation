İstasyon sayısı uç noktası, şarj istasyonlarının toplam sayısını döndürür.

## Kurulum
İstasyon sayısını almak için aşağıdaki URL'ye bir `GET` isteği yapın:

```bash Count / Base URL
https://api.chargetrip.io/v2/station/count
```

### Filtreleme
Sayımı belirli ölçütlere göre daraltmak için `filter` sorgu parametresini kullanın. Daha fazla bilgi için [filtreler belgelerine](/api-reference/tiles/filters) bakın.
