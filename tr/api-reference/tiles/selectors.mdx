Yanıt süresini ve boyutunu optimize etmek için MVT ve JSON API varsayılan olarak küçültülmüş bir yanıt döndürür. Bu yaklaşım en yüksek performansı sağlar ve akıcı harita etkileşimleri için kritik olan karo (tile) yük boyutlarını azaltır. Seçicileri kullanarak, uygulamanızın özellikle ihtiyaç duyduğu ek veri noktalarını dahil edebilirsiniz.

## Kullanılabilir seçiciler

MVT ve JSON karoları için istasyon özelliklerinde listelenen herhangi bir alan, JSON uç noktasında döndürülen zorunlu GeoJSON alanları hariç, ilgili serviste seçici olarak kullanılabilir.

`count` · `integer` · <span class="text-accent">default</span>
: Bir kümedeki istasyon sayısı. 1 olan bir sayı Station özelliğini, 1'den büyük bir sayı ise Cluster özelliğini ifade eder.

`expansion_zoom` · `integer` · <span class="text-accent">default</span>
: Bir kümenin birden fazla daha küçük kümeye veya istasyona ayrıldığı yakınlaştırma seviyesi.

`id` · `string`
: İstasyonun tanımlayıcısı.

`lng` · `float`
: İstasyonun boylamı.

`lat` · `float`
: İstasyonun enlemi.

`station_maximum_power` · `integer`
: İstasyonda sunulan maksimum şarj gücü (kW cinsinden). Bu değer statiktir ve konnektör filtrelerinden bağımsız olarak her zaman istasyonun en yüksek kapasitesini yansıtır.

`connector_maximum_power` · `integer`
: `connectors[]` filtresiyle eşleşen konnektörlerden sunulan maksimum şarj gücü (kW cinsinden). Filtre verilmezse tüm konnektörler dikkate alınır ve değer `station_maximum_power` ile aynı olur.

`preferred_operator` · `boolean`
: Bir istasyonun operatörünün tercih edilen operatör olup olmadığını belirtir. Tercih edilen operatörler Dashboard'da proje düzeyinde yönetilebilir.

`evse_status_blocked` · `integer`
: Engellenmiş durumdaki EVSE sayısı. Bir `connectors[]` filtresi verilirse yalnızca seçilen konnektör türleriyle eşleşen engellenmiş EVSE'leri sayar.

`evse_status_planned` · `integer`
: Planlanmış durumdaki EVSE sayısı. Bir `connectors[]` filtresi verilirse yalnızca seçilen konnektör türlerinden en az birine sahip planlanmış EVSE'leri sayar.

`evse_status_available` · `integer`
: Müsait durumdaki EVSE sayısı. Bir `connectors[]` filtresi verilirse yalnızca seçilen konnektör türlerinden en az birine sahip müsait EVSE'leri sayar.

`evse_status_charging` · `integer`
: Şarj olma durumundaki EVSE sayısı. Bir `connectors[]` filtresi verilirse yalnızca seçilen konnektör türlerinden en az birine sahip şarj olan EVSE'leri sayar.

`evse_status_unknown` · `integer`
: Bilinmeyen durumdaki EVSE sayısı. Bir `connectors[]` filtresi verilirse yalnızca seçilen konnektör türlerinden en az birine sahip durumu bilinmeyen EVSE'leri sayar.

`evse_status_reserved` · `integer`
: Rezerve edilmiş durumdaki EVSE sayısı. Bir `connectors[]` filtresi verilirse yalnızca seçilen konnektör türlerinden en az birine sahip rezerve edilmiş EVSE'leri sayar.

`evse_status_out_of_order` · `integer`
: out_of_order durumundaki EVSE sayısı. Bir `connectors[]` filtresi verilirse yalnızca seçilen konnektör türlerinden en az birine sahip arızalı EVSE'leri sayar.

`evse_status_inoperative` · `integer`
: inoperative durumundaki EVSE sayısı. Bir `connectors[]` filtresi verilirse yalnızca seçilen konnektör türlerinden en az birine sahip çalışmayan EVSE'leri sayar.

## Uygulama

Belirli özellikleri istemek için karo isteği URL'sine `station_properties[]` sorgu parametresini ekleyin.

```bash Tile / Selectors / Example
https://api.chargetrip.io/v2/station/.../?station_properties[]={selector1}&station_properties[]={selector2}&station_properties[]={selector3}
```

## Davranış örnekleri

Seçiciler verildiğinde istek yalnızca belirtilen alanları döndürür.

### GeoJSON

GeoJSON uç noktasında zorunlu GeoJSON alanları (`type`, `geometry` ve `id`), seçilen seçicilerden bağımsız olarak her zaman döndürülür.

```json JSON Selectors example
{
  "type": "FeatureCollection",
  "features": [
    // Station feature
    {
      "id": "132313",
      "type": "Feature",
      "geometry": {
        "type": "Point",
        "coordinates": [6.789, 52.234]
      },
      // 'count' is missing because it wasn't provided as selector
      "properties": {
        "station_maximum_power": 350,
        "preferred_operator": true
      }
    },
    // Cluster feature
    // Cluster feature is not modified, as it's not affected by the selectors.
    {
      "type": "Feature",
      "geometry": {
        "type": "Point",
        "coordinates": [6.723, 50.0]
      },
      "properties": {
        "count": 3,
        "expansion_zoom": 18
      }
    }
  ]
}
```

### MVT

MVT uç noktasında zorunlu alan olmadığından yalnızca açıkça seçilen parametreler döndürülür.

```json MVT Selectors example
// Station feature
// 'count' is missing because it wasn't provided as a selector.
{
  "id": "132313",
  "preferred_operator": false,
  "station_maximum_power": 350
}

// Cluster feature
// Cluster feature is not modified, as it's not affected by the selectors.
{
  "count": 3,
  "expansion_zoom": 32
}
```
