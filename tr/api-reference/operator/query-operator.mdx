schemaType: Query
---

operator sorgusunu kullanarak bir şarj noktası operatörünün ayrıntılarını alın. Bu, operatör bilgilerini bir istasyon veya oturumla birlikte göstermek istediğinizde kullanışlıdır.

## Sorgu

Operatör ayrıntılarını almak için bir operatör `id` gereklidir. `id`, [operatorList sorgusu](/api-reference/operator/query-operator-list) üzerinden alınabilir.
