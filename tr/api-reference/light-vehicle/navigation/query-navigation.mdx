navigation sorgusunu kullanarak etkin bir navigasyon oturumunu alın. Bu, bir sürücünün rota boyunca mevcut ilerlemesini göstermek istediğinizde kullanışlıdır.

## Sorgu

Ayrıntılarını almak için bir navigasyon oturumu `id` gereklidir. `id`, [startNavigation mutasyonu](/api-reference/light-vehicle/navigation/mutation-start-navigation) üzerinden alınabilir.
