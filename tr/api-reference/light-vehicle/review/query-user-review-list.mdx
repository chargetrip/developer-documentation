userReviewList sorgusunu kullanarak kimliği doğrulanmış kullanıcının istasyonlar genelinde eklediği tüm incelemeleri alın. Bu, bir kullanıcının kendi inceleme geçmişini göstermek istediğinizde kullanışlıdır. Bu bir premium özelliktir. Daha fazla bilgi için bizimle iletişime geçin.

## Sorgu

İncelemelerini almak istediğiniz kullanıcıyı yetkilendirmek için `x-token` başlığı gereklidir. Bunlar arasında [sayfalandırma](/api-reference/light-vehicle/api/pagination) yapmak için `size` ve `page` argümanlarını kullanın.
