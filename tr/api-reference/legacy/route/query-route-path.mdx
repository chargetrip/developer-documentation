---
title: Rota yolu sorgusu
heading: Rota yolu
description: "Rotanın polyline çizgisini haritada göstermek için routePath sorgusuyla daha önce hesaplanmış rotanın yolunu alın."
schemaName: routePath
schemaType: Query
---

routePath sorgusunu kullanarak daha önce hesaplanmış bir rotanın yolunu alın. Bu, bir rotanın çoklu çizgisini (polyline) haritada göstermek istediğinizde kullanışlıdır.
