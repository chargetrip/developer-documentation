Eski routeUpdatedById aboneliğini kullanarak bir rotaya abone olun ve hesaplanırken gerçek zamanlı güncellemeler alın. Yeni entegrasyonlar bunun yerine [route aboneliğini](/api-reference/route/subscription-route) kullanmalıdır.
