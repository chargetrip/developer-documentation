Eski tariffList sorgusunu kullanarak tarifelerin tam listesine erişin. Yeni entegrasyonlar bunun yerine [stationPrices sorgusunu](/api-reference/core/station-pricing/query-station-prices) kullanmalıdır.

## Sorgu

Bu sorguyu çalıştırmak için herhangi bir girdi gerekmez. Sonuçlar arasında [sayfalandırma](/api-reference/core/api/pagination) yapmak için `size` ve `page` argümanlarını kullanın.
