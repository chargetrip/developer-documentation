---
title: Tarife listesi
schemaName: tariffList
schemaType: Query
---

tariffList sorgusunu kullanarak tarifelerin tam listesine erişin. Bu, istasyonlar arasındaki şarj maliyetlerini göstermek veya karşılaştırmak istediğinizde kullanışlıdır.

## Sorgu

Bu sorguyu çalıştırmak için herhangi bir girdi gerekmez. Sonuçlar arasında [sayfalandırma](/api-reference/api/pagination) yapmak için `size` ve `page` argümanlarını kullanın.
