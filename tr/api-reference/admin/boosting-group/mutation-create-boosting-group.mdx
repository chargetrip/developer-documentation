createBoostingGroup mutasyonunu kullanarak bir öne çıkarma grubu oluşturun. Bu, rotaları, örneğin daha avantajlı bir ticari anlaşma nedeniyle, belirli şarj istasyonlarına yönlendirmek istediğinizde kullanışlıdır. Etkin gruplar, [createRoute](/api-reference/light-vehicle/route/mutation-create-route) ile hesapladığınız her rotaya otomatik olarak uygulanır. Ayrıntılar için [öne çıkarma grupları kılavuzuna](/docs/getting-started/route-boosting-groups) bakın.

## Mutasyon

Bir `name`, bir `client_id` ve bir `stations` listesi gereklidir. Her istasyonu `id` değeriyle veya istasyon sağlayıcınızın kullandığı `external_id` değeriyle tanımlayın. Grubu henüz rota hesaplamada kullanmadan oluşturmak için `status` değerini `inactive` yapın.

> [!WARNING] Alpha
> Bu işlem alpha aşamasındadır ve ücretsiz planlarda kullanılamaz. Erişim için destekle iletişime geçin.

<details>
  <summary>İki istasyonlu etkin olmayan bir öne çıkarma grubu oluşturun.</summary>
  Bir istasyon dahili `id` değeriyle, diğeri sağlayıcınızın `external_id` değeriyle tanımlanır.

```graphql Example request
mutation CreateBoostingGroup {
  createBoostingGroup(
    input: {
      name: "Preferred stations"
      client_id: "60b8d5a2f1c8e9001b9e2831"
      status: inactive
      stations: [{ id: "5f6a1b2c3d4e5f6a7b8c9d0e" }, { external_id: "NL-AMS-0001" }]
    }
  ) {
    id
    status
  }
}
```
</details>
