boostingGroups sorgusunu kullanarak workspace'inizin öne çıkarma gruplarını listeleyin. Bu, gruplarınıza genel bir bakış oluşturmak veya şu anda etkin olan grupları bulmak istediğinizde kullanışlıdır.

## Sorgu

Bu sorguyu çalıştırmak için girdi gerekmez. Sonuçlar arasında [sayfalamak](/api-reference/light-vehicle/api/pagination) için `first` ve `after` argümanlarını, `client_id` veya `status` değerine göre daraltmak için `filter` argümanını kullanın.
