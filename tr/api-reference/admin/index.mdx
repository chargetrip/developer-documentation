Admin API, kendi şemasına sahip ayrı bir GraphQL API'sidir. Projenizin davranışını şekillendiren kaynakları Chargetrip desteğinden istemek yerine bu API ile yönetin. Bugün için, rotalama sırasında tek tek şarj istasyonlarına öncelik vermenizi sağlayan güçlendirme gruplarını kapsar. Güçlendirme gruplarının bir rotayı nasıl etkilediğini öğrenmek için [tek tek şarj istasyonlarına öncelik verme](/docs/getting-started/route-boosting-groups) sayfasına bakın.

> [!WARNING] Alpha
> Admin API alpha aşamasındadır ve ücretsiz planlarda kullanılamaz. Erişim almak için destekle iletişime geçin ve şemanın değişebileceğini göz önünde bulundurun.
