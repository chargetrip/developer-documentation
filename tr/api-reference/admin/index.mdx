---
title: "Admin API referansı"
description: "Workspace'iniz için öne çıkarma grupları gibi kaynakları yönetmekte kullandığınız Admin API'nin sorgularına ve mutasyonlarına göz atın."
---

Admin API, kendi şemasına sahip ayrı bir GraphQL API'dir. Projenizin davranışını belirleyen kaynakları Chargetrip desteğinden talep etmek yerine bu API ile yönetin. Şu anda, yönlendirme sırasında tek tek şarj istasyonlarına öncelik vermenizi sağlayan öne çıkarma gruplarını kapsar.

İstekler, API referansının geri kalanından farklı bir uç noktaya gider ve oluşturduğunuz veya okuduğunuz her kaynak, `x-token` başlığınızın tanımladığı workspace'e aittir.

> [!WARNING] Alpha
> Admin API alpha aşamasındadır ve ücretsiz planlarda kullanılamaz. Erişim için destekle iletişime geçin ve şemanın değişebileceğini unutmayın.
