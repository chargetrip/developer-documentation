---
title: Tek tek şarj istasyonlarına öncelik verin
---

Boosting Group'lar (güçlendirme grupları), istasyon seçimini kendi iş kurallarınıza göre belirli şarj noktalarına yönlendirmenizi sağlar.

[Operatör tercihleri](/docs/getting-started/route-operators) tüm şarj ağlarına öncelik vermenize olanak tanırken, Boosting Group'lar size istasyon düzeyinde ayrıntılı kontrol sağlar. Daha düşük fiyatlandırma, düşük kullanım oranı veya daha iyi bir ticari anlaşma gibi bu istasyonları tercih etme nedeniniz ne olursa olsun, onları istasyon hiyerarşisinin en üstüne çıkarabilirsiniz.

## İstasyonlar nasıl güçlendirilir

Başlamak için öncelik vermek istediğiniz istasyonların listesiyle [destek](https://www.chargetrip.com/contact/support) ekibiyle iletişime geçmeniz yeterlidir.

Grubunuz kurulup projenizde etkinleştirildikten sonra, [createRoute](/api-reference/core/route/mutation-create-route) ile hesaplanan tüm rotalar bunu arka planda otomatik olarak kullanır; dolayısıyla API isteklerinizde herhangi bir değişikliğe veya ek parametreye gerek yoktur.

## Nasıl çalışır

Boosting Group'lar yalnızca olumlu önceliklendirmeyi destekler. Bunları istasyonları öne çıkarmak için kullanabilirsiniz, ancak istasyonlardan kaçınmak veya onları hariç tutmak için kullanamazsınız. Tek başına kullanıldığında, güçlendirilmiş istasyonlar rota boyunca diğer tüm istasyonlardan önce önceliklendirilir.

Operatör tercihleriyle birlikte kullanıldığında rota planlayıcı istasyonları şu öncelik sırasına göre (en yüksekten en düşüğe) önceliklendirir:

- Etkin Boosting Group'lar, tek tek güçlendirilmiş istasyonlardır. İstasyonun operatörü `avoid` veya `excluded` olarak ayarlanmış olsa bile tüm operatör tercihlerini geçersiz kılarlar.
- Tercih edilen operatörler (`high`, `medium`, `low`), tercih edilen şarj ağlarına ait istasyonlardır.
- Sıralanmamış istasyonlar, hiçbir güçlendirme grubu veya operatör tercihi uygulanmamış standart istasyonlardır.
- Önceliği düşürülmüş operatörler (`avoid`), kaçınılacak olarak işaretlenmiş operatörlere ait istasyonlardır. Yalnızca daha iyi bir seçenek olmadığında kullanılırlar.

Operatör tercihleri gibi, istasyon güçlendirme de en iyi çaba esasına göre çalışır. Rota planlayıcı, güçlendirilmiş bir istasyonun seçilmesinin hiçbir zaman verimsiz bir rotayla sonuçlanmaması için istasyon önceliğini istasyon yoğunluğu ve yol sapması etkisiyle dengeler.

## Örnekler

<details>
  <summary>Etkin Boosting Group'larla bir rota hesaplayın</summary>

  Boosting Group'lar proje düzeyinde otomatik olarak uygulandığından, yalnızca standart bir `createRoute` mutasyonu göndermeniz yeterlidir. Etkin tüm Boosting Group'lar otomatik olarak önceliklendirilir.

```graphql Example request
mutation CreateRoute {
  createRoute(
    input: {
      vehicle: { id: "607823b2c246f9001b97b1a2" }
      origin: {
        type: Feature
        geometry: { type: Point, coordinates: [4.895168, 52.370216] }
      }
      destination: {
        type: Feature
        geometry: { type: Point, coordinates: [6.773456, 51.227741] }
      }
    }
  ) {
    id
    status
  }
}
```
</details>

<details>
  <summary>Önerilen istasyonların bir Boosting Group'a ait olup olmadığını kontrol edin</summary>

  Hesaplanan rotayı `getRoute` veya `route` aboneliği ile alırken, hangi etkin Boosting Group'ların o durakla eşleştiğini görmek için bölüm istasyonunda `boosting_group_ids` alanını isteyin.

```graphql Example request {{ mark: [11] }}
query GetRoute {
  getRoute(id: "6527e1f1a8b4c2d3e4f5a6b7") {
    status
    route {
      id
      legs {
        origin {
          properties {
            station_id
            station {
              boosting_group_ids
            }
          }
        }
      }
    }
  }
}
```
</details>
