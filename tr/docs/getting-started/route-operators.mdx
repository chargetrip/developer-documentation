---
title: Operatör tercihli rota planlama
description: "Panelde veya istek bazında operatör tercihlerini ayarlayarak rota servisinin hangi şarj ağlarını tercih edeceğini kontrol edin."
---
Operatör tercihleri, bir EV rotası hesaplanırken rota planlama hizmetinin hangi şarj ağlarını tercih edeceğini kontrol etmenizi sağlar.

Tercihleri iki yerde yapılandırabilirsiniz:
- [Chargetrip panosu](https://account.chargetrip.io/projects): Projeniz için genel operatör tercihleri yapılandırmasını proje / gelişmiş / istasyon operatörü tercihleri altında ayarlayın.
- [Rota oluşturma isteği](/api-reference/route/mutation-create-route#arg-input-operators): `createRoute` mutasyonundaki `input.operators` alanını kullanarak tercihleri dinamik olarak tanımlayın veya pano operatör tercihleri yapılandırmasını istek başına geçersiz kılın.

---

### 1. Tercih türleri ve rota davranışı


Operatör tercihleri dört türde gelir ve her biri belirli ülkelerle sınırlandırılabilir:

| Tercih | Rota planlama davranışı |
|:---|:---|
| Hariç tutulan | Bu operatörlerin istasyonları hiçbir koşulda kesinlikle hariç tutulur. |
| Kaçınılan  |  Daha iyi bir alternatif yoksa bu operatörlerin istasyonlarından kaçınılır. |
| Tercih edilen | Bu operatörlerin istasyonlarına sıralamalarına (yüksek, orta, düşük) göre öncelik verilir. Katman ne kadar yüksekse, istasyonun seçilme olasılığı o kadar yüksektir. Daha iyi bir alternatif yoksa rota yine de sıralanmamış veya kaçınılan istasyonları kullanır.|
| Zorunlu  | Yalnızca bu operatörlerin istasyonları kullanılır. İzin verilen bu havuz içinde sıralama katmanları yine geçerlidir; yani yüksek sıralı operatörler orta ve düşük sıralı operatörlere tercih edilir. Araç varış noktasına yalnızca sıralanmış istasyonları kullanarak ulaşamazsa rota hesaplaması başarısız olur.|


---

### 2. Pano düzeyindeki tercihler nasıl uygulanır

İstek düzeyindeki girdilerin pano ayarlarıyla nasıl etkileşime girdiğini anlamak, öngörülebilir rota planlama davranışı sağlar:

- **Panodaki Hariç tutulan ve Kaçınılan operatörler otomatik olarak uygulanır**:
Panoda Hariç tutulan veya Kaçınılan olarak yapılandırılan operatörler, `createRoute` isteğinizde herhangi bir parametre gerektirmeden her rota hesaplamasına uygulanır.
- **Panodaki sıralama katmanları, sıralama türü olmadan etkin olmaz**:
Sıralama katmanlarında yapılandırılan operatörler, `createRoute` isteğinizde `input.operators.ranking.type` ayarlanarak etkinleştirilmelidir; aksi halde istasyon seçimini etkilemezler.
- **İstek düzeyindeki operatörler, ilgili pano tercihlerinin yerini alır**:
`createRoute` isteğinde operatör kimliklerini belirtmek, yalnızca panodaki ilgili yapılandırmanın yerini alır. Örneğin `input.operators.exclude[]` sağlamak panonun hariç tutulan operatörler yapılandırmasının tamamının yerini alırken, pano düzeyindeki kaçınılan operatörler uygulanmaya devam eder.
---
### 3. Uygulama örnekleri

<details>
  <summary>Yalnızca pano hariç tutmalarını ve kaçınmalarını kullanın</summary>
  Panoda ayarlanan hariç tutulan ve kaçınılan operatör yapılandırmalarını uygular. `input.operators.ranking.type` belirtilmediği için panonun sıralama ayarları etkin değildir.

```graphql Örnek istek
createRoute(
  input: {
    vehicle: { id: "607823b2c246f9001b97b1a2" }
    origin: {
      type: Feature
      geometry: { type: Point, coordinates: [4.895168, 52.370216] }
    }
    destination: {
      type: Feature
      geometry: { type: Point, coordinates: [2.352222, 48.856614] }
    }
  }
)
```
</details>

<details>
  <summary>Panoda sıralanan operatörleri "Tercih edilen" olarak kullanın</summary>
  Panodaki hariç tutulan ve kaçınılan operatör yapılandırmalarını uygular ve pano sıralama katmanlarına ait istasyonları tercih eder.

```graphql Örnek istek {{ mark: [14] }}
createRoute(
  input: {
    vehicle: { id: "607823b2c246f9001b97b1a2" }
    origin: {
      type: Feature
      geometry: { type: Point, coordinates: [4.895168, 52.370216] }
    }
    destination: {
      type: Feature
      geometry: { type: Point, coordinates: [2.352222, 48.856614] }
    }
    operators: {
      ranking: {
        type: preferred
      }
    }
  }
)
```
</details>

<details>
  <summary>Panoda sıralanan operatörleri "Zorunlu" olarak kullanın</summary>
  Rotayı yalnızca pano sıralama katmanlarında yapılandırılan operatörlere ait istasyonlarda şarj olacak şekilde kısıtlar.

```graphql Örnek istek {{ mark: [14] }}
createRoute(
  input: {
    vehicle: { id: "607823b2c246f9001b97b1a2" }
    origin: {
      type: Feature
      geometry: { type: Point, coordinates: [4.895168, 52.370216] }
    }
    destination: {
      type: Feature
      geometry: { type: Point, coordinates: [2.352222, 48.856614] }
    }
    operators: {
      ranking: {
        type: required
      }
    }
  }
)
```
</details>

<details>
  <summary>Özel tercihler tanımlayın ve pano ayarlarını geçersiz kılın</summary>
  Tam operatör yapılandırmalarını doğrudan API çağrısında sağlayın. Belirtilen her alan (ranking, avoid veya exclude), o istek için panodaki ilgili yapılandırmayı geçersiz kılar.

```graphql Örnek istek  {{ mark: [13,14,15,16,17,18,19,20,21] }}
createRoute(
  input: {
    vehicle: { id: "607823b2c246f9001b97b1a2" }
    origin: {
      type: Feature
      geometry: { type: Point, coordinates: [4.895168, 52.370216] }
    }
    destination: {
      type: Feature
      geometry: { type: Point, coordinates: [2.352222, 48.856614] }
    }
    operators: {
      ranking: {
        type: preferred
        level: {
          high: [{ id: "5e8c22366f9c5f23ab0eff01" }]
          medium: [{ id: "5e8c22366f9c5f23ab0eff02" }]
        }
      }
      avoid: [{ id: "5e8c22366f9c5f23ab0eff03" }]
      exclude: [{ id: "5e8c22366f9c5f23ab0eff04" }]
    }
  }
)
```
</details>
