---
title: "Operatör tercihli rota planlama"
description: "Panelde veya istek başına operatör tercihlerini ayarlayarak rota planlama hizmetinin hangi şarj ağlarını tercih edeceğini kontrol edin."
---
Operatör tercihleri, bir elektrikli araç rotası hesaplanırken rota planlama hizmetinin hangi şarj ağlarını tercih edeceğini kontrol etmenizi sağlar.

Tercihleri iki yerden yapılandırabilirsiniz:
- [Chargetrip paneli](https://account.chargetrip.io/projects): Projeniz için genel operatör tercihleri yapılandırmasını project / advanced / station operator preferences altında ayarlayın.
- [Rota oluşturma isteği](/api-reference/core/route/mutation-create-route#arg-input-operators): `createRoute` mutasyonundaki `input.operators` alanını kullanarak tercihleri dinamik olarak tanımlayın veya panelde yapılandırılan operatör tercihlerini istek başına geçersiz kılın.

---

### 1. Tercih türleri ve rota davranışı


Operatör tercihleri dört türdedir ve her biri belirli ülkelerle sınırlandırılabilir:

| Tercih | Rota planlama davranışı |
|:---|:---|
| Hariç tutulan | Bu operatörlerin istasyonları her koşulda kesinlikle hariç tutulur. |
| Kaçınılan  |  Bu operatörlerin istasyonlarından, daha iyi bir alternatif yoksa kaçınılır. |
| Tercih edilen | Bu operatörlerin istasyonları sıralamalarına (high, medium, low) göre önceliklendirilir. Kademe yükseldikçe istasyonun seçilme olasılığı artar. Daha iyi bir alternatif yoksa rota yine de sıralanmamış veya kaçınılan istasyonları kullanır.|
| Zorunlu  | Yalnızca bu operatörlerin istasyonları kullanılır. İzin verilen bu havuz içinde sıralama kademeleri yine geçerlidir; yani high sıralı operatörler medium ve low sıralı operatörlere tercih edilir. Araç, yalnızca sıralanmış istasyonları kullanarak varış noktasına ulaşamıyorsa rota hesaplaması başarısız olur.|


---

### 2. Panel düzeyindeki tercihler nasıl uygulanır

İstek düzeyindeki girdilerin panel ayarlarıyla nasıl etkileşime girdiğini anlamak, rota planlamanın öngörülebilir olmasını sağlar:

- **Paneldeki Hariç tutulan ve Kaçınılan operatörler otomatik olarak uygulanır**:
Panelde Hariç tutulan veya Kaçınılan olarak yapılandırılan operatörler, `createRoute` isteğinizde herhangi bir parametre gerektirmeden her rota hesaplamasına uygulanır.
- **Paneldeki sıralama kademeleri, bir sıralama türü olmadan etkin olmaz**:
Sıralama kademelerinde yapılandırılan operatörlerin `createRoute` isteğinizde `input.operators.ranking.type` ayarlanarak etkinleştirilmesi gerekir; aksi takdirde istasyon seçimini etkilemezler.
- **İstek düzeyindeki operatörler, panelde yapılandırılan ilgili tercihlerin yerini alır**:
`createRoute` isteğinde operatör kimlikleri belirtmek, panelden yalnızca ilgili yapılandırmanın yerini alır. Örneğin `input.operators.exclude[]` sağlamak panelin hariç tutulan operatörler yapılandırmasının tamamının yerini alırken, panel düzeyindeki avoid operatörleri uygulanmaya devam eder.
---
### 3. Uygulama örnekleri

<details>
  <summary>Yalnızca panel düzeyindeki hariç tutma ve kaçınma ayarlarını kullanın</summary>
  Panelde ayarlanan hariç tutulan ve kaçınılan operatör yapılandırmalarını uygular. `input.operators.ranking.type` belirtilmediği için paneldeki sıralama ayarları etkin değildir.

```graphql Example request
createRoute(
  input: {
    vehicle: { id: "607823b2c246f9001b97b1a2" }
    origin: {
      type: Feature
      geometry: { type: Point, coordinates: [4.895168, 52.370216] }
    }
    destination: {
      type: Feature
      geometry: { type: Point, coordinates: [2.352222, 48.856614] }
    }
  }
)
```
</details>

<details>
  <summary>Paneldeki sıralı operatörleri "Tercih edilen" olarak kullanın</summary>
  Paneldeki hariç tutulan ve kaçınılan operatör yapılandırmalarını uygular ve panel sıralama kademelerine ait istasyonları tercih eder.

```graphql Example request {{ mark: [14] }}
createRoute(
  input: {
    vehicle: { id: "607823b2c246f9001b97b1a2" }
    origin: {
      type: Feature
      geometry: { type: Point, coordinates: [4.895168, 52.370216] }
    }
    destination: {
      type: Feature
      geometry: { type: Point, coordinates: [2.352222, 48.856614] }
    }
    operators: {
      ranking: {
        type: preferred
      }
    }
  }
)
```
</details>

<details>
  <summary>Paneldeki sıralı operatörleri "Zorunlu" olarak kullanın</summary>
  Rotanın yalnızca panel sıralama kademelerinde yapılandırılan operatörlere ait istasyonlarda şarj etmesini kısıtlar.

```graphql Example request {{ mark: [14] }}
createRoute(
  input: {
    vehicle: { id: "607823b2c246f9001b97b1a2" }
    origin: {
      type: Feature
      geometry: { type: Point, coordinates: [4.895168, 52.370216] }
    }
    destination: {
      type: Feature
      geometry: { type: Point, coordinates: [2.352222, 48.856614] }
    }
    operators: {
      ranking: {
        type: required
      }
    }
  }
)
```
</details>

<details>
  <summary>Özel tercihler tanımlayın ve panel ayarlarını geçersiz kılın</summary>
  Tam operatör yapılandırmalarını doğrudan API çağrısında sağlayın. Belirtilen herhangi bir alan (ranking, avoid veya exclude), o istek için panelde yapılandırılan ilgili yapılandırmanın yerini alır.

```graphql Example request  {{ mark: [13,14,15,16,17,18,19,20,21] }}
createRoute(
  input: {
    vehicle: { id: "607823b2c246f9001b97b1a2" }
    origin: {
      type: Feature
      geometry: { type: Point, coordinates: [4.895168, 52.370216] }
    }
    destination: {
      type: Feature
      geometry: { type: Point, coordinates: [2.352222, 48.856614] }
    }
    operators: {
      ranking: {
        type: preferred
        level: {
          high: [{ id: "5e8c22366f9c5f23ab0eff01" }]
          medium: [{ id: "5e8c22366f9c5f23ab0eff02" }]
        }
      }
      avoid: [{ id: "5e8c22366f9c5f23ab0eff03" }]
      exclude: [{ id: "5e8c22366f9c5f23ab0eff04" }]
    }
  }
)
```
</details>
