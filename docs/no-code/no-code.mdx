Not every use case requires custom development. For teams that want to launch fast, ready-made, brandable tools are available to embed directly on a website or in an app, built on the same routing and vehicle data as the API.

## Features

**Route Planning**
: Tested and proven UX flows built on the routing engine, embedded directly on a site or in an app. Removes EV driver range anxiety without in-house development.

**Station Map**
: An interactive map of a charging network, with fast clustering and detailed station data. Helps end-users explore the infrastructure and find a station.

**Range Spider**
: Visualizes the real-world range of an EV from any point, accounting for factors like elevation and weather. Helps prospective EV drivers understand range up front.

## Customization

Every no-code tool is fully brandable to match your product. Features can be moved around and toggled on or off, and the whole styleguide, including colors and branding, can be altered to match your product. Tools can also be embedded within mobile applications, not just on the web.
