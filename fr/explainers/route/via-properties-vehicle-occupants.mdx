---
title: Comment fonctionnent les occupants via
slug: route-via-properties-vehicle-occupants
fieldName: RoutePropertiesVehicleInput.occupants
variant: tooltip
position: top
---
Définissez le nombre d'occupants du véhicule à partir de ce point via. Cela remplace la valeur de l'origine, tient compte du poids supplémentaire dans la consommation d'énergie du véhicule et persiste pour tous les tronçons restants, sauf mise à jour à un point via ultérieur.
