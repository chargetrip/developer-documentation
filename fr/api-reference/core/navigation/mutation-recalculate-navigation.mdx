Recalculez l'itinéraire d'une session de navigation active en utilisant la mutation recalculateNavigation. Elle est utile lorsqu'un conducteur s'écarte de l'itinéraire initial ou que les conditions changent en cours de route.

## Mutation

Un `id` de session de navigation et une `current_location` sont obligatoires pour recalculer son itinéraire. Incluez éventuellement `state_of_charge`, `via` ou `telemetry` pour affiner le nouvel itinéraire. L'`id` peut être obtenu via la [mutation startNavigation](/api-reference/core/navigation/mutation-start-navigation).
