Une fois que vous avez un `id` de session de navigation issu de la [mutation startNavigation](/api-reference/core/navigation/mutation-start-navigation), souscrivez-y pour recevoir le statut et les détails des mises à jour en temps réel pendant la progression du conducteur sur l'itinéraire.

> [!TIP] Restez abonné
> Utilisez cette souscription en permanence pour ne manquer aucune mise à jour de la session de navigation.

## Souscription

Un `id` de session de navigation est obligatoire pour souscrire à ses mises à jour. L'`id` peut être obtenu via la [mutation startNavigation](/api-reference/core/navigation/mutation-start-navigation). Utilisez `last_change.type` pour voir pourquoi une session a été mise à jour, par exemple `route_updated` ou `next_station_availability_updated`. `meta.updated_at` change chaque fois que l'itinéraire doit être réaffiché, par exemple après un appel de la [mutation recalculateNavigation](/api-reference/core/navigation/mutation-recalculate-navigation).
