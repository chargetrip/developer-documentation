Mettez fin à une session de navigation active en utilisant la mutation finishNavigation. Elle est utile lorsqu'un conducteur atteint sa destination ou que le trajet est annulé.

## Mutation

Un `id` de session de navigation et une `current_location` sont obligatoires pour la terminer. L'`id` peut être obtenu via la [mutation startNavigation](/api-reference/core/navigation/mutation-start-navigation).
