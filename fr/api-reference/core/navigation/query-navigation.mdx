Obtenez une session de navigation active en utilisant la requête navigation. Elle est utile lorsque vous souhaitez afficher la progression actuelle d'un conducteur sur un itinéraire.

## Requête

Un `id` de session de navigation est obligatoire pour obtenir ses détails. L'`id` peut être obtenu via la [mutation startNavigation](/api-reference/core/navigation/mutation-start-navigation).
