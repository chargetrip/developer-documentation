Accédez à la base de données complète de véhicules avec la requête `vehicleList`. Par défaut, la base de données de véhicules utilise la nomenclature européenne pour les véhicules et les types de prises.

## Requête

Aucune entrée n'est requise pour exécuter la requête `vehicleList`. Utilisez `filter` et `search` pour affiner et personnaliser les résultats. Utilisez le paramètre country en combinaison avec le filtre de région pour renvoyer les véhicules disponibles dans votre région avec des noms et des types de prises connus localement. Utilisez les arguments `size` et `page` pour les [paginer](/api-reference/core/api/pagination).
