Accédez à la base de données complète des véhicules avec la requête `vehicleList`. Par défaut, la base de données des véhicules utilise la nomenclature européenne pour les véhicules et les types de prises.

## Query

Aucune entrée n'est requise pour exécuter la requête `vehicleList`. Utilisez `filter` et `search` pour affiner et personnaliser les résultats. Utilisez le paramètre country en combinaison avec le filtre region pour renvoyer ici les véhicules disponibles dans votre région avec leurs noms et types de prises connus localement. Utilisez les arguments `size` et `page` pour les [paginer](/api-reference/core/api/pagination).
