Accédez à des données encore plus détaillées avec la requête vehiclePremium. Elle contient des données étendues sur la batterie, la carrosserie du véhicule, la disponibilité, le prix, l'efficacité, la sécurité et plus encore. [Contactez les ventes](https://www.chargetrip.com/contact/sales) pour passer aux données de véhicule premium.

## Requête

Un `id` de véhicule est requis pour obtenir les détails d'un véhicule premium. L'`id` peut être obtenu via la [requête vehicleList](/api-reference/core/vehicle/query-vehicles). Utilisez l'argument country pour appliquer la localisation aux données.
