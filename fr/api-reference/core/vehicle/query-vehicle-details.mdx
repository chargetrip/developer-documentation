Obtenez les spécifications d'un véhicule avec la requête vehicle.

## Requête

Un `id` de véhicule est requis pour obtenir les détails d'un véhicule. L'`id` peut être obtenu via la [requête vehicleList](/api-reference/core/vehicle/query-vehicles). Utilisez l'argument country pour appliquer la localisation aux données.
