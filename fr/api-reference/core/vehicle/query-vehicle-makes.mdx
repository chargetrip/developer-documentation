Obtenez une liste de marques de véhicules à l'aide de la requête vehicleMakes.

## Query
Aucune entrée n'est requise pour exécuter la requête vehicleMakes. Utilisez l'argument `filter` pour affiner les résultats par région et/ou par type, ainsi que les arguments `first` et `after` pour les [paginer](/api-reference/core/api/pagination). Utilisez l'argument `country` pour appliquer la localisation aux données.
