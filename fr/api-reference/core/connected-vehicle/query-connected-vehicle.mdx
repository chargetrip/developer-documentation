Obtenez les détails d'un véhicule connecté en utilisant la requête connectedVehicle. Elle est utile lorsque vous souhaitez vérifier le statut d'autorisation d'un véhicule connecté.

## Requête

Un `id` de véhicule connecté est obligatoire pour obtenir ses détails. L'`id` peut être obtenu via la [mutation createConnectedVehicle](/api-reference/core/connected-vehicle/mutation-create-connected-vehicle) ou la [requête connectedVehicleList](/api-reference/core/connected-vehicle/query-connected-vehicle-list).
