Obtenez les détails d'un véhicule connecté à l'aide de la requête connectedVehicle. Elle est utile lorsque vous souhaitez vérifier le statut d'autorisation d'un véhicule connecté.

## Query

Un `id` de véhicule connecté est requis pour obtenir ses détails. L'`id` peut être obtenu via la [mutation createConnectedVehicle](/api-reference/core/connected-vehicle/mutation-create-connected-vehicle) ou la [requête connectedVehicleList](/api-reference/core/connected-vehicle/query-connected-vehicle-list).
