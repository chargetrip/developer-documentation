Terminez l'autorisation d'un véhicule connecté en utilisant la mutation authorizeConnectedVehicle. Elle est utile une fois que l'utilisateur final a accordé l'accès via le fournisseur de connectivité.

## Mutation

Un `id` et des `options` propres au fournisseur sont obligatoires pour autoriser un véhicule connecté. L'`id` peut être obtenu via la [mutation createConnectedVehicle](/api-reference/core/connected-vehicle/mutation-create-connected-vehicle).
