Supprimez un véhicule connecté et révoquez son accès en utilisant la mutation removeConnectedVehicle. Elle est utile lorsqu'un utilisateur final déconnecte son véhicule du fournisseur de connectivité.

## Mutation

Un `id` est obligatoire pour supprimer un véhicule connecté. L'`id` peut être obtenu via la [mutation createConnectedVehicle](/api-reference/core/connected-vehicle/mutation-create-connected-vehicle).
