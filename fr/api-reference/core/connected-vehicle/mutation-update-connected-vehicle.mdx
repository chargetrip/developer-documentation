Mettez à jour un véhicule connecté en utilisant la mutation updateConnectedVehicle. Elle est utile lorsque vous souhaitez modifier le libellé d'un véhicule connecté.

## Mutation

Un `id` est obligatoire pour mettre à jour un véhicule connecté. Utilisez `label` pour définir un nouveau libellé. L'`id` peut être obtenu via la [mutation createConnectedVehicle](/api-reference/core/connected-vehicle/mutation-create-connected-vehicle).
