Obtenez des données de véhicule en direct en utilisant la requête connectedVehicleData. Elle est utile lorsque vous souhaitez récupérer des données en temps réel directement depuis un véhicule connecté, comme son état de charge ou sa position.

## Requête

Un `id` de véhicule connecté est obligatoire pour obtenir ses données en direct. L'`id` peut être obtenu via la [mutation createConnectedVehicle](/api-reference/core/connected-vehicle/mutation-create-connected-vehicle).
