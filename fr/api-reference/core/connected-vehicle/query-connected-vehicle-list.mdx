Obtenez la liste des véhicules connectés de l'utilisateur actuel en utilisant la requête connectedVehicleList. Elle est utile lorsque vous souhaitez afficher tous les véhicules qu'un utilisateur a connectés à un fournisseur.

## Requête

Aucune entrée n'est requise pour exécuter cette requête. Utilisez `filter` pour restreindre les résultats par statut, et les arguments `size` et `page` pour les [paginer](/api-reference/core/api/pagination).
