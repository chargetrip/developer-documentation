Obtenez les détails d'une isoline précédemment calculée en utilisant la requête isoline. Elle est utile lorsque vous souhaitez afficher la zone accessible à un véhicule.

## Requête

Un `id` d'isoline est obligatoire pour obtenir les détails de l'isoline. L'`id` peut être obtenu via la [mutation createIsoline](/api-reference/core/isoline/mutation-create-isoline).
