Souscrivez à une isoline en utilisant la souscription isoline. Elle est utile lorsque vous souhaitez recevoir des mises à jour en temps réel pendant le calcul d'une isoline.

## Souscription

Un `id` d'isoline est obligatoire pour souscrire à ses mises à jour. L'`id` peut être obtenu via la [mutation createIsoline](/api-reference/core/isoline/mutation-create-isoline).
