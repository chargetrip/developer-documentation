Obtenez les détails d'un itinéraire concordant précédemment calculé en utilisant la requête getMatchedRoute. Elle est utile lorsque vous souhaitez récupérer à nouveau un itinéraire concordant sans ouvrir de nouvelle souscription.

## Requête

Un `id` d'itinéraire concordant est obligatoire pour obtenir les détails de l'itinéraire. L'`id` peut être obtenu via la [mutation createMatchedRoute](/api-reference/core/matched-route/mutation-create-matched-route).
