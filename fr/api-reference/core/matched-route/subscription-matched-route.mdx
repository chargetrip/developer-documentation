Souscrivez à un itinéraire concordant en utilisant la souscription matchedRoute. Elle est utile lorsque vous souhaitez recevoir des mises à jour en temps réel pendant le calcul d'un itinéraire concordant.

## Souscription

Un `id` d'itinéraire concordant est obligatoire pour souscrire à ses mises à jour. L'`id` peut être obtenu via la [mutation createMatchedRoute](/api-reference/core/matched-route/mutation-create-matched-route).
