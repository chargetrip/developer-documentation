Récupérez tous les avis ajoutés par l'utilisateur authentifié sur l'ensemble des stations en utilisant la requête userReviewList. Elle est utile lorsque vous souhaitez afficher l'historique des avis d'un utilisateur. Il s'agit d'une fonctionnalité premium. Contactez-nous pour plus d'informations.

## Requête

Un en-tête `x-token` est obligatoire pour autoriser l'utilisateur dont vous souhaitez récupérer les avis. Utilisez les arguments `size` et `page` pour les [paginer](/api-reference/core/api/pagination).
