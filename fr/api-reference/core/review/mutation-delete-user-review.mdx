Supprimez un avis ajouté par l'utilisateur authentifié en utilisant la mutation deleteUserReview. Il s'agit d'une fonctionnalité premium. Contactez-nous pour plus d'informations.

## Mutation

Un `id` d'avis est obligatoire pour le supprimer. Un en-tête `x-token` est obligatoire pour autoriser l'utilisateur. L'avis doit lui appartenir, sinon une erreur se produit.
