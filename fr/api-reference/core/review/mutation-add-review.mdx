Ajoutez un avis sur une station en utilisant la mutation addReview. Incluez une note et un message, ainsi que le VE et le type de prise utilisés, pour donner plus de contexte aux autres utilisateurs. Si un en-tête `x-token` est envoyé pour un utilisateur valide, l'avis lui appartiendra ; sinon, il est ajouté de façon anonyme.

## Mutation

Un objet `review` est obligatoire, contenant l'`id` de la station, la `rating` et le `message`. Incluez éventuellement le `ev`, le `plugType`, la `locale`, les `properties` et les `tags` utilisés lors de la visite.
