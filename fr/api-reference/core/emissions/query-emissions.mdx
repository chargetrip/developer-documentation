Obtenez le profil d'émissions d'un itinéraire en utilisant la requête getRouteEmissions. Elle est utile lorsque vous souhaitez afficher l'impact environnemental d'un trajet.

## Requête

Un `route_id` et un `route_details_id` sont obligatoires pour obtenir les émissions d'un itinéraire. Les deux peuvent être obtenus via la [requête getRoute](/api-reference/core/route/query-get-route).
