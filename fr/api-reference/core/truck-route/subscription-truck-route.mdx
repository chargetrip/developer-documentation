Abonnez-vous à un itinéraire camion avec la souscription truckRoute. C'est utile lorsque vous souhaitez recevoir des mises à jour en temps réel pendant le calcul d'un itinéraire de camion électrique.

## Souscription

Un `id` d'itinéraire camion est requis pour s'abonner à ses mises à jour. L'`id` peut être obtenu via la [mutation createTruckRoute](/api-reference/core/truck-route/mutation-create-truck-route).
