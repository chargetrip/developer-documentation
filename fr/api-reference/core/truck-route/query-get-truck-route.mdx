Obtenez les détails d'un itinéraire camion précédemment calculé avec la requête getTruckRoute. C'est utile lorsque vous souhaitez afficher les arrêts de recharge, la distance et la durée d'un itinéraire camion.

## Requête

Un `id` d'itinéraire camion est requis pour obtenir les détails de l'itinéraire. L'`id` peut être obtenu via la [mutation createTruckRoute](/api-reference/core/truck-route/mutation-create-truck-route).
