Obtenez les détails d'un itinéraire camion précédemment calculé à l'aide de la requête getTruckRoute. Elle est utile lorsque vous souhaitez afficher les arrêts de recharge, la distance et la durée d'un itinéraire camion.

## Query

Un `id` d'itinéraire camion est requis pour obtenir les détails de l'itinéraire. L'`id` peut être obtenu via la [mutation createTruckRoute](/api-reference/core/truck-route/mutation-create-truck-route).
