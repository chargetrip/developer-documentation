Accédez à la liste complète des tarifs avec la requête tariffList. C'est utile lorsque vous souhaitez afficher ou comparer les coûts de recharge entre les stations. Pour savoir comment afficher la tarification, consultez le [guide de tarification des stations](/docs/getting-started/station-pricing).

## Requête

Aucune entrée n'est requise pour exécuter cette requête. Utilisez les arguments `size` et `page` pour les [paginer](/api-reference/core/api/pagination).
