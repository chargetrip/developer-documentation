Obtenez les détails d'un tarif avec la requête tariff. C'est utile lorsque vous utilisez une base de stations autre qu'Ecomovement et que vous souhaitez afficher le coût de la recharge dans une station. Pour savoir comment afficher la tarification, consultez le [guide de tarification des stations](/docs/getting-started/station-pricing).

## Requête

Un `id` de tarif est requis pour obtenir les détails d'un tarif. L'`id` peut être obtenu via la [requête tariffList](/api-reference/core/tariff/query-tariff-list).
