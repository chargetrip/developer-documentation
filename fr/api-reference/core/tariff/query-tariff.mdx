Obtenez les détails d'un tarif à l'aide de la requête tariff. Elle est utile lorsque vous utilisez une base de données de stations autre qu'Ecomovement et que vous souhaitez afficher le coût de la recharge à une station. Pour savoir comment afficher les prix, consultez le [guide sur la tarification des stations](/docs/getting-started/station-pricing).

## Query

Un `id` de tarif est requis pour obtenir ses détails. L'`id` peut être obtenu via la [requête tariffList](/api-reference/core/tariff/query-tariff-list).
