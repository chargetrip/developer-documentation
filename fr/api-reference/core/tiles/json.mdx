Le service de tuiles JSON donne accès aux données géographiques liées aux stations au format JSON.

## Configuration

Pour accéder aux données des stations au format JSON, envoyez une requête à l'endpoint suivant :

```bash Tile / JSON / Base URL
https://api.chargetrip.io/v2/station/{z}/{x}/{y}/tile.json
```

L'URL JSON utilise les paramètres de chemin suivants :

- `z` : le niveau de zoom de la tuile.
- `x` : la coordonnée x de la tuile.
- `y` : la coordonnée y de la tuile.

La plupart des fournisseurs de cartes disposent de méthodes intégrées pour convertir la latitude et la longitude en coordonnées de pixels. Pour convertir manuellement des coordonnées de latitude et de longitude en x et y, utilisez la [projection Web Mercator](https://en.wikipedia.org/wiki/Web_Mercator_projection).

### Filtrage
Utilisez le paramètre de requête `filter` pour filtrer les stations renvoyées selon des critères spécifiques. Consultez la [documentation des filtres](/api-reference/core/tiles/filters) pour plus d'informations.

### Sélecteurs
Utilisez le paramètre de requête `station_properties[]` pour spécifier les champs renvoyés pour chaque feature de station. Consultez la [documentation des sélecteurs](/api-reference/core/tiles/selectors) pour plus d'informations.

### Devise
Utilisez le paramètre de requête `currency` pour définir la devise des prix de l'énergie renvoyés et utilisés pour le filtrage. Consultez la [documentation sur la conversion de devise](/api-reference/core/tiles/filters) pour plus d'informations.
