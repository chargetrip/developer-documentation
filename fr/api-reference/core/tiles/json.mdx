Le service de tuiles JSON donne accès aux données géographiques liées aux stations au format JSON.

## Configuration

Pour accéder aux données des stations au format JSON, envoyez une requête au endpoint suivant :

```bash Tile / JSON / Base URL
https://api.chargetrip.io/v2/station/{z}/{x}/{y}/tile.json
```

L'URL JSON utilise les paramètres de chemin suivants :

- `z` : le niveau de zoom de la tuile.
- `x` : la coordonnée x de la tuile.
- `y` : la coordonnée y de la tuile.

La plupart des fournisseurs de cartes disposent de méthodes intégrées pour convertir la latitude et la longitude en coordonnées en pixels. Pour convertir manuellement les coordonnées de latitude et de longitude en x et y, utilisez la [projection Web Mercator](https://en.wikipedia.org/wiki/Web_Mercator_projection).

### Filtrage
Utilisez le paramètre de requête `filter` pour filtrer les stations renvoyées selon des critères précis. Consultez la [documentation des filtres](/api-reference/core/tiles/filters) pour plus d'informations.

### Sélecteurs
Utilisez le paramètre de requête `station_properties[]` pour indiquer les champs renvoyés pour chaque entité station. Consultez la [documentation des sélecteurs](/api-reference/core/tiles/selectors) pour plus d'informations.

## Réponse
L'API renvoie une `FeatureCollection` GeoJSON contenant les champs GeoJSON obligatoires (id, type, geometry et properties). Chaque élément de `features` représente soit une station individuelle (`count: 1`), soit un regroupement de stations (`count > 1`).



`id` · `string` · <span class="text-accent">obligatoire</span>
: L'identifiant unique de la station. Renvoyé uniquement pour les entités de station individuelles.

`type` · `string` · <span class="text-accent">obligatoire</span>
: Toujours défini sur `"Feature"`.

`geometry` · `object` · <span class="text-accent">obligatoire</span>
: Géométrie GeoJSON standard `Point` contenant les coordonnées `[longitude, latitude]`.

`properties` · `object` · <span class="text-accent">obligatoire</span>
: Attributs de l'entité. Par défaut, les entités de station renvoient `{ "count": 1 }` et les entités de regroupement renvoient `{ "count": N, "expansion_zoom": Z }`. Des champs de station supplémentaires peuvent être demandés à l'aide des [sélecteurs](/api-reference/core/tiles/selectors).

Les champs renvoyés dans `properties` dépendent du type d'entité et des sélecteurs fournis :

- Entités de regroupement : renvoient toujours `{ "count": N, "expansion_zoom": Z }`.

- Entités de station : renvoient `{ "count": 1 }` si aucun sélecteur n'est fourni, ou uniquement les champs demandés si des [sélecteurs](/api-reference/core/tiles/selectors) sont fournis.

```json Example response
    {
      "type": "Feature",
      "geometry": {

      },
      "properties": {
        "count": 4,

      }
    }
  ]
}
```

### Devise
Utilisez le paramètre de requête `currency` pour définir la devise des prix de l'énergie renvoyés et filtrés. Consultez la [documentation sur la conversion de devise](/api-reference/core/tiles/filters) pour plus d'informations.
