Les filtres permettent aux applications d'affiner les stations de recharge renvoyées par l'API Tile Service. Au-delà du simple masquage des résultats non correspondants, certains filtres transforment également les données des stations afin que la réponse reste pertinente selon le contexte.

## Effet des filtres sur les données

Lorsqu'une requête inclut des filtres, le service de tuiles effectue deux opérations distinctes :

1. **Exclusion des stations non correspondantes**
   Toute station qui ne répond pas aux critères de filtrage spécifiés est entièrement retirée de la réponse. Cette opération a lieu lorsque des filtres de niveau station ou de niveau EVSE sont utilisés.
2. **Transformation des données**
   Lorsque certains paramètres de filtrage sont fournis, le service de tuiles recalcule certaines propriétés dynamiques de la station. Cette opération a lieu lorsque des filtres de niveau EVSE sont utilisés.

## Mise en œuvre

Les paramètres de filtre peuvent être ajoutés sous forme de chaînes de requête à l'URL de n'importe quel endpoint du service de tuiles (MVT, JSON ou Count). Si aucun filtre n'est appliqué, toutes les stations de recharge disponibles sont renvoyées et aucune transformation de données n'est effectuée.

```bash Tile / Filter / Example
https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?{filter_1}&{filter_2}&{filter_n}
```

## Niveaux

Les filtres peuvent exister à deux niveaux : le niveau EVSE ou le niveau station, chacun ayant son propre impact et ses propres résultats, comme décrit ci-dessous.

### Niveau station

Filtres qui évaluent les attributs globaux de la station. Ces filtres servent uniquement à exclure : ils écartent les stations non correspondantes, mais ne modifient jamais les champs de données renvoyés.

`amenities` · `enum` · [Afficher un exemple d'URL](tip:https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?amenities[]=HOTEL)
: Filtre pour inclure uniquement les stations qui proposent les équipements spécifiés.
: `HOTEL`, `SHOPPING`, `BATHROOM`, `SUPERMARKET`, `PLAYGROUND`, `PHARMACY`, `MUSEUM`, `COFFEE`, `PARK`, `RESTAURANT`

`preferred_operators` · `boolean` · [Afficher un exemple d'URL](tip:https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?preferred_operators=true)
: Filtre pour inclure uniquement les stations exploitées par des opérateurs configurés comme préférés. Les opérateurs préférés peuvent être définis dans les paramètres du projet, dans le tableau de bord.
: `true`, `false`

`hide_excluded_operators` · `boolean` · [Afficher un exemple d'URL](tip:https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?hide_excluded_operators=true)
: Filtre pour exclure les stations exploitées par des opérateurs configurés comme exclus. Les opérateurs exclus peuvent être définis dans les paramètres du projet, dans le tableau de bord.
: `true`, `false`

`operator_ids` · `string` · [Afficher un exemple d'URL](tip:https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?operator_ids[]=631834841e604d2273ffb2b5&operator_ids[]=64e6979d49ed0ae2316ec052)
: Filtre pour inclure uniquement les stations exploitées par des ID d'opérateurs spécifiques. Accepte un tableau d'ID d'opérateurs.

`truck_dedicated` · `boolean` · [Afficher l'URL d'exemple](tip:https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?truck_dedicated=true)
: Filtre pour inclure uniquement les stations dédiées ou principalement destinées à la recharge de camions. Applicable uniquement si la base de données de stations Eco-Movement est utilisée ; sinon, il est ignoré.
: `true`, `false`

`vehicle_types` · `enum` · [Afficher l'URL d'exemple](tip:https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?vehicle_types[]=VAN&vehicle_types[]=RIGID)
: Filtre pour inclure uniquement les stations prenant en charge les types de véhicules OCPI spécifiés. Tous les types de véhicules sont inclus par défaut. Applicable uniquement si la base de données de stations Eco-Movement est utilisée ; sinon, il est ignoré.
: `VAN`, `RIGID`, `TRUCK_WITH_TRAILER`

### Niveau EVSE

Filtres qui évaluent les capacités de recharge spécifiques de la station. Ces filtres effectuent une exclusion et une [transformation](/api-reference/core/tiles/filters#exemples-de-transformation-des-données) : les stations non correspondantes sont exclues, et les champs dynamiques des stations correspondantes sont recalculés.

`minimum_power` · `integer` · [Afficher un exemple d'URL](tip:https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?minimum_power=50)
: Filtre pour inclure uniquement les stations dont au moins un connecteur atteint ou dépasse la valeur de puissance spécifiée (en kW). Accepte un entier supérieur à 0.

`maximum_power` · `integer` · [Afficher un exemple d'URL](tip:https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?maximum_power=150)
: Filtre pour inclure uniquement les stations dont la puissance de recharge maximale de n'importe quel connecteur ne dépasse pas la valeur de puissance spécifiée (en kW). Accepte un entier supérieur à 0.

`minimum_energy_price` · `number` · [beta](tip:Bêta;;Ce filtre est en bêta et peut changer avant de devenir stable.) · [Afficher l'URL d'exemple](tip:https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?minimum_energy_price=0.2&currency=EUR)
: Filtre pour inclure uniquement les stations dont les connecteurs compatibles ont au moins un prix actif supérieur ou égal à la valeur spécifiée, évalué dans la devise définie par `currency`. Voir [tarification des stations](/docs/getting-started/station-pricing). Applicable uniquement si la base de données de stations Eco-Movement est utilisée ; sinon, il est ignoré.

`maximum_energy_price` · `number` · [beta](tip:Bêta;;Ce filtre est en bêta et peut changer avant de devenir stable.) · [Afficher l'URL d'exemple](tip:https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?maximum_energy_price=0.5&currency=EUR)
: Filtre pour inclure uniquement les stations dont les connecteurs compatibles ont au moins un prix actif inférieur ou égal à la valeur spécifiée, évalué dans la devise définie par `currency`. Voir [tarification des stations](/docs/getting-started/station-pricing). Applicable uniquement si la base de données de stations Eco-Movement est utilisée ; sinon, il est ignoré.

`connectors` · `enum` · [Afficher un exemple d'URL](tip:https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?connectors[]=CHADEMO)
: Filtre pour inclure uniquement les stations qui ont des EVSE avec les types de connecteurs spécifiés. Accepte un tableau de chaînes contenant n'importe quelle valeur de connecteur OCPI 2.2.1.
: `CHADEMO`, `DOMESTIC_A`, `DOMESTIC_B`, `DOMESTIC_C`, `DOMESTIC_D`, `DOMESTIC_E`, `DOMESTIC_F`, `DOMESTIC_G`, `DOMESTIC_H`, `DOMESTIC_I`, `DOMESTIC_J`, `DOMESTIC_K`,
`DOMESTIC_L`, `DOMESTIC_M`, `DOMESTIC_N`, `DOMESTIC_O`, `IEC_60309_2_single_16`, `IEC_60309_2_three_16`, `IEC_60309_2_three_32`, `IEC_60309_2_three_64`, `IEC_62196_T1`,
`IEC_62196_T1_COMBO`, `IEC_62196_T2`, `IEC_62196_T2_COMBO`, `IEC_62196_T3A`, `IEC_62196_T3C`, `PANTOGRAPH_BOTTOM_UP`, `PANTOGRAPH_TOP_DOWN`, `TESLA_R`, `TESLA_S`, `GB_T`,
`CHAOJI`, `NEMA_5_20`, `NEMA_6_30`, `NEMA_6_50`, `NEMA_10_30`, `NEMA_10_50`, `NEMA_14_30`, `NEMA_14_50`

`evse_statuses` · `enum` · [Afficher un exemple d'URL](tip:https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?evse_statuses[]=AVAILABLE&evse_statuses[]=CHARGING)
: Filtre pour inclure uniquement les stations dont les EVSE ont les statuts spécifiés.
: `BLOCKED`, `PLANNED`, `AVAILABLE`, `CHARGING`, `UNKNOWN`, `RESERVED`, `OUT_OF_ORDER`, `INOPERATIVE`

## Conversion de devise

Le paramètre de requête `currency` est pris en charge sur l'ensemble des endpoints du service de tuiles (`tile.json`, `tile.mvt` et `count`). Il définit la devise des prix de l'énergie renvoyés et filtrés.

- Lorsque `currency` est omis, `connector_minimum_energy_price` et `connector_maximum_energy_price` sont renvoyés en EUR.
- Lorsque `currency` est un code de devise ISO 4217 valide, tel que `USD`, `GBP`, `DKK` ou `EUR` :
  - Les valeurs renvoyées dans `connector_minimum_energy_price` et `connector_maximum_energy_price` sont converties de leur devise source vers la devise demandée côté serveur, à l'aide du taux de conversion actif.
  - Les filtres `minimum_energy_price` et `maximum_energy_price` sont évalués sur les prix convertis dans la devise demandée, ou en EUR si `currency` est omis.
- Lorsque la devise d'origine est identique à la devise demandée, `price_conversion_rate` est renvoyé avec la valeur `1.0`.
- Lorsque `currency` n'est pas un code de devise ISO 4217 valide, le service de tuiles renvoie une erreur avec les détails suivants :
  - Statut : `400 Bad Request`
  - Code : `TILE_INVALID_PARAMETER_VALUE`
  - Message : `Invalid parameter 'currency': found string {invalid currency} but expected one of {supported currencies}.`

```bash Example URL
https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?maximum_energy_price=0.5&currency=USD
```

### Exemples de transformation des données

Certaines sorties sont recalculées lorsque des filtres au niveau de l'EVSE sont appliqués. Ces champs sont « transformés » pour ignorer les connecteurs qui ne correspondent pas aux critères de recherche de l'utilisateur.
Ces champs de sortie « dynamiques » sont `connector_maximum_power`, `connector_minimum_energy_price`, `connector_maximum_energy_price` et `evses_*`.

<details>
  <summary>Même type de filtre, valeurs différentes</summary>
  La requête inclut un filtre de connecteur CHADEMO. La station est incluse car elle possède un connecteur CHADEMO, mais les champs dynamiques sont transformés pour ignorer les bornes Combo Type 1.

```bash Example URL
https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?connectors[]=IEC_62196_T1_COMBO&connectors[]=CHADEMO
```

```json Response
{
  "id": "station_a",
  // Static: Remains 150 kW (This represents the station maximum power across all connectors)
  "station_maximum_power": 150,
  // Dynamic: Adjusted to 100 kW (Max power of the CHADEMO connector)
  "connector_maximum_power": 100,
  // Dynamic: Counts the 1 CHADEMO chargers
  "evses_out_of_order": 0,
  // Dynamic: 0, because the charging Type 1 plugs are filtered out
  "evses_available": 1
}
```
</details>

<details>
  <summary>Filtres de prix</summary>
  La requête inclut un filtre `maximum_energy_price`, éventuellement combiné à d'autres filtres de niveau EVSE. Un connecteur ne correspond que s'il satisfait tous les filtres à la fois, et les champs de prix dynamiques sont recalculés uniquement pour les connecteurs correspondants.


**Station A de référence**

- **EVSE 1 :** CCS • 150 kW • Disponible • 0,65 €
- **EVSE 2 :** CCS • 50 kW • Disponible • 0,35 €
- **EVSE 3 :** Type 2 • 22 kW • Disponible • 0,25 €

**Scénario 1 : filtre de prix uniquement**

```bash Example URL
https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?maximum_energy_price=0.40
```

Correspondance : les EVSE 2 et 3 sont retenus. L'EVSE 1 est exclu.

```json Response
{
  "connector_maximum_power": 50,
  "evses_available": 2,
  // Dynamic: lowest price of the matching connectors, not of the entire station
  "connector_minimum_energy_price": 0.25,
  // Dynamic: highest price of the matching connectors, not of the entire station
  "connector_maximum_energy_price": 0.35
}
```

**Scénario 2 : filtre de connecteur uniquement**

```bash Example URL
https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?connectors[]=CCS
```

Correspondance : les EVSE 1 et 2 sont retenus.

```json Response
{
  "connector_maximum_power": 150,
  "evses_available": 2,
  // Dynamic: lowest price of the CCS connectors
  "connector_minimum_energy_price": 0.35,
  // Dynamic: highest price of the CCS connectors
  "connector_maximum_energy_price": 0.65
}
```

**Scénario 3 : filtre de prix et de connecteur**

```bash Example URL
https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?connectors[]=CCS&maximum_energy_price=0.30
```

Correspondance :

- Évalue `connector == CCS AND price <= 0.30`.
- Les connecteurs CCS (EVSE 1 et 2) coûtent 0,65 € et 0,35 €, ils ne passent donc pas le filtre de prix.
- Le connecteur Type 2 (EVSE 3) respecte le prix, mais ne passe pas le filtre de connecteur.

Résultat : station exclue (0 EVSE correspondant).

**Scénario 4 : filtre de prix et de puissance**

```bash Example URL
https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?minimum_power=100&maximum_energy_price=0.40
```

Correspondance :

- Évalue `power >= 100 kW AND price <= 0.40 €` sur le **même EVSE**.
- Le connecteur de 150 kW est trop cher (0,65 €).
- Les connecteurs moins chers (0,25 € à 0,35 €) sont trop lents (50 kW ou moins).

Résultat : station exclue (0 EVSE correspondant).
</details>
