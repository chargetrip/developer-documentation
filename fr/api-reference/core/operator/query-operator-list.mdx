Accédez à la liste complète des opérateurs de bornes de recharge en utilisant la requête operatorList. Elle est utile lorsque vous souhaitez parcourir ou rechercher des opérateurs.

## Requête

Aucune entrée n'est requise pour exécuter cette requête. Utilisez `filter` et `search` pour restreindre les résultats, et les arguments `size` et `page` pour les [paginer](/api-reference/core/api/pagination).
