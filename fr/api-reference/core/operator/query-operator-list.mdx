Accédez à la liste complète des opérateurs de bornes de recharge à l'aide de la requête operatorList. Elle est utile lorsque vous souhaitez parcourir ou rechercher des opérateurs.

## Query

Aucune entrée n'est requise pour exécuter cette requête. Utilisez `filter` et `search` pour affiner les résultats, ainsi que les arguments `size` et `page` pour les [paginer](/api-reference/core/api/pagination).
