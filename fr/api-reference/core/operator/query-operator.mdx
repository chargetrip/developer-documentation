Obtenez les détails d'un opérateur de bornes de recharge en utilisant la requête operator. Elle est utile lorsque vous souhaitez afficher les informations de l'opérateur à côté d'une station ou d'une session.

## Requête

Un `id` d'opérateur est obligatoire pour obtenir les détails de l'opérateur. L'`id` peut être obtenu via la [requête operatorList](/api-reference/core/operator/query-operator-list).
