Obtenez la liste des équipements disponibles autour d'une station donnée avec la requête amenityList. C'est utile lorsque vous souhaitez afficher les restaurants, commerces ou autres services à proximité pendant la recharge d'un véhicule.

## Requête

Un `id` de station est requis pour obtenir ses équipements. L'`id` peut être obtenu via un [itinéraire](/api-reference/core/route/query-get-route), le [service de tuiles](/api-reference/core/tiles/mvt) ou la [requête de stations à proximité](/api-reference/core/station/query-station-around). Utilisez l'argument `filter` pour affiner les résultats selon des critères précis, et les arguments `size` et `page` pour les [paginer](/api-reference/core/api/pagination).
