Avec la requête stationAround, vous pouvez récupérer les stations situées dans un rayon donné autour d'un point GeoJSON. C'est utile lorsqu'une station est occupée, ou lorsque vous souhaitez proposer plusieurs options de recharge.

## Requête

Un `location` (point GeoJSON) et une `distance` en mètres sont requis pour rechercher des stations autour d'un point. Utilisez les arguments `filter` et `search` pour affiner les résultats, et les arguments `size` et `page` pour les [paginer](/api-reference/core/api/pagination).
