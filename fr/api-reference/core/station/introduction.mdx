Le calcul d'itinéraire d'un VE repose sur la connaissance des endroits où il peut se recharger ; la base de données de stations doit donc être alimentée avant de pouvoir planifier des itinéraires. Par défaut, le schéma de station est conforme à la dernière norme [OCPI](https://evroaming.org/ocpi/). Des propriétés personnalisées peuvent être ajoutées, mais elles sont généralement déplacées vers des requêtes supplémentaires plutôt que vers la requête de station elle-même.

## Sources de données prises en charge

Données Eco-Movement
: En l'absence d'accord commercial, Chargetrip peut préremplir votre compte avec des données de stations premium d'[Eco-Movement](https://eco-movement.com). Elles couvrent plus de 100 000 stations de recharge en Europe, y compris la disponibilité en temps réel, la tarification et la disponibilité prévue, lorsqu'elles sont disponibles. Vous n'avez ainsi pas besoin de connecter plusieurs fournisseurs de bases de données de stations pour obtenir une couverture européenne. Consultez [eco-movement.com](https://eco-movement.com) pour les limitations régionales. [Contactez les ventes](mailto:sales@chargetrip.com) pour connaître les tarifs.

Données de stations personnalisées
: Les données de stations statiques comme dynamiques peuvent être importées dans Chargetrip. Cela nécessite un accord commercial avec le fournisseur. [Contactez les ventes](mailto:sales@chargetrip.com) pour discuter des possibilités.
