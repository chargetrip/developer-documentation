Souscrivez à un itinéraire en utilisant la souscription route. Elle est utile lorsque vous souhaitez recevoir des mises à jour en temps réel pendant le calcul d'un itinéraire.

## Souscription

Un `id` d'itinéraire est obligatoire pour souscrire à ses mises à jour. L'`id` peut être obtenu via la [mutation createRoute](/api-reference/core/route/mutation-create-route).
