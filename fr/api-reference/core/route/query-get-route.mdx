Obtenez les détails d'un itinéraire précédemment calculé en utilisant la requête getRoute. Elle est utile lorsque vous souhaitez afficher les arrêts de recharge, la distance et la durée d'un itinéraire.

## Requête

Un `id` d'itinéraire est obligatoire pour obtenir les détails de l'itinéraire. L'`id` peut être obtenu via la [mutation createRoute](/api-reference/core/route/mutation-create-route).
