Accédez à la liste complète des tarifs avec la requête héritée tariffList. Les nouvelles intégrations doivent utiliser à la place la [requête stationPrices](/api-reference/core/station-pricing/query-station-prices).

## Requête

Aucune entrée n'est requise pour exécuter cette requête. Utilisez les arguments `size` et `page` pour les [paginer](/api-reference/core/api/pagination).
