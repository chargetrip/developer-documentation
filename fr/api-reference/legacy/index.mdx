Ces opérations sont obsolètes. Une opération obsolète continue de fonctionner normalement pendant au moins 12 mois. Passé ce délai, elle est supprimée et les requêtes qui l'utilisent renvoient des erreurs GraphQL. Consultez les [obsolescences](/deprecations) pour le calendrier et pour l'opération qui remplace chacune d'entre elles.
