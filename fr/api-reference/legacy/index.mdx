## Politique de dépréciation

Ces opérations sont dépréciées. Une opération dépréciée continue de fonctionner normalement pendant au moins 12 mois. Passé ce délai, elle est supprimée et les requêtes qui l'utilisent retournent des erreurs GraphQL. Consultez les [dépréciations](/deprecations) pour le calendrier.

## Remplacements

Les nouvelles intégrations doivent utiliser les opérations de remplacement ci-dessous.

| Opération legacy | Remplacement |
| --- | --- |
| [`newRoute` mutation](/api-reference/legacy/route/mutation-new-route) | [`createRoute` mutation](/api-reference/core/route/mutation-create-route) |
| [`route` query](/api-reference/legacy/route/query-route) | [`getRoute` query](/api-reference/core/route/query-get-route) |
| [`routePath` query](/api-reference/legacy/route/query-route-path) | champ `RouteDetails.path_plot` |
| [`routeEmissions` query](/api-reference/legacy/route/query-route-emissions) | [`getRouteEmissions` query](/api-reference/core/emissions/query-emissions) |
| [`routeUpdatedById` subscription](/api-reference/legacy/route/subscription-route-updated-by-id) | [`route` subscription](/api-reference/core/route/subscription-route) |
