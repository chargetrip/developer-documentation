---
title: Liste des avis de l'utilisateur
schemaName: userReviewList
schemaType: Query
---

Récupérez tous les avis ajoutés par l'utilisateur authentifié pour l'ensemble des stations à l'aide de la requête userReviewList. Elle est utile lorsque vous souhaitez afficher l'historique des avis d'un utilisateur. Il s'agit d'une fonctionnalité premium. Contactez-nous pour plus d'informations.

## Query

Un en-tête `x-token` est requis pour autoriser l'utilisateur dont vous souhaitez récupérer les avis. Utilisez les arguments `size` et `page` pour les [paginer](/api-reference/api/pagination).
