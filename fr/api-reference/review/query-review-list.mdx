Chaque station peut être accompagnée d'avis d'utilisateurs. Interrogez des propriétés telles que la note et le message, ou recevez des données sur l'EV utilisé pour la recharge. Les avis sont limités à une seule base de données de stations et ne peuvent pas être utilisés entre différents projets.

## Query

Un `id` de station est requis pour obtenir ses avis. L'`id` peut être obtenu via un [itinéraire](/api-reference/route/query-get-route), le [service de tuiles](/api-reference/tiles/mvt) ou la [requête station around](/api-reference/station/query-station-around). Utilisez les arguments `size` et `page` pour les [paginer](/api-reference/api/pagination).
