---
title: Supprimer l'avis de l'utilisateur
schemaName: deleteUserReview
schemaType: Mutation
---

Supprimez un avis ajouté par l'utilisateur authentifié à l'aide de la mutation deleteUserReview. Il s'agit d'une fonctionnalité premium. Contactez-nous pour plus d'informations.

## Mutation

Un `id` d'avis est requis pour le supprimer. Un en-tête `x-token` est obligatoire pour autoriser l'utilisateur — l'avis doit lui appartenir, sinon une erreur se produit.
