L'endpoint de comptage des stations renvoie le nombre total de stations de recharge.

## Configuration
Pour récupérer le nombre de stations, effectuez une requête `GET` vers l'URL suivante :

```bash Count / Base URL
https://api.chargetrip.io/v2/station/count
```

### Filtrage
Utilisez le paramètre de requête `filter` pour affiner le comptage selon des critères spécifiques. Consultez la [documentation des filtres](/api-reference/tiles/filters) pour plus d'informations.

### Devise
Utilisez le paramètre de requête `currency` pour définir la devise des prix de l'énergie renvoyés et utilisés pour le filtrage. Consultez la [documentation sur la conversion de devise](/api-reference/tiles/filters) pour plus d'informations.
