Pour optimiser le temps de réponse et la taille, l'API MVT et l'API JSON renvoient par défaut une réponse minimisée. Cette approche garantit des performances optimales et réduit la taille des tuiles, ce qui est essentiel pour des interactions fluides avec la carte. Grâce aux sélecteurs, vous pouvez inclure les données supplémentaires dont votre application a spécifiquement besoin.

## Sélecteurs disponibles

Tout champ listé dans les propriétés de station des tuiles MVT et JSON peut être utilisé comme sélecteur dans son service respectif, à l'exception des champs GeoJSON obligatoires renvoyés par l'endpoint JSON.

`count` · `integer` · <span class="text-accent">default</span>
: Le nombre de stations dans un cluster. Un nombre de 1 signifie une feature Station, tandis qu'un nombre supérieur à 1 signifie une feature Cluster.

`expansion_zoom` · `integer` · <span class="text-accent">default</span>
: Le niveau de zoom auquel un cluster se divise en plusieurs clusters ou stations plus petits.

`id` · `string`
: L'identifiant de la station.

`lng` · `float`
: La longitude de la station.

`lat` · `float`
: La latitude de la station.

`station_maximum_power` · `integer`
: La puissance de charge maximale de la station (en kW) disponible à la station. Cette valeur est statique et reflète toujours la capacité maximale de la station, quels que soient les filtres de connecteurs.

`connector_maximum_power` · `integer`
: La puissance de charge maximale (en kW) disponible sur les connecteurs correspondant au filtre `connectors[]`. Si aucun filtre n'est fourni, tous les connecteurs sont pris en compte et elle est égale à `station_maximum_power`.

`preferred_operator` · `boolean`
: Indique si l'opérateur d'une station est un opérateur préféré. Les opérateurs préférés peuvent être gérés au niveau du projet dans le Dashboard.

`connector_minimum_energy_price` · `float` · [beta](tip:Bêta;;Ce champ est en bêta et peut changer avant de devenir stable.)
: Le prix de l'énergie le plus bas parmi les connecteurs de la station. Non renvoyé s'il n'est pas disponible.

`connector_maximum_energy_price` · `float` · [beta](tip:Bêta;;Ce champ est en bêta et peut changer avant de devenir stable.)
: Le prix de l'énergie le plus élevé parmi les connecteurs de la station. Non renvoyé s'il n'est pas disponible.

`price_vat` · `float` · [beta](tip:Bêta;;Ce champ est en bêta et peut changer avant de devenir stable.)
: La TVA appliquée au prix. Non renvoyé s'il n'est pas disponible.

`price_valid_until` · `string` · [beta](tip:Bêta;;Ce champ est en bêta et peut changer avant de devenir stable.)
: La date et l'heure jusqu'auxquelles le prix est valable. Non renvoyé s'il n'est pas disponible.

`price_original_currency` · `string` · [beta](tip:Bêta;;Ce champ est en bêta et peut changer avant de devenir stable.)
: La devise dans laquelle le prix était initialement défini, avant conversion en `currency`. Non renvoyé s'il n'est pas disponible.

`price_conversion_rate` · `float` · [beta](tip:Bêta;;Ce champ est en bêta et peut changer avant de devenir stable.)
: Le taux utilisé pour convertir le prix de sa devise d'origine en `currency`. Non renvoyé s'il n'est pas disponible.

`evse_status_blocked` · `integer`
: Le nombre d'EVSE au statut bloqué. Si un filtre `connectors[]` est fourni, seuls les EVSE bloqués correspondant aux types de connecteurs sélectionnés sont comptés.

`evse_status_planned` · `integer`
: Nombre d'EVSE au statut planifié. Si un filtre `connectors[]` est fourni, seuls les EVSE planifiés ayant au moins un des types de connecteurs sélectionnés sont comptés.

`evse_status_available` · `integer`
: Nombre d'EVSE au statut disponible. Si un filtre `connectors[]` est fourni, seuls les EVSE disponibles ayant au moins un des types de connecteurs sélectionnés sont comptés.

`evse_status_charging` · `integer`
: Nombre d'EVSE au statut en charge. Si un filtre `connectors[]` est fourni, seuls les EVSE en charge ayant au moins un des types de connecteurs sélectionnés sont comptés.

`evse_status_unknown` · `integer`
: Nombre d'EVSE au statut inconnu. Si un filtre `connectors[]` est fourni, seuls les EVSE inconnus ayant au moins un des types de connecteurs sélectionnés sont comptés.

`evse_status_reserved` · `integer`
: Nombre d'EVSE au statut réservé. Si un filtre `connectors[]` est fourni, seuls les EVSE réservés ayant au moins un des types de connecteurs sélectionnés sont comptés.

`evse_status_out_of_order` · `integer`
: Nombre d'EVSE au statut out_of_order. Si un filtre `connectors[]` est fourni, seuls les EVSE hors service ayant au moins un des types de connecteurs sélectionnés sont comptés.

`evse_status_inoperative` · `integer`
: Nombre d'EVSE au statut inoperative. Si un filtre `connectors[]` est fourni, seuls les EVSE inopérants ayant au moins un des types de connecteurs sélectionnés sont comptés.

## Implémentation

Pour demander des propriétés spécifiques, ajoutez le paramètre de requête `station_properties[]` à l'URL de la requête de tuile.

```bash Tile / Selectors / Example
https://api.chargetrip.io/v2/station/10/516/352/tile.mvt?station_properties[]={selector1}&station_properties[]={selector2}&station_properties[]={selector3}
```

## Exemples de comportement

Lorsque des sélecteurs sont fournis, la requête ne renvoie que les champs spécifiés.

### GeoJSON

Dans l'endpoint GeoJSON, les champs GeoJSON obligatoires (`type`, `geometry` et `id`) sont toujours renvoyés, quels que soient les sélecteurs choisis.

```json JSON Selectors example
{
  "type": "FeatureCollection",
  "features": [
    // Station feature
    {
      "id": "132313",
      "type": "Feature",
      "geometry": {
        "type": "Point",
        "coordinates": [6.789, 52.234]
      },
      // 'count' is missing because it wasn't provided as selector
      "properties": {
        "station_maximum_power": 350,
        "preferred_operator": true
      }
    },
    // Cluster feature
    // Cluster feature is not modified, as it's not affected by the selectors.
    {
      "type": "Feature",
      "geometry": {
        "type": "Point",
        "coordinates": [6.723, 50.0]
      },
      "properties": {
        "count": 3,
        "expansion_zoom": 18
      }
    }
  ]
}
```

### MVT

Dans l'endpoint MVT, seuls les paramètres explicitement sélectionnés sont renvoyés, car il n'y a aucun champ obligatoire.

```json MVT Selectors example
// Station feature
// 'count' is missing because it wasn't provided as a selector.
{
  "id": "132313",
  "preferred_operator": false,
  "station_maximum_power": 350
}

// Cluster feature
// Cluster feature is not modified, as it's not affected by the selectors.
{
  "count": 3,
  "expansion_zoom": 32
}
```
