title: Create truck route
schemaName: createTruckRoute
schemaType: Mutation
---

Create a new truck route by using the createTruckRoute mutation. This is useful when you want to calculate charging stops, energy consumption, and drive time for an e-truck between an origin and a destination.

## Mutation

A `vehicle`, `origin`, and `destination` are required to create a truck route. Optionally add `via` points, `operators`, `weather`, or other preferences to refine the calculation. The mutation returns a truck route `id`, which can be used to retrieve route details or subscribe to updates.
