schemaName: getRouteEmissions

---

Obtenez le profil d'émissions d'un itinéraire à l'aide de la requête getRouteEmissions. Elle est utile lorsque vous souhaitez afficher l'impact environnemental d'un trajet.

## Query

Un `route_id` et un `route_details_id` sont requis pour obtenir les émissions d'un itinéraire. Les deux peuvent être obtenus via la [requête getRoute](/api-reference/route/query-get-route).
