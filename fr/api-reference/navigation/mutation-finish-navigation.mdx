---
title: Terminer la navigation
schemaName: finishNavigation
schemaType: Mutation
---

Mettez fin à une session de navigation active à l'aide de la mutation finishNavigation. Elle est utile lorsqu'un conducteur arrive à destination ou que le trajet est annulé.

## Mutation

Un `id` de session de navigation et une `current_location` sont requis pour la terminer. L'`id` peut être obtenu via la [mutation startNavigation](/api-reference/navigation/mutation-start-navigation).
