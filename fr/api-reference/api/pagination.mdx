---
title: Pagination
---

Pour garder l'API rapide et réactive, les queries de liste limitent la quantité de données renvoyées dans une même requête. Deux types de pagination sont utilisés dans l'API :

- Par curseur (actuelle) : utilisée par les queries de liste récemment développées.
- Par décalage (héritée) : utilisée par la plupart des queries de liste existantes. Elles seront à terme remplacées par des versions par curseur.

> [!WARNING] Limites de pagination
> Quel que soit le type de pagination, les queries de liste renvoient au maximum 100 éléments par page, sauf la query `getRouteStationsWithAmenities`, qui est limitée à 10.

## Pagination par curseur

La pagination par curseur est le standard actuel. Elle vous permet de définir le point de départ d'une requête à l'aide d'un curseur, un identifiant unique pour une position dans l'ensemble de résultats.

### Arguments

`first` · <span class="text-muted">Integer</span>
: Le nombre d'éléments à renvoyer.

`after` · <span class="text-muted">String</span>
: Le curseur à partir duquel commencer. Omettez cet argument, ou définissez-le à `null`, pour récupérer la première page. Pour les pages suivantes, utilisez la valeur `page_info.end_cursor` de la réponse précédente.

### Réponse

La réponse renvoie les résultats directement via un tableau `nodes`, accompagné de métadonnées de pagination.

`nodes` · <span class="text-muted">Array</span>
: La liste des objets de données de la page actuelle.

`total_count` · <span class="text-muted">Integer</span>
: Le nombre total d'éléments correspondant à la query, toutes pages confondues.

`page_info.has_next_page` · <span class="text-muted">Boolean</span>
: Indique si d'autres résultats sont disponibles après la page actuelle.

`page_info.has_previous_page` · <span class="text-muted">Boolean</span>
: Indique si d'autres résultats sont disponibles avant la page actuelle.

`page_info.start_cursor` · <span class="text-muted">String</span>
: Le curseur du premier nœud de `nodes`.

`page_info.end_cursor` · <span class="text-muted">String</span>
: Le curseur du dernier nœud de `nodes`. Utilisez cette valeur comme argument `after` dans votre prochaine query.

## Pagination par décalage (héritée)

La pagination par décalage est le standard hérité, encore utilisé par la plupart des queries de liste. Elle utilise `page` pour ignorer un nombre défini d'enregistrements et `size` pour renvoyer une fenêtre de résultats de taille fixe.

### Arguments

`size` · <span class="text-muted">Integer</span>
: Le nombre d'éléments à renvoyer par page.

`page` · <span class="text-muted">Integer</span>
: Le numéro de la page à récupérer. Omettez cet argument, ou définissez-le à `0`, pour récupérer la première page.

### Réponse

La réponse renvoie directement une liste d'objets de données, limitée par la valeur `size`.
