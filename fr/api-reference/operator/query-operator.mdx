Obtenez les détails d'un opérateur de bornes de recharge à l'aide de la requête operator. Elle est utile lorsque vous souhaitez afficher les informations d'un opérateur à côté d'une station ou d'une session.

## Query

Un `id` d'opérateur est requis pour obtenir ses détails. L'`id` peut être obtenu via la [requête operatorList](/api-reference/operator/query-operator-list).
