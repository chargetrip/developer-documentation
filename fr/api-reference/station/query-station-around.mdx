Avec la requête stationAround, vous pouvez récupérer les stations situées dans un rayon donné autour d'un point GeoJSON. Cela peut être utile lorsqu'une station est occupée, ou lorsque vous souhaitez proposer plusieurs options de recharge.

## Query

Une `location` (point GeoJSON) et une `distance` en mètres sont requises pour rechercher des stations autour d'un point. Utilisez les arguments `filter` et `search` pour affiner les résultats, ainsi que les arguments `size` et `page` pour les [paginer](/api-reference/api/pagination).
