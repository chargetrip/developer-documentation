title: Liste des équipements
schemaName: amenityList
schemaType: Query
---

Obtenez la liste des équipements disponibles autour d'une station donnée à l'aide de la requête amenityList. Elle est utile lorsque vous souhaitez afficher les restaurants, commerces ou autres installations à proximité pendant la recharge d'un véhicule.

## Query

Un `id` de station est requis pour obtenir ses équipements. L'`id` peut être obtenu via un [itinéraire](/api-reference/route/query-get-route), le [service de tuiles](/api-reference/tiles/mvt) ou la [requête station around](/api-reference/station/query-station-around). Utilisez l'argument `filter` pour affiner les résultats selon des critères spécifiques, ainsi que les arguments `size` et `page` pour les [paginer](/api-reference/api/pagination).
