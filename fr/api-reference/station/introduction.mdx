Calculer l'itinéraire d'un EV suppose de savoir où il peut se recharger : la base de données de stations doit donc être alimentée avant de pouvoir planifier des itinéraires. Par défaut, le schéma des stations est conforme au dernier standard [OCPI](https://evroaming.org/ocpi/). Des propriétés personnalisées peuvent être ajoutées, mais elles sont généralement déplacées vers des queries supplémentaires plutôt que dans la query de station elle-même.

## Sources de données prises en charge

Données Eco-Movement
: Sans accord commercial préalable, Chargetrip peut préremplir votre compte avec des données de stations premium d'[Eco-Movement](https://eco-movement.com). Elles couvrent plus de 100 000 stations de recharge en Europe, avec la disponibilité en temps réel, les tarifs et la disponibilité prévue, lorsqu'ils sont disponibles. Cela évite de connecter plusieurs fournisseurs de bases de données de stations pour obtenir une couverture européenne. Consultez [eco-movement.com](https://eco-movement.com) pour les limitations régionales. [Contactez l'équipe commerciale](mailto:sales@chargetrip.com) pour connaître les tarifs.

Données de stations personnalisées
: Des données de stations statiques comme dynamiques peuvent être importées dans Chargetrip. Cela nécessite un accord commercial avec le fournisseur. [Contactez l'équipe commerciale](mailto:sales@chargetrip.com) pour discuter des possibilités.
