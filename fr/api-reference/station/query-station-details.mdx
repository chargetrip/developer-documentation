Obtenez les détails d'une station à l'aide de la requête station. Elle est utile lorsque vous souhaitez afficher le type et le nombre de chargeurs, l'emplacement ou tout autre détail actuellement disponible pour une station.

## Query

Un `id` ou un `evse_id` de station est requis pour obtenir ses détails. L'`id` peut être obtenu via un [itinéraire](/api-reference/route/query-get-route), le [service de tuiles](/api-reference/tiles/mvt) ou la [requête station around](/api-reference/station/query-station-around).
