---
title: Route details
schemaName: getRoute
schemaType: Query
---

Get the details of a previously calculated route by using the getRoute query. This is useful when you want to display a route's charging stops, distance, and duration.

## Query

A route `id` is required to get route details. The `id` can be obtained through the [createRoute mutation](/api-reference/route/mutation-create-route).
