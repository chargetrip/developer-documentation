description: "Obtenez le chemin d'un itinéraire précédemment calculé avec la query routePath pour afficher la polyligne de l'itinéraire sur une carte."
schemaName: routePath
schemaType: Query
---

Obtenez le chemin d'un itinéraire précédemment calculé à l'aide de la requête routePath. Elle est utile lorsque vous souhaitez afficher la polyligne d'un itinéraire sur une carte.
