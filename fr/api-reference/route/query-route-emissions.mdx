---
title: Émissions de l'itinéraire
schemaName: routeEmissions
schemaType: Query
---

Obtenez le profil d'émissions d'un itinéraire à l'aide de l'ancienne requête routeEmissions. Les nouvelles intégrations doivent utiliser à la place la [requête getRouteEmissions](/api-reference/emissions/query-emissions).
