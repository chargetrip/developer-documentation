---
title: Liste de véhicules connectés
schemaName: connectedVehicleList
schemaType: Query
---

Obtenez la liste des véhicules connectés de l'utilisateur actuel à l'aide de la requête connectedVehicleList. Elle est utile lorsque vous souhaitez afficher tous les véhicules qu'un utilisateur a connectés à un fournisseur.

## Query

Aucune entrée n'est requise pour exécuter cette requête. Utilisez `filter` pour affiner les résultats par statut, ainsi que les arguments `size` et `page` pour les [paginer](/api-reference/api/pagination).
