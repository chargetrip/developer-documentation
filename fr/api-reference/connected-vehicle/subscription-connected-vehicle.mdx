Subscribe to a connected vehicle by using the connectedVehicle subscription. This is useful when you want to receive real-time updates on its authorization status.

## Subscription

A connected vehicle `id` is required to subscribe to its updates. The `id` can be obtained through the [createConnectedVehicle mutation](/api-reference/connected-vehicle/mutation-create-connected-vehicle).
