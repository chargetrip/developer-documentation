---
title: Données de véhicule connecté
schemaName: connectedVehicleData
schemaType: Query
---

Obtenez les données en direct d'un véhicule à l'aide de la requête connectedVehicleData. Elle est utile lorsque vous souhaitez récupérer en temps réel des données directement depuis un véhicule connecté, comme son état de charge ou sa position.

## Query

Un `id` de véhicule connecté est requis pour obtenir ses données en direct. L'`id` peut être obtenu via la [mutation createConnectedVehicle](/api-reference/connected-vehicle/mutation-create-connected-vehicle).
