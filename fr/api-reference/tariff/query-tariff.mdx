---
title: Détails du tarif
schemaName: tariff
schemaType: Query
---

Obtenez les détails d'un tarif à l'aide de la requête tariff. Elle est utile lorsque vous utilisez une base de données de stations autre qu'Ecomovement et que vous souhaitez afficher le coût de la recharge à une station.

## Query

Un `id` de tarif est requis pour obtenir ses détails. L'`id` peut être obtenu via la [requête tariffList](/api-reference/tariff/query-tariff-list).
