Accédez à la liste complète des tarifs à l'aide de la requête tariffList. Elle est utile lorsque vous souhaitez afficher ou comparer les coûts de recharge entre stations.

## Query

Aucune entrée n'est requise pour exécuter cette requête. Utilisez les arguments `size` et `page` pour les [paginer](/api-reference/api/pagination).
