Obtenez les détails d'une isoline précédemment calculée à l'aide de la requête isoline. Elle est utile lorsque vous souhaitez afficher la zone accessible pour un véhicule.

## Query

Un `id` d'isoline est requis pour obtenir les détails de l'isoline. L'`id` peut être obtenu via la [mutation createIsoline](/api-reference/isoline/mutation-create-isoline).
