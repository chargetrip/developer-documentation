Listez les groupes de mise en avant de votre workspace à l'aide de la requête boostingGroups. Elle est utile pour afficher une vue d'ensemble de vos groupes ou trouver ceux qui sont actuellement actifs.

## Query

Aucune entrée n'est requise pour exécuter cette requête. Utilisez les arguments `first` et `after` pour [paginer](/api-reference/light-vehicle/api/pagination) les résultats, et l'argument `filter` pour les restreindre par `client_id` ou `status`.
