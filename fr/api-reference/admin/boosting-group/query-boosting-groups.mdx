Listez les groupes de boost de votre espace de travail en utilisant la requête boostingGroups. Elle est utile lorsque vous souhaitez créer une vue d'ensemble de vos groupes ou trouver les groupes actuellement actifs.

## Requête

Aucune entrée n'est requise pour exécuter cette requête. Utilisez les arguments `first` et `after` pour [paginer](/api-reference/core/api/pagination) les résultats, et l'argument `filter` pour les restreindre par `client_id` ou `status`.
