Obtenez un groupe de boost en utilisant la requête boostingGroup. Elle est utile lorsque vous souhaitez vérifier si un groupe est actif ou quelles stations il favorise actuellement. Pour comprendre l'effet des groupes de boost sur un itinéraire, consultez le [guide des groupes de boost](/docs/getting-started/route-boosting-groups).

## Requête

Un `id` de groupe de boost est obligatoire. L'`id` peut être obtenu via la [mutation createBoostingGroup](/api-reference/admin/boosting-group/mutation-create-boosting-group) ou la [requête boostingGroups](/api-reference/admin/boosting-group/query-boosting-groups).
