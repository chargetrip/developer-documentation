L'API Admin est une API GraphQL distincte dotée de son propre schéma. Utilisez-la pour gérer les ressources qui déterminent le comportement de votre projet, plutôt que de les demander au support Chargetrip. Aujourd'hui, elle couvre les groupes de boost, qui vous permettent de donner la priorité à certaines stations de recharge lors du calcul d'itinéraire. Pour comprendre l'effet des groupes de boost sur un itinéraire, consultez [donner la priorité à certaines stations de recharge](/docs/getting-started/route-boosting-groups).

> [!WARNING] Alpha
> L'API Admin est en alpha et n'est pas disponible dans les offres gratuites. Contactez le support pour y accéder et attendez-vous à des changements du schéma.
