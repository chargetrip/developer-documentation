Obtenez les détails d'un itinéraire précédemment calculé à l'aide de la requête getRoute. Elle est utile lorsque vous souhaitez afficher les arrêts de recharge, la distance et la durée d'un itinéraire.

## Query

Un `id` d'itinéraire est requis pour obtenir les détails de l'itinéraire. L'`id` peut être obtenu via la [mutation createRoute](/api-reference/light-vehicle/route/mutation-create-route).
