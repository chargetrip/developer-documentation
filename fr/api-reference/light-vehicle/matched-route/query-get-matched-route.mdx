Obtenez les détails d'un itinéraire concordant précédemment calculé à l'aide de la requête getMatchedRoute. Elle est utile lorsque vous souhaitez récupérer à nouveau un itinéraire concordant sans ouvrir de nouvelle subscription.

## Query

Un `id` d'itinéraire concordant est requis pour obtenir les détails de l'itinéraire. L'`id` peut être obtenu via la [mutation createMatchedRoute](/api-reference/light-vehicle/matched-route/mutation-create-matched-route).
