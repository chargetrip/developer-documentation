Accédez à des données encore plus détaillées grâce à la requête vehiclePremium. Elle contient des données étendues sur la batterie, la carrosserie du véhicule, la disponibilité, le prix, l'efficacité, la sécurité, et plus encore. [Contactez le service commercial](https://www.chargetrip.com/contact/sales) pour passer aux données véhicule premium.

## Query

Un `id` de véhicule est requis pour obtenir les détails premium d'un véhicule. L'`id` peut être obtenu via la [requête vehicleList](/api-reference/light-vehicle/vehicle/query-vehicles). Utilisez l'argument country pour appliquer la localisation aux données.
