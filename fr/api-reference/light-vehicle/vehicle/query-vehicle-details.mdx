Obtenez les caractéristiques d'un véhicule à l'aide de la requête vehicle.

## Query

Un `id` de véhicule est requis pour obtenir ses détails. L'`id` peut être obtenu via la [requête vehicleList](/api-reference/light-vehicle/vehicle/query-vehicles). Utilisez l'argument country pour appliquer la localisation aux données.
