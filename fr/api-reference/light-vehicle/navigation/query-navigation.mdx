Obtenez une session de navigation active à l'aide de la requête navigation. Elle est utile lorsque vous souhaitez afficher la progression actuelle d'un conducteur sur un itinéraire.

## Query

Un `id` de session de navigation est requis pour obtenir ses détails. L'`id` peut être obtenu via la [mutation startNavigation](/api-reference/light-vehicle/navigation/mutation-start-navigation).
