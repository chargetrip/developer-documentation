Mettez à jour une session de navigation active à l'aide de la mutation updateNavigation. Elle est utile lorsque vous souhaitez signaler la position d'un conducteur au fil de sa progression sur un itinéraire.

## Mutation

Un `id` de session de navigation et des `location_data` sont requis pour la mettre à jour. L'`id` peut être obtenu via la [mutation startNavigation](/api-reference/light-vehicle/navigation/mutation-start-navigation).
