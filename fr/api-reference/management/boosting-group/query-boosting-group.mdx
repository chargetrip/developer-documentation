Obtenez un groupe de mise en avant à l'aide de la requête boostingGroup. Elle est utile lorsque vous voulez vérifier si un groupe est actif, ou quelles stations il met actuellement en avant. Pour savoir comment les groupes de mise en avant influencent un itinéraire, consultez le [guide des groupes de mise en avant](/docs/getting-started/route-boosting-groups).

## Query

Un `id` de groupe de mise en avant est requis. L'`id` peut être obtenu via la [mutation createBoostingGroup](/api-reference/management/boosting-group/mutation-create-boosting-group) ou la [requête boostingGroups](/api-reference/management/boosting-group/query-boosting-groups).
