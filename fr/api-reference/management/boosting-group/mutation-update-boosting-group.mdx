Mettez à jour un groupe de mise en avant à l'aide de la mutation updateBoostingGroup. Elle est utile lorsque vous voulez activer ou désactiver un groupe sans le supprimer.

## Mutation

Un `id` de groupe de mise en avant est requis. L'`id` peut être obtenu via la [mutation createBoostingGroup](/api-reference/management/boosting-group/mutation-create-boosting-group). N'envoyez que les champs que vous souhaitez modifier. Cette mutation ne modifie pas les stations d'un groupe.

> [!WARNING] Alpha
> Cette opération est en alpha et n'est pas disponible sur les offres gratuites. Contactez le support pour y accéder.

<details>
  <summary>Désactiver un groupe de mise en avant.</summary>
  Un groupe inactif n'est plus utilisé dans les calculs d'itinéraire.

```graphql Example request
mutation UpdateBoostingGroup {
  updateBoostingGroup(
    input: { id: "6527e1f1a8b4c2d3e4f5a6b7", status: inactive }
  ) {
    id
    status
  }
}
```
</details>
