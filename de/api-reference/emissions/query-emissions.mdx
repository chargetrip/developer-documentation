Rufen Sie das Emissionsprofil einer Route mit der Query getRouteEmissions ab. Dies ist nützlich, wenn Sie die Umweltauswirkungen einer Fahrt anzeigen möchten.

## Query

Zum Abrufen der Emissionen einer Route sind eine `route_id` und eine `route_details_id` erforderlich. Beide erhalten Sie über die [Query getRoute](/api-reference/route/query-get-route).
