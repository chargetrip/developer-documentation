Abonnieren Sie eine Route mit der Subscription route. Das ist nützlich, wenn Sie Echtzeit-Updates erhalten möchten, während eine Route berechnet wird.

## Subscription

Zum Abonnieren der Updates ist die `id` einer Route erforderlich. Die `id` erhalten Sie über die [Mutation createRoute](/api-reference/core/route/mutation-create-route).
