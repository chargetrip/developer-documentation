Rufen Sie die Details einer zuvor berechneten Route mit der Query getRoute ab. Das ist nützlich, wenn Sie die Ladestopps, die Distanz und die Dauer einer Route anzeigen möchten.

## Query

Zum Abrufen der Routendetails ist die `id` einer Route erforderlich. Die `id` erhalten Sie über die [Mutation createRoute](/api-reference/core/route/mutation-create-route).
