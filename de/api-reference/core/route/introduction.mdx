Die Routenplanung für EVs bringt besondere Herausforderungen mit sich. Faktoren wie Batteriekapazität, realer Energieverbrauch, Topografie, Wetter und die Verfügbarkeit von Ladenetzen bestimmen gemeinsam, ob ein Fahrzeug sein Ziel erreicht.

Der Routing-Service berücksichtigt all diese Variablen, um optimale EV-Routen zu finden. Mit einem erstklassigen Energieverbrauchsmodell platziert er Ladestopps automatisch genau dann und dort, wo sie benötigt werden. Routen sind außerdem vollständig anpassbar, sodass Sie sie auf die Geschäftsregeln, Netze und Fahrerpräferenzen abstimmen können, die für Sie wichtig sind.

> [!WARNING] Hybridfahrzeuge
> Hybrid- und Plug-in-Hybridfahrzeuge sind nicht ausschließlich auf ihre Batterie angewiesen, daher enthalten ihre Routen keine Ladestopps.

## Eine Route auf Ihr Ziel optimieren

Dieselbe Anfrage kann je nach Optimierungsziel unterschiedliche Routen liefern. Dies sind die häufigsten Ziele und die Anleitungen, die jedes davon ausführlich behandeln.

Schnellste Ankunft
: Passen Sie den Fahrstil mit `speed_factor`, `maximum_speed` oder einem `style` von `eco` oder `sport` an. Fügen Sie Echtzeit-Verkehrsdaten und eine Abfahrtszeit hinzu, um genaue Ankunftszeiten zu erhalten, und bevorzugen Sie Stationen direkt an der Autobahn, um Umwege zu vermeiden. Siehe [Route erstellen](/docs/getting-started/route).

Ihr eigenes Netz oder die Ladekarte eines Fahrers
: Lenken Sie Fahrer zu den Netzen, die sie Ihrer Meinung nach nutzen sollen. Bevorzugen oder verlangen Sie bestimmte Betreiber, stufen Sie sie als `high`, `medium` oder `low` ein, beschränken Sie Rankings pro Land oder schließen Sie Betreiber ganz aus bzw. vermeiden Sie sie. Legen Sie Standardwerte für Ihr Projekt im Dashboard fest und überschreiben Sie sie pro Anfrage. Siehe [Routing mit bevorzugten Betreibern](/docs/getting-started/route-operators).

Laden in der Nähe von Ausstattung
: Finden Sie Stationen entlang einer Route, die zu Fuß von Restaurants, Cafés oder Geschäften erreichbar sind, damit Fahrer einen Ladestopp um das herum planen können, was sie unternehmen möchten. Siehe [Stopps mit Ausstattung entlang der Route](/docs/getting-started/route-amenity-stops).

Ihre eigene Reiseroute
: Fügen Sie Wegpunkte hinzu, entweder als einfache Standortstopps wie eine Zustellung oder Abholung oder als Ladestopps an einer bestimmten Station. Legen Sie fest, wie lange das Fahrzeug an jedem Stopp bleibt und welche Ladung es von dort an transportiert. Siehe [Route mit Stopps](/docs/getting-started/route-stop).
