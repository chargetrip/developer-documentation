Rufen Sie mit der tariff-Query die Tarifdetails ab. Das ist nützlich, wenn Sie eine andere Stationsdatenbank als Ecomovement verwenden und die Ladekosten an einer Station anzeigen möchten. Wie Sie Preise darstellen, erfahren Sie in der [Anleitung zur Stationspreisgestaltung](/docs/getting-started/station-pricing).

## Query

Um Tarifdetails abzurufen, ist die `id` eines Tarifs erforderlich. Die `id` erhalten Sie über die [tariffList-Query](/api-reference/core/tariff/query-tariff-list).
