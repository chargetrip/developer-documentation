Rufen Sie mit der tariffList-Query die vollständige Liste der Tarife ab. Das ist nützlich, wenn Sie die Ladekosten verschiedener Stationen anzeigen oder vergleichen möchten. Wie Sie Preise darstellen, erfahren Sie in der [Anleitung zur Stationspreisgestaltung](/docs/getting-started/station-pricing).

## Query

Zur Ausführung dieser Query ist keine Eingabe erforderlich. Mit den Argumenten `size` und `page` [paginieren](/api-reference/core/api/pagination) Sie die Ergebnisse.
