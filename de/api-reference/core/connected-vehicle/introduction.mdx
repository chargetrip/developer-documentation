Eine Navigationsanwendung für Elektrofahrzeuge benötigt Echtzeit-Fahrzeugdaten wie den Ladezustand, um damit Routen zu planen. Fast alle heute zugelassenen Elektrofahrzeuge haben ein Modem, das diese Daten an externe Anwendungen senden kann, doch die Standards und die Art der Bereitstellung unterscheiden sich je nach Hersteller.

Die Fahrzeugkonnektivität bringt diese Daten über eine einzige Quelle in Ihre Anwendung. Eine Abstraktionsschicht erfasst, bereinigt und bereitet die Daten vieler Anbieter für die Routing-Engine auf, und eine anpassbare Landingpage ermöglicht Ihren Nutzern die Authentifizierung und Einwilligung. Sie funktioniert mit Ihrem aktuellen Anbieter für Daten verbundener Fahrzeuge, Ihrer Telemetrie-API oder Ihrem OBD-II-Dongle und ist mit [Enode](https://enode.io) vorintegriert.

Für den Zugang oder die Nutzung eines anderen Datenanbieters oder Ihrer eigenen API kontaktieren Sie [sales@chargetrip.com](mailto:sales@chargetrip.com).

## Unterstützte Datenquellen

Datenplattform für verbundene Fahrzeuge
: Cloud-Lösungen, die sich mit den APIs von Fahrzeugherstellern verbinden und diese Daten Dritten bereitstellen. Sie übernehmen die Einwilligung der Fahrzeughalter und standardisieren das Datenformat. Unterstützte Marken und Preise unterscheiden sich zwischen den Plattformen erheblich. Das eignet sich für App-Entwickler, zum Beispiel für einen CPO oder eMSP. Unterstützte Plattformen sind [Enode](https://enode.io), [High Mobility](https://high-mobility.com), [Smartcar](https://smartcar.com) und [WirelessCar](https://wirelesscar.com).

Hardware-Dongle
: Bluetooth-Dongles, die manuell im Fahrzeug installiert werden. Sie haben relativ hohe Anschaffungskosten, aber geringe laufende Kosten, weshalb sie bei Logistik-Flottenbetreibern beliebt sind. Der [Geotab Go9](https://support.geotab.com/go-devices/go9/doc/go9-document) wird weltweit unterstützt.

Ihre eigene API oder eine herstellerspezifische API
: Ein Fahrzeughersteller kann Fahrzeugdaten über das Fahrzeugmodem senden und über eine API bereitstellen. Das gilt auch, wenn Sie nur eine bestimmte Fahrzeugmarke unterstützen möchten. [Auf Anfrage verfügbar](mailto:sales@chargetrip.com).

Ein anderer Telemetriedaten-Anbieter
: Wird über einen individuellen Datenintegrationsablauf hinzugefügt. [Auf Anfrage verfügbar](mailto:sales@chargetrip.com).
