Rufen Sie die Liste der verbundenen Fahrzeuge des aktuellen Nutzers mit der Query connectedVehicleList ab. Das ist nützlich, wenn Sie alle Fahrzeuge anzeigen möchten, die ein Nutzer mit einem Anbieter verbunden hat.

## Query

Für diese Query ist keine Eingabe erforderlich. Mit `filter` grenzen Sie die Ergebnisse nach Status ein, und mit den Argumenten `size` und `page` [paginieren](/api-reference/core/api/pagination) Sie sie.
