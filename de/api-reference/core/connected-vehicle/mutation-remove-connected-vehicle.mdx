Entfernen Sie ein verbundenes Fahrzeug und widerrufen Sie seinen Zugriff mit der Mutation removeConnectedVehicle. Das ist nützlich, wenn ein Endnutzer sein Fahrzeug vom Konnektivitätsanbieter trennt.

## Mutation

Zum Entfernen eines verbundenen Fahrzeugs ist eine `id` erforderlich. Die `id` erhalten Sie über die [Mutation createConnectedVehicle](/api-reference/core/connected-vehicle/mutation-create-connected-vehicle).
