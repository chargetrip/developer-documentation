Schließen Sie die Autorisierung eines verbundenen Fahrzeugs mit der Mutation authorizeConnectedVehicle ab. Das ist nützlich, nachdem der Endnutzer den Zugriff über den Konnektivitätsanbieter gewährt hat.

## Mutation

Zum Autorisieren eines verbundenen Fahrzeugs sind eine `id` und anbieterspezifische `options` erforderlich. Die `id` erhalten Sie über die [Mutation createConnectedVehicle](/api-reference/core/connected-vehicle/mutation-create-connected-vehicle).
