title: "Asynchrone Operationen"
description: "Erfahren Sie, wie asynchrone Operationen in der API funktionieren: Erstellen Sie mit einer Mutation und verfolgen und rufen Sie das Ergebnis anschließend mit einer Subscription oder Query ab."
---

Einige Operationen, etwa das Erstellen einer Route oder einer zugeordneten Route, laufen asynchron, damit die API reaktionsfähig bleibt. Statt darauf zu warten, dass eine Mutation das vollständige Ergebnis zurückgibt, erhalten Sie sofort eine `id` und verfolgen und rufen das Ergebnis anschließend ab.

## So funktioniert es

1. **Erstellen**
   Rufen Sie die Mutation auf. Sie gibt sofort eine `id` zurück, mit der Sie im nächsten Schritt das Ergebnis verfolgen und abrufen.
2. **Subscription öffnen**
   Abonnieren Sie mit der `id` aus dem vorherigen Schritt. Während das Ergebnis berechnet wird, sendet die Subscription Statusupdates, mit denen Sie einen asynchronen Ladezustand in Ihrer Oberfläche steuern können.
3. **Ergebnis darstellen**
   Sobald `status` einen endgültigen Wert erreicht, stellen Sie die passende Oberfläche für dieses Ergebnis dar.
4. **Fertiges Ergebnis erneut abrufen**
   Sobald ein Ergebnis einen endgültigen Status erreicht hat, ist es bereits vorberechnet. Wenn Sie es später erneut benötigen, zum Beispiel nach der Rückkehr zu einer Ansicht, verwenden Sie die passende Query, statt eine neue Subscription zu öffnen.
