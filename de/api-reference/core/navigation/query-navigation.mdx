Rufen Sie eine aktive Navigationssitzung mit der Query navigation ab. Das ist nützlich, wenn Sie den aktuellen Fortschritt eines Fahrers entlang einer Route anzeigen möchten.

## Query

Zum Abrufen der Details ist die `id` einer Navigationssitzung erforderlich. Die `id` erhalten Sie über die [Mutation startNavigation](/api-reference/core/navigation/mutation-start-navigation).
