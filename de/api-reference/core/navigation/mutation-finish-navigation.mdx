Beenden Sie eine aktive Navigationssitzung mit der Mutation finishNavigation. Dies ist nützlich, wenn ein Fahrer sein Ziel erreicht oder die Fahrt abgebrochen wird.

## Mutation

Zum Beenden einer Navigationssitzung sind deren `id` und `current_location` erforderlich. Die `id` erhalten Sie über die [Mutation startNavigation](/api-reference/core/navigation/mutation-start-navigation).
