Aktualisieren Sie eine aktive Navigationssitzung mit der Mutation updateNavigation. Das ist nützlich, wenn Sie den Standort eines Fahrers melden möchten, während er auf einer Route vorankommt.

## Mutation

Zum Aktualisieren sind die `id` einer Navigationssitzung und `location_data` erforderlich. Die `id` erhalten Sie über die [Mutation startNavigation](/api-reference/core/navigation/mutation-start-navigation).
