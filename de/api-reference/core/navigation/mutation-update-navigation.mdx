Aktualisieren Sie eine aktive Navigationssitzung mit der Mutation updateNavigation. Dies ist nützlich, wenn Sie den Standort eines Fahrers melden möchten, während er auf einer Route vorankommt.

## Mutation

Zum Aktualisieren einer Navigationssitzung sind deren `id` und `location_data` erforderlich. Die `id` erhalten Sie über die [Mutation startNavigation](/api-reference/core/navigation/mutation-start-navigation).
