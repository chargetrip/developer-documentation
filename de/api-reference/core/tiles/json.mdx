Der JSON-Kachel-Service bietet Zugriff auf stationsbezogene Geodaten im JSON-Format.

## Einrichtung

Um auf die Stationsdaten im JSON-Format zuzugreifen, senden Sie eine Anfrage an den folgenden Endpoint:

```bash Tile / JSON / Base URL
https://api.chargetrip.io/v2/station/{z}/{x}/{y}/tile.json
```

Die JSON-URL verwendet die folgenden Pfadparameter:

- `z`: Die Zoomstufe der Kachel.
- `x`: Die x-Koordinate der Kachel.
- `y`: Die y-Koordinate der Kachel.

Die meisten Kartenanbieter bieten integrierte Methoden, um Breiten- und Längengrad in Pixelkoordinaten umzurechnen. Um Breiten- und Längengrad manuell in x und y umzurechnen, verwenden Sie die [Web-Mercator-Projektion](https://en.wikipedia.org/wiki/Web_Mercator_projection).

### Filtern
Verwenden Sie den Query-Parameter `filter`, um die zurückgegebenen Stationen anhand bestimmter Kriterien zu filtern. Weitere Informationen finden Sie in der [Dokumentation zu Filtern](/api-reference/core/tiles/filters).

### Selektoren
Verwenden Sie den Query-Parameter `station_properties[]`, um die Felder festzulegen, die für jedes Stations-Feature zurückgegeben werden. Weitere Informationen finden Sie in der [Dokumentation zu Selektoren](/api-reference/core/tiles/selectors).

### Währung
Verwenden Sie den Query-Parameter `currency`, um die Währung der Energiepreise festzulegen, die zurückgegeben und nach denen gefiltert wird. Weitere Informationen finden Sie in der [Dokumentation zur Währungsumrechnung](/api-reference/core/tiles/filters).
