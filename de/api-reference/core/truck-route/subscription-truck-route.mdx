Abonnieren Sie mit der truckRoute-Subscription eine Lkw-Route. Das ist nützlich, wenn Sie Echtzeit-Updates erhalten möchten, während eine E-Lkw-Route berechnet wird.

## Subscription

Um Updates einer Lkw-Route zu abonnieren, ist deren `id` erforderlich. Die `id` erhalten Sie über die [createTruckRoute-Mutation](/api-reference/core/truck-route/mutation-create-truck-route).
