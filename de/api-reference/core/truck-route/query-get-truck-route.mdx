Rufen Sie mit der getTruckRoute-Query die Details einer zuvor berechneten Lkw-Route ab. Das ist nützlich, wenn Sie die Ladestopps, die Distanz und die Dauer einer Lkw-Route anzeigen möchten.

## Query

Um Routendetails abzurufen, ist die `id` einer Lkw-Route erforderlich. Die `id` erhalten Sie über die [createTruckRoute-Mutation](/api-reference/core/truck-route/mutation-create-truck-route).
