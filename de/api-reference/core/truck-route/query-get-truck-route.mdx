Rufen Sie die Details einer zuvor berechneten Lkw-Route mit der Query getTruckRoute ab. Dies ist nützlich, wenn Sie die Ladestopps, die Distanz und die Dauer einer Lkw-Route anzeigen möchten.

## Query

Zum Abrufen der Routendetails ist die `id` einer Lkw-Route erforderlich. Die `id` erhalten Sie über die [Mutation createTruckRoute](/api-reference/core/truck-route/mutation-create-truck-route).
