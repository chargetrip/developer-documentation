Rufen Sie die Details eines Ladepunktbetreibers mit der Query operator ab. Das ist nützlich, wenn Sie Betreiberinformationen neben einer Station oder Sitzung anzeigen möchten.

## Query

Zum Abrufen der Betreiberdetails ist die `id` eines Betreibers erforderlich. Die `id` erhalten Sie über die [Query operatorList](/api-reference/core/operator/query-operator-list).
