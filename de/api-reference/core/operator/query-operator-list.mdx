Greifen Sie mit der Query operatorList auf die vollständige Liste der Ladepunktbetreiber zu. Das ist nützlich, wenn Sie Betreiber durchsuchen möchten.

## Query

Für diese Query ist keine Eingabe erforderlich. Mit `filter` und `search` grenzen Sie die Ergebnisse ein, und mit den Argumenten `size` und `page` [paginieren](/api-reference/core/api/pagination) Sie sie.
