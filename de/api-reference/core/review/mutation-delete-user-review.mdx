Entfernen Sie mit der Mutation deleteUserReview eine Bewertung, die der authentifizierte Nutzer hinzugefügt hat. Dies ist eine Premium-Funktion. Kontaktieren Sie uns für weitere Informationen.

## Mutation

Zum Entfernen einer Bewertung ist deren `id` erforderlich. Zur Autorisierung des Nutzers ist ein `x-token`-Header zwingend. Die Bewertung muss ihm gehören, andernfalls tritt ein Fehler auf.
