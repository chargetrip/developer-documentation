Greifen Sie über die vehiclePremium-Query auf noch detailliertere Daten zu. Sie enthält erweiterte Daten zu Batterie, Karosserie des Fahrzeugs, Verfügbarkeit, Preisen, Effizienz, Sicherheit und mehr. [Kontaktieren Sie den Vertrieb](https://www.chargetrip.com/contact/sales), um auf Premium-Fahrzeugdaten umzusteigen.

## Query

Um Premium-Fahrzeugdetails abzurufen, ist die `id` eines Fahrzeugs erforderlich. Die `id` erhalten Sie über die [vehicleList-Query](/api-reference/core/vehicle/query-vehicles). Mit dem Argument country lokalisieren Sie die Daten.
