Rufen Sie mit der vehicle-Query die Fahrzeugspezifikationen ab.

## Query

Um Fahrzeugdetails abzurufen, ist die `id` eines Fahrzeugs erforderlich. Die `id` erhalten Sie über die [vehicleList-Query](/api-reference/core/vehicle/query-vehicles). Mit dem Argument country lokalisieren Sie die Daten.
