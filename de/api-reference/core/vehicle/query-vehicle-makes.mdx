Rufen Sie mit der vehicleMakes-Query eine Liste der Fahrzeughersteller ab.

## Query
Zur Ausführung der vehicleMakes-Query ist keine Eingabe erforderlich. Mit dem Argument `filter` grenzen Sie die Ergebnisse nach Region und/oder Typ ein, mit den Argumenten `first` und `after` [paginieren](/api-reference/core/api/pagination) Sie sie. Mit dem Argument `country` lokalisieren Sie die Daten.
