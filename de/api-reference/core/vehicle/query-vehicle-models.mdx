Rufen Sie mit der vehicleModels-Query eine Liste eindeutiger Fahrzeugmodelle ab. Diese Query ist in Kombination mit der vehicleMakes-[Query](/api-reference/core/vehicle/query-vehicle-makes) nützlich, um eine aufeinander aufbauende Fahrzeugauswahl zu erstellen.

## Query
Um die Modelle eines Fahrzeugherstellers abzurufen, ist dessen `id` erforderlich. Die id erhalten Sie über die vehicleMakes-[Query](/api-reference/core/vehicle/query-vehicle-makes). Mit den Argumenten `first` und `after` [paginieren](/api-reference/core/api/pagination) Sie die Ergebnisse, mit `filters` grenzen Sie die Suchergebnisse ein und mit dem Argument `country` lokalisieren Sie die Daten.
