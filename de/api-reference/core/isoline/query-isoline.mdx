Rufen Sie die Details einer zuvor berechneten Isoline mit der Query isoline ab. Das ist nützlich, wenn Sie das erreichbare Gebiet eines Fahrzeugs anzeigen möchten.

## Query

Zum Abrufen der Isolinien-Details ist die `id` einer Isoline erforderlich. Die `id` erhalten Sie über die [Mutation createIsoline](/api-reference/core/isoline/mutation-create-isoline).
