Das Routing eines Elektrofahrzeugs hängt davon ab, zu wissen, wo es laden kann. Die Stationsdatenbank muss daher mit Stationsdaten befüllt sein, bevor Routen geplant werden können. Standardmäßig entspricht das Stationsschema dem aktuellen [OCPI](https://evroaming.org/ocpi/)-Standard. Benutzerdefinierte Eigenschaften können hinzugefügt werden, werden aber in der Regel in zusätzliche Queries ausgelagert statt in die Stations-Query selbst.

## Unterstützte Datenquellen

Eco-Movement-Daten
: Ohne bestehende kommerzielle Vereinbarung kann Chargetrip Ihr Konto mit Premium-Stationsdaten von [Eco-Movement](https://eco-movement.com) vorbefüllen. Sie umfassen über 100.000 Ladestationen in ganz Europa, einschließlich Echtzeitverfügbarkeit, Preisen und prognostizierter Verfügbarkeit, sofern vorhanden. Damit entfällt die Notwendigkeit, mehrere Anbieter von Stationsdatenbanken anzubinden, um europäische Abdeckung zu erhalten. Regionale Einschränkungen finden Sie unter [eco-movement.com](https://eco-movement.com). [Kontaktieren Sie den Vertrieb](mailto:sales@chargetrip.com) für Preise.

Benutzerdefinierte Stationsdaten
: Sowohl statische als auch dynamische Stationsdaten können in Chargetrip importiert werden. Dies erfordert eine kommerzielle Vereinbarung mit dem Anbieter. [Kontaktieren Sie den Vertrieb](mailto:sales@chargetrip.com), um die Möglichkeiten zu besprechen.
