Rufen Sie mit der station-Query bestimmte Stationsdetails ab. Das ist nützlich, wenn Sie den Typ und die Anzahl der Ladepunkte, den Standort, die Ladekosten oder andere aktuell verfügbare Details einer Station anzeigen möchten. Die [Anleitung zur Stationspreisgestaltung](/docs/getting-started/station-pricing) behandelt die Preisgestaltung im Detail.

## Query

Um Stationsdetails abzurufen, ist die `id` oder `evse_id` einer Station erforderlich. Die `id` erhalten Sie entweder über eine [Route](/api-reference/core/route/query-get-route), den [Tile-Service](/api-reference/core/tiles/mvt) oder die [Station-Around-Query](/api-reference/core/station/query-station-around).
