Mit der stationAround-Query rufen Sie die Stationen innerhalb eines bestimmten Radius um einen GeoJSON-Punkt ab. Das kann nützlich sein, wenn eine Station belegt ist oder wenn Sie mehrere Lademöglichkeiten anbieten möchten.

## Query

Für die Suche nach Stationen um einen Punkt sind eine `location` (GeoJSON-Punkt) und eine `distance` in Metern erforderlich. Mit den Argumenten `filter` und `search` grenzen Sie die Ergebnisse ein, mit den Argumenten `size` und `page` [paginieren](/api-reference/core/api/pagination) Sie sie.
