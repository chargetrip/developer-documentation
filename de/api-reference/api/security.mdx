---
title: "Sicherheit"
description: "Verhindern Sie die unbefugte Nutzung Ihrer Anwendungen, indem Sie einschränken, welche Plattform oder Origin Anfragen mit Ihrer App-ID senden darf."
---

Mit einer Anfrage gesendete Header, einschließlich `x-app-id`, sind für jeden sichtbar, der den Netzwerkverkehr untersucht. Um die unbefugte Nutzung Ihrer Anwendungen zu verhindern, legen Sie eine Einschränkung fest, die begrenzt, welche Plattform oder welcher Origin sie verwenden darf.

> [!WARNING] Eine Einschränkung pro Anwendung
> Pro Anwendung kann nur eine Einschränkung festgelegt werden. Um Einschränkungen zu kombinieren, zum Beispiel für einen Web- und einen Mobile-Client, erstellen Sie für jeden eine eigene Anwendung.

## Einschränkungstypen

Es stehen vier Einschränkungstypen zur Verfügung, die jeweils für eine andere Plattform oder ein anderes Kommunikationsmuster geeignet sind.

### Web

Schränken Sie eine Webanwendung über den HTTP-Referrer ein, angewendet auf den Header `x-app-id`. Einer Anwendung können mehrere URLs hinzugefügt werden.

### Machine-to-Machine (M2M)

Schränken Sie die Server-zu-Server-Kommunikation über die IP-Adresse ein (IPv4 und IPv6 werden unterstützt), konfiguriert im App-Dashboard. Dies ist die sicherste Option, da Zugangsdaten nie einen Browser oder ein Gerät erreichen.

### Android

Schränken Sie eine Android-Anwendung über die Header `x-app-identifier` und `x-app-fingerprint` ein, die bei jeder Anfrage gesendet werden.

### iOS

Schränken Sie eine iOS-Anwendung über den Header `x-app-identifier` ein, der die Bundle-ID der App enthält.
