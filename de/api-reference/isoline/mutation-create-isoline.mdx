Erstellen Sie eine verbrauchsbasierte Isoline mit der Mutation createIsoline. Dies ist nützlich, wenn Sie das Gebiet visualisieren möchten, das ein Fahrzeug von einem bestimmten Punkt aus erreichen kann.

## Mutation

Zum Erstellen einer Isoline sind eine `vehicle_id` und ein `origin` erforderlich. Optional können Sie `state_of_charge`, `polygon_count` oder weitere Präferenzen hinzufügen, um die Berechnung zu verfeinern. Die Mutation gibt eine Isoline-`id` zurück, mit der Sie Isolinien-Details abrufen oder Updates abonnieren können.
