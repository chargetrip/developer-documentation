Eine Isoline, auch Reichweitenspinne genannt, zeigt das Gebiet, das ein EV von einem bestimmten Punkt aus mit der an Bord befindlichen Energie erreichen kann. Wählen Sie ein Fahrzeug und einen Startpunkt, und die API berechnet die Isolinien, die die Grenze der Fahrstrecke markieren, als Formen, die Sie auf einer Karte darstellen können. Die Berechnung verwendet das reale Straßennetz als Referenz: Sie ermittelt die am weitesten entfernten Punkte, die das Fahrzeug auf der Straße erreichen kann, und die Umrisslinie verbindet diese Punkte. Das Ergebnis ist eine ausgefüllte Fläche und keine Linie, die den Straßen folgt, sodass auch Bereiche zwischen Straßen, wie Wälder oder Felder, darin liegen können.

## Eine Isoline auf Ihr Ziel optimieren

Dieselbe Anfrage kann je nach Optimierungsziel unterschiedliche Isolinien liefern. Dies sind die häufigsten Ziele und die Optionen, die jedes davon prägen.

Reichweitenkarte
: Zeigen Sie als Fläche auf einer Karte, wie weit ein Fahrzeug von einem Punkt aus fahren kann, zum Beispiel rund um eine Stadt. Legen Sie fest, wie viele Polygone Sie erhalten, bis zu 20, von einem einfachen Bild der Fahrzeugreichweite bis zu feineren Abstufungen für einen Farbverlauf. Tauschen Sie Genauigkeit gegen Geschwindigkeit mit `quality` und beziehen Sie Fähren mit `ferry_connections` ein, was die Berechnungszeit und die Anzahl der Polygone erhöht. Siehe [Fahrzeugreichweite visualisieren](/docs/getting-started/vehicle-range).

Erreichbarkeitsprüfung
: Beantworten Sie "Komme ich dort ohne Laden an?" für ein bestimmtes Fahrzeug, was hilft, der Reichweitenangst zu begegnen. Starten Sie mit dem tatsächlichen Batteriestand über `state_of_charge`, halten Sie mit `final_state_of_charge` eine Reserve vor oder verwenden Sie `round_trip`, um nur Punkte einzubeziehen, von denen das Fahrzeug auch zum Startpunkt zurückfahren kann.

Erreichbare Stationen
: Filtern Sie Ladestationen auf diejenigen, die ein Fahrzeug von seinem aktuellen Standort aus tatsächlich erreichen kann. Kombinieren Sie dies mit `final_state_of_charge`, sodass eine Station nur zählt, wenn das Fahrzeug mit Restladung ankommt.

Realistische Bedingungen
: Berücksichtigen Sie, was den Verbrauch verändert: Wetter oder Jahreszeit, das vom Fahrzeug transportierte Gewicht sowie Heizen und Kühlen mit der Klimaanlage. Ohne Batteriestand verwendet die Isoline die volle nutzbare Batteriekapazität des Fahrzeugs, und das Wetter verwendet standardmäßig Echtzeitdaten.
