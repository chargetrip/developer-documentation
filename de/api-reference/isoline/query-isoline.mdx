Rufen Sie die Details einer zuvor berechneten Isoline mit der Query isoline ab. Dies ist nützlich, wenn Sie das erreichbare Gebiet eines Fahrzeugs anzeigen möchten.

## Query

Zum Abrufen der Isolinien-Details ist eine Isoline-`id` erforderlich. Die `id` erhalten Sie über die [Mutation createIsoline](/api-reference/isoline/mutation-create-isoline).
