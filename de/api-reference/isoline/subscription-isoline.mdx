Abonnieren Sie eine Isoline mit der Subscription isoline. Dies ist nützlich, wenn Sie Echtzeit-Updates erhalten möchten, während eine Isoline berechnet wird.

## Subscription

Zum Abonnieren der Updates ist eine Isoline-`id` erforderlich. Die `id` erhalten Sie über die [Mutation createIsoline](/api-reference/isoline/mutation-create-isoline).
