Subscribe to an isoline by using the isoline subscription. This is useful when you want to receive real-time updates as an isoline is calculated.

## Subscription

An isoline `id` is required to subscribe to its updates. The `id` can be obtained through the [createIsoline mutation](/api-reference/isoline/mutation-create-isoline).
