Abonnieren Sie ein verbundenes Fahrzeug mit der Subscription connectedVehicle. Dies ist nützlich, wenn Sie Echtzeit-Updates zu dessen Autorisierungsstatus erhalten möchten.

## Subscription

Zum Abonnieren der Updates ist die `id` eines verbundenen Fahrzeugs erforderlich. Die `id` erhalten Sie über die [Mutation createConnectedVehicle](/api-reference/connected-vehicle/mutation-create-connected-vehicle).
