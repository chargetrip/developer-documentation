Eine Navigationsanwendung für Elektrofahrzeuge benötigt Echtzeit-Fahrzeugdaten, wie den Ladezustand, um damit Routen zu planen. Fast alle heute zugelassenen EVs verfügen über ein Modem, das diese Daten an externe Anwendungen senden kann, doch die Standards und die Art der Bereitstellung unterscheiden sich je nach Hersteller.

Die Fahrzeugkonnektivität bringt diese Daten über eine einzige Quelle in Ihre Anwendung. Eine Abstraktionsschicht nimmt die Daten vieler Hersteller auf, bereinigt sie und bereitet sie für die Routing-Engine auf, und eine anpassbare Landingpage ermöglicht es Ihren Nutzern, sich zu authentifizieren und ihre Einwilligung zu erteilen. Sie funktioniert mit Ihrem aktuellen Anbieter für Connected-Vehicle-Daten, Ihrer Telemetrie-API oder Ihrem OBD-II-Dongle und ist mit [Enode](https://enode.io) vorintegriert, das Zugriff auf über 130 EV-Modelle bietet.

Um Zugang zu erhalten oder einen anderen Datenanbieter bzw. Ihre eigene API zu verwenden, wenden Sie sich an [sales@chargetrip.com](mailto:sales@chargetrip.com).

## Unterstützte Datenquellen

Connected-Vehicle-Datenplattform
: Cloud-Lösungen, die sich mit den APIs von Fahrzeugherstellern verbinden und diese Daten Dritten zur Verfügung stellen. Sie übernehmen die Einwilligung der Fahrzeughalter und standardisieren das Datenformat. Unterstützte Marken und Preise unterscheiden sich erheblich zwischen den Plattformen. Das eignet sich für App-Entwickler, zum Beispiel für einen CPO oder eMSP. Unterstützte Plattformen sind [Enode](https://enode.io), [High Mobility](https://high-mobility.com), [Smartcar](https://smartcar.com) und [WirelessCar](https://wirelesscar.com).

Hardware-Dongle
: Bluetooth-Dongles, die manuell im Fahrzeug installiert werden. Sie haben relativ hohe Anschaffungskosten, aber niedrige laufende Kosten, weshalb sie bei Logistik-Flottenbetreibern beliebt sind. Der [Geotab Go9](https://support.geotab.com/go-devices/go9/doc/go9-document) wird weltweit unterstützt.

Ihre eigene API oder eine herstellerspezifische API
: Ein Fahrzeughersteller sendet Fahrzeugdaten möglicherweise über das Fahrzeugmodem und stellt sie über eine API bereit. Das gilt auch, wenn Sie nur eine bestimmte Fahrzeugmarke unterstützen möchten. [Auf Anfrage verfügbar](mailto:sales@chargetrip.com).

Ein anderer Telemetriedaten-Anbieter
: Wird über einen individuellen Datenintegrationsprozess hinzugefügt. [Auf Anfrage verfügbar](mailto:sales@chargetrip.com).
