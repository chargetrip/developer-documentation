Aktualisieren Sie ein verbundenes Fahrzeug mit der Mutation updateConnectedVehicle. Dies ist nützlich, wenn Sie die Bezeichnung eines verbundenen Fahrzeugs ändern möchten.

## Mutation

Zum Aktualisieren eines verbundenen Fahrzeugs ist eine `id` erforderlich. Verwenden Sie `label`, um eine neue Bezeichnung festzulegen. Die `id` erhalten Sie über die [Mutation createConnectedVehicle](/api-reference/connected-vehicle/mutation-create-connected-vehicle).
