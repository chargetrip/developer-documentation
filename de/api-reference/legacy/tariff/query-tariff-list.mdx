Rufen Sie mit der Legacy-Query tariffList die vollständige Liste der Tarife ab. Neue Integrationen sollten stattdessen die [stationPrices-Query](/api-reference/core/station-pricing/query-station-prices) verwenden.

## Query

Zur Ausführung dieser Query ist keine Eingabe erforderlich. Mit den Argumenten `size` und `page` [paginieren](/api-reference/core/api/pagination) Sie die Ergebnisse.
