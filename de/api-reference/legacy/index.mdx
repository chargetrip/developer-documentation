## Richtlinie zur Veraltung

Diese Operationen sind veraltet. Eine veraltete Operation funktioniert mindestens 12 Monate lang normal. Nach diesem Zeitraum wird sie entfernt, und Anfragen, die sie verwenden, geben GraphQL-Fehler zurück. Den Zeitplan finden Sie unter [veraltete Funktionen](/deprecations).
