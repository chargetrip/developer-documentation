title: Veraltete Operationen
description: "Durchsuchen Sie die veralteten Queries, Mutations und Subscriptions und finden Sie die Operation, die jeweils an ihre Stelle tritt."
template: overview
---

Diese Operationen sind veraltet. Eine veraltete Operation funktioniert mindestens 12 Monate lang weiterhin normal. Danach wird sie entfernt, und Anfragen, die sie verwenden, geben GraphQL-Fehler zurück. Den Zeitplan und die jeweils ersetzende Operation finden Sie unter [Veraltete Funktionen](/deprecations).
