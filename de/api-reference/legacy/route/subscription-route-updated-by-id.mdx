Abonnieren Sie mit der Legacy-Subscription routeUpdatedById eine Route, um Echtzeit-Updates zu erhalten, während sie berechnet wird. Neue Integrationen sollten stattdessen die [route-Subscription](/api-reference/core/route/subscription-route) verwenden.
