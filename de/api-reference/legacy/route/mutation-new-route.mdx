Erstellen Sie mit der Legacy-Mutation newRoute eine neue Route. Sie bleibt verfügbar, während Sie auf die [createRoute-Mutation](/api-reference/core/route/mutation-create-route) migrieren, die Ladestopps, Energieverbrauch und Fahrzeit mit einem neu organisierten Schema und länderspezifischen Betreiberpräferenzen berechnet.
