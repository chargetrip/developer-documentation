Greifen Sie mit der Query tariffList auf die vollständige Liste der Tarife zu. Dies ist nützlich, wenn Sie Ladekosten über Stationen hinweg anzeigen oder vergleichen möchten. Wie Sie Preise darstellen, erfahren Sie im [Leitfaden zu Stationspreisen](/docs/getting-started/station-pricing).

## Query

Für diese Query ist keine Eingabe erforderlich. Verwenden Sie die Argumente `size` und `page`, um die Ergebnisse zu [paginieren](/api-reference/api/pagination).
