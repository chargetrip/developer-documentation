Rufen Sie die Tarifdetails mit der Query tariff ab. Dies ist nützlich, wenn Sie eine andere Stationsdatenbank als Ecomovement verwenden und die Ladekosten an einer Station anzeigen möchten.

## Query

Zum Abrufen der Tarifdetails ist eine Tarif-`id` erforderlich. Die `id` erhalten Sie über die [Query tariffList](/api-reference/tariff/query-tariff-list).
