Rufen Sie bestimmte Stationsdetails mit der Query station ab. Dies ist nützlich, wenn Sie Typ und Anzahl der Ladepunkte, den Standort oder andere aktuell verfügbare Details einer Station anzeigen möchten.

## Query

Zum Abrufen der Stationsdetails ist die `id` oder `evse_id` einer Station erforderlich. Die `id` erhalten Sie entweder über eine [Route](/api-reference/route/query-get-route), den [Kachel-Service](/api-reference/tiles/mvt) oder die [Query stationAround](/api-reference/station/query-station-around).
