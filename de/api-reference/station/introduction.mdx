Die Routenplanung für ein EV hängt davon ab, zu wissen, wo es laden kann. Daher muss die Stationsdatenbank mit Stationsdaten befüllt sein, bevor Routen geplant werden können. Standardmäßig entspricht das Stationsschema dem aktuellen [OCPI](https://evroaming.org/ocpi/)-Standard. Benutzerdefinierte Eigenschaften können hinzugefügt werden, werden aber meist in zusätzliche Queries verlagert, statt in die Stations-Query selbst.

## Unterstützte Datenquellen

Eco-Movement-Daten
: Ohne bestehende kommerzielle Vereinbarung kann Chargetrip Ihr Konto mit Premium-Stationsdaten von [Eco-Movement](https://eco-movement.com) vorab befüllen. Sie umfassen über 100.000 Ladestationen in ganz Europa, einschließlich Echtzeit-Verfügbarkeit, Preisen und prognostizierter Verfügbarkeit, sofern vorhanden. Damit müssen Sie nicht mehrere Anbieter von Stationsdatenbanken anbinden, um eine europaweite Abdeckung zu erhalten. Regionale Einschränkungen finden Sie auf [eco-movement.com](https://eco-movement.com). [Kontaktieren Sie den Vertrieb](mailto:sales@chargetrip.com) für Preise.

Benutzerdefinierte Stationsdaten
: Sowohl statische als auch dynamische Stationsdaten können in Chargetrip importiert werden. Dafür ist eine kommerzielle Vereinbarung mit dem Anbieter erforderlich. [Kontaktieren Sie den Vertrieb](mailto:sales@chargetrip.com), um die Möglichkeiten zu besprechen.
