title: Navigationsetappe fortschreiten

Setzen Sie eine aktive Navigationssitzung mit der Mutation advanceNavigationLeg zur nächsten Routenetappe fort. Dies ist nützlich, wenn ein Fahrer eine Etappe abschließt, etwa einen Ladestopp beendet, und zur nächsten weiterfährt.

## Mutation

Zum Fortschreiten zur nächsten Etappe sind die `id` einer Navigationssitzung und `current_location` erforderlich. Optional können Sie `state_of_charge` angeben, um den Ladezustand des Fahrzeugs am aktuellen Standort festzulegen. Die `id` erhalten Sie über die [Mutation startNavigation](/api-reference/navigation/mutation-start-navigation).
