Rufen Sie eine aktive Navigationssitzung mit der Query navigation ab. Dies ist nützlich, wenn Sie den aktuellen Fortschritt eines Fahrers entlang einer Route anzeigen möchten.

## Query

Zum Abrufen der Details einer Navigationssitzung ist deren `id` erforderlich. Die `id` erhalten Sie über die [Mutation startNavigation](/api-reference/navigation/mutation-start-navigation).
