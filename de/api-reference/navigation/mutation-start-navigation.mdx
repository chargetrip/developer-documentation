Starten Sie mit der Mutation startNavigation eine neue Navigationssitzung auf Basis einer bestehenden Route. Dies ist nützlich, wenn ein Fahrer beginnt, einer berechneten Route zu folgen.

> [!WARNING] Sitzungsdauer
> Eine Navigationssitzung wird nach 48 Stunden Inaktivität automatisch beendet.

## Mutation

Zum Starten einer Navigationssitzung sind `route_id`, `route_details_id` und `current_location` erforderlich. Beide Routen-IDs erhalten Sie über die [Query getRoute](/api-reference/route/query-get-route). Die Mutation gibt die `id` einer Navigationssitzung zurück, mit der Sie die Sitzung abrufen, aktualisieren oder beenden können.
