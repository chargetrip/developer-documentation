---
title: Liste der Stationsbetreiber
schemaName: operatorList
schemaType: Query
---

Greifen Sie mit der Query operatorList auf die vollständige Liste der Ladepunktbetreiber zu. Dies ist nützlich, wenn Sie Betreiber durchsuchen oder nach ihnen suchen möchten.

## Query

Für diese Query ist keine Eingabe erforderlich. Verwenden Sie `filter` und `search`, um die Ergebnisse einzugrenzen, sowie die Argumente `size` und `page`, um die Ergebnisse zu [paginieren](/api-reference/api/pagination).
