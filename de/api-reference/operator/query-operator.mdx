title: Details zum Stationsbetreiber
schemaName: operator
schemaType: Query

Rufen Sie die Details eines Ladepunktbetreibers mit der Query operator ab. Dies ist nützlich, wenn Sie Betreiberinformationen neben einer Station oder Ladesitzung anzeigen möchten.

## Query

Zum Abrufen der Betreiberdetails ist die `id` eines Betreibers erforderlich. Die `id` erhalten Sie über die [Query operatorList](/api-reference/operator/query-operator-list).
