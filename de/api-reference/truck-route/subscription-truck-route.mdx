Abonnieren Sie eine Lkw-Route mit der Subscription truckRoute. Dies ist nützlich, wenn Sie Echtzeit-Updates erhalten möchten, während die Route eines E-Lkw berechnet wird.

## Subscription

Zum Abonnieren der Updates ist die `id` einer Lkw-Route erforderlich. Die `id` erhalten Sie über die [Mutation createTruckRoute](/api-reference/truck-route/mutation-create-truck-route).
