---
title: Lkw-Route erstellen
schemaName: createTruckRoute
schemaType: Mutation
---

Erstellen Sie mit der Mutation createTruckRoute eine neue Lkw-Route. Dies ist nützlich, wenn Sie Ladestopps, Energieverbrauch und Fahrzeit für einen E-Lkw zwischen einem Start und einem Ziel berechnen möchten.

## Mutation

Zum Erstellen einer Lkw-Route sind ein `vehicle`, ein `origin` und eine `destination` erforderlich. Optional können Sie `via`-Punkte, `operators`, `weather` oder weitere Präferenzen hinzufügen, um die Berechnung zu verfeinern. Die Mutation gibt die `id` einer Lkw-Route zurück, mit der Sie Routendetails abrufen oder Updates abonnieren können.
