Rufen Sie die Tarifdetails mit der Query tariff ab. Dies ist nützlich, wenn Sie eine andere Stationsdatenbank als Ecomovement verwenden und die Ladekosten an einer Station anzeigen möchten. Wie Sie Preise darstellen, erfahren Sie im [Leitfaden zu Stationspreisen](/docs/getting-started/station-pricing).

## Query

Zum Abrufen der Tarifdetails ist eine Tarif-`id` erforderlich. Die `id` erhalten Sie über die [Query tariffList](/api-reference/light-vehicle/tariff/query-tariff-list).
