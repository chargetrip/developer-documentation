Rufen Sie mit der Query vehicleModels eine Liste eindeutiger Fahrzeugmodelle ab. Diese Query ist in Kombination mit der vehicleMakes-[Query](/api-reference/light-vehicle/vehicle/query-vehicle-makes) nützlich, um eine sequenzielle Fahrzeugauswahl aufzubauen.

## Query
Zum Abrufen der Modelle ist die `id` eines Fahrzeugherstellers erforderlich. Die ID erhalten Sie über die vehicleMakes-[Query](/api-reference/light-vehicle/vehicle/query-vehicle-makes). Verwenden Sie die Argumente `first` und `after`, um die Ergebnisse zu [paginieren](/api-reference/light-vehicle/api/pagination), `filters`, um die Suchergebnisse einzugrenzen, und das Argument `country`, um die Daten zu lokalisieren.
