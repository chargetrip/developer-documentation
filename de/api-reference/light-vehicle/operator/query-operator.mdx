Rufen Sie die Details eines Ladepunktbetreibers mit der Query operator ab. Dies ist nützlich, wenn Sie Betreiberinformationen neben einer Station oder Ladesitzung anzeigen möchten.

## Query

Zum Abrufen der Betreiberdetails ist die `id` eines Betreibers erforderlich. Die `id` erhalten Sie über die [Query operatorList](/api-reference/light-vehicle/operator/query-operator-list).
