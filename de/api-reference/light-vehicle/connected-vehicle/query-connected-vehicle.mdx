Rufen Sie die Details eines verbundenen Fahrzeugs mit der Query connectedVehicle ab. Dies ist nützlich, wenn Sie den Autorisierungsstatus eines verbundenen Fahrzeugs prüfen möchten.

## Query

Zum Abrufen der Details ist die `id` eines verbundenen Fahrzeugs erforderlich. Die `id` erhalten Sie über die [Mutation createConnectedVehicle](/api-reference/light-vehicle/connected-vehicle/mutation-create-connected-vehicle) oder die [Query connectedVehicleList](/api-reference/light-vehicle/connected-vehicle/query-connected-vehicle-list).
