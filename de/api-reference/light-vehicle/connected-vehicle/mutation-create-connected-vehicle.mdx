Verbinden Sie ein Fahrzeug mit einem Konnektivitätsanbieter, indem Sie die Mutation createConnectedVehicle verwenden. Dies ist nützlich, wenn Sie Live-Fahrzeugdaten direkt vom Fahrzeug statt aus einer Routenberechnung abrufen möchten.

## Mutation

Zum Erstellen eines verbundenen Fahrzeugs sind eine `vehicle_id` und ein `provider` sowie anbieterspezifische `options` erforderlich. Die Mutation gibt eine `id` des verbundenen Fahrzeugs und eine `authorization_url` zurück, mit der die Autorisierung über die [Mutation authorizeConnectedVehicle](/api-reference/light-vehicle/connected-vehicle/mutation-authorize-connected-vehicle) abgeschlossen werden kann.
