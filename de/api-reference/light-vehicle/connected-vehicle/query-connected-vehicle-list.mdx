Rufen Sie die Liste der verbundenen Fahrzeuge des aktuellen Nutzers mit der Query connectedVehicleList ab. Dies ist nützlich, wenn Sie alle Fahrzeuge anzeigen möchten, die ein Nutzer mit einem Anbieter verbunden hat.

## Query

Für diese Query ist keine Eingabe erforderlich. Verwenden Sie `filter`, um die Ergebnisse nach Status einzugrenzen, sowie die Argumente `size` und `page`, um die Ergebnisse zu [paginieren](/api-reference/light-vehicle/api/pagination).
