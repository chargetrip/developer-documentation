Rufen Sie mit der Query amenityList eine Liste der Ausstattungen ab, die rund um eine bestimmte Station verfügbar sind. Dies ist nützlich, wenn Sie Restaurants, Geschäfte oder andere Einrichtungen in der Nähe anzeigen möchten, während ein Fahrzeug lädt.

## Query

Zum Abrufen der Ausstattungen einer Station ist deren `id` erforderlich. Die `id` erhalten Sie entweder über eine [Route](/api-reference/light-vehicle/route/query-get-route), den [Kachel-Service](/api-reference/light-vehicle/tiles/mvt) oder die [Query stationAround](/api-reference/light-vehicle/station/query-station-around). Verwenden Sie das Argument `filter`, um die Ergebnisse anhand bestimmter Kriterien einzugrenzen, sowie die Argumente `size` und `page`, um die Ergebnisse zu [paginieren](/api-reference/light-vehicle/api/pagination).
