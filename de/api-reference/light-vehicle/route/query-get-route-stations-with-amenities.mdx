Suchen Sie mit der Query getRouteStationsWithAmenities nach Ladestationen mit Ausstattungen an einem bestimmten Punkt entlang einer Route. Dies ist nützlich, wenn Sie einen Ladestopp in der Nähe von Restaurants, Geschäften oder anderen Ausstattungen planen möchten.

## Query

Zum Suchen von Stationen entlang einer Route sind `route_id`, `route_details_id`, `time_window` und `amenity_types` erforderlich. Beide IDs erhalten Sie über die [Query getRoute](/api-reference/light-vehicle/route/query-get-route). Verwenden Sie das Argument `filter`, um die Ergebnisse anhand bestimmter Kriterien einzugrenzen, sowie die Argumente `first` und `after`, um die Ergebnisse zu [paginieren](/api-reference/light-vehicle/api/pagination).

> [!WARNING] Limits
> `first` darf bei dieser Query nicht größer als 10 sein.
