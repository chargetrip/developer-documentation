---
title: Routendetails
schemaName: getRoute
schemaType: Query
---

Rufen Sie die Details einer zuvor berechneten Route mit der Query getRoute ab. Dies ist nützlich, wenn Sie die Ladestopps, die Distanz und die Dauer einer Route anzeigen möchten.

## Query

Zum Abrufen der Routendetails ist eine Routen-`id` erforderlich. Die `id` erhalten Sie über die [Mutation createRoute](/api-reference/route/mutation-create-route).
