---
title: Neue Route
schemaName: newRoute
schemaType: Mutation
---

Erstellen Sie mit der veralteten Mutation newRoute eine neue Route. Sie bleibt verfügbar, während Sie auf die [Mutation createRoute](/api-reference/route/mutation-create-route) migrieren, die Ladestopps, Energieverbrauch und Fahrzeit mit einem neu organisierten Schema und länderspezifischen Betreiberpräferenzen berechnet.
