Der Endpoint für die Stationsanzahl gibt die Gesamtzahl der Ladestationen zurück.

## Einrichtung
Um die Stationsanzahl abzurufen, senden Sie eine `GET`-Anfrage an die folgende URL:

```bash Count / Base URL
https://api.chargetrip.io/v2/station/count
```

### Filtern
Verwenden Sie den Query-Parameter `filter`, um die Anzahl anhand bestimmter Kriterien einzugrenzen. Weitere Informationen finden Sie in der [Dokumentation zu Filtern](/api-reference/tiles/filters).
