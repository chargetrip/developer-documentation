GraphQL ist eine Abfragesprache für APIs. Sie ermöglicht es Ihnen, genau die Daten in einem einzigen Aufruf abzufragen, die Sie benötigen, anstatt viele feste REST-Endpoints zu durchlaufen.

Die API basiert auf GraphQL. Jede Ressource, etwa Fahrzeuge, Stationen, Routen und Navigationssitzungen, ist über eine einzige GraphQL API verfügbar. Sie können jede davon als Query, Mutation oder Subscription aufrufen.

Wenn Sie neu bei GraphQL sind, ist die [offizielle GraphQL-Dokumentation](https://graphql.org/learn/) ein guter Einstiegspunkt.

## GraphQL-Endpoints

Queries, Mutationen und Subscriptions sind unter den folgenden Endpoints verfügbar. Ein Beispiel finden Sie unter [Ihre erste Anfrage senden](/docs/getting-started/api-request).

Für Queries und Mutationen verwenden Sie:

```bash Mutation and Query URL
https://api.chargetrip.io/graphql
```

Für Subscriptions verwenden Sie:

```bash Subscriptions URL
wss://api.chargetrip.io/subscription
```

### Authentifizierung

Jede Anfrage wird mit den Headern `x-client-id` und `x-app-id` authentifiziert. Wie Sie diese erhalten und senden, erfahren Sie unter [Autorisierung](/docs/getting-started/api-request#autorisierungs-header).

### Pagination

Listen-Queries verwenden entweder die Argumente `size` und `page` oder, bei cursorbasierter Pagination, die Argumente `first` und `after`. Details finden Sie unter [Pagination](/api-reference/api/pagination).

### Rate Limiting

Für Anfragen gilt [Rate Limiting](/api-reference/api/rate-limiting).

### Lebenszyklus

Chargetrip verwendet eine einzige, sich weiterentwickelnde GraphQL API anstelle versionierter Releases. Wie wir mit breaking und nicht-breaking Änderungen umgehen, erfahren Sie unter [Lebenszyklus](/api-reference/api/lifecycle).
