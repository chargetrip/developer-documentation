---
title: Updates zugeordneter Routen
schemaName: matchedRoute
schemaType: Subscription
---

Abonnieren Sie eine zugeordnete Route mit der Subscription matchedRoute. Dies ist nützlich, wenn Sie Echtzeit-Updates erhalten möchten, während eine zugeordnete Route berechnet wird.

## Subscription

Zum Abonnieren der Updates ist die `id` einer zugeordneten Route erforderlich. Die `id` erhalten Sie über die [Mutation createMatchedRoute](/api-reference/matched-route/mutation-create-matched-route).
