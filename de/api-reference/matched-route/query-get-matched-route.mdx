Rufen Sie die Details einer zuvor berechneten zugeordneten Route mit der Query getMatchedRoute ab. Dies ist nützlich, wenn Sie eine zugeordnete Route erneut abrufen möchten, ohne eine neue Subscription zu öffnen.

## Query

Zum Abrufen der Routendetails ist die `id` einer zugeordneten Route erforderlich. Die `id` erhalten Sie über die [Mutation createMatchedRoute](/api-reference/matched-route/mutation-create-matched-route).
