Erstellen Sie mit der Mutation createMatchedRoute eine Route aus einer Folge von GPS-Punkten. Dies ist besonders nützlich, wenn Sie bereits eine Route auf Basis Ihrer eigenen Geschäftsregeln haben und darauf aufbauend Ladestopps hinzufügen und den Energieverbrauch berechnen möchten.

## Mutation

Zum Erstellen einer zugeordneten Route sind ein `vehicle` und mindestens zwei chronologisch geordnete `points` erforderlich. Optional können Sie `via`-Punkte, `departure_time`, `weather`, `driving_preferences`, `operators` oder `alternative_station_radius` hinzufügen, um die Berechnung zu verfeinern. Setzen Sie `plan_charging_stops`, um Ladestopps zu finden und zu planen, falls der Ladezustand des Fahrzeugs an einer beliebigen Stelle der Route den Schwellenwert erreicht. Die Mutation gibt die `id` einer zugeordneten Route zurück, mit der Sie Routendetails abrufen oder Updates abonnieren können.
