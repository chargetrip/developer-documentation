Entfernen Sie eine vom authentifizierten Nutzer hinzugefügte Bewertung mit der Mutation deleteUserReview. Dies ist eine Premium-Funktion. Kontaktieren Sie uns für weitere Informationen.

## Mutation

Zum Entfernen einer Bewertung ist deren `id` erforderlich. Ein `x-token`-Header ist zur Autorisierung des Nutzers zwingend erforderlich — die Bewertung muss ihm gehören, andernfalls tritt ein Fehler auf.
