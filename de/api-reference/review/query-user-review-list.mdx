Rufen Sie mit der Query userReviewList alle Bewertungen ab, die der authentifizierte Nutzer stationsübergreifend hinzugefügt hat. Dies ist nützlich, wenn Sie den eigenen Bewertungsverlauf eines Nutzers anzeigen möchten. Dies ist eine Premium-Funktion. Kontaktieren Sie uns für weitere Informationen.

## Query

Ein `x-token`-Header ist erforderlich, um den Nutzer zu autorisieren, dessen Bewertungen Sie abrufen möchten. Verwenden Sie die Argumente `size` und `page`, um die Ergebnisse zu [paginieren](/api-reference/api/pagination).
