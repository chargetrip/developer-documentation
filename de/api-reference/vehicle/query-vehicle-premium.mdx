Erhalten Sie mit der Query vehiclePremium Zugriff auf noch detailliertere Daten. Sie enthält erweiterte Daten zu Batterie, Karosserie, Verfügbarkeit, Preisen, Effizienz, Sicherheit und mehr. [Kontaktieren Sie den Vertrieb](https://www.chargetrip.com/contact/sales), um auf Premium-Fahrzeugdaten umzusteigen.

## Query

Zum Abrufen der Premium-Fahrzeugdetails ist eine Fahrzeug-`id` erforderlich. Die `id` erhalten Sie über die [Query vehicleList](/api-reference/vehicle/query-vehicles). Verwenden Sie das Argument country, um die Daten zu lokalisieren.
