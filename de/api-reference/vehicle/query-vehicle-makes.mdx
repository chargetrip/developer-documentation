Rufen Sie mit der Query vehicleMakes eine Liste der Fahrzeughersteller ab.

## Query
Für die Query vehicleMakes ist keine Eingabe erforderlich. Verwenden Sie das Argument `filter`, um die Ergebnisse nach Region und/oder Typ einzugrenzen, sowie die Argumente `first` und `after`, um die Ergebnisse zu [paginieren](/api-reference/api/pagination). Verwenden Sie das Argument `country`, um die Daten zu lokalisieren.
