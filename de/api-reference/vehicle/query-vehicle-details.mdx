Rufen Sie die Fahrzeugspezifikationen mit der Query vehicle ab.

## Query

Zum Abrufen der Fahrzeugdetails ist eine Fahrzeug-`id` erforderlich. Die `id` erhalten Sie über die [Query vehicleList](/api-reference/vehicle/query-vehicles). Verwenden Sie das Argument country, um die Daten zu lokalisieren.
