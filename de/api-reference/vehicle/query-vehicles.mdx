schemaName: vehicleList

Greifen Sie mit der Query `vehicleList` auf die vollständige Fahrzeugdatenbank zu. Standardmäßig verwendet die Fahrzeugdatenbank EU-Bezeichnungen für Fahrzeuge und Steckertypen.

## Query

Für die Query `vehicleList` ist keine Eingabe erforderlich. Verwenden Sie `filter` und `search`, um die Ergebnisse einzugrenzen und anzupassen. Verwenden Sie den Parameter country in Kombination mit dem Regionsfilter, um Fahrzeuge zurückzugeben, die in Ihrer Region verfügbar sind, mit lokal bekannten Namen und Steckertypen. Verwenden Sie die Argumente `size` und `page`, um die Ergebnisse zu [paginieren](/api-reference/api/pagination).
