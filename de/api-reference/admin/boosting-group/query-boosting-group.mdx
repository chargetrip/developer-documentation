Rufen Sie eine Boosting Group mit der Query boostingGroup ab. Das ist nützlich, wenn Sie prüfen möchten, ob eine Gruppe aktiv ist oder welche Stationen sie aktuell priorisiert. Wie sich Boosting Groups auf eine Route auswirken, erfahren Sie im [Leitfaden zu Boosting Groups](/docs/getting-started/route-boosting-groups).

## Query

Eine `id` der Boosting Group ist erforderlich. Die `id` erhalten Sie über die [Mutation createBoostingGroup](/api-reference/admin/boosting-group/mutation-create-boosting-group) oder die [Query boostingGroups](/api-reference/admin/boosting-group/query-boosting-groups).

> [!WARNING] Alpha
> Diese Operation befindet sich in der Alpha-Phase und ist in kostenlosen Tarifen nicht verfügbar. Wenden Sie sich für den Zugang an den Support.
