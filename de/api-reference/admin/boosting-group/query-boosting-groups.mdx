Listen Sie die Boosting Groups Ihres Workspace mit der Query boostingGroups auf. Das ist nützlich, wenn Sie eine Übersicht Ihrer Gruppen erstellen oder die aktuell aktiven Gruppen finden möchten.

## Query

Für diese Query ist keine Eingabe erforderlich. Mit den Argumenten `first` und `after` [paginieren](/api-reference/core/api/pagination) Sie die Ergebnisse, mit dem Argument `filter` grenzen Sie sie nach `client_id` oder `status` ein.
