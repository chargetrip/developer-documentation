Löschen Sie eine Boosting Group mit der Mutation deleteBoostingGroup. Das ist nützlich, wenn Sie die Stationen einer Gruppe nicht mehr priorisieren möchten. Um eine Gruppe nur vorübergehend nicht zu nutzen, [setzen Sie stattdessen ihren Status auf inactive](/api-reference/admin/boosting-group/mutation-update-boosting-group).

## Mutation

Eine `id` der Boosting Group ist erforderlich. Die Mutation gibt einen Boolean zurück.
