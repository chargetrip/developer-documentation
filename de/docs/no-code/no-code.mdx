Nicht jeder Anwendungsfall erfordert eine individuelle Entwicklung. Für Teams, die schnell starten möchten, stehen fertige, anpassbare Tools zur Verfügung, die sich direkt in eine Website oder App einbetten lassen und auf denselben Routing- und Fahrzeugdaten wie die API basieren.

## Funktionen

**Routenplanung**
: Erprobte und bewährte UX-Abläufe auf Basis der Routing-Engine, direkt in eine Website oder App eingebettet. Nimmt EV-Fahrern die Reichweitenangst, ganz ohne eigene Entwicklung.

**Stationskarte**
: Eine interaktive Karte eines Ladenetzes mit schnellem Clustering und detaillierten Stationsdaten. Hilft Endnutzern, die Infrastruktur zu erkunden und eine Station zu finden.

**Range Spider**
: Visualisiert die reale Reichweite eines EV von jedem beliebigen Punkt aus und berücksichtigt dabei Faktoren wie Höhenunterschiede und Wetter. Hilft angehenden EV-Fahrern, die Reichweite von Anfang an zu verstehen.
