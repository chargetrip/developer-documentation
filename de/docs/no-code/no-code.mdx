Nicht jeder Anwendungsfall erfordert eine individuelle Entwicklung. Für Teams, die schnell starten möchten, stehen vorgefertigte, an die eigene Marke anpassbare Tools zur Verfügung, die direkt in eine Website oder App eingebettet werden können und auf denselben Routing- und Fahrzeugdaten wie die API basieren.

## Funktionen

**Routenplanung**
: Erprobte und bewährte UX-Abläufe auf Basis der Routing-Engine, direkt in eine Website oder App eingebettet. Nimmt E-Fahrern die Reichweitenangst, ohne dass eine eigene Entwicklung nötig ist.

**Stationskarte**
: Eine interaktive Karte eines Ladenetzwerks mit schnellem Clustering und detaillierten Stationsdaten. Hilft Endnutzern, die Infrastruktur zu erkunden und eine Station zu finden.

**Range Spider**
: Visualisiert die reale Reichweite eines E-Fahrzeugs von jedem Punkt aus und berücksichtigt dabei Faktoren wie Höhenprofil und Wetter. Hilft angehenden E-Fahrern, die Reichweite von Anfang an zu verstehen.
