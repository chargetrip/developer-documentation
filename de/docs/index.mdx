Diese Anleitungen führen durch die Einrichtung Ihres Kontos, das Senden Ihrer ersten Anfrage und die Entwicklung gängiger Funktionen wie Routing und Preisgestaltung. Die vollständige Liste der Queries, Mutations und Subscriptions finden Sie in der [API-Referenz](/api-reference).

## Anleitungen

| Anleitung | Beschreibung |
| --- | --- |
| [Konto einrichten](/docs/getting-started/account-setup) | Erstellen Sie einen Workspace, ein Projekt und eine App und halten Sie Ihre Zugangsdaten sicher. |
| [Anfragen senden](/docs/getting-started/api-request) | Authentifizieren Sie sich und senden Sie Ihre erste Anfrage an die API. |
| [Route erstellen](/docs/getting-started/route) | Erstellen Sie eine Route, rufen Sie sie ab und passen Sie sie an Ihren Anwendungsfall an. |
| [Route mit Betreiberpräferenzen erstellen](/docs/getting-started/route-operators) | Erstellen Sie eine Route mit Betreiberpräferenzen. |
| [Route mit bevorzugten Stationen erstellen](/docs/getting-started/route-boosting-groups) | Lenken Sie Routen anhand Ihrer eigenen Geschäftsregeln gezielt zu bestimmten Ladestationen. |
| [Route mit vom Nutzer gewählten Zwischenstopps erstellen](/docs/getting-started/route-stop) | Erstellen Sie eine Route mit vom Nutzer gewählten Zwischenstopps. |
| [Fahrzeugreichweite visualisieren](/docs/getting-started/vehicle-range) | Visualisieren Sie das Gebiet, das ein Fahrzeug mit seinem aktuellen Akkustand von einem Punkt aus erreichen kann. |
| [Stationspreise](/docs/getting-started/station-pricing) | Stellen Sie Preise auf der Karte dar und ermitteln Sie den Preis eines Ladevorgangs. |
| [No-Code](/docs/no-code/no-code) | Betten Sie fertige, anpassbare Routing-Tools ein, ohne Code zu schreiben. |
