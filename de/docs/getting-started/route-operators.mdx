---
title: "Routing nach Betreiberpräferenz"
description: "Steuern Sie, welche Ladenetzwerke der Routing-Dienst bevorzugt, indem Sie Betreiberpräferenzen im Dashboard oder pro Anfrage festlegen."
---
Mit Betreiberpräferenzen steuern Sie, welche Ladenetzwerke der Routing-Dienst bei der Berechnung einer E-Fahrzeug-Route bevorzugt.

Sie können Präferenzen an zwei Stellen konfigurieren:
- [Chargetrip-Dashboard](https://account.chargetrip.io/projects): Legen Sie globale Betreiberpräferenzen für Ihr Projekt unter Projekt / Erweitert / Stationsbetreiber-Präferenzen fest.
- [Create-Route-Anfrage](/api-reference/core/route/mutation-create-route#arg-input-operators): Definieren Sie Präferenzen dynamisch oder überschreiben Sie die Betreiberpräferenzen aus dem Dashboard pro Anfrage über das Feld `input.operators` in der Mutation `createRoute`.

---

### 1. Präferenztypen und Routenverhalten


Betreiberpräferenzen gibt es in vier Typen, und jede kann auf bestimmte Länder begrenzt werden:

| Präferenz | Routing-Verhalten |
|:---|:---|
| Ausgeschlossen | Stationen dieser Betreiber werden unter allen Umständen strikt ausgeschlossen. |
| Gemieden  |  Stationen dieser Betreiber werden gemieden, sofern keine bessere Alternative existiert. |
| Bevorzugt | Stationen dieser Betreiber werden nach ihrem Ranking (high, medium, low) priorisiert. Je höher die Stufe, desto wahrscheinlicher wird die Station ausgewählt. Die Route nutzt weiterhin nicht eingestufte oder gemiedene Stationen, wenn keine bessere Alternative existiert.|
| Erforderlich  | Es werden nur Stationen dieser Betreiber verwendet. Innerhalb dieses zulässigen Pools gelten die Ranking-Stufen weiterhin, das heißt, hoch eingestufte Betreiber werden gegenüber mittel und niedrig eingestuften bevorzugt. Wenn das Fahrzeug das Ziel nicht allein mit eingestuften Stationen erreichen kann, schlägt die Routenberechnung fehl.|


---

### 2. Anwendung der Präferenzen auf Dashboard-Ebene

Wenn Sie verstehen, wie Eingaben auf Anfrageebene mit den Dashboard-Einstellungen zusammenwirken, bleibt das Routing-Verhalten vorhersehbar:

- **Im Dashboard ausgeschlossene und gemiedene Betreiber gelten automatisch**:
Betreiber, die im Dashboard als ausgeschlossen oder gemieden konfiguriert sind, gelten für jede Routenberechnung, ohne dass Parameter in Ihrer `createRoute`-Anfrage erforderlich sind.
- **Ranking-Stufen im Dashboard bleiben ohne Ranking-Typ inaktiv**:
Betreiber, die in Ranking-Stufen konfiguriert sind, müssen durch Setzen von `input.operators.ranking.type` in Ihrer `createRoute`-Anfrage aktiviert werden, andernfalls beeinflussen sie die Stationsauswahl nicht.
- **Betreiber auf Anfrageebene ersetzen die jeweiligen Dashboard-Präferenzen**:
Die Angabe von Betreiber-IDs in der `createRoute`-Anfrage ersetzt nur die entsprechende Konfiguration aus dem Dashboard. Wenn Sie beispielsweise `input.operators.exclude[]` angeben, ersetzt das die gesamte Konfiguration der ausgeschlossenen Betreiber im Dashboard, während die Dashboard-Betreiber zum Meiden weiterhin gelten.
---
### 3. Implementierungsbeispiele

<details>
  <summary>Nur Dashboard-Ausschlüsse und -Vermeidungen verwenden</summary>
  Wendet die im Dashboard festgelegten Konfigurationen für ausgeschlossene und gemiedene Betreiber an. Die Ranking-Einstellungen des Dashboards sind inaktiv, da kein `input.operators.ranking.type` angegeben ist.

```graphql Example request
createRoute(
  input: {
    vehicle: { id: "607823b2c246f9001b97b1a2" }
    origin: {
      type: Feature
      geometry: { type: Point, coordinates: [4.895168, 52.370216] }
    }
    destination: {
      type: Feature
      geometry: { type: Point, coordinates: [2.352222, 48.856614] }
    }
  }
)
```
</details>

<details>
  <summary>Ranking-Betreiber aus dem Dashboard als „Bevorzugt“ verwenden</summary>
  Wendet die Dashboard-Konfigurationen für ausgeschlossene und gemiedene Betreiber an und bevorzugt Stationen, die zu den Ranking-Stufen des Dashboards gehören.

```graphql Example request {{ mark: [14] }}
createRoute(
  input: {
    vehicle: { id: "607823b2c246f9001b97b1a2" }
    origin: {
      type: Feature
      geometry: { type: Point, coordinates: [4.895168, 52.370216] }
    }
    destination: {
      type: Feature
      geometry: { type: Point, coordinates: [2.352222, 48.856614] }
    }
    operators: {
      ranking: {
        type: preferred
      }
    }
  }
)
```
</details>

<details>
  <summary>Ranking-Betreiber aus dem Dashboard als „Erforderlich“ verwenden</summary>
  Beschränkt die Route darauf, ausschließlich an Stationen von Betreibern zu laden, die in den Ranking-Stufen des Dashboards konfiguriert sind.

```graphql Example request {{ mark: [14] }}
createRoute(
  input: {
    vehicle: { id: "607823b2c246f9001b97b1a2" }
    origin: {
      type: Feature
      geometry: { type: Point, coordinates: [4.895168, 52.370216] }
    }
    destination: {
      type: Feature
      geometry: { type: Point, coordinates: [2.352222, 48.856614] }
    }
    operators: {
      ranking: {
        type: required
      }
    }
  }
)
```
</details>

<details>
  <summary>Eigene Präferenzen definieren und Dashboard-Einstellungen überschreiben</summary>
  Geben Sie die vollständigen Betreiberkonfigurationen direkt im API-Aufruf an. Jedes angegebene Feld (ranking, avoid oder exclude) überschreibt für diese Anfrage die entsprechende Dashboard-Konfiguration.

```graphql Example request  {{ mark: [13,14,15,16,17,18,19,20,21] }}
createRoute(
  input: {
    vehicle: { id: "607823b2c246f9001b97b1a2" }
    origin: {
      type: Feature
      geometry: { type: Point, coordinates: [4.895168, 52.370216] }
    }
    destination: {
      type: Feature
      geometry: { type: Point, coordinates: [2.352222, 48.856614] }
    }
    operators: {
      ranking: {
        type: preferred
        level: {
          high: [{ id: "5e8c22366f9c5f23ab0eff01" }]
          medium: [{ id: "5e8c22366f9c5f23ab0eff02" }]
        }
      }
      avoid: [{ id: "5e8c22366f9c5f23ab0eff03" }]
      exclude: [{ id: "5e8c22366f9c5f23ab0eff04" }]
    }
  }
)
```
</details>

<details>
  <summary>Eigene Präferenzen für bestimmte Länder definieren</summary>
  Geben Sie die vollständigen Betreiberkonfigurationen direkt im API-Aufruf an. Jedes angegebene Feld (ranking, avoid oder exclude) überschreibt für diese Anfrage die entsprechende Dashboard-Konfiguration.

```graphql Example request  {{ mark: [13,14,15,16,17,18,19,20,21] }}
createRoute(
  input: {
    vehicle: { id: "607823b2c246f9001b97b1a2" }
    origin: {
      type: Feature
      geometry: { type: Point, coordinates: [4.895168, 52.370216] }
    }
    destination: {
      type: Feature
      geometry: { type: Point, coordinates: [2.352222, 48.856614] }
    }
    operators: {
      ranking: {
        type: preferred
        level: {
          high: [{ id: "5e8c22366f9c5f23ab0eff01", countries: ["NL", "DE"] }]
          medium: [{ id: "5e8c22366f9c5f23ab0eff01", countries: ["FR"] }]
        }
      }
      avoid: [{ id: "5e8c22366f9c5f23ab0eff03", countries: ["AT"] }]
      exclude: [{ id: "5e8c22366f9c5f23ab0eff04" }]
    }
  }
)
```
</details>
