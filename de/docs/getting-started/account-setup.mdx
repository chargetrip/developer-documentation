Um die API zu nutzen, erstellen Sie ein Konto. Sobald Ihr Konto eingerichtet ist, können Sie die API direkt in der Produktionsumgebung verwenden.

## Umgebung einrichten

Das Dashboard ist in drei Ebenen gegliedert, von der allgemeinsten bis zur spezifischsten.

1. **Workspace**
   Ein Workspace ermöglicht es den Mitgliedern Ihres Teams, gemeinsam an denselben Projekten zu arbeiten, zum Beispiel wenn ein Country Manager Betreiberpräferenzen verwalten muss und ein Entwickler Zugriff auf die API-Schlüssel benötigt. Ein Workspace ist außerdem die abrechenbare Beziehung zu uns, mehrere Workspaces bedeuten also mehrere Verträge.
2. **Projekt**
   Richten Sie innerhalb eines Workspaces ein Projekt ein. Projekte werden auf Grundlage von Betreiberpräferenzen, Stationsdatenbank und Fahrzeugauswahl erstellt. Wenn Sie Anwendungsfälle mit einer anderen Konfiguration haben, erstellen Sie für jeden ein eigenes Projekt.
3. **App**
   Wenn Sie diese Einstellungen teilen, aber dennoch getrennte Analysen oder Sicherheitsmaßnahmen wünschen, zum Beispiel wenn Sie eine iOS- und eine Android-App entwickeln, erstellen Sie innerhalb eines Projekts verschiedene Apps.

Unter [Anfragen senden](/docs/getting-started/api-request) erfahren Sie, wie Sie Ihre Projekt- und App-IDs zur Authentifizierung von Anfragen verwenden.

## Konto schützen

Nachdem Sie Ihr Konto eingerichtet haben, sollten Sie es schützen. Hier sind unsere Empfehlungen:

- **Schützen Sie Ihre Zugangsdaten**: Committen Sie niemals einen API-Schlüssel in die Versionsverwaltung, speichern Sie ihn stattdessen in einem Secrets-Tresor und beschränken Sie ihn auf den nötigen Zugriff, da unsere Schlüssel eingeschränkt werden können.
- **Gewähren Sie Zugriff über Teammitglieder statt durch das Teilen von Logins**: Laden Sie Kollegen mit nur dem benötigten Zugriff in Ihren Workspace ein, anstatt Ihre eigenen Zugangsdaten weiterzugeben.
