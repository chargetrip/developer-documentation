Um die API zu nutzen, erstellen Sie ein Konto. Sobald Ihr Konto eingerichtet ist, können Sie die API direkt in der Produktionsumgebung verwenden.

## Umgebung einrichten

Das Dashboard ist in drei Ebenen gegliedert, von der allgemeinsten bis zur spezifischsten.

1. **Workspace**
   Ein Workspace ermöglicht es Ihren Teammitgliedern, gemeinsam an denselben Projekten zu arbeiten, zum Beispiel wenn ein Country Manager Betreiberpräferenzen verwalten muss und ein Entwickler Zugriff auf die API-Schlüssel benötigt. Ein Workspace ist außerdem die abrechnungsrelevante Vertragsbeziehung mit uns, mehrere Workspaces bedeuten also mehrere Verträge.
2. **Projekt**
   Richten Sie innerhalb eines Workspace ein Projekt ein. Projekte werden auf Basis von Betreiberpräferenzen, Stationsdatenbank und Fahrzeugauswahl erstellt. Wenn Sie Anwendungsfälle mit einer abweichenden Konfiguration haben, erstellen Sie für jeden ein eigenes Projekt.
3. **App**
   Wenn Sie diese Einstellungen teilen, aber dennoch getrennte Analysen oder Sicherheitsmaßnahmen wünschen, zum Beispiel wenn Sie eine iOS- und eine Android-App entwickeln, erstellen Sie innerhalb eines Projekts verschiedene Apps.

Unter [Anfragen senden](/docs/getting-started/api-request) erfahren Sie, wie Sie Ihre Projekt- und App-IDs zur Authentifizierung von Anfragen verwenden.

## Konto schützen

Nach der Einrichtung Ihres Kontos sollten Sie es schützen. Hier unsere Empfehlungen:

- **Schützen Sie Ihre Zugangsdaten**: Committen Sie niemals einen API-Schlüssel in die Versionsverwaltung, speichern Sie ihn stattdessen in einem Secrets-Vault und beschränken Sie ihn auf die benötigten Zugriffsrechte, da sich unsere Schlüssel einschränken lassen.
- **Gewähren Sie Zugriff über Teammitglieder statt über gemeinsame Logins**: Laden Sie Kolleginnen und Kollegen mit nur den benötigten Zugriffsrechten in Ihren Workspace ein, anstatt Ihre eigenen Zugangsdaten weiterzugeben.
