# Routenemissionen

Migrieren bis: Q1 2027

Migrieren Sie vom veralteten Emissions-Dienst auf die neueste Version. Der neue Dienst ist als eigene dedizierte Query aufgebaut und besser auf Skalierbarkeit und zukünftige Updates ausgerichtet.

## Änderungen an der Query

Emissionsdaten wurden aus der Routenantwort in eine eigene dedizierte Query `getRouteEmissions` verlagert, sodass sie unabhängig von einer Routenberechnung angefordert werden können.
