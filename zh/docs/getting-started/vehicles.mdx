全面的车辆数据库对任何 EV 应用都至关重要。车辆数据可以让最终用户更好地了解自己的车辆，并找到适合自己的充电站。它对路线规划同样必不可少，因为最优路线会因所驾驶的车辆不同而大相径庭。

## 简介

关于 EV 以及车辆数据为何对路线规划至关重要的简要介绍。

### 电动车与内燃机车

ICE（内燃机）车辆依靠燃烧化石燃料运行。EV 依靠电力运行，并通过连接充电桩来充电。

### 为电动车充电

EV 在充电站使用几种插头类型之一进行充电，因此了解驾驶员的车辆和充电桩支持的插头非常重要。充电速度分为三个等级：1 级和 2 级使用交流电，需要数小时；3 级“快速充电”使用直流电，可在一小时内为车辆充满电。Chargetrip API 会考虑每辆车的充电曲线，并按地点提供可用的支付方式，因为这些方式会因地区和运营商而异。

### 电池的影响因素

电池性能会受到天气、空调使用情况和车辆规格的影响，就像手机电池在寒冷环境中表现不同一样。Chargetrip 会考虑这些因素，以得出准确的续航里程估算。

### EV 路线规划

里程焦虑，即担心在到达目的地或充电桩之前电量耗尽，可以通过路线规划来缓解，路线规划会显示途中是否需要充电以及在何处充电。

### 续航里程预测

准确的路线规划取决于预测车辆在两点之间会消耗多少能量，这使应用能够在行程中推荐充电停靠点。使用等值线可以可视化车辆在给定条件和偏好下可到达的区域。

## 数据库

大多数 EV 路线规划 API 通常要求您提供车辆的全部数据和详细信息，而车辆数据库则无需如此，它包含超过 2,200 种 BEV（纯电动车）、PHEV（插电式混合动力车）、HEV（混合动力车）和 EREV（增程式电动车）车型。所有 BEV 和 EREV 都配有各自经过验证的能耗模型。

能耗模型会考虑诸如风阻系数、与速度相关的滚动阻力、海拔、充电速度、充电温度、电池温度等众多属性。

此外，所有车辆都附带详细的车辆规格和图片，可用于前端展示。新车型上市后会持续添加。

### 高级数据

如果您需要标准车辆数据之外的更多信息，可以将 [vehiclePremium](/api-reference/vehicle/query-vehicle-premium) 作为附加组件使用。它包含有关电池、车身、可用性、价格、能效、安全性等方面的扩展数据。请[联系销售](https://www.chargetrip.com/contact/sales)升级到高级车辆数据。

### 图片

与 `vehiclePremium` 一样，已获授权的车辆图片也可作为附加组件使用。这些图片的质量高于车辆数据库默认提供的图片。请[联系销售](https://www.chargetrip.com/contact/sales)为您的项目启用此功能。

## 实现

通过 [vehicleList](/api-reference/vehicle/query-vehicles) 查询访问完整的车辆数据库，并使用 [vehicle](/api-reference/vehicle/query-vehicle-details) 查询获取更详细的信息。

任何[路线](/docs/getting-started/route)或等值线变更都需要车辆 `id`，可通过 `vehicleList` 查询获取。
