---
title: 优先选择特定充电站
---

Boosting Groups 让您可以根据自己的业务规则，将充电站的选择引导至特定的充电地点。

[运营商偏好](/docs/getting-started/route-operators)可以让您优先选择整个充电网络，而 Boosting Groups 则为您提供精细的、充电站级别的控制。无论您偏好这些充电站的原因是什么，例如价格更低、利用率低或商业条件更优，您都可以将它们提升到充电站层级的最前面。

## 如何提升充电站

要开始使用，只需联系[支持](https://www.chargetrip.com/contact/support)并提供您想要优先选择的充电站列表。

在您的分组设置完成并在项目中启用后，所有使用 [createRoute](/api-reference/core/route/mutation-create-route) 计算的路线都会在后台自动使用它，因此您的 API 请求无需任何更改或额外参数。

## 工作原理

Boosting Groups 仅支持正向优先级。您可以用它们来推广充电站，但不能用来避开或排除充电站。单独使用时，被提升的充电站会优先于路线沿途的所有其他充电站。

与运营商偏好结合使用时，路线规划器按以下优先顺序（从高到低）选择充电站：

- 生效的 Boosting Groups 是被单独提升的充电站。它们会覆盖所有运营商偏好，即使该充电站的运营商被设置为 `avoid` 或 `excluded`。
- 偏好的运营商（`high`、`medium`、`low`）是属于偏好充电网络的充电站。
- 未排序的充电站是未应用 boosting group 或运营商偏好的标准充电站。
- 降低优先级的运营商（`avoid`）是属于被标记为避开的运营商的充电站。仅在没有更好选择时才会使用它们。

与运营商偏好一样，充电站提升按尽力而为的方式运行。路线规划器会在充电站优先级与充电站密度和绕行影响之间取得平衡，因此选择被提升的充电站绝不会导致低效的路线。

## 示例

<details>
  <summary>使用生效的 boosting groups 计算路线</summary>

  由于 Boosting Groups 在项目级别自动应用，您只需发送标准的 `createRoute` mutation。所有生效的 Boosting Groups 都会被自动优先选择。

```graphql Example request
mutation CreateRoute {
  createRoute(
    input: {
      vehicle: { id: "607823b2c246f9001b97b1a2" }
      origin: {
        type: Feature
        geometry: { type: Point, coordinates: [4.895168, 52.370216] }
      }
      destination: {
        type: Feature
        geometry: { type: Point, coordinates: [6.773456, 51.227741] }
      }
    }
  ) {
    id
    status
  }
}
```
</details>

<details>
  <summary>检查推荐的充电站是否属于某个 boosting group</summary>

  使用 `getRoute` 或 `route` subscription 获取已计算的路线时，请在路段的充电站上请求 `boosting_group_ids`，以查看哪些生效的 Boosting Groups 匹配了该停靠点。

```graphql Example request {{ mark: [11] }}
query GetRoute {
  getRoute(id: "6527e1f1a8b4c2d3e4f5a6b7") {
    status
    route {
      id
      legs {
        origin {
          properties {
            station_id
            station {
              boosting_group_ids
            }
          }
        }
      }
    }
  }
}
```
</details>
