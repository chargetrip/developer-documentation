要开始使用 API，请先创建账户。账户设置完成后，您即可直接针对生产环境使用 API。

## 设置您的环境

控制台分为三个层级，从最宽泛到最具体。

1. **工作区**
   工作区让您的团队成员可以在相同的项目上协作，例如当区域经理需要管理运营商偏好，而开发者需要访问 API 密钥时。工作区也是与我们之间的计费关系，因此多个工作区意味着多份合同。
2. **项目**
   在工作区内设置项目。项目根据运营商偏好、充电站数据库和车辆选择来创建。如果您的用例需要不同的设置，请为每个用例创建单独的项目。
3. **应用**
   如果您共用这些设置，但仍希望拥有各自独立的分析或安全措施，例如构建 iOS 和 Android 应用时，请在一个项目中创建不同的应用。

有关如何使用项目 ID 和应用 ID 对请求进行身份验证，请参阅[发送请求](/docs/getting-started/api-request)。

## 保护您的账户安全

设置好账户后，您需要保障其安全。以下是我们的建议：

- **保护您的凭据**：切勿将 API 密钥提交到源代码管理中，而应将其存储在密钥保管库中，并将其权限限定在所需的访问范围内，因为我们的密钥可以受到限制。
- **通过团队成员授予访问权限，而不是共享登录信息**：邀请同事加入您的工作区，只授予其所需的访问权限，而不是交出您自己的凭据。
