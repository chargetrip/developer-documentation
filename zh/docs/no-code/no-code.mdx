并非每个使用场景都需要定制开发。对于希望快速上线的团队，我们提供现成的、可定制品牌的工具，可直接嵌入网站或应用中，并基于与 API 相同的路线和车辆数据构建。

## 功能

**路线规划**
: 基于路线引擎构建、经过验证的成熟用户体验流程，可直接嵌入网站或应用。无需自行开发，即可消除 EV 驾驶员的里程焦虑。

**充电站地图**
: 充电网络的交互式地图，具备快速聚合和详细的充电站数据。帮助最终用户探索充电设施并找到充电站。

**Range Spider**
: 从任意地点可视化 EV 的真实续航里程，并考虑海拔和天气等因素。帮助潜在 EV 驾驶员提前了解续航里程。

## 定制

每个无代码工具都可以完全定制品牌，以匹配您的产品。功能可以自由调整位置并开启或关闭，整套样式指南（包括颜色和品牌元素）也可以修改，以匹配您的产品。这些工具还可以嵌入移动应用中，而不仅限于网页。
