并非每个用例都需要定制开发。对于希望快速上线的团队，我们提供现成的、可定制品牌的工具，可直接嵌入网站或应用，并基于与 API 相同的路线规划和车辆数据构建。

## 功能

**路线规划**
: 基于路线规划引擎构建的、经过测试和验证的 UX 流程，可直接嵌入网站或应用。无需自行开发即可消除电动汽车驾驶员的里程焦虑。

**充电站地图**
: 充电网络的交互式地图，具有快速聚合和详细的充电站数据。帮助终端用户探索基础设施并找到充电站。

**续航蛛网图**
: 可视化电动汽车从任意地点出发的真实续航范围，并考虑海拔和天气等因素。帮助潜在的电动汽车驾驶员提前了解续航里程。

## 定制

每个无代码工具都可以完全定制品牌，以匹配您的产品。功能可以调整位置并开启或关闭，整个样式指南（包括颜色和品牌）都可以更改，以匹配您的产品。这些工具也可以嵌入移动应用中，而不仅限于网页。
