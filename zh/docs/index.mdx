这些指南将带您完成账户设置、发送第一个请求，以及构建路线规划和定价等常见功能。有关查询、变更和订阅的完整列表，请参阅 [API 参考](/api-reference)。

## 指南

| 指南 | 描述 |
| --- | --- |
| [设置您的账户](/docs/getting-started/account-setup) | 创建工作区、项目和应用，并妥善保管您的凭据。 |
| [发送请求](/docs/getting-started/api-request) | 进行身份验证，并向 API 发送您的第一个请求。 |
| [构建路线](/docs/getting-started/route) | 创建路线、获取路线，并根据您的使用场景进行自定义。 |
| [构建带运营商偏好的路线](/docs/getting-started/route-operators) | 创建带有运营商偏好的路线。 |
| [构建使用增强充电站的路线](/docs/getting-started/route-boosting-groups) | 根据您自己的业务规则，将路线引导至特定的充电站。 |
| [构建带用户所选停靠点的路线](/docs/getting-started/route-stop) | 创建带有用户所选停靠点的路线。 |
| [可视化车辆续航里程](/docs/getting-started/vehicle-range) | 可视化车辆以当前电量从某一地点出发可到达的区域。 |
| [充电站定价](/docs/getting-started/station-pricing) | 在地图上呈现价格，并计算一次充电会话的费用。 |
| [无代码](/docs/no-code/no-code) | 无需编写任何代码，即可嵌入现成的、可定制品牌的路线规划工具。 |
