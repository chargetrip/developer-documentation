使用 updateConnectedVehicle 变更更新联网车辆。当您想更改联网车辆的标签时，此操作非常有用。

## 变更

更新联网车辆需要 `id`。使用 `label` 设置新标签。`id` 可通过 [createConnectedVehicle 变更](/api-reference/connected-vehicle/mutation-create-connected-vehicle)获取。
