使用 connectedVehicle 查询获取联网车辆的详细信息。当您想检查联网车辆的授权状态时，此操作非常有用。

## 查询

获取联网车辆的详细信息需要联网车辆的 `id`。`id` 可通过 [createConnectedVehicle 变更](/api-reference/connected-vehicle/mutation-create-connected-vehicle)或 [connectedVehicleList 查询](/api-reference/connected-vehicle/query-connected-vehicle-list)获取。
