---
title: 安全
---

随请求发送的请求头（包括 `x-app-id`）对任何检查网络流量的人都是可见的。为防止您的应用被未经授权地使用，请应用限制，以限定可以使用它的平台或来源。

> [!WARNING] 每个应用只能有一种限制
> 每个应用只能应用一种限制。若要组合多种限制，例如同时支持 Web 和移动客户端，请为每个客户端分别创建一个应用。

## 限制类型

提供四种限制类型，分别适用于不同的平台或通信模式。

### Web

通过 HTTP referrer 限制 Web 应用，应用于 `x-app-id` 请求头。单个应用可以添加多个 URL。

### 机器对机器（M2M）

通过 IP 地址（支持 IPv4 和 IPv6）限制服务器之间的通信，在应用控制面板中配置。这是最安全的选项，因为凭据永远不会到达浏览器或设备。

### Android

使用随每个请求发送的 `x-app-identifier` 和 `x-app-fingerprint` 请求头来限制 Android 应用。

### iOS

使用携带应用 bundle identifier 的 `x-app-identifier` 请求头来限制 iOS 应用。
