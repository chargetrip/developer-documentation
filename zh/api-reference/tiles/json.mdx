JSON 瓦片服务以 JSON 格式提供与充电站相关的地理数据。

## 设置

要以 JSON 格式获取充电站数据，请向以下端点发送请求：

```bash Tile / JSON / Base URL
https://api.chargetrip.io/v2/station/{z}/{x}/{y}/tile.json
```

JSON URL 使用以下路径参数：

- `z`：瓦片的缩放级别。
- `x`：瓦片的 x 坐标。
- `y`：瓦片的 y 坐标。

大多数地图提供商都内置了将纬度和经度转换为像素坐标的方法。若要手动将纬度和经度坐标转换为 x 和 y，请使用 [Web 墨卡托投影](https://en.wikipedia.org/wiki/Web_Mercator_projection)。

### 筛选
使用 `filter` 查询参数，根据特定条件筛选返回的充电站。更多信息请参见[筛选文档](/api-reference/tiles/filters)。

### 选择器
使用 `station_properties[]` 查询参数指定为每个充电站要素返回的字段。更多信息请参见[选择器文档](/api-reference/tiles/selectors)。
