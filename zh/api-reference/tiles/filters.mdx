---
title: 筛选
tag: Rest
---

筛选让应用可以细化 Tile Service API 返回的充电站。除了简单地隐藏不匹配的结果外，某些筛选还会转换充电站数据，以确保响应与上下文相关。

## 筛选如何影响数据

当请求包含筛选时，Tile 服务会执行两个不同的操作：

1. **排除不匹配的充电站**
   任何不满足指定筛选条件的充电站都会从响应中完全移除。使用充电站级别筛选或 EVSE 级别筛选时会执行此操作。
2. **数据转换**
   当提供特定的筛选参数时，Tile 服务会重新计算充电站的某些动态属性。使用 EVSE 级别筛选时会执行此操作。

## 实现

筛选参数可以作为查询字符串附加到请求 URL 上，适用于任何 Tile 服务端点（MVT、JSON 或 Count）。如果未应用任何筛选，则返回所有可用的充电站，并且不会进行任何数据转换。

```bash Tile / Filter / Example
https://api.chargetrip.io/v2/station/..../?{filter_1}&{filter_2}&{filter_n}
```

## 级别

筛选可以存在于两个级别：EVSE 级别或充电站级别，各自的影响和结果如下所述。

### 充电站级别

评估充电站整体属性的筛选。这些筛选仅用于排除：排除不匹配的充电站，但绝不会修改返回的数据字段。

`amenities` · `enum` · [显示示例 URL](tip:https://api.chargetrip.io/v2/station?amenities[]=HOTEL)
: 筛选，仅包含提供指定设施的充电站。
: `HOTEL`, `SHOPPING`, `BATHROOM`, `SUPERMARKET`, `PLAYGROUND`, `PHARMACY`, `MUSEUM`, `COFFEE`, `RESTAURANT`

`preferred_operators` · `boolean` · [显示示例 URL](tip:https://api.chargetrip.io/v2/station?preferred_operators=true)
: 筛选，仅包含由配置为首选的运营商运营的充电站。可以在 Dashboard 的项目设置中设置首选运营商。
: `true`, `false`

`truck_dedicated` · `boolean` · [显示示例 URL](tip:https://api.chargetrip.io/v2/station?truck_dedicated=true)
: 筛选，仅包含专用于或主要用于货车充电的充电站。**仅在使用 Eco-Movement 充电站数据库时适用；否则将被忽略。**
: `true`, `false`

### EVSE 级别

评估充电站具体充电能力的筛选。这些筛选会执行排除和[转换](/api-reference/tiles/filters#数据转换示例)：不匹配的充电站被排除，匹配的充电站其动态字段会被重新计算。

`connectors` · `enum` · [显示示例 URL](tip:https://api.chargetrip.io/v2/station?connectors[]=CHADEMO)
: 筛选，仅包含具有指定连接器类型 EVSE 的充电站。接受包含任意 OCPI 2.2.1 连接器值的字符串数组。
: `CHADEMO`, `DOMESTIC_A`, `DOMESTIC_B`, `DOMESTIC_C`, `DOMESTIC_D`, `DOMESTIC_E`, `DOMESTIC_F`, `DOMESTIC_G`, `DOMESTIC_H`, `DOMESTIC_I`, `DOMESTIC_J`, `DOMESTIC_K`,
`DOMESTIC_L`, `DOMESTIC_M`, `DOMESTIC_N`, `DOMESTIC_O`, `IEC_60309_2_single_16`, `IEC_60309_2_three_16`, `IEC_60309_2_three_32`, `IEC_60309_2_three_64`, `IEC_62196_T1`,
`IEC_62196_T1_COMBO`, `IEC_62196_T2`, `IEC_62196_T2_COMBO`, `IEC_62196_T3A`, `IEC_62196_T3C`, `PANTOGRAPH_BOTTOM_UP`, `PANTOGRAPH_TOP_DOWN`, `TESLA_R`, `TESLA_S`, `GB_T`,
`CHAOJI`, `NEMA_5_20`, `NEMA_6_30`, `NEMA_6_50`, `NEMA_10_30`, `NEMA_10_50`, `NEMA_14_30`, `NEMA_14_50`

### 数据转换示例

应用 EVSE 级别筛选时，某些输出会被重新计算。这些字段会被“转换”，以忽略与用户搜索条件不匹配的连接器。
这些“动态”输出字段是 `connector_maximum_power` 和 `evse_status_*`。

<details>
  <summary>相同的筛选类型，不同的值</summary>
  请求包含 CHADEMO 连接器筛选。该充电站因为具有 CHADEMO 连接器而被包含，但其动态字段会被转换，以忽略 Combo Type 1 充电桩。

```bash Example URL
https://api.chargetrip.io/v2/station?connectors[]=IEC_62196_T1_COMBO&connectors[]=CHADEMO
```

```json Response
{
  "id": "station_a",
  // Static: Remains 150 kW (This represents the station maximum power across all connectors)
  "station_maximum_power": 150,
  // Dynamic: Adjusted to 100 kW (Max power of the CHADEMO connector)
  "connector_maximum_power": 100,
  // Dynamic: Counts the 1 CHADEMO chargers
  "evse_status_out_of_order": 0,
  // Dynamic: 0, because the charging Type 1 plugs are filtered out
  "evse_status_available": 1
}
```
</details>
