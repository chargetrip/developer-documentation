使用 navigation 查询获取进行中的导航会话。当您想显示驾驶员沿路线的当前进度时，此操作非常有用。

## 查询

获取导航会话的详细信息需要其 `id`。`id` 可通过 [startNavigation 变更](/api-reference/navigation/mutation-start-navigation)获取。
