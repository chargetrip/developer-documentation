使用 updateNavigation 变更更新进行中的导航会话。当您想在驾驶员沿路线行进时上报其位置时，此操作非常有用。

## 变更

更新导航会话需要其 `id` 和 `location_data`。`id` 可通过 [startNavigation 变更](/api-reference/navigation/mutation-start-navigation)获取。
