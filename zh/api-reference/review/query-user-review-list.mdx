使用 userReviewList 查询获取已认证用户在各充电站添加的所有评价。当您想显示用户自己的评价历史时，此操作非常有用。这是一项高级功能。请联系我们了解更多信息。

## 查询

需要 `x-token` 请求头来授权要获取其评价的用户。使用 `size` 和 `page` 参数对结果进行[分页](/api-reference/api/pagination)。
