每个充电站都可以附带用户评价。您可以查询评分和留言等属性，也可以获取有关充电时所用 EV 的数据。评价仅限于单个充电站数据库，不能跨不同项目使用。

## 查询

获取充电站的评价需要充电站的 `id`。`id` 可通过[路线](/api-reference/route/query-get-route)、[瓦片服务](/api-reference/tiles/mvt)或[周边充电站查询](/api-reference/station/query-station-around)获取。使用 `size` 和 `page` 参数对结果进行[分页](/api-reference/api/pagination)。
