使用 isoline subscription 订阅等值线。当您想在等值线计算过程中接收实时更新时，这会很有用。

## Subscription

订阅等值线的更新需要提供其 `id`。`id` 可以通过 [createIsoline mutation](/api-reference/core/isoline/mutation-create-isoline) 获取。
