等值线，也称为续航蜘蛛图，显示电动汽车凭借车上现有电量从给定地点出发可以到达的区域。选择一辆车和一个出发地，API 就会计算出标记行驶距离极限的等值线，以可放置在地图上的形状呈现。该计算以真实道路网络为参照：它找出车辆经由道路可到达的最远点，轮廓线将这些点连接起来。结果是一个填充区域，而不是沿着道路的线条，因此道路之间的区域，例如森林或田野，也可能落在其中。

## 根据您的目标优化等值线

同一个请求可以根据您优化的目标产生不同的等值线。以下是最常见的目标，以及影响每个目标的选项。

续航地图
: 以地图上的区域形式展示车辆从某一地点出发（例如围绕一座城市）可以行驶多远。您可以选择获得多少个多边形，最多 20 个，从展示车辆续航范围的简单图像到用于渐变效果的更精细分级。使用 `quality` 在精度和速度之间权衡，并使用 `ferry_connections` 纳入渡轮，这会增加计算时间和多边形数量。请参阅[可视化车辆续航范围](/docs/getting-started/vehicle-range)。

可达性检查
: 针对特定车辆回答“不充电我能到那里吗？”这一问题，有助于缓解里程焦虑。使用 `state_of_charge` 从实际电量开始，使用 `final_state_of_charge` 保留储备电量，或使用 `round_trip` 仅包含车辆同样可以返回出发地的点。

可达充电站
: 将充电站筛选为车辆从当前位置实际可以到达的那些。将其与 `final_state_of_charge` 结合使用，这样只有当车辆到达时仍有剩余电量，充电站才会被计入。

真实条件
: 考虑会改变能耗的因素：天气或季节、车辆所载重量，以及空调的制热和制冷。在没有电量的情况下，等值线使用车辆的全部可用电池容量，天气默认使用实时数据。
