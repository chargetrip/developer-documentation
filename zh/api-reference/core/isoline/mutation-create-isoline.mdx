使用 createIsoline mutation 创建基于能耗的等值线。当您想可视化车辆从给定地点出发可到达的区域，例如作为续航地图时，这会很有用。[车辆续航范围指南](/docs/getting-started/vehicle-range)展示了如何将结果转换为可放置在地图上的形状。

## Mutation

创建等值线需要提供 `vehicle_id` 和 `origin`。还可以选择性地添加 `state_of_charge`、`polygon_count` 或其他偏好设置来优化计算。该 mutation 返回等值线 `id`，可用于获取等值线详情或订阅更新。
