通过 vehiclePremium 查询获取更为详细的数据。它包含有关电池、车身、可用性、价格、能效、安全性等方面的扩展数据。[联系销售](https://www.chargetrip.com/contact/sales)以升级到高级车辆数据。

## 查询

获取高级车辆详情需要提供车辆 `id`。该 `id` 可以通过 [vehicleList 查询](/api-reference/core/vehicle/query-vehicles)获得。使用 country 参数对数据进行本地化。
