为电动车规划路线与为燃油车规划路线不同。车辆能行驶多远、可以使用哪些充电桩以及充电速度有多快，都取决于车辆本身。车辆数据库为您提供这些信息，让您无需自行收集和维护。

每个路线和等值线请求都需要车辆 `id`，同样的数据还可以让您构建车辆选择器、展示规格，并将充电站筛选为驾驶员可以使用的充电站。

## 电动车基础知识

电动车的几个特性说明了车辆数据为何重要。

### 动力系统

ICE（内燃机）车辆燃烧燃料。电动车则依靠电池中的电力运行，电池在充电站充电。数据库涵盖四种动力系统类型：

| 动力系统 | 说明 |
|:---|:---|
| BEV | 纯电动车。仅依靠电池运行。 |
| PHEV | 插电式混合动力电动车。结合了可外接充电的电池和内燃机。 |
| EREV | 增程式电动车。由电池驱动，并配有可延长续航里程的内燃机。 |
| HEV | 混合动力电动车。结合了内燃机和无法外接充电的电池。 |

### 充电

电动车使用多种插头类型之一进行充电，因此只有当车辆支持充电桩的连接器时，该充电桩才有用。充电速度分为三个级别。1 级和 2 级使用交流电，需要数小时。3 级也称为快速充电，使用直流电，可以在一小时内为车辆充满电。车辆的实际充电速度取决于其充电曲线，路线规划服务会将其考虑在内。

### 影响续航里程的因素

电池性能会随天气、空调的使用以及车辆的规格而变化，就像手机电池在寒冷天气中耗电更快一样。这就是为什么单一的续航里程数字不足以规划行程。续航里程取决于各种条件，路线规划服务会考虑这些条件，以预测车辆在两点之间消耗多少能量。正是这一预测让应用能够沿途[推荐充电停靠点](/docs/getting-started/route)，并通过[等值线](/api-reference/core/isoline/mutation-create-isoline)展示车辆可到达的区域。它解决了里程焦虑，即担心在到达目的地或充电桩之前电量耗尽。
