使用 vehicleModels 查询获取唯一车型列表。此查询与 vehicleMakes [查询](/api-reference/core/vehicle/query-vehicle-makes)结合使用，可构建逐级车辆选择。

## 查询
获取车型需要提供车辆品牌 `id`。该 id 可以通过 vehicleMakes [查询](/api-reference/core/vehicle/query-vehicle-makes)获得。使用 `first` 和 `after` 参数对结果进行[分页](/api-reference/core/api/pagination)，使用 `filters` 缩小搜索结果范围，并使用 `country` 参数对数据进行本地化。
