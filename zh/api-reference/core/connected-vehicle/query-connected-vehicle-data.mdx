使用 connectedVehicleData 查询获取实时车辆数据。当您想直接从联网车辆获取实时数据（例如其电量状态或位置）时，这会很有用。

## 查询

获取联网车辆的实时数据需要提供其 `id`。`id` 可以通过 [createConnectedVehicle mutation](/api-reference/core/connected-vehicle/mutation-create-connected-vehicle) 获取。
