电动汽车导航应用需要实时车辆数据（例如电量状态）来规划路线。如今道路上几乎所有电动汽车都配有调制解调器，可以将这些数据发送给外部应用，但不同厂商的标准和数据开放方式各不相同。

车辆连接通过单一数据源将这些数据带入您的应用。抽象层会摄取、清理来自众多厂商的数据，并为路线引擎做好准备，同时提供可定制品牌的落地页，让您的用户进行身份验证并授予同意。它可与您当前的联网车辆数据供应商、遥测 API 或 OBD-II 加密狗配合使用，并已预先集成 [Enode](https://enode.io)。

如需获取访问权限，或使用其他数据提供商或您自己的 API，请联系 [sales@chargetrip.com](mailto:sales@chargetrip.com)。

## 支持的数据源

联网车辆数据平台
: 连接到车辆制造商 API 并将这些数据开放给第三方的云解决方案。它们负责处理车主同意并标准化数据格式。不同平台支持的品牌和定价差异很大。这适合应用开发者，例如充电桩运营商 (CPO) 或电动出行服务提供商 (eMSP)。支持的平台包括 [Enode](https://enode.io)、[High Mobility](https://high-mobility.com)、[Smartcar](https://smartcar.com) 和 [WirelessCar](https://wirelesscar.com)。

硬件加密狗
: 需要手动安装在车辆中的蓝牙加密狗。它们的前期成本相对较高，但持续成本较低，因此深受物流车队运营商欢迎。全球范围内均支持 [Geotab Go9](https://support.geotab.com/go-devices/go9/doc/go9-document)。

您自己的 API 或特定品牌的 API
: 车辆制造商可能会通过车辆调制解调器广播车辆数据，并通过 API 开放这些数据。如果您只想支持特定的车辆品牌，这也同样适用。[可应要求提供](mailto:sales@chargetrip.com)。

其他遥测数据提供商
: 通过自定义数据集成流程添加。[可应要求提供](mailto:sales@chargetrip.com)。
