使用 connectedVehicleList 查询获取当前用户的联网车辆列表。当您想显示用户已连接到提供商的所有车辆时，此操作非常有用。

## 查询

执行此查询无需任何输入。使用 `filter` 按状态缩小结果范围，并使用 `size` 和 `page` 参数对结果进行[分页](/api-reference/core/api/pagination)。
