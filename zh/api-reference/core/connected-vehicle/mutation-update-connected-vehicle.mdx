使用 updateConnectedVehicle mutation 更新联网车辆。当您想更改联网车辆的标签时，这会很有用。

## Mutation

更新联网车辆需要提供 `id`。使用 `label` 设置新标签。`id` 可以通过 [createConnectedVehicle mutation](/api-reference/core/connected-vehicle/mutation-create-connected-vehicle) 获取。
