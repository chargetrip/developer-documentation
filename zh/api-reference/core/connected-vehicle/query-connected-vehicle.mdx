使用 connectedVehicle 查询获取联网车辆的详细信息。当您想检查联网车辆的授权状态时，这会很有用。

## 查询

获取联网车辆的详细信息需要提供其 `id`。`id` 可以通过 [createConnectedVehicle mutation](/api-reference/core/connected-vehicle/mutation-create-connected-vehicle) 或 [connectedVehicleList 查询](/api-reference/core/connected-vehicle/query-connected-vehicle-list)获取。
