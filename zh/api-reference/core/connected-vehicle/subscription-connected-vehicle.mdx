使用 connectedVehicle subscription 订阅联网车辆。当您想接收其授权状态的实时更新时，这会很有用。

## Subscription

订阅联网车辆的更新需要提供其 `id`。`id` 可以通过 [createConnectedVehicle mutation](/api-reference/core/connected-vehicle/mutation-create-connected-vehicle) 获取。
