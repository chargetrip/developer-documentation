使用 authorizeConnectedVehicle mutation 完成联网车辆的授权。在最终用户通过连接提供商授予访问权限之后，这会很有用。

## Mutation

授权联网车辆需要提供 `id` 和特定于提供商的 `options`。`id` 可以通过 [createConnectedVehicle mutation](/api-reference/core/connected-vehicle/mutation-create-connected-vehicle) 获取。
