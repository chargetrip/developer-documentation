使用 getRouteEmissions 查询获取路线的排放概况。当您想展示行程对环境的影响时，这会很有用。

## 查询

获取路线的排放需要提供 `route_id` 和 `route_details_id`。两者都可以通过 [getRoute 查询](/api-reference/core/route/query-get-route)获取。
