路线排放提供车辆在行程中产生的温室气体 (GHG) 排放的详细明细，涵盖隐含排放、运行排放和报废排放三个范围。可以获取任何使用 Chargetrip API 计算的路线的排放数据。排放以克二氧化碳当量 (gCO₂eq) 表示。组件级数据可让您构建自己的排放汇总。

有关该方法的更详细说明，请参阅[这篇博客文章](https://www.chargetrip.com/newsroom/abstract-a-generalized-method-for-estimating-comprehensive-emissions-for-electric-vehicles-on-a-per-trip-basis)。如需更多详情，请[申请白皮书](https://www.chargetrip.com/newsroom/abstract-a-generalized-method-for-estimating-comprehensive-emissions-for-electric-vehicles-on-a-per-trip-basis#download-paper)。

## 范围

隐含排放
: 车辆制造过程中产生的排放份额。包括材料获取、零部件运输和生产、车辆和电池的组装，以及车辆的初始分销。

运行排放
: 沿路线驾驶车辆所产生的直接和间接排放。主要部分是燃料或电力的生产、分配和消耗。其他部分包括车辆维护和道路基础设施。该估算考虑了能源电网的预计需求，以及当地的气候和季节。

报废排放
: 针对给定路线，车辆报废时将产生的排放份额。包括车辆主要部件和车身的处置。
