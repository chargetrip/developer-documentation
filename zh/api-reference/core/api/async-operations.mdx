---
title: 异步操作
description: "了解 API 中异步操作的工作方式：通过 mutation 创建，然后使用 subscription 或查询跟踪并获取结果。"
---

某些操作，例如创建路线或匹配路线，以异步方式运行，以保持 API 的响应能力。您无需等待 mutation 返回完整结果，而是会立即获得一个 `id`，随后跟进以跟踪并获取结果。

## 工作方式

1. **创建**
   调用 mutation。它会立即返回一个 `id`，您将在下一步中使用它来跟踪并获取结果。
2. **打开 subscription**
   使用上一步中的 `id` 进行订阅。在结果计算期间，subscription 会推送状态更新，您可以用它来驱动 UI 中的异步加载状态。
3. **渲染结果**
   一旦 `status` 变为最终值，就渲染与该结果对应的 UI。
4. **重新获取已完成的结果**
   结果一旦达到最终状态，就已预先计算完成。如果之后需要再次获取，例如在导航返回时，请使用对应的查询，而不是打开新的 subscription。
