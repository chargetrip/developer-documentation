Chargetrip 通过结构化的实验计划推出重要的新功能。它让您能够在 schema 和契约成为永久性之前，抢先体验并评估即将推出的功能，并影响其设计。

> [!WARNING] 不适用 12 个月弃用政策
> 处于 alpha 和 beta 阶段的功能不适用 [12 个月弃用政策](/api-reference/core/api/lifecycle#弃用时间线)，可能会更早发生变更或被停用。

## 实验性功能的类型

- 新操作：全新的查询、mutation 或 subscription。
- 对现有操作的扩展：添加到现有稳定操作中的新可选参数或输出字段。

## 实验性功能的阶段

| 维度 | Alpha | Beta |
 | ----- | ----- | ----- |
| **生产就绪度** | 严格不建议用于生产环境。 | 适用于受控的试点。不建议用于关键业务流程。 |
| **激活方式** | 默认禁用。需要在仪表板中明确选择启用。 | 默认对所有客户端启用。 |
| **稳定性** | 稳定，但 schema 可能频繁变更。| 稳定。可能有小幅 schema 变更。 |
| **Schema 标识** | 在 schema 字段描述中标记为 `[ALPHA]`。 | 在 schema 字段描述中标记为 `[BETA]`。 |
| **停用通知** | 无。可能随时被修改或停用。 | 主动直接联系正在集成的客户。 |

有关稳定功能提供的保证，请参阅 [API 生命周期](/api-reference/core/api/lifecycle)。


## 最佳实践

 - 将 alpha 功能用于沙盒评估、概念验证和反馈。如果您仍然将其发布上线，那么当它发生变化时，您将不会收到任何通知，也没有兼容性保护。
 - 如果您向最终用户开放 beta 功能，请显示“beta”标记，让他们知道该功能仍在趋于稳定。


## 升级生命周期

1. **从 Alpha 到 Beta** 当功能和 schema 达到足够成熟度时，该功能将升级为 beta。描述标记从 `[ALPHA]` 更新为 `[BETA]`，所有客户默认启用访问，并在发布说明中公布变更。

2. **从 Beta 到稳定** 当可靠性和成熟度在多个客户端得到验证后，将移除 `[BETA]` 描述标记和运行时警告，该功能升级到[稳定生命周期](/api-reference/core/api/lifecycle)。


## 定价
- 对标记为实验性的操作发出的请求**免费**。
- 对包含可选实验性输入参数或输出字段的稳定端点发出的请求，将根据您的订阅套餐**收费**。

## 程序化警告
为了让您的开发团队了解活跃流量中的实验性依赖，使用 alpha 或 beta 功能的 API 响应会在 GraphQL `extensions` 块中返回警告元数据：

<details>
  <summary>alpha 功能的警告示例</summary>

```json Example request and response
{
  "data": {
    "getTruckRoute": {
      "id": "dd07b4d0-6b79-11f0-bf8f-e6b813282ac3",
      "status": "done"
    }
  },
  "extensions": {
    "warnings": [
      {
        "code": "ALPHA_FEATURE",
        "path": ["getTruckRoute"],
        "message": "This feature is currently in ALPHA. Visit https://developers.chargetrip.com/api-reference for more information."
      }
    ]
  }
}
```
</details>
