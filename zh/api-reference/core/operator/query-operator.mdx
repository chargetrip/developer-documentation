使用 operator 查询获取充电桩运营商的详细信息。当您想在显示充电站或充电会话的同时展示运营商信息时，此操作非常有用。

## 查询

获取运营商详情需要运营商的 `id`。`id` 可通过 [operatorList 查询](/api-reference/core/operator/query-operator-list)获取。
