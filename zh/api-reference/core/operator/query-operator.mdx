使用 operator 查询获取充电桩运营商的详细信息。当您想在充电站或充电会话旁显示运营商信息时，这会很有用。

## 查询

获取运营商详情需要提供运营商 `id`。`id` 可以通过 [operatorList 查询](/api-reference/core/operator/query-operator-list)获取。
