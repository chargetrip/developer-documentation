使用 route subscription 订阅路线。当您想在路线计算过程中接收实时更新时，这会很有用。

## Subscription

订阅路线的更新需要提供其 `id`。`id` 可以通过 [createRoute mutation](/api-reference/core/route/mutation-create-route) 获取。
