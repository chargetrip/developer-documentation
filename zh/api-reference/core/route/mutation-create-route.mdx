使用 createRoute mutation 创建新路线。当您想计算出发地与目的地之间的充电停靠点、能耗和行驶时间时，这会很有用。如果您刚接触路线规划，[路线指南](/docs/getting-started/route)将带您从第一个请求一直到自定义路线。在此基础上，您可以通过运营商偏好[引导路线优先选择哪些充电网络](/docs/getting-started/route-operators)，或使用途经停靠点[围绕您自己的途经点来规划行程](/docs/getting-started/route-stop)。

## Mutation

创建路线需要提供 `vehicle`、`origin` 和 `destination`。还可以选择性地添加 `via` 点、`operators`、`weather` 或其他偏好设置来优化计算。该 mutation 返回路线 `id`，可用于获取路线详情、排放或沿途的便利设施。
