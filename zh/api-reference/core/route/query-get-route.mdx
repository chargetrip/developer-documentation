使用 getRoute 查询获取先前计算的路线的详细信息。当您想显示路线的充电停靠点、距离和时长时，这会很有用。

## 查询

获取路线详情需要提供路线 `id`。`id` 可以通过 [createRoute mutation](/api-reference/core/route/mutation-create-route) 获取。
