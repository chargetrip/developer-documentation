为电动汽车规划路线面临独特的挑战。电池容量、真实能耗、地形、天气和充电网络可用性等因素，共同决定车辆能否到达目的地。

路线服务会综合考虑所有这些变量，以找到最优的电动汽车路线。借助世界一流的能耗模型，它会在需要的时间和地点自动放置充电停靠点。路线还可以完全自定义，因此您可以根据对您重要的业务规则、网络和驾驶员偏好进行调整。

> [!WARNING] 混合动力车辆
> 混合动力和插电式混合动力车辆并不完全依赖电池，因此其路线不包含充电停靠点。

## 根据您的目标优化路线

同一个请求可以根据您优化的目标产生不同的路线。以下是最常见的目标，以及深入介绍每个目标的指南。

最快到达
: 使用 `speed_factor`、`maximum_speed` 或 `style`（`eco` 或 `sport`）调整驾驶风格。添加实时交通和出发时间以获得准确的到达时间，并优先选择直接位于高速公路上的充电站以避免绕行。请参阅[创建路线](/docs/getting-started/route)。

您自己的网络或驾驶员的充电卡
: 引导驾驶员使用您希望他们使用的网络。优先选择或要求特定运营商，将其排名为 `high`、`medium` 或 `low`，按国家/地区设置排名，或完全排除和避开某些运营商。在仪表板中为您的项目设置默认值，并在每个请求中覆盖它们。请参阅[运营商优先路由](/docs/getting-started/route-operators)。

在便利设施附近充电
: 查找路线沿途步行即可到达餐厅、咖啡店或商店的充电站，让驾驶员可以围绕自己想做的事情规划充电停靠。请参阅[路线沿途的便利设施停靠点](/docs/getting-started/route-amenity-stops)。

您自己的行程
: 添加途经点，可以是送货或取货等普通位置停靠点，也可以是特定充电站的充电停靠点。设置车辆在每个停靠点的停留时间，以及从该处起所载的负载。请参阅[带停靠点的路线](/docs/getting-started/route-stop)。
