使用 getRouteStationsWithAmenities 查询搜索路线沿途某一点附近带有便利设施的充电站。当您想在餐厅、商店或其他便利设施附近规划充电停靠时，这会很有用。

## 查询

沿路线搜索充电站需要提供 `route_id`、`route_details_id`、`time_window` 和 `amenity_types`。两个 ID 都可以通过 [getRoute 查询](/api-reference/core/route/query-get-route)获取。使用 `filter` 参数根据特定条件缩小结果范围，并使用 `first` 和 `after` 参数对结果进行[分页](/api-reference/core/api/pagination)。

> [!WARNING] 限制
> 此查询的 `first` 不能超过 10。
