使用 matchedRoute subscription 订阅匹配路线。当您想在匹配路线计算过程中接收实时更新时，这会很有用。

## Subscription

订阅匹配路线的更新需要提供其 `id`。`id` 可以通过 [createMatchedRoute mutation](/api-reference/core/matched-route/mutation-create-matched-route) 获取。
