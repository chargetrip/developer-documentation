使用 getMatchedRoute 查询获取先前计算的匹配路线的详细信息。当您想重新获取匹配路线而不打开新的 subscription 时，这会很有用。

## 查询

获取路线详情需要提供匹配路线 `id`。`id` 可以通过 [createMatchedRoute mutation](/api-reference/core/matched-route/mutation-create-matched-route) 获取。
