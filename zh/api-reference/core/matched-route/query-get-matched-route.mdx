使用 getMatchedRoute 查询获取先前计算的匹配路线的详细信息。当您想重新获取匹配路线而无需开启新的订阅时，此操作非常有用。

## 查询

获取路线详情需要匹配路线的 `id`。`id` 可通过 [createMatchedRoute 变更](/api-reference/core/matched-route/mutation-create-matched-route)获取。
