使用 tariff 查询获取费率详情。当您使用 Ecomovement 以外的充电站数据库，并希望展示在充电站充电的费用时，此查询非常有用。要了解如何呈现价格，请参阅[充电站定价指南](/docs/getting-started/station-pricing)。

## 查询

获取费率详情需要提供费率 `id`。该 `id` 可以通过 [tariffList 查询](/api-reference/core/tariff/query-tariff-list)获得。
