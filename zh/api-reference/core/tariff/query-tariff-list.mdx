使用 tariffList 查询获取完整的费率列表。当您希望展示或比较不同充电站的充电费用时，此查询非常有用。要了解如何呈现价格，请参阅[充电站定价指南](/docs/getting-started/station-pricing)。

## 查询

执行此查询无需任何输入。使用 `size` 和 `page` 参数对结果进行[分页](/api-reference/core/api/pagination)。
