充电站计数端点返回充电站的总数。

## 设置
要获取充电站数量，请向以下 URL 发送 `GET` 请求：

```bash Count / Base URL
https://api.chargetrip.io/v2/station/count
```

### 筛选
使用 `filter` 查询参数，根据特定条件缩小计数范围。更多信息请参见[筛选文档](/api-reference/core/tiles/filters)。


## 响应

端点返回一个 JSON 对象，其中包含匹配充电站的总数：

`count` · `integer`
: 与请求筛选条件匹配的充电站总数（如果未提供筛选条件，则为所有可用充电站）。
