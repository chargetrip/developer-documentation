MVT（Mapbox Vector Tile）服务以基于瓦片的格式提供与充电站相关的地理数据。矢量瓦片以 Protocol Buffers（PBF）编码，可实现结构化数据的高效序列化。

## 设置

要以 MVT 格式获取充电站数据，请向以下端点发送请求：

```bash Tile / MVT / Base URL
https://api.chargetrip.io/v2/station/{z}/{x}/{y}/tile.mvt
```

MVT URL 使用以下路径参数：

- `z`：瓦片的缩放级别。
- `x`：瓦片的 x 坐标。
- `y`：瓦片的 y 坐标。

大多数地图提供商都内置了将纬度和经度转换为像素坐标的方法。若要手动将纬度和经度坐标转换为 x 和 y，请使用 [Web 墨卡托投影](https://en.wikipedia.org/wiki/Web_Mercator_projection)。

### 筛选
使用 `filter` 查询参数，根据特定条件筛选返回的充电站。更多信息请参见[筛选文档](/api-reference/core/tiles/filters)。

### 选择器
使用 `station_properties[]` 查询参数指定为每个充电站要素返回的字段。更多信息请参见[选择器文档](/api-reference/core/tiles/selectors)。

### 货币
使用 `currency` 查询参数设置返回及筛选所用能源价格的货币。更多信息请参阅[货币转换文档](/api-reference/core/tiles/filters)。
