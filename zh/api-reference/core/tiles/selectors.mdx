为了优化网络延迟和渲染性能，Chargetrip 的 MVT 和 JSON 瓦片服务默认返回最小化的载荷。该默认载荷提供快速渲染地图瓦片所需的基本几何和聚合数据。

通过使用选择器，您可以只请求客户端应用所需的特定充电站数据属性，而不会产生不必要的载荷开销。



## 实现

要请求特定的充电站属性，请在瓦片请求 URL 中附加 `station_properties[]` 查询参数。对每个要包含的选择器重复该参数：

```bash Tile / Selectors / Example
https://api.chargetrip.io/v2/station/...?station_properties[]={selector1}&station_properties[]={selector2}&station_properties[]={selector3}
```

## 可用的选择器
选择器仅适用于**充电站要素**，聚合要素不受影响，并且始终返回 `count` 和 `expansion_zoom`。


`count` · `integer` · <span class="text-accent">default</span>
: 聚合点内的充电站数量。数量为 1 表示充电站要素，数量大于 1 则表示聚合要素。

`id` · `string` · <span class="text-accent">default</span>
: 充电站的 Chargetrip 唯一标识符。仅适用于 [MVT 瓦片](/api-reference/core/tiles/mvt)。

`lng` · `float`
: 充电站的经度。仅适用于 [MVT 瓦片](/api-reference/core/tiles/mvt)。

`lat` · `float`
: 充电站的纬度。仅适用于 [MVT 瓦片](/api-reference/core/tiles/mvt)。

`operator_id` · `string`
: 充电站运营商的唯一 Chargetrip 标识符。如果运营商未知，则不会返回。

`station_maximum_power` · `integer`
: 充电站可提供的最大充电功率（单位 kW）。此值是静态的，始终反映充电站的最高能力，不受连接器筛选影响。

`connector_maximum_power` · `integer`
: 与 `connectors[]` 筛选匹配的连接器可提供的最大充电功率（单位 kW）。如果未提供筛选，则考虑所有连接器，此时该值与 `station_maximum_power` 一致。

`preferred_operator` · `boolean`
: 表示充电站的运营商是否为首选运营商。可以在 [Chargetrip 的 Dashboard](https://account.chargetrip.io/projects) 中管理运营商偏好。

`connector_minimum_energy_price` · `float` · [beta](tip:Beta;;此字段处于 Beta 阶段，在稳定之前可能会发生变化。)
: 充电站连接器中最低的能源价格。如果不可用则不返回。

`connector_maximum_energy_price` · `float` · [beta](tip:Beta;;此字段处于 Beta 阶段，在稳定之前可能会发生变化。)
: 充电站连接器中最高的能源价格。如果不可用则不返回。

`price_vat` · `float` · [beta](tip:Beta;;此字段处于 Beta 阶段，在稳定之前可能会发生变化。)
: 价格所适用的增值税。如果不可用则不返回。

`price_valid_until` · `string` · [beta](tip:Beta;;此字段处于 Beta 阶段，在稳定之前可能会发生变化。)
: 价格的有效截止日期和时间。如果不可用则不返回。

`price_original_currency` · `string` · [beta](tip:Beta;;此字段处于 Beta 阶段，在稳定之前可能会发生变化。)
: 价格最初定义时使用的货币，即转换为 `currency` 之前的货币。如果不可用则不返回。

`price_conversion_rate` · `float` · [beta](tip:Beta;;此字段处于 Beta 阶段，在稳定之前可能会发生变化。)
: 将价格从其原始货币转换为 `currency` 所使用的汇率。如果不可用则不返回。

`evses_blocked` · `integer`
: 被物理或电子方式阻断的 EVSE 数量。 如果提供了 `connectors[]` 筛选，则只统计至少具有一种所选连接器类型的已阻断的 EVSE。

`evses_planned` · `integer`
: 处于 planned 状态的 EVSE 数量。 如果提供了 `connectors[]` 筛选，则只统计至少具有一种所选连接器类型的planned EVSE。

`evses_available` · `integer`
: 处于 available 状态的 EVSE 数量。 如果提供了 `connectors[]` 筛选，则只统计至少具有一种所选连接器类型的available EVSE。

`evses_charging` · `integer`
: 当前被占用的 EVSE 数量。 如果提供了 `connectors[]` 筛选，则只统计至少具有一种所选连接器类型的正在充电的 EVSE。

`evses_unknown` · `integer`
: 实时状态当前未知的 EVSE 数量。 如果提供了 `connectors[]` 筛选，则只统计至少具有一种所选连接器类型的状态未知的 EVSE。

`evses_reserved` · `integer`
: 已为驾驶员预留的 EVSE 数量。 如果提供了 `connectors[]` 筛选，则只统计至少具有一种所选连接器类型的已预留的 EVSE。

`evses_out_of_order` · `integer`
: 被标记为故障的 EVSE 数量。 如果提供了 `connectors[]` 筛选，则只统计至少具有一种所选连接器类型的故障的 EVSE。

`evses_inoperative` · `integer`
: 暂时无法运行的 EVSE 数量。 如果提供了 `connectors[]` 筛选，则只统计至少具有一种所选连接器类型的暂时无法运行的 EVSE。

## 示例

<details>
  <summary>在 JSON 瓦片中请求充电站功率和运营商偏好</summary>

在 JSON 瓦片中，充电站要素始终保留必需的要素结构（`type`、`geometry`、`id`），而 `properties` 仅包含请求的选择器（默认的 `count` 属性因未被请求而被省略）。聚合要素不受选择器影响，仍会返回 `count` 和 `expansion_zoom`。

```bash Example request {{ mark: [2,3] }}
https://api.chargetrip.io/v2/station/10/582/325/tile.json
  ?station_properties[]=station_maximum_power
  &station_properties[]=preferred_operator
```

```json Example response {{ mark: [13,14,15,16] }}
{
  "type": "FeatureCollection",
  "features": [
    // Station feature (count = 1)
    {
      "id": "5e5f3e8f8e0c1a0012345678",
      "type": "Feature",
      "geometry": {
        "type": "Point",
        "coordinates": [4.895168, 52.370216]
      },
      "properties": {
        "station_maximum_power": 350,
        "preferred_operator": true
      }
    },
   // Cluster feature (unaffected by selectors)
    {
      "type": "Feature",
      "geometry": {
        "type": "Point",
        "coordinates": [5.1214, 52.0907]
      },
      "properties": {
        "count": 4,
        "expansion_zoom": 14
      }
    }
  ]
}
```

</details>

<details>
  <summary>在 MVT 矢量瓦片中请求充电站 ID、功率和运营商偏好</summary>

 在 MVT 瓦片中，只有明确请求的选择器才会被编码到充电站要素中（省略默认的 `count` 属性），而聚合要素不受选择器影响，始终保留 `count` 和 `expansion_zoom`。

```bash Example request {{ mark: [2,3,4] }}
https://api.chargetrip.io/v2/station/10/582/325/tile.mvt
  ?station_properties[]=id
  &station_properties[]=station_maximum_power
  &station_properties[]=preferred_operator
```

```json Example response {{ mark: [2,3,4,5,6] }}
// Station feature ('count' is omitted because it wasn't requested as a selector)
{
  "id": "5e5f3e8f8e0c1a0012345678",
  "preferred_operator": true,
  "station_maximum_power": 350
}

// Cluster feature (unaffected by selectors)
{
  "count": 4,
  "expansion_zoom": 14
}
```

</details>

<details>
  <summary>将选择器与连接器筛选结合，获取实时 EVSE 状态</summary>

  按特定连接器类型（例如 CCS / `IEC_62196_T2_COMBO`）筛选时，`connector_maximum_power` 和 `evses_available` 的数量仅反映与该连接器筛选匹配的 EVSE。

```bash Example request {{ mark: [2,3,4] }}
https://api.chargetrip.io/v2/station/10/582/325/tile.json
  ?connectors[]=IEC_62196_T2_COMBO
  &station_properties[]=connector_maximum_power
  &station_properties[]=evses_available
```

```json Example response {{ mark: [12,13,14,15] }}
{
  "type": "FeatureCollection",
  "features": [
    {
      "id": "5e5f3e8f8e0c1a0012345678",
      "type": "Feature",
      "geometry": {
        "type": "Point",
        "coordinates": [4.895168, 52.370216]
      },
      "properties": {
        "connector_maximum_power": 300,
        "evses_available": 2
      }
    }
  ]
}
```
</details>
