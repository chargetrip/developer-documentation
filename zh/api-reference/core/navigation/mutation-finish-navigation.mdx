使用 finishNavigation 变更结束进行中的导航会话。当驾驶员到达目的地或行程被取消时，此操作非常有用。

## 变更

完成导航会话需要其 `id` 和 `current_location`。`id` 可通过 [startNavigation 变更](/api-reference/core/navigation/mutation-start-navigation)获取。
