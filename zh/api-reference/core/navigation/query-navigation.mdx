使用 navigation 查询获取进行中的导航会话。当您想显示驾驶员沿路线的当前进度时，这会很有用。

## 查询

获取导航会话的详细信息需要提供其 `id`。`id` 可以通过 [startNavigation mutation](/api-reference/core/navigation/mutation-start-navigation) 获取。
