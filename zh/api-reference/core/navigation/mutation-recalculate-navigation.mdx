使用 recalculateNavigation mutation 重新计算进行中的导航会话的路线。当驾驶员偏离原始路线或沿途情况发生变化时，这会很有用。

## Mutation

重新计算导航会话的路线需要提供其 `id` 和 `current_location`。还可以选择性地包含 `state_of_charge`、`via` 或 `telemetry` 来优化新路线。`id` 可以通过 [startNavigation mutation](/api-reference/core/navigation/mutation-start-navigation) 获取。
