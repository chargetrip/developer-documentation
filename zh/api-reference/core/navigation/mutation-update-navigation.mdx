使用 updateNavigation mutation 更新进行中的导航会话。当您想在驾驶员沿路线前进时上报其位置时，这会很有用。

## Mutation

更新导航会话需要提供其 `id` 和 `location_data`。`id` 可以通过 [startNavigation mutation](/api-reference/core/navigation/mutation-start-navigation) 获取。
