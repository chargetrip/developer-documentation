使用 advanceNavigationLeg 变更将进行中的导航会话推进到下一路线路段。当驾驶员完成某一路段（例如结束充电停靠）并继续前往下一路段时，此操作非常有用。

## 变更

推进到下一路段需要导航会话的 `id` 和 `current_location`。您还可以包含 `state_of_charge`，以指定车辆在当前位置的电量。`id` 可通过 [startNavigation 变更](/api-reference/core/navigation/mutation-start-navigation)获取。
