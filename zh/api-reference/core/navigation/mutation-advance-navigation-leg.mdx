使用 advanceNavigationLeg mutation 将进行中的导航会话推进到下一个路线路段。当驾驶员完成一个路段（例如完成一次充电停靠）并继续前往下一个路段时，这会很有用。

## Mutation

推进到下一个路段需要提供导航会话 `id` 和 `current_location`。还可以选择性地包含 `state_of_charge`，以指定车辆在当前位置的电量水平。`id` 可以通过 [startNavigation mutation](/api-reference/core/navigation/mutation-start-navigation) 获取。
