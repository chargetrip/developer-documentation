使用 startNavigation mutation 在现有路线之上开始新的导航会话。当驾驶员开始沿已计算的路线行驶时，这会很有用。

> [!WARNING] 会话时长
> 导航会话在 48 小时无活动后会自动结束。

## Mutation

开始导航会话需要提供 `route_id`、`route_details_id` 和 `current_location`。两个路线 ID 都可以通过 [getRoute 查询](/api-reference/core/route/query-get-route)获取。该 mutation 返回导航会话 `id`，可用于获取、更新或结束该会话。
