电动汽车的路线规划取决于了解它可以在哪里充电，因此必须先用充电站数据填充充电站数据库，才能规划任何路线。默认情况下，充电站 schema 符合最新的 [OCPI](https://evroaming.org/ocpi/) 标准。可以添加自定义属性，但通常会将其移至额外的查询中，而不是放在充电站查询本身。

## 支持的数据源

Eco-Movement 数据
: 在没有商业协议的情况下，Chargetrip 可以为您的账户预加载来自 [Eco-Movement](https://eco-movement.com) 的高级充电站数据。它覆盖整个欧洲超过 100,000 个充电站，包括实时可用性、定价和预测可用性（如有）。这样无需连接多个充电站数据库提供商即可获得欧洲覆盖。有关区域限制，请参阅 [eco-movement.com](https://eco-movement.com)。[联系销售](mailto:sales@chargetrip.com)了解定价。

自定义充电站数据
: 静态和动态充电站数据都可以导入 Chargetrip。这需要与提供商达成商业协议。[联系销售](mailto:sales@chargetrip.com)讨论各种可能性。
