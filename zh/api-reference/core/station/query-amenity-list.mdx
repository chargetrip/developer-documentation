使用 amenityList 查询获取特定充电站周边的可用设施列表。当您想在车辆充电期间显示附近的餐厅、商店或其他设施时，此操作非常有用。

## 查询

获取充电站的设施需要充电站的 `id`。`id` 可通过[路线](/api-reference/core/route/query-get-route)、[瓦片服务](/api-reference/core/tiles/mvt)或[周边充电站查询](/api-reference/core/station/query-station-around)获取。使用 `filter` 参数根据特定条件缩小结果范围，并使用 `size` 和 `page` 参数对结果进行[分页](/api-reference/core/api/pagination)。
