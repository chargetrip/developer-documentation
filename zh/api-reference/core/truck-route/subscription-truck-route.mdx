使用 truckRoute subscription 订阅货车路线。当您希望在电动货车路线计算过程中接收实时更新时，此 subscription 非常有用。

## Subscription

订阅货车路线更新需要提供货车路线 `id`。该 `id` 可以通过 [createTruckRoute mutation](/api-reference/core/truck-route/mutation-create-truck-route) 获得。
