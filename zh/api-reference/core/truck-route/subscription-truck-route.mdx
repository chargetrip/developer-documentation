使用 truckRoute 订阅来订阅货车路线。当您想在电动货车路线计算过程中实时接收更新时，此操作非常有用。

## 订阅

订阅货车路线的更新需要货车路线的 `id`。`id` 可通过 [createTruckRoute 变更](/api-reference/core/truck-route/mutation-create-truck-route)获取。
