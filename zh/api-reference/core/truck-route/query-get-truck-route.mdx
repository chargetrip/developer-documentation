使用 getTruckRoute 查询获取先前计算的货车路线的详细信息。当您想显示货车路线的充电停靠点、距离和时长时，此操作非常有用。

## 查询

获取路线详情需要货车路线的 `id`。`id` 可通过 [createTruckRoute 变更](/api-reference/core/truck-route/mutation-create-truck-route)获取。
