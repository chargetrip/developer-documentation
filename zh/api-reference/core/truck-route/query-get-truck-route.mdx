使用 getTruckRoute 查询获取先前计算的货车路线的详细信息。当您希望展示货车路线的充电停靠点、距离和时长时，此查询非常有用。

## 查询

获取路线详情需要提供货车路线 `id`。该 `id` 可以通过 [createTruckRoute mutation](/api-reference/core/truck-route/mutation-create-truck-route) 获得。
