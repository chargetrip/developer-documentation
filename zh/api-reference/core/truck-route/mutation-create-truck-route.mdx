使用 createTruckRoute mutation 创建新的货车路线。当您希望为电动货车计算起点与终点之间的充电停靠点、能耗和行驶时间时，此 mutation 非常有用。

## Mutation

创建货车路线需要提供 `vehicle`、`origin` 和 `destination`。还可以选择添加 `via` 点、`operators`、`weather` 或其他偏好设置来优化计算。该 mutation 会返回货车路线 `id`，可用于获取路线详情或订阅更新。
