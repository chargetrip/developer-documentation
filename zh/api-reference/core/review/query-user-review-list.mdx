使用 userReviewList 查询检索已验证用户在各个充电站添加的所有评价。当您想显示用户自己的评价历史时，这会很有用。这是一项高级功能。请联系我们了解更多信息。

## 查询

需要提供 `x-token` 请求头，以授权您想要检索其评价的用户。使用 `size` 和 `page` 参数对结果进行[分页](/api-reference/core/api/pagination)。
