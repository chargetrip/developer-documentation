使用 deleteUserReview mutation 删除已验证用户添加的评价。这是一项高级功能。请联系我们了解更多信息。

## Mutation

删除评价需要提供评价 `id`。必须提供 `x-token` 请求头以授权用户。该评价必须属于该用户，否则会发生错误。
