## 弃用政策

这些操作已被弃用。已弃用的操作将继续正常工作至少 12 个月。此期限过后，它将被移除，使用它的请求将返回 GraphQL 错误。有关时间安排，请参见[弃用](/deprecations)。

## 替代操作

新的集成应使用下面列出的替代操作。

| --- | --- |
| [`newRoute` 变更](/api-reference/legacy/route/mutation-new-route) | [`createRoute` 变更](/api-reference/light-vehicle/route/mutation-create-route) |
