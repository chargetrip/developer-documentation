使用旧版 tariffList 查询获取完整的费率列表。新的集成应改用 [stationPrices 查询](/api-reference/core/station-pricing/query-station-prices)。

## 查询

执行此查询无需任何输入。使用 `size` 和 `page` 参数对结果进行[分页](/api-reference/core/api/pagination)。
