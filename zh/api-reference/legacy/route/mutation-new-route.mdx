title: 旧版路线变更
heading: 创建路线
description: "使用旧版 newRoute 变更创建路线。在您迁移到 createRoute 变更期间，它仍然可用。"
schemaName: newRoute
schemaType: Mutation
---

使用旧版 newRoute 变更创建新路线。在您迁移到 [createRoute 变更](/api-reference/core/route/mutation-create-route)期间，该变更仍然可用；createRoute 变更采用重新组织的架构和按国家设置的运营商偏好，用于计算充电停靠点、能耗和行驶时间。
