schemaName: newRoute
schemaType: Mutation
---

使用旧版 newRoute mutation 创建新路线。在您迁移到 [createRoute mutation](/api-reference/core/route/mutation-create-route) 期间它仍然可用，后者采用重新组织的 schema 和按国家设置的运营商偏好，来计算充电停靠点、能耗和行驶时间。
