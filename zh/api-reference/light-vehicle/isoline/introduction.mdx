等值线，也称为续航蛛网图，显示 EV 以其车载能量从给定地点出发可到达的区域。选择车辆和起点后，API 会计算标出行驶距离极限的等值线，这些等值线以可放置在地图上的形状呈现。计算以真实的道路网络为参照：它会找出车辆通过道路可到达的最远点，轮廓则将这些点连接起来。结果是一个填充的区域，而不是沿着道路延伸的线，因此道路之间的区域（例如森林或田野）也可能落在其中。

## 针对您的目标优化等值线

同一个请求可以根据优化目标的不同生成不同的等值线。以下是最常见的目标，以及决定每个目标效果的选项。

续航地图
: 将车辆从某一点出发（例如围绕一座城市）能行驶多远，以地图上的区域形式显示出来。选择获得多少个多边形，最多 20 个，从车辆可达范围的简单图示到用于渐变效果的更精细层级均可。使用 `quality` 在精度和速度之间取舍，并使用 `ferry_connections` 包含渡轮，这会增加计算时间和多边形数量。请参阅[可视化车辆续航里程](/docs/getting-started/vehicle-range)。

可达性检查
: 针对特定车辆回答“我不充电能到那里吗？”，有助于缓解里程焦虑。使用 `state_of_charge` 从实际电池电量开始，使用 `final_state_of_charge` 保留预留电量，或使用 `round_trip` 仅包含车辆也能行驶回起点的点。

可达充电站
: 将充电站筛选为车辆从当前位置实际可到达的充电站。与 `final_state_of_charge` 结合使用，这样只有当车辆到达时仍有剩余电量，充电站才会被计入。

真实条件
: 考虑会改变能耗的因素：天气或季节、车辆所载重量，以及空调的制热和制冷。如果未提供电池电量，等值线将使用车辆的全部可用电池容量，天气默认使用实时数据。
