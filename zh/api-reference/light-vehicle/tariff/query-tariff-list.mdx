使用 tariffList 查询获取完整的费率列表。当您想显示或比较各充电站的充电费用时，此操作非常有用。要了解如何展示价格，请参阅[充电站定价指南](/docs/getting-started/station-pricing)。

## 查询

执行此查询无需任何输入。使用 `size` 和 `page` 参数对结果进行[分页](/api-reference/light-vehicle/api/pagination)。
