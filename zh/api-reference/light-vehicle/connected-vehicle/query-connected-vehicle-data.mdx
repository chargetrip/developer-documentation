使用 connectedVehicleData 查询获取实时车辆数据。当您想直接从联网车辆获取实时数据（例如其电量状态或位置）时，此操作非常有用。

## 查询

获取联网车辆的实时数据需要联网车辆的 `id`。`id` 可通过 [createConnectedVehicle 变更](/api-reference/light-vehicle/connected-vehicle/mutation-create-connected-vehicle)获取。
