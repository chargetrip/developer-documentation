使用 connectedVehicle 订阅来订阅联网车辆。当您想实时接收其授权状态的更新时，此操作非常有用。

## 订阅

订阅联网车辆的更新需要联网车辆的 `id`。`id` 可通过 [createConnectedVehicle 变更](/api-reference/light-vehicle/connected-vehicle/mutation-create-connected-vehicle)获取。
