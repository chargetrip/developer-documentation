为 EV 规划路线会面临独特的挑战。电池容量、实际能耗、地形、天气和充电网络可用性等因素，共同决定车辆能否到达目的地。

路线规划服务会综合考虑所有这些变量，以找到最优的 EV 路线。借助世界一流的能耗模型，它会在需要的时间和地点自动精准地设置充电停靠点。路线也可以完全自定义，因此您可以根据对您重要的业务规则、网络和驾驶员偏好进行调整。

> [!WARNING] 混合动力车辆
> 混合动力和插电式混合动力车辆并不完全依赖电池，因此其路线不包含充电停靠点。

## 针对您的目标优化路线

同一个请求可以根据优化目标的不同生成不同的路线。以下是最常见的目标，以及对每个目标进行深入介绍的指南。

最快到达
: 使用 `speed_factor`、`maximum_speed` 或将 `style` 设置为 `eco` 或 `sport` 来调整驾驶风格。添加实时交通和出发时间以获得准确的到达时间，并优先选择直接位于高速公路上的充电站以避免绕路。请参阅[创建路线](/docs/getting-started/route)。

您自己的网络或驾驶员的充电卡
: 引导驾驶员使用您希望他们使用的网络。优先选择或要求使用特定运营商，将其排名为 `high`、`medium` 或 `low`，按国家/地区限定排名，或完全排除、规避运营商。在控制台中为您的项目设置默认值，并可针对每个请求覆盖。请参阅[运营商偏好路线规划](/docs/getting-started/route-operators)。

在便利设施附近充电
: 查找沿途步行即可到达餐厅、咖啡店或商店的充电站，让驾驶员可以围绕自己想做的事情来规划充电停靠。请参阅[沿途便利设施停靠点](/docs/getting-started/route-amenity-stops)。

您自己的行程
: 添加途经点，既可以是送货或取货等普通的地点停靠，也可以是特定充电站的充电停靠。设置车辆在每个停靠点停留的时间，以及从该点起所载的负载。请参阅[带停靠点的路线](/docs/getting-started/route-stop)。
