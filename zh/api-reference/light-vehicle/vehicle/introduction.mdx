为 EV 规划路线与为燃油车规划路线不同。车辆能行驶多远、可以使用哪些充电桩以及充电速度有多快，都取决于车辆本身。车辆数据库为您提供这些信息，让您无需自行收集和维护。

每个路线和等值线请求都需要一个车辆 `id`，同样的数据还可以用来构建车辆选择器、展示规格参数，并将充电站筛选为驾驶员可以使用的充电站。

## EV 基础知识

电动汽车的一些属性可以说明车辆数据为何重要。

### 动力类型

ICE（内燃机）车辆燃烧燃料。EV 则使用电池中的电力行驶，并在充电站为电池充电。数据库涵盖四种动力类型：

| 动力类型 | 说明 |
|:---|:---|
| BEV | 纯电动汽车。仅依靠电池行驶。 |
| PHEV | 插电式混合动力汽车。结合了可外接充电的电池和内燃机。 |
| EREV | 增程式电动汽车。由电池驱动，内燃机用于延长续航里程。 |
| HEV | 混合动力汽车。结合了内燃机和无法外接充电的电池。 |

### 充电

EV 使用多种插头类型之一进行充电，因此只有当车辆支持充电桩的连接器时，该充电桩才有用。充电速度分为三个级别。1 级和 2 级使用 AC，需要数小时。3 级也称为快速充电，使用 DC，可在一小时内为车辆充满电。车辆实际的充电速度取决于其充电曲线，路线规划服务会将其考虑在内。

### 影响续航里程的因素

电池性能会随天气、空调等气候控制的使用以及车辆规格而变化，就像手机电池在寒冷环境中耗电更快一样。因此，仅凭单一的续航里程数字不足以规划行程。续航里程取决于各种条件，路线规划服务会考虑这些条件，以预测车辆在两点之间消耗多少能量。这一预测使应用程序能够沿途[推荐充电停靠点](/docs/getting-started/route)，并通过[等值线](/api-reference/light-vehicle/isoline/mutation-create-isoline)显示车辆可到达的区域。它还能缓解里程焦虑，即担心在到达目的地或充电桩之前电量耗尽。
