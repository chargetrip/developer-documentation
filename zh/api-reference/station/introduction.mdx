EV 路线规划取决于了解车辆可以在哪里充电，因此在规划任何路线之前，必须先在充电站数据库中填充充电站数据。默认情况下，充电站 schema 符合最新的 [OCPI](https://evroaming.org/ocpi/) 标准。可以添加自定义属性，但通常会将其移至额外的查询中，而不是放在充电站查询本身。

## 支持的数据源

Eco-Movement 数据
: 在没有商业协议的情况下，Chargetrip 可以为您的账户预加载来自 [Eco-Movement](https://eco-movement.com) 的高级充电站数据。该数据覆盖欧洲 100,000 多个充电站，并在可用时包含实时可用性、价格和预测可用性。这样您就无需连接多个充电站数据库提供商即可获得欧洲覆盖。有关地区限制，请参阅 [eco-movement.com](https://eco-movement.com)。价格请[联系销售团队](mailto:sales@chargetrip.com)。

自定义充电站数据
: 静态和动态充电站数据都可以导入 Chargetrip。这需要与数据提供商签订商业协议。请[联系销售团队](mailto:sales@chargetrip.com)讨论各种可能性。
