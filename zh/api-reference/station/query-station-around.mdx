使用 stationAround 查询，您可以获取某个 GeoJSON 点特定半径范围内的充电站。当某个充电站繁忙，或您想提供多个充电选择时，此操作非常有用。

## 查询

按点搜索周边充电站需要 `location`（GeoJSON 点）和以米为单位的 `distance`。使用 `filter` 和 `search` 参数缩小结果范围，并使用 `size` 和 `page` 参数对结果进行[分页](/api-reference/api/pagination)。
