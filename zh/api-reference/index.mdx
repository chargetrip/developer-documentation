GraphQL 是一种用于 API 的查询语言。它让您可以在一次调用中精确请求所需的数据，而无需处理许多固定的 REST 端点。

该 API 基于 GraphQL 构建。每种资源，例如车辆、充电站、路线和导航会话，都可以通过同一个 GraphQL API 访问。您可以将它们作为查询（query）、变更（mutation）或订阅（subscription）来访问。

如果您刚接触 GraphQL，可以从 [GraphQL 官方文档](https://graphql.org/learn/)开始。

## GraphQL 端点

查询、变更和订阅可通过以下端点访问。示例请参见[发送您的第一个请求](/docs/getting-started/api-request)。

对于查询和变更，请使用：

```bash Mutation and Query URL
https://api.chargetrip.io/graphql
```

对于订阅，请使用：

```bash Subscriptions URL
wss://api.chargetrip.io/subscription
```

### 身份验证

每个请求都通过 `x-client-id` 和 `x-app-id` 请求头进行身份验证。有关如何获取和发送它们，请参见[授权](/docs/getting-started/api-request#授权请求头)。

### 分页

列表查询使用 `size` 和 `page` 参数，或者对于基于游标的分页，使用 `first` 和 `after` 参数。详情请参见[分页](/api-reference/api/pagination)。

### 速率限制

请求受[速率限制](/api-reference/api/rate-limiting)约束。

### 生命周期

Chargetrip 使用单一的、持续演进的 GraphQL API，而不是带版本的发布。有关我们如何处理破坏性和非破坏性变更，请参见[生命周期](/api-reference/api/lifecycle)。
