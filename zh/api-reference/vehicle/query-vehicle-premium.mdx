通过 vehiclePremium 查询获取更详细的数据。它包含有关电池、车身、可用性、定价、能效、安全等方面的扩展数据。[联系销售团队](https://www.chargetrip.com/contact/sales)即可升级到高级车辆数据。

## 查询

获取高级车辆详情需要车辆的 `id`。`id` 可通过 [vehicleList 查询](/api-reference/vehicle/query-vehicles)获取。使用 country 参数对数据进行本地化。
