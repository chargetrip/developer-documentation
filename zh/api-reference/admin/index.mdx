---
title: Admin API 参考
description: "浏览 Admin API 的查询和 mutations，您可以使用它们为您的工作区管理增强组等资源。"
---

Admin API 是一个独立的 GraphQL API，拥有自己的 schema。您可以使用它来管理影响项目行为的资源，而无需向 Chargetrip 支持团队申请。目前它涵盖增强组，可让您在路线规划中优先考虑个别充电站。要了解增强组如何影响路线，请参阅[优先考虑个别充电站](/docs/getting-started/route-boosting-groups)。

> [!WARNING] Alpha
> Admin API 处于 alpha 阶段，免费套餐不提供。请联系支持团队获取访问权限，并预期 schema 会发生变化。
