使用 boostingGroups 查询列出您工作区的优先群组。当您想概览所有群组，或找出当前已启用的群组时，此操作非常有用。

## 查询

执行此查询无需任何输入。使用 `first` 和 `after` 参数对结果进行[分页](/api-reference/light-vehicle/api/pagination)，并使用 `filter` 参数按 `client_id` 或 `status` 缩小范围。

> 此操作处于 alpha 阶段，免费套餐不可用。请联系客户支持以获取访问权限。
