使用 matchedRoute 订阅来订阅匹配路线。当您想在匹配路线计算过程中实时接收更新时，此操作非常有用。

## 订阅

订阅匹配路线的更新需要匹配路线的 `id`。`id` 可通过 [createMatchedRoute 变更](/api-reference/matched-route/mutation-create-matched-route)获取。
