使用 updateBoostingGroup 变更更新优先群组。当您想在不删除群组的情况下启用或停用它时，此操作非常有用。

## 变更

需要优先群组的 `id`。`id` 可通过 [createBoostingGroup 变更](/api-reference/management/boosting-group/mutation-create-boosting-group)获取。只发送您想修改的字段。此变更不会修改群组中的充电站。

> [!WARNING] Alpha
> 此操作处于 alpha 阶段，免费套餐不可用。请联系客户支持以获取访问权限。

<details>
  <summary>停用优先群组。</summary>
  未启用的群组不再用于路线计算。

```graphql Example request
mutation UpdateBoostingGroup {
  updateBoostingGroup(
    input: { id: "6527e1f1a8b4c2d3e4f5a6b7", status: inactive }
  ) {
    id
    status
  }
}
```
</details>
