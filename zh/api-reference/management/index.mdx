---

Management API 是一个独立的 GraphQL API，拥有自己的 schema。您可以用它管理决定项目行为的资源，而无需向 Chargetrip 客户支持申请。目前它涵盖优先群组，让您在路线规划时优先选择特定的充电站。

请求会发送到与 API 参考其余部分不同的端点，您创建或读取的每个资源都属于由 `x-token` 请求头标识的工作区。

> [!WARNING] Alpha
> Management API 处于 alpha 阶段，免费套餐不可用。请联系客户支持以获取访问权限，并预期 schema 会发生变化。
