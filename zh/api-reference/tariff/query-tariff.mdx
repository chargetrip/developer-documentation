使用 tariff 查询获取费率详情。当您使用 Ecomovement 以外的充电站数据库，并想显示在某个充电站的充电费用时，此操作非常有用。要了解如何展示价格，请参阅[充电站定价指南](/docs/getting-started/station-pricing)。

## 查询

获取费率详情需要费率的 `id`。`id` 可通过 [tariffList 查询](/api-reference/tariff/query-tariff-list)获取。
