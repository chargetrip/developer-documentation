使用 createTruckRoute 变更创建新的货车路线。当您想为电动货车计算起点与终点之间的充电停靠点、能耗和行驶时间时，此操作非常有用。

## 变更

创建货车路线需要 `vehicle`、`origin` 和 `destination`。您还可以添加 `via` 点、`operators`、`weather` 或其他偏好设置来优化计算。该变更会返回货车路线的 `id`，可用于获取路线详情或订阅更新。
