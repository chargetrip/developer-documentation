Get the details of a previously calculated isoline by using the isoline query. This is useful when you want to display the reachable area for a vehicle.

## Query

An isoline `id` is required to get isoline details. The `id` can be obtained through the [createIsoline mutation](/api-reference/isoline/mutation-create-isoline).
