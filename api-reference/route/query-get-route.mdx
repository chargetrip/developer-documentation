---
title: Route details
schemaName: getRoute
schemaType: Query
---

Get the details of a previously calculated route by using the getRoute query. Best used for reloading saved journeys or displaying precomputed routes without opening a subscription.

## Query

A route `id` is required to get route details. The `id` can be obtained through the [createRoute mutation](/api-reference/route/mutation-create-route).
