Monitor route calculation in real time using route subscription. The subscription provides real-time updates on the route creation status and pushes the route details as soon as they are ready, eliminating the need for polling.

## Subscription

A route `id` is required to subscribe to its updates. The `id` can be obtained through the [createRoute mutation](/api-reference/route/mutation-create-route).
