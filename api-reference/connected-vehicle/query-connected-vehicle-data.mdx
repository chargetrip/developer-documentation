---
title: Connected vehicle data
schemaName: connectedVehicleData
schemaType: Query
---

Get live vehicle data by using the connectedVehicleData query. This is useful when you want to retrieve real-time data directly from a connected vehicle, such as its state of charge or location.

## Query

A connected vehicle `id` is required to get its live data. The `id` can be obtained through the [createConnectedVehicle mutation](/api-reference/connected-vehicle/mutation-create-connected-vehicle).
