Update an active navigation session by using the updateNavigation mutation. This is useful when you want to report a driver's location as they progress along a route.

## Mutation

A navigation session `id` and `location_data` are required to update it. The `id` can be obtained through the [startNavigation mutation](/api-reference/navigation/mutation-start-navigation).
