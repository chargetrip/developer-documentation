Recalculate the route of an active navigation session by using the recalculateNavigation mutation. This is useful when a driver deviates from the original route or conditions change along the way.

## Mutation

A navigation session `id` and `current_location` are required to recalculate its route. Optionally include `state_of_charge`, `via`, or `telemetry` to refine the new route. The `id` can be obtained through the [startNavigation mutation](/api-reference/navigation/mutation-start-navigation).
