---
title: Vehicle makes
schemaName: vehicleMakes
schemaType: Query
---

Get a list of all unique vehicle manufacturers (makes) supported by Chargetrip. This query is useful for building vehicle search filters like manufacturer dropdowns or brand selections.

## Query
No input is required to execute the vehicleMakes query. Use the `filter` argument to narrow the results down by region and/or type, and the `first` and `after` arguments to [paginate](/docs/pagination) through them. Use the `country` argument to apply localization to the data.
